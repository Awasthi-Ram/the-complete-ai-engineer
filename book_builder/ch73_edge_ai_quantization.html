1. The Physical Constraints of Edge Hardware

Deploying AI models to edge devices (Apple iPhones, Android smartphones, DJI drones, Raspberry Pi microcontrollers, and VR headsets) requires engineering under severe physical constraints:

  • Thermal Envelopes: Edge devices have passive cooling with zero fans. Sustained compute exceeding $3$ to $5 \text{ Watts}$ causes thermal throttling, rapidly draining batteries and degrading user experience.
  • Memory Bandwidth & Capacity: While cloud servers feature 80GB HBM3 memory running at 3.35 TB/s, smartphones share 4GB to 8GB of low-power LPDDR5 RAM ($50-100\text{ GB/s}$) across the operating system and camera pipeline.
  • Dedicated Neural Accelerators: Modern edge SoCs deploy specialized NPUs (Apple Neural Engine ANE, Qualcomm Hexagon NPU, Google Tensor TPU) that deliver peak TOPS only when computations are mapped strictly to 8-bit or 16-bit integer SIMD tensors.

2. MobileNet: Depthwise Separable Convolutions (Howard et al., Google 2017)

Standard 2D convolutions perform spatial filtering and channel combination simultaneously in a single heavy operation. MobileNet factors this into two decoupled steps:

  1. Depthwise Convolution: Applies a single $D_K \times D_K$ convolutional filter per input channel independently (computes spatial features with zero inter-channel communication).
  2. Pointwise Convolution: Applies a $1 \times 1$ convolution across all channels, linearly combining spatial features into $N$ output channels.

🏆 The Mathematical FLOPs Reduction Derivation

Let input feature map be $D_F \times D_F \times M$ and output be $D_F \times D_F \times N$ with filter size $D_K \times D_K$:

  • Standard Convolution FLOPs: $$\text{FLOPs}_{\text{std}} = D_K \cdot D_K \cdot M \cdot N \cdot D_F \cdot D_F$$
  • Depthwise Separable Convolution FLOPs: $$\text{FLOPs}_{\text{sep}} = \underbrace{D_K \cdot D_K \cdot M \cdot D_F \cdot D_F}_{\text{Depthwise Step}} + \underbrace{M \cdot N \cdot D_F \cdot D_F}_{\text{Pointwise Step}}$$

Compute the ratio of computation:

$$\text{Ratio} = \frac{D_K^2 \cdot M \cdot D_F^2 + M \cdot N \cdot D_F^2}{D_K^2 \cdot M \cdot N \cdot D_F^2} = \frac{D_K^2 \cdot M + M \cdot N}{D_K^2 \cdot M \cdot N} = \mathbf{\frac{1}{N} + \frac{1}{D_K^2}}$$

For standard $3 \times 3$ filters ($D_K = 3$) with $N = 512$ channels:

$$\text{Ratio} = \frac{1}{512} + \frac{1}{9} \approx 0.00195 + 0.11111 \approx \mathbf{0.113} \implies \mathbf{88.7\% \text{ Reduction in FLOPs!}}$$

Depthwise Separable Convolutions deliver an $8.8\times$ reduction in computational operations and parameter count with virtually zero loss in visual accuracy!

3. Uniform Affine Quantization & Integer GEMM

Converting a 32-bit floating point tensor $r \in [r_{\min}, r_{\max}]$ to an 8-bit unsigned integer $q \in [0, 255]$ maps continuous values to discrete grid steps:

$$q = \text{clamp}\left( \left\lfloor \frac{r}{S} \right\rceil + Z, \; 0, \; 255 \right)$$ $$S = \frac{r_{\max} - r_{\min}}{255}, \quad Z = \text{round}\left( -\frac{r_{\min}}{S} \right)$$

where $S > 0$ is the real Scale Factor and $Z \in \mathbb{Z}$ is the integer Zero-Point that maps real zero to an exact integer representation.

Integer Arithmetic in Matrix Multiplication (GEMM)

When computing $Y = X W$, the dequantized approximation is:

$$\hat{Y}_{i, k} = \sum_{j=1}^D S_X(q_{X, i, j} - Z_X) \cdot S_W(q_{W, j, k} - Z_W) = S_X S_W \sum_{j=1}^D (q_{X, i, j} - Z_X)(q_{W, j, k} - Z_W)$$

Expanding the product:

$$\hat{Y}_{i, k} = S_X S_W \left( \sum_{j=1}^D q_{X, i, j} q_{W, j, k} - Z_W \sum_{j=1}^D q_{X, i, j} - Z_X \sum_{j=1}^D q_{W, j, k} + D \cdot Z_X Z_W \right)$$

The Hardware Miracle: The core summation $\sum q_X q_W$ is computed using fast 8-bit integer dot products (ARM NEON SDOT, Intel VNNI VPDPBUSD, NVIDIA DP4A) with 32-bit accumulation. The weight sum $\sum q_W$ and offset $D \cdot Z_X Z_W$ are pre-computed offline once!

4. Quantization-Aware Training (QAT) & Straight-Through Estimators

Post-Training Quantization (PTQ) often degrades compact edge networks. Quantization-Aware Training (QAT) models quantization noise during backprop using Fake-Quantization:

$$\hat{r} = S \cdot \left( \text{clamp}\left( \left\lfloor \frac{r}{S} \right\rceil + Z, \; q_{\min}, \; q_{\max} \right) - Z \right)$$

Because the rounding function $\lfloor x \rceil$ has derivative zero almost everywhere, standard backpropagation fails. The Straight-Through Estimator (STE - Bengio et al., 2013) models the gradient as an identity pass-through within dynamic range bounds:

$$\frac{\partial \hat{r}}{\partial r} = \begin{cases} 1 & \text{if } r_{\min} \le r \le r_{\max} \\ 0 & \text{otherwise} \end{cases}$$

Problem 7.3.1 Medium Apple Google

QUESTION: A computer vision model on an Apple Neural Engine (ANE) processes an intermediate feature map of dimensions $H = 56$, $W = 56$, and $M = 128$ input channels. The layer produces $N = 256$ output channels using a $3 \times 3$ filter ($D_K = 3$) with stride 1 and padding 1 (preserving spatial dimensions $56 \times 56$).

Tasks:

  1. Calculate the parameter count and Multiply-Accumulate (MAC) operations for a standard 2D convolution layer.
  2. Calculate the parameter count and MAC operations for a Depthwise Separable Convolution layer (Depthwise $3 \times 3$ + Pointwise $1 \times 1$).
  3. Compute the exact percentage reduction in parameter count and computational operations.
  4. Calculate the memory bandwidth traffic required to read model weights from LPDDR5 RAM during a single forward inference pass in FP16 (2 bytes/param) for standard vs separable convolution.
✓ Step-by-Step MobileNet Arithmetic Solution

Step 1: Standard Convolution Calculations:
Weights parameter count: $$P_{\text{std}} = D_K \times D_K \times M \times N = 3 \times 3 \times 128 \times 256 = \mathbf{294,912\text{ parameters}}$$ Multiply-Accumulate (MAC) operations ($H \times W$ spatial output locations): $$\text{MACs}_{\text{std}} = H \times W \times P_{\text{std}} = 56 \times 56 \times 294,912 = 3,136 \times 294,912 = \mathbf{924,844,032\text{ MACs} \approx 924.84\text{ MMACs}}$$

Step 2: Depthwise Separable Convolution Calculations:
(a) Depthwise Convolution ($3 \times 3$ spatial filter per channel):
Parameters: $$P_{\text{dw}} = D_K \times D_K \times M = 3 \times 3 \times 128 = 1,152\text{ parameters}$$ MACs: $$\text{MACs}_{\text{dw}} = H \times W \times P_{\text{dw}} = 3,136 \times 1,152 = 3,612,672\text{ MACs} \approx 3.61\text{ MMACs}$$
(b) Pointwise Convolution ($1 \times 1$ channel projection):
Parameters: $$P_{\text{pw}} = 1 \times 1 \times M \times N = 128 \times 256 = 32,768\text{ parameters}$$ MACs: $$\text{MACs}_{\text{pw}} = H \times W \times P_{\text{pw}} = 3,136 \times 32,768 = 102,760,448\text{ MACs} \approx 102.76\text{ MMACs}$$
Total Depthwise Separable Metrics: $$P_{\text{sep}} = P_{\text{dw}} + P_{\text{pw}} = 1,152 + 32,768 = \mathbf{33,920\text{ parameters}}$$ $$\text{MACs}_{\text{sep}} = \text{MACs}_{\text{dw}} + \text{MACs}_{\text{pw}} = 3,612,672 + 102,760,448 = \mathbf{106,373,120\text{ MACs} \approx 106.37\text{ MMACs}}$$

Step 3: Percentage Reductions:
Theoretical ratio from formula $\frac{1}{N} + \frac{1}{D_K^2}$: $$\text{Ratio} = \frac{1}{256} + \frac{1}{9} \approx 0.003906 + 0.111111 = 0.115017 \quad (11.50\%)$$ Direct parameter reduction: $$\text{Param Reduction} = \left(1 - \frac{33,920}{294,912}\right) \times 100\% = (1 - 0.115017) \times 100\% = \mathbf{88.50\% \text{ Reduction}}$$ Direct compute reduction: $$\text{Compute Reduction} = \left(1 - \frac{106,373,120}{924,844,032}\right) \times 100\% = \mathbf{88.50\% \text{ Reduction}}$$

Step 4: LPDDR5 Memory Traffic:
In FP16 precision ($2\text{ bytes per parameter}$):

  • Standard Conv: $294,912 \times 2\text{ bytes} = 589,824\text{ bytes} = \mathbf{589.82\text{ KB}}$
  • Separable Conv: $33,920 \times 2\text{ bytes} = 67,840\text{ bytes} = \mathbf{67.84\text{ KB}}$
$$\text{Bandwidth Traffic Saved} = 589.82\text{ KB} - 67.84\text{ KB} = 521.98\text{ KB per forward pass (88.5\% saved!)}$$

Problem 7.3.2 Medium Qualcomm ARM

QUESTION: An activation tensor in an edge Vision Transformer exhibits dynamic range $r \in [-2.40, +6.20]$. You are calibrating an 8-bit unsigned uniform affine quantizer ($q \in [0, 255]$).

Tasks:

  1. Calculate the exact scale factor $S$ to 8 decimal places and the integer zero-point $Z$.
  2. Quantize the following real floating-point values into 8-bit integers: $$r_1 = -2.40, \quad r_2 = 0.00, \quad r_3 = +4.15$$
  3. Dequantize the resulting integer values back to real floating-point representations $\hat{r}_1, \hat{r}_2, \hat{r}_3$, and calculate the absolute quantization error $|r_i - \hat{r}_i|$ for each.
  4. Explain why preserving an exact integer representation for real zero ($r = 0.0$) is mathematically mandatory in deep learning inference.
✓ Step-by-Step Affine Quantization Arithmetic

Step 1: Scale Factor and Zero-Point Calculation:
The scale factor maps the continuous span to 255 discrete bins: $$S = \frac{r_{\max} - r_{\min}}{q_{\max} - q_{\min}} = \frac{6.20 - (-2.40)}{255 - 0} = \frac{8.60}{255} \approx \mathbf{0.03372549}$$ The integer zero-point maps real $0.0$ to the discrete grid: $$Z = \text{round}\left( -\frac{r_{\min}}{S} \right) = \text{round}\left( -\frac{-2.40}{0.03372549} \right) = \text{round}(71.1628) = \mathbf{71}$$

Step 2: Quantization of Values:
Quantization formula: $q = \text{clamp}\left( \text{round}(r / S) + Z, \; 0, \; 255 \right)$.

For $r_1 = -2.40$: $$q_1 = \text{round}\left( \frac{-2.40}{0.03372549} \right) + 71 = \text{round}(-71.1628) + 71 = -71 + 71 = \mathbf{0}$$ For $r_2 = 0.00$: $$q_2 = \text{round}\left( \frac{0.00}{0.03372549} \right) + 71 = 0 + 71 = \mathbf{71}$$ For $r_3 = +4.15$: $$q_3 = \text{round}\left( \frac{4.15}{0.03372549} \right) + 71 = \text{round}(123.052) + 71 = 123 + 71 = \mathbf{194}$$

Step 3: Dequantization and Quantization Error:
Dequantization formula: $\hat{r} = S \cdot (q - Z)$.

For $q_1 = 0$: $$\hat{r}_1 = 0.03372549 \times (0 - 71) = 0.03372549 \times (-71) \approx \mathbf{-2.39451}$$ $$\text{Error}_1 = |-2.40 - (-2.39451)| = \mathbf{0.00549}$$ For $q_2 = 71$: $$\hat{r}_2 = 0.03372549 \times (71 - 71) = 0.03372549 \times 0 = \mathbf{0.00000}$$ $$\text{Error}_2 = |0.00 - 0.00000| = \mathbf{0.00000\text{ (Zero Error!)}}$$ For $q_3 = 194$: $$\hat{r}_3 = 0.03372549 \times (194 - 71) = 0.03372549 \times 123 \approx \mathbf{4.14824}$$ $$\text{Error}_3 = |4.15 - 4.14824| = \mathbf{0.00176}$$

Step 4: Architectural Importance of Exact Zero Representation:
In neural networks, zero values occur with high frequency due to:

  • ReLU activations: $\text{ReLU}(x) = \max(0, x)$ produces exact zeroes for 50%+ of neurons.
  • Zero-padding in convolutions: Boundaries of images are padded with exact zeroes.
If real $0.0$ did not map to an exact integer ($Z \notin \mathbb{Z}$), padding borders would map to non-zero values (e.g. $0.004$), corrupting spatial boundary convolutions, increasing energy consumption, and creating systemic activation drift!

Problem 7.3.5 Expert Google Univ. of Toronto

QUESTION: In Hinton's Knowledge Distillation (Hinton et al., 2015), a compact student model with logits $\mathbf{z}_S \in \mathbb{R}^C$ is trained to match the softened probability distribution of a large teacher model with logits $\mathbf{z}_T \in \mathbb{R}^C$.

The soft distillation cross-entropy loss with distillation temperature $T > 0$ is:

$$\mathcal{L}_{\text{KD}} = -\sum_{i=1}^C q_i(T) \ln p_i(T)$$

where $q_i(T) = \frac{\exp(z_{T, i} / T)}{\sum_k \exp(z_{T, k} / T)}$ and $p_i(T) = \frac{\exp(z_{S, i} / T)}{\sum_k \exp(z_{S, k} / T)}$.

Tasks:

  1. Derive the gradient of $\mathcal{L}_{\text{KD}}$ with respect to student logit $z_{S, i}$.
  2. Using the Taylor expansion of the exponential function $\exp(x) \approx 1 + x$ for large $T$ (where $z_i / T \to 0$), prove that in the high-temperature limit ($T \to \infty$): $$\frac{\partial \mathcal{L}_{\text{KD}}}{\partial z_{S, i}} \approx \frac{1}{C T^2} \left( (z_{S, i} - \bar{z}_S) - (z_{T, i} - \bar{z}_T) \right)$$ where $\bar{z}_S = \frac{1}{C}\sum_k z_{S, k}$ and $\bar{z}_T = \frac{1}{C}\sum_k z_{T, k}$.
  3. Prove that minimizing distillation loss at high temperature is mathematically equivalent to minimizing Mean Squared Error (MSE) between zero-meaned teacher and student logits, and explain why multiplying $\mathcal{L}_{\text{KD}}$ by $T^2$ is mathematically essential.
✓ Mathematical Proof of High-Temperature KD Equivalence to Logit MSE

Step 1: Gradient with Respect to Student Logits:
Recall that for softmax probabilities with temperature $T$, the derivative $\frac{\partial p_j(T)}{\partial z_{S, i}}$ is: $$\frac{\partial p_j(T)}{\partial z_{S, i}} = \frac{1}{T} p_i(T)(\delta_{i, j} - p_j(T))$$ Differentiating $\mathcal{L}_{\text{KD}}$: $$\frac{\partial \mathcal{L}_{\text{KD}}}{\partial z_{S, i}} = -\sum_{j=1}^C \frac{q_j(T)}{p_j(T)} \frac{\partial p_j(T)}{\partial z_{S, i}} = -\sum_{j=1}^C \frac{q_j(T)}{p_j(T)} \left[ \frac{1}{T} p_i(T)(\delta_{i, j} - p_j(T)) \right]$$ $$= -\frac{1}{T} \left( q_i(T) - p_i(T) \sum_{j=1}^C q_j(T) \right)$$ Since $\sum_{j=1}^C q_j(T) = 1$: $$\frac{\partial \mathcal{L}_{\text{KD}}}{\partial z_{S, i}} = \mathbf{\frac{1}{T} \big( p_i(T) - q_i(T) \big)}$$

Step 2: Taylor Expansion in High-Temperature Limit ($T \to \infty$):
When $T \gg |z_k|$, the exponent $z_k / T$ is close to zero. We apply the first-order Taylor expansion $e^x \approx 1 + x$: $$\exp\left(\frac{z_{S, i}}{T}\right) \approx 1 + \frac{z_{S, i}}{T}$$ Summing across all $C$ classes: $$\sum_{k=1}^C \exp\left(\frac{z_{S, k}}{T}\right) \approx \sum_{k=1}^C \left(1 + \frac{z_{S, k}}{T}\right) = C + \frac{1}{T}\sum_{k=1}^C z_{S, k} = C \left( 1 + \frac{\bar{z}_S}{T} \right)$$ where $\bar{z}_S = \frac{1}{C}\sum z_{S, k}$.
Now expand the student softmax probability: $$p_i(T) = \frac{1 + \frac{z_{S, i}}{T}}{C\left(1 + \frac{\bar{z}_S}{T}\right)} \approx \frac{1}{C} \left(1 + \frac{z_{S, i}}{T}\right)\left(1 - \frac{\bar{z}_S}{T}\right) \approx \frac{1}{C}\left(1 + \frac{z_{S, i} - \bar{z}_S}{T}\right)$$ Applying the exact same Taylor expansion to the teacher probabilities: $$q_i(T) \approx \frac{1}{C}\left(1 + \frac{z_{T, i} - \bar{z}_T}{T}\right)$$ Subtracting the two probabilities: $$p_i(T) - q_i(T) \approx \frac{1}{C} \left(1 + \frac{z_{S, i} - \bar{z}_S}{T} - 1 - \frac{z_{T, i} - \bar{z}_T}{T}\right) = \frac{1}{C T} \left( (z_{S, i} - \bar{z}_S) - (z_{T, i} - \bar{z}_T) \right)$$ Substituting back into the gradient from Step 1: $$\frac{\partial \mathcal{L}_{\text{KD}}}{\partial z_{S, i}} = \frac{1}{T} \big( p_i(T) - q_i(T) \big) \approx \mathbf{\frac{1}{C T^2} \Big( (z_{S, i} - \bar{z}_S) - (z_{T, i} - \bar{z}_T) \Big)} \quad \text{Q.E.D.}$$

Step 3: Equivalence to Logit MSE & Necessity of $T^2$:
Consider the Mean Squared Error loss between zero-meaned logits: $$\mathcal{L}_{\text{MSE}} = \frac{1}{2 C} \sum_{i=1}^C \left( (z_{S, i} - \bar{z}_S) - (z_{T, i} - \bar{z}_T) \right)^2$$ The gradient is: $$\frac{\partial \mathcal{L}_{\text{MSE}}}{\partial z_{S, i}} = \frac{1}{C} \left( (z_{S, i} - \bar{z}_S) - (z_{T, i} - \bar{z}_T) \right)$$ Comparing with our derivation in Step 2: $$\frac{\partial \mathcal{L}_{\text{KD}}}{\partial z_{S, i}} \approx \frac{1}{T^2} \frac{\partial \mathcal{L}_{\text{MSE}}}{\partial z_{S, i}}$$ Why the $T^2$ multiplier is essential:
Notice that the gradient of $\mathcal{L}_{\text{KD}}$ scales as $1/T^2$! If $T = 5$, the gradient magnitude is suppressed by $25\times$. If $T = 10$, gradients are suppressed by $100\times$!
To prevent the distillation loss from being drowned out by the hard ground-truth label cross-entropy loss $\mathcal{L}_{\text{CE}}$, Hinton multiplies $\mathcal{L}_{\text{KD}}$ by $T^2$: $$\mathcal{L}_{\text{total}} = (1 - \alpha)\mathcal{L}_{\text{CE}} + \alpha \mathbf{T^2} \mathcal{L}_{\text{KD}}$$ This cancels the $1/T^2$ suppression, ensuring stable, balanced gradient updates regardless of temperature!

Problem 7.3.6 Expert NVIDIA Stanford

QUESTION: NVIDIA Ampere, Ada Lovelace, and Hopper architectures feature hardware acceleration for 2:4 Structured Sparsity: in every contiguous block of 4 weight values, at least 2 must be zero.

Let $\mathbf{w} = [w_1, w_2, w_3, w_4] \in \mathbb{R}^4$ be an arbitrary block of 4 weights. We seek the sparse projection $\hat{\mathbf{w}} \in \mathbb{R}^4$ that minimizes the Euclidean approximation error:

$$\min_{\hat{\mathbf{w}}} \|\mathbf{w} - \hat{\mathbf{w}}\|_2^2 \quad \text{subject to } \|\hat{\mathbf{w}}\|_0 \le 2$$

Tasks:

  1. Prove that the optimal projection $\hat{\mathbf{w}}^*$ is obtained by sorting the absolute values $|w_{(1)}| \le |w_{(2)}| \le |w_{(3)}| \le |w_{(4)}|$ and zeroing out the two smallest magnitudes: $$\hat{w}_i^* = \begin{cases} w_i & \text{if } |w_i| \in \{|w_{(3)}|, |w_{(4)}|\} \\ 0 & \text{otherwise} \end{cases}$$
  2. For weight block $\mathbf{w} = [0.45, \; -0.82, \; 0.12, \; -0.95]$, compute the optimal sparse vector $\hat{\mathbf{w}}^*$ and calculate the exact squared approximation error $\|\mathbf{w} - \hat{\mathbf{w}}^*\|_2^2$.

✓ Mathematical Derivation of Optimal 2:4 Structured Sparsity

Step 1: Proof of Optimal Projection via Component Analysis:
Let $\hat{\mathbf{w}}$ have at most 2 non-zero elements. Let index set $\mathcal{I} \subset \{1, 2, 3, 4\}$ with $|\mathcal{I}| = 2$ denote the indices of the zeroed elements ($\hat{w}_j = 0$ for $j \in \mathcal{I}$).
For elements not zeroed ($k \notin \mathcal{I}$), setting $\hat{w}_k = w_k$ trivially minimizes $(w_k - \hat{w}_k)^2 = 0$.
Therefore, the squared error is: $$\|\mathbf{w} - \hat{\mathbf{w}}\|_2^2 = \sum_{j \in \mathcal{I}} (w_j - 0)^2 + \sum_{k \notin \mathcal{I}} (w_k - w_k)^2 = \sum_{j \in \mathcal{I}} w_j^2 = \sum_{j \in \mathcal{I}} |w_j|^2$$ To minimize the squared error, we must choose the 2-element index set $\mathcal{I}$ that minimizes $\sum_{j \in \mathcal{I}} |w_j|^2$.
Because the objective is a separable sum of non-negative terms $|w_j|^2$, the global minimum is uniquely achieved by selecting the indices corresponding to the two smallest magnitudes in $\mathbf{w}$: $$\mathcal{I}^* = \arg\min_{|\mathcal{I}|=2} \sum_{j \in \mathcal{I}} |w_j|^2 = \big\{ \text{indices of } |w_{(1)}| \text{ and } |w_{(2)}| \big\} \quad \text{Q.E.D.}$$

Step 2: Numerical Projection Computation:
Given $\mathbf{w} = [0.45, \; -0.82, \; 0.12, \; -0.95]$:
Compute absolute magnitudes: $$|w_1| = 0.45, \quad |w_2| = 0.82, \quad |w_3| = 0.12, \quad |w_4| = 0.95$$ Sorting magnitudes in ascending order: $$|w_{(1)}| = 0.12\ (w_3), \quad |w_{(2)}| = 0.45\ (w_1), \quad |w_{(3)}| = 0.82\ (w_2), \quad |w_{(4)}| = 0.95\ (w_4)$$ Zero out the two smallest elements ($w_1$ and $w_3$): $$\hat{\mathbf{w}}^* = [\mathbf{0.0}, \; \mathbf{-0.82}, \; \mathbf{0.0}, \; \mathbf{-0.95}]$$ Squared approximation error: $$\|\mathbf{w} - \hat{\mathbf{w}}^*\|_2^2 = |w_1|^2 + |w_3|^2 = (0.45)^2 + (0.12)^2 = 0.2025 + 0.0144 = \mathbf{0.2169}$$

Step 3: Hardware Acceleration Mechanism:
In general unstructured sparsity, skipping zero multiplications requires pointer-based sparse formats (CSR / CSC) with high memory indirection overhead that destroys GPU SIMD parallelism.
NVIDIA 2:4 Sparse Tensor Cores:

  1. The model weights are compressed by $50\%$ in VRAM: each 4-element block stores only the 2 non-zero FP16 values ($2 \times 2\text{ bytes} = 4\text{ bytes}$) plus a 4-bit metadata index (2 bits per non-zero value, specifying original indices $0, 1, 2,$ or $3$).
  2. At execution time, the Sparse Matrix Multiply unit uses the 4-bit index to multiplex and fetch the exact 2 matching activations from the dense input vector.
  3. A modified MAC tree evaluates the two multiplications in parallel on half-sized hardware, doubling math throughput ($2\times$ TFLOPS) while cutting memory bandwidth traffic in half!

Problem 7.3.7 Hard Qualcomm Apple

QUESTION: An engineer quantizes a convolutional neural network from FP32 to INT8 using symmetric quantization. For a depthwise convolution layer with 128 channels, the engineer evaluates two calibration strategies:

  • Strategy 1 (Per-Tensor Quantization): A single global scale factor $S = \frac{\max_{c, i, j} |w_{c, i, j}|}{127}$ is shared across all 128 channels.
  • Strategy 2 (Per-Channel Quantization): Each of the 128 channels receives its own private scale factor $S_c = \frac{\max_{i, j} |w_{c, i, j}|}{127}$.

In this layer, Channel 4 has extreme outlier weights reaching $\pm 8.5$, while all other 127 channels have weights strictly bounded within $\pm 0.3$. Which of the following correctly characterizes the outcome of Strategy 1 versus Strategy 2?

  1. Strategy 1 achieves identical accuracy to Strategy 2 because batch normalization re-scales all channels prior to quantization.
  2. In Strategy 1, the single outlier channel forces the global scale factor to $S = 8.5 / 127 \approx 0.067$. For the other 127 channels where weights are bounded by $\pm 0.3$, all weights are quantized to $\lfloor 0.3 / 0.067 \rceil \le 4$ discrete bins out of 255, destroying precision and zeroing out subtle features. Strategy 2 isolates Channel 4's scale ($S_4 = 0.067$) while preserving fine-grained scales ($S_c \approx 0.0024$) across the other 127 channels, maintaining full dynamic resolution.
  3. Strategy 2 is physically impossible on ARM and mobile NPUs because SIMD registers cannot execute multiple scale factors simultaneously.
  4. Strategy 1 causes integer overflow in the ALU accumulator because $8.5 \times 127 > 255$.
✓ Correct Answer: B (Exhaustive Distractor Analysis)

Distractor Analysis:

  • Option A is False: While batch normalization is folded into weights during compilation, folded weights still exhibit significant inter-channel variance.
  • Option B is Correct:
    • In Per-Tensor Quantization, the global grid step is dictated by the maximum absolute element across the entire tensor: $$S = \frac{8.5}{127} \approx 0.0669$$
    • For the other 127 channels with weights in $[-0.3, +0.3]$: $$\text{Max quantized integer} = \text{round}\left( \frac{0.3}{0.0669} \right) = \mathbf{4}$$
    • Instead of using the full 255 integer range $[-127, +127]$, 99% of the layer's weights are squashed into only 9 discrete values $\{-4, -3, -2, -1, 0, 1, 2, 3, 4\}$. This massive loss of precision completely destroys visual feature filters!
    • Per-Channel Quantization assigns 128 independent scale factors: Channel 4 uses $S_4 = 0.0669$, while normal channels use $S_c = 0.3 / 127 \approx 0.00236$, using all 255 integer levels across all channels.
  • Option C is False: Per-channel *weight* quantization is natively supported by virtually all modern hardware (TFLite, ONNX Runtime, TensorRT, CoreML, Qualcomm QNN). Because each output channel corresponds to a separate row of the GEMM, the per-channel scale factor is simply multiplied into the final scalar accumulator after the integer dot product completes!
  • Option D is False: Integer accumulation occurs in 32-bit registers, which can hold values up to $\pm 2.14 \times 10^9$.
Problem 7.3.8 Hard Apple Google

ASSERTION-REASONING:

Assertion (A): When deploying MobileNetV2 to edge microcontrollers, applying naive Post-Training Quantization (PTQ) causes severe, non-recoverable accuracy collapse on the narrow Linear Bottleneck Layers unless Quantization-Aware Training (QAT) with learnable clipping bounds (PACT) is utilized.

Reason (R): MobileNetV2's linear bottlenecks deliberately omit non-linear ReLU activations to prevent manifold information destruction in low-dimensional space ($D = 16$ or $24$); consequently, bottleneck activations exhibit unbounded, heavy-tailed distributions with high dynamic range, making standard min-max PTQ calibration squash the majority of feature signals into a handful of quantization bins.

Options:

  1. Both (A) and (R) are true, and (R) is the correct explanation of (A).
  2. Both (A) and (R) are true, but (R) is NOT the correct explanation of (A).
  3. (A) is true, but (R) is false.
  4. (A) is false, but (R) is true.
✓ Correct Answer: A (Comprehensive Linear Bottleneck Analysis)

Deep Architectural Analysis:

Evaluation of Assertion (A): True.
MobileNetV2 is notoriously difficult to quantize using standard PTQ. On ImageNet, naive INT8 PTQ drops top-1 accuracy from 72.0% down to under 50% (or even single digits). In contrast, QAT recovers full 71.8% accuracy.

Evaluation of Reason (R): True & Explanatory.
In MobileNetV2 (Sandler et al., Google 2018):

  • The inverted residual block expands channels by $6\times$ ($16 \to 96$), applies Depthwise Conv with ReLU6, and then projects back down to a narrow bottleneck ($96 \to 16$) using a linear projection layer with NO non-linearity.
  • The authors proved that applying non-linearities (like ReLU) in low-dimensional manifolds destroys information by zeroing out negative coordinates.
  • However, because there is no ReLU or ReLU6 capping the bottleneck activations, the distribution is unbounded and contains extreme positive and negative outliers.
  • Standard PTQ calibrators (like Min-Max or Percentile) observe these rare outliers and set a wide dynamic range $[r_{\min}, r_{\max}]$. This makes the scale factor $S = (r_{\max} - r_{\min}) / 255$ very large, squashing the dense cluster of core activations near zero into only 2 or 3 quantization levels!
  • QAT with PACT (Parameterized Activation Clipping): Adds a learnable clipping parameter $\alpha$ trained via backpropagation. PACT finds the mathematically optimal trade-off between clipping outliers and preserving resolution in the central distribution, allowing MobileNetV2 to run in INT8 with zero accuracy degradation!

Code Lab 7.3 — Quantization-Aware Training with Custom STE Autograd Function

🔗 View in GitHub: part7_system_design/ch73_edge_ai/qat_ste.py

import torch
import torch.nn as nn

class StraightThroughEstimator(torch.autograd.Function):
    @staticmethod
    def forward(ctx, r: torch.Tensor, scale: torch.Tensor, zero_point: torch.Tensor, qmin: int = 0, qmax: int = 255):
        ctx.save_for_backward(r, scale, zero_point)
        ctx.qmin = qmin
        ctx.qmax = qmax

        # 1. Quantize: q = clamp(round(r / S) + Z)
        q = torch.clamp(torch.round(r / scale) + zero_point, qmin, qmax)
        # 2. Dequantize: r_hat = S * (q - Z)
        r_hat = scale * (q - zero_point)
        return r_hat

    @staticmethod
    def backward(ctx, grad_output: torch.Tensor):
        r, scale, zero_point = ctx.saved_tensors
        qmin, qmax = ctx.qmin, ctx.qmax

        # Straight-Through Estimator: Pass gradient strictly inside [r_min, r_max]
        r_min = scale * (qmin - zero_point)
        r_max = scale * (qmax - zero_point)
        mask = (r >= r_min) & (r <= r_max)

        grad_r = grad_output * mask.float()
        return grad_r, None, None, None, None

class FakeQuantizeAffine(nn.Module):
    def __init__(self, num_bits: int = 8):
        super().__init__()
        self.qmin = 0
        self.qmax = 2**num_bits - 1

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        if self.training:
            # Dynamically compute scale and zero-point
            r_min = x.detach().min()
            r_max = x.detach().max()
            scale = (r_max - r_min) / (self.qmax - self.qmin)
            scale = torch.clamp(scale, min=1e-8)
            zero_point = torch.round(-r_min / scale)
            zero_point = torch.clamp(zero_point, self.qmin, self.qmax)
            return StraightThroughEstimator.apply(x, scale, zero_point, self.qmin, self.qmax)
        else:
            return x

if __name__ == "__main__":
    torch.manual_seed(42)
    fake_quant = FakeQuantizeAffine(num_bits=8)
    
    # Input tensor with gradient tracking
    x = torch.tensor([-2.5, -0.8, 0.0, 1.5, 4.2], requires_grad=True)
    out = fake_quant(x)
    loss = out.sum()
    loss.backward()

    print(f"Original Tensor      : {x.data}")
    print(f"Fake-Quantized Output: {out.data}")
    print(f"STE Gradients Passed : {x.grad}")
