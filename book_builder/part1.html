1. Geometric Foundations: Space, Bases & Projections

To an AI engineer, a vector is not merely an array of numbers; it is a point or arrow in an abstract high-dimensional vector space $\mathbb{R}^d$. When OpenAI's text-embedding-3-large represents a sentence as a 3,072-dimensional vector, that vector represents a single coordinate inside a 3,072-dimensional semantic hypersphere. Concepts that are semantically related point in nearly identical spatial directions.

Linear Combinations, Span & Linear Independence

Given a set of vectors $\{\mathbf{v}_1, \mathbf{v}_2, \dots, \mathbf{v}_k\} \subset \mathbb{R}^d$, a linear combination is any vector formed by scaling and adding them: $$\mathbf{x} = c_1 \mathbf{v}_1 + c_2 \mathbf{v}_2 + \dots + c_k \mathbf{v}_k = \sum_{i=1}^k c_i \mathbf{v}_i, \quad c_i \in \mathbb{R}$$ The Span of these vectors is the set of all possible linear combinations. If no vector in the set can be expressed as a linear combination of the others, the set is linearly independent: $$c_1 \mathbf{v}_1 + c_2 \mathbf{v}_2 + \dots + c_k \mathbf{v}_k = \mathbf{0} \iff c_1 = c_2 = \dots = c_k = 0$$ A linearly independent set of vectors that spans a space $V$ forms a Basis for $V$. The number of vectors in this basis defines the Dimension of $V$.

The Dot Product, Norms & Cosine Similarity

The inner product (dot product) between two vectors $\mathbf{u}, \mathbf{v} \in \mathbb{R}^d$ is the algebraic engine of modern search, recommendation, and transformer attention: $$\mathbf{u} \cdot \mathbf{v} = \mathbf{u}^T \mathbf{v} = \sum_{i=1}^d u_i v_i$$ Geometrically, the dot product connects algebra to trigonometry: $$\mathbf{u} \cdot \mathbf{v} = \|\mathbf{u}\|_2 \|\mathbf{v}\|_2 \cos(\theta)$$ Where $\|\mathbf{u}\|_2 = \sqrt{\sum_{i=1}^d u_i^2}$ is the Euclidean $L_2$ norm. Dividing both sides yields Cosine Similarity, which measures the angular orientation of two vectors irrespective of their magnitude: $$\text{CosineSimilarity}(\mathbf{u}, \mathbf{v}) = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|_2 \|\mathbf{v}\|_2} = \cos(\theta) \in [-1, 1]$$

Why Transformers Normalize Vectors: When query and key vectors are $L_2$-normalized to unit length ($\|\mathbf{q}\|_2 = \|\mathbf{k}\|_2 = 1$), their dot product simplifies to pure cosine similarity: $\mathbf{q} \cdot \mathbf{k} = \cos(\theta)$. This bounds the input to the softmax attention function, preventing exponential saturation and vanishing gradients!

2. Matrix Multiplication: Four Perspectives

A matrix $A \in \mathbb{R}^{m \times n}$ is not a static 2D grid; it is a Linear Transformation mapping vectors from $\mathbb{R}^n$ into $\mathbb{R}^{m}$. To master deep learning, you must understand all four mathematical perspectives of matrix multiplication $C = A B$ (where $A \in \mathbb{R}^{m \times k}$ and $B \in \mathbb{R}^{k \times n}$):

  1. The Element Perspective (Dot Products): Each element $C_{ij}$ is the dot product of row $i$ of $A$ and column $j$ of $B$: $$C_{ij} = \sum_{p=1}^k A_{ip} B_{pj}$$
  2. The Column Perspective (Linear Combinations): Each column of $C$ is a linear combination of the columns of $A$, weighted by the corresponding column of $B$: $$\mathbf{c}_j = \sum_{p=1}^k B_{pj} \mathbf{a}_p$$ Deep Learning Insight: A neural network forward pass $W \mathbf{x}$ takes a linear combination of the column features in weight matrix $W$!
  3. The Row Perspective: Each row of $C$ is a linear combination of the rows of $B$, weighted by the corresponding row of $A$.
  4. The Outer Product Perspective (Rank-1 Summation): $C$ is the sum of $k$ rank-1 outer product matrices: $$C = \sum_{p=1}^k \mathbf{a}_p \mathbf{b}_p^T, \quad \text{where } \mathbf{a}_p \in \mathbb{R}^{m \times 1}, \mathbf{b}_p^T \in \mathbb{R}^{1 \times n}$$ Hardware Insight: Modern GPU Tensor Cores perform fused multiply-accumulate (FMA) across outer products to maximize arithmetic throughput.

3. Singular Value Decomposition (SVD) & The Eckart-Young Theorem

Eigenvalue decomposition ($A = Q \Lambda Q^{-1}$) is limited because it requires $A$ to be a square, diagonalizable matrix. In real-world AI, data matrices are almost always rectangular: $N$ samples by $d$ features ($N \neq d$).

Figure 1.1.1: The geometric transformation of Singular Value Decomposition ($\mathbf{A} = \mathbf{U} \mathbf{\Sigma} \mathbf{V}^T$). Any real linear map transforms a unit sphere through an orthogonal rotation ($\mathbf{V}^T$), axis-aligned stretching by singular values $\sigma_i$, and an orthogonal rotation ($\mathbf{U}$) into an ellipsoid in $\mathbb{R}^m$.

Singular Value Decomposition (SVD) is the pinnacle of linear algebra because it factorizes ANY rectangular matrix $A \in \mathbb{R}^{m \times n}$ into three geometrically pristine matrices:

$$A = U \Sigma V^T$$
  • $U \in \mathbb{R}^{m \times m}$: An orthogonal matrix ($U^T U = I_m$). Its columns $\mathbf{u}_i$ are the Left Singular Vectors (eigenvectors of $A A^T$).
  • $\Sigma \in \mathbb{R}^{m \times n}$: A diagonal matrix of non-negative real numbers $\sigma_1 \ge \sigma_2 \ge \dots \ge \sigma_r > 0$ called the Singular Values ($\sigma_i = \sqrt{\lambda_i(A^T A)}$).
  • $V \in \mathbb{R}^{n \times n}$: An orthogonal matrix ($V^T V = I_n$). Its columns $\mathbf{v}_i$ are the Right Singular Vectors (eigenvectors of $A^T A$).

Step-by-Step Hand-Worked SVD Walkthrough

Let us trace SVD with zero skipped steps on a concrete rectangular matrix $A = \begin{bmatrix} 3 & 2 & 2 \\ 2 & 3 & -2 \end{bmatrix} \in \mathbb{R}^{2 \times 3}$:

Step 1: Compute $A A^T \in \mathbb{R}^{2 \times 2}$: $$A A^T = \begin{bmatrix} 3 & 2 & 2 \\ 2 & 3 & -2 \end{bmatrix} \begin{bmatrix} 3 & 2 \\ 2 & 3 \\ 2 & -2 \end{bmatrix} = \begin{bmatrix} 9+4+4 & 6+6-4 \\ 6+6-4 & 4+9+4 \end{bmatrix} = \begin{bmatrix} 17 & 8 \\ 8 & 17 \end{bmatrix}$$

Step 2: Find Eigenvalues of $A A^T$:
Solve the characteristic polynomial $\det(A A^T - \lambda I) = 0$: $$\det \begin{bmatrix} 17 - \lambda & 8 \\ 8 & 17 - \lambda \end{bmatrix} = (17 - \lambda)^2 - 64 = 0$$ $$(17 - \lambda)^2 = 64 \implies 17 - \lambda = \pm 8 \implies \lambda_1 = 25, \quad \lambda_2 = 9$$

Step 3: Determine Singular Values $\sigma_i = \sqrt{\lambda_i}$: $$\sigma_1 = \sqrt{25} = 5, \quad \sigma_2 = \sqrt{9} = 3 \implies \Sigma = \begin{bmatrix} 5 & 0 & 0 \\ 0 & 3 & 0 \end{bmatrix}$$

Step 4: Find Left Singular Vectors $U$ (Eigenvectors of $A A^T$):
For $\lambda_1 = 25$: $$(A A^T - 25 I)\mathbf{u}_1 = \begin{bmatrix} -8 & 8 \\ 8 & -8 \end{bmatrix} \begin{bmatrix} u_{11} \\ u_{12} \end{bmatrix} = \mathbf{0} \implies u_{11} = u_{12} \implies \mathbf{u}_1 = \frac{1}{\sqrt{2}} \begin{bmatrix} 1 \\ 1 \end{bmatrix}$$ For $\lambda_2 = 9$: $$(A A^T - 9 I)\mathbf{u}_2 = \begin{bmatrix} 8 & 8 \\ 8 & 8 \end{bmatrix} \begin{bmatrix} u_{21} \\ u_{22} \end{bmatrix} = \mathbf{0} \implies u_{21} = -u_{22} \implies \mathbf{u}_2 = \frac{1}{\sqrt{2}} \begin{bmatrix} 1 \\ -1 \end{bmatrix}$$ $$U = \frac{1}{\sqrt{2}} \begin{bmatrix} 1 & 1 \\ 1 & -1 \end{bmatrix}$$

Step 5: Compute Right Singular Vectors $\mathbf{v}_i = \frac{1}{\sigma_i} A^T \mathbf{u}_i$: $$\mathbf{v}_1 = \frac{1}{5} \begin{bmatrix} 3 & 2 \\ 2 & 3 \\ 2 & -2 \end{bmatrix} \left( \frac{1}{\sqrt{2}} \begin{bmatrix} 1 \\ 1 \end{bmatrix} \right) = \frac{1}{5\sqrt{2}} \begin{bmatrix} 5 \\ 5 \\ 0 \end{bmatrix} = \frac{1}{\sqrt{2}} \begin{bmatrix} 1 \\ 1 \\ 0 \end{bmatrix}$$ $$\mathbf{v}_2 = \frac{1}{3} \begin{bmatrix} 3 & 2 \\ 2 & 3 \\ 2 & -2 \end{bmatrix} \left( \frac{1}{\sqrt{2}} \begin{bmatrix} 1 \\ -1 \end{bmatrix} \right) = \frac{1}{3\sqrt{2}} \begin{bmatrix} 1 \\ -1 \\ 4 \end{bmatrix}$$ Find the third orthogonal vector $\mathbf{v}_3$ via cross product: $\mathbf{v}_3 = \frac{1}{3} \begin{bmatrix} 2 \\ -2 \\ -1 \end{bmatrix}$. We have factored $A$ completely!

The Eckart-Young-Mirsky Theorem

🏆 The Eckart-Young-Mirsky Theorem (1936)

The optimal rank-$k$ approximation of $A$ under both the Frobenius norm and the spectral $L_2$ norm is obtained by truncating the SVD summation to the top $k$ terms:

$$A_k = \sum_{i=1}^k \sigma_i \mathbf{u}_i \mathbf{v}_i^T = U_k \Sigma_k V_k^T$$

Furthermore, the exact approximation error is bounded by the discarded singular values:

$$\|A - A_k\|_F = \sqrt{\sum_{i=k+1}^{\min(m, n)} \sigma_i^2} \quad \text{and} \quad \|A - A_k\|_2 = \sigma_{k+1}$$

4. The Moore-Penrose Pseudoinverse

In classical school algebra, if $a x = b$, then $x = a^{-1} b$. But in AI, we frequently encounter linear systems $X \mathbf{w} = \mathbf{y}$ where $X \in \mathbb{R}^{N \times d}$ is not square ($N \gg d$ in regression, or $N \ll d$ in overparameterized deep networks). $X$ cannot be inverted because $X^{-1}$ does not exist.

The Moore-Penrose Pseudoinverse (denoted $X^+$) generalizes matrix inversion to all rectangular matrices using SVD:

$$X^+ = V \Sigma^+ U^T$$

Where $\Sigma^+$ is formed by inverting all non-zero singular values ($\frac{1}{\sigma_i}$) and transposing the matrix.

Problem 1.1.6 Level 3: FAANG Challenge Meta OpenAI

QUESTION: Let $\mathbf{u}, \mathbf{v} \in \mathbb{R}^d$ be two non-zero embedding vectors. Derive the analytical gradient of the Cosine Similarity $S(\mathbf{u}, \mathbf{v}) = \frac{\mathbf{u}^T \mathbf{v}}{\|\mathbf{u}\|_2 \|\mathbf{v}\|_2}$ with respect to vector $\mathbf{u}$. Show that the gradient is strictly orthogonal to $\mathbf{u}$.

✓ Complete Step-by-Step Mathematical Derivation

Step 1: Express Cosine Similarity as a Quotient:
Let $f(\mathbf{u}) = \mathbf{u}^T \mathbf{v}$ and $g(\mathbf{u}) = \|\mathbf{u}\|_2 \|\mathbf{v}\|_2 = (\mathbf{u}^T \mathbf{u})^{1/2} \|\mathbf{v}\|_2$.
Applying the vector quotient rule: $$\nabla_{\mathbf{u}} S(\mathbf{u}, \mathbf{v}) = \frac{g(\mathbf{u}) \nabla_{\mathbf{u}} f(\mathbf{u}) - f(\mathbf{u}) \nabla_{\mathbf{u}} g(\mathbf{u})}{g(\mathbf{u})^2}$$

Step 2: Compute Gradients:
$\nabla_{\mathbf{u}} (\mathbf{u}^T \mathbf{v}) = \mathbf{v}$.
$\nabla_{\mathbf{u}} \|\mathbf{u}\|_2 = \frac{\mathbf{u}}{\|\mathbf{u}\|_2} \implies \nabla_{\mathbf{u}} g(\mathbf{u}) = \|\mathbf{v}\|_2 \frac{\mathbf{u}}{\|\mathbf{u}\|_2}$.

Step 3: Substitute and Simplify: $$\nabla_{\mathbf{u}} S = \frac{\|\mathbf{u}\|_2 \|\mathbf{v}\|_2 \mathbf{v} - (\mathbf{u}^T \mathbf{v}) \|\mathbf{v}\|_2 \frac{\mathbf{u}}{\|\mathbf{u}\|_2}}{\|\mathbf{u}\|_2^2 \|\mathbf{v}\|_2^2} = \frac{1}{\|\mathbf{u}\|_2} \left[ \frac{\mathbf{v}}{\|\mathbf{v}\|_2} - \left( \frac{\mathbf{u}^T \mathbf{v}}{\|\mathbf{u}\|_2 \|\mathbf{v}\|_2} \right) \frac{\mathbf{u}}{\|\mathbf{u}\|_2} \right]$$ Let unit vectors be $\hat{\mathbf{u}} = \frac{\mathbf{u}}{\|\mathbf{u}\|_2}$ and $\hat{\mathbf{v}} = \frac{\mathbf{v}}{\|\mathbf{v}\|_2}$: $$\nabla_{\mathbf{u}} S(\mathbf{u}, \mathbf{v}) = \frac{1}{\|\mathbf{u}\|_2} \left[ \hat{\mathbf{v}} - (\hat{\mathbf{u}}^T \hat{\mathbf{v}}) \hat{\mathbf{u}} \right]$$

Step 4: Prove Orthogonality to $\mathbf{u}$:
Compute inner product with $\hat{\mathbf{u}}$: $$\hat{\mathbf{u}}^T \nabla_{\mathbf{u}} S = \frac{1}{\|\mathbf{u}\|_2} \left[ \hat{\mathbf{u}}^T \hat{\mathbf{v}} - (\hat{\mathbf{u}}^T \hat{\mathbf{v}})(\hat{\mathbf{u}}^T \hat{\mathbf{u}}) \right]$$ Since $\hat{\mathbf{u}}^T \hat{\mathbf{u}} = 1$: $$\hat{\mathbf{u}}^T \nabla_{\mathbf{u}} S = \frac{1}{\|\mathbf{u}\|_2} \left[ \hat{\mathbf{u}}^T \hat{\mathbf{v}} - \hat{\mathbf{u}}^T \hat{\mathbf{v}} \right] = \mathbf{0}$$ Geometric Beauty: The gradient points strictly perpendicular to $\mathbf{u}$, rotating $\mathbf{u}$ toward $\mathbf{v}$ along the hypersphere without altering its length!

import numpy as np

def truncated_svd_compress(A: np.ndarray, k: int):
    """
    Computes optimal rank-k approximation via Eckart-Young Theorem.
    """
    # 1. Full SVD decomposition
    U, s, Vt = np.linalg.svd(A, full_matrices=False)

    # 2. Truncate to top k singular values and vectors
    U_k = U[:, :k]
    s_k = s[:k]
    Vt_k = Vt[:k, :]

1. Gradients: The Direction of Steepest Descent

Machine learning models learn by minimizing an empirical loss function $\mathcal{L}(\mathbf{w}): \mathbb{R}^d \to \mathbb{R}$. In high dimensions ($d = 70 \times 10^9$ parameters), we cannot visualize the loss surface. Calculus provides the mathematical compass that guides us toward the minimum.

The Gradient Vector

For a scalar-valued function $f(\mathbf{x})$, the gradient $\nabla f(\mathbf{x}) \in \mathbb{R}^d$ is the vector of all first-order partial derivatives: $$\nabla f(\mathbf{x}) = \begin{bmatrix} \frac{\partial f}{\partial x_1}, & \frac{\partial f}{\partial x_2}, & \dots, & \frac{\partial f}{\partial x_d} \end{bmatrix}^T$$

📐 Mathematical Proof: Why the Gradient Points in the Direction of Steepest Ascent

Let $\mathbf{u}$ be a unit vector ($\|\mathbf{u}\|_2 = 1$) representing an arbitrary direction in parameter space. The directional derivative $D_{\mathbf{u}} f(\mathbf{x})$ measures the rate of change of $f$ in direction $\mathbf{u}$:

$$D_{\mathbf{u}} f(\mathbf{x}) = \lim_{h \to 0} \frac{f(\mathbf{x} + h \mathbf{u}) - f(\mathbf{x})}{h} = \nabla f(\mathbf{x}) \cdot \mathbf{u}$$

By the Cauchy-Schwarz inequality and trigonometric dot-product definition:

$$D_{\mathbf{u}} f(\mathbf{x}) = \|\nabla f(\mathbf{x})\|_2 \|\mathbf{u}\|_2 \cos(\theta) = \|\nabla f(\mathbf{x})\|_2 \cos(\theta)$$

Since $\cos(\theta) \in [-1, 1]$, this rate of change is maximized when $\cos(\theta) = 1$, which occurs when $\theta = 0^\circ$ (meaning $\mathbf{u}$ points in the exact same direction as $\nabla f(\mathbf{x})$)! Conversely, it is minimized (steepest descent) when $\cos(\theta) = -1$, pointing in direction $-\nabla f(\mathbf{x})$.

2. Higher-Order Derivatives: Jacobians & Hessians

The Jacobian Matrix (Vector-to-Vector Derivatives)

When a function maps a vector to another vector $\mathbf{f}: \mathbb{R}^n \to \mathbb{R}^m$, its first derivatives form the Jacobian matrix $J \in \mathbb{R}^{m \times n}$:

$$J_{ij} = \frac{\partial f_i}{\partial x_j} \implies J = \begin{bmatrix} \frac{\partial f_1}{\partial x_1} & \cdots & \frac{\partial f_1}{\partial x_n} \\ \vdots & \ddots & \vdots \\ \frac{\partial f_m}{\partial x_1} & \cdots & \frac{\partial f_m}{\partial x_n} \end{bmatrix}$$

The Hessian Matrix & Loss Surface Curvature

For a scalar loss function $\mathcal{L}(\mathbf{w})$, the second-order partial derivatives form the symmetric Hessian matrix $H \in \mathbb{R}^{d \times d}$ where $H_{ij} = \frac{\partial^2 \mathcal{L}}{\partial w_i \partial w_j}$.

The Hessian dictates the curvature of the loss surface via the second-order Taylor expansion:

$$\mathcal{L}(\mathbf{w} + \Delta \mathbf{w}) \approx \mathcal{L}(\mathbf{w}) + \nabla \mathcal{L}(\mathbf{w})^T \Delta \mathbf{w} + \frac{1}{2} \Delta \mathbf{w}^T H(\mathbf{w}) \Delta \mathbf{w}$$
  • All Eigenvalues $\lambda_i(H) > 0$ (Positive Definite): The surface curves upward in all directions $\to$ Local Minimum.
  • Mixed Eigenvalues (Some positive, some negative): Saddle Point! In high-dimensional deep learning ($d > 10^6$), local minima are extremely rare; saddle points dominate.
  • Condition Number $\kappa(H) = \frac{\lambda_{\max}}{\lambda_{\min}} \gg 1$: Ill-conditioned "ravine"! Gradient descent will oscillate wildly across steep ravine walls while making excruciatingly slow progress along the flat valley. This physical reality is why Momentum and Adam optimizers are mandatory!

3. Forward-Mode vs. Reverse-Mode Automatic Differentiation

How does PyTorch compute gradients across a model with 100 billion parameters? There are four ways to differentiate:

  1. Manual Analytical Calculus: Writing derivative formulas by hand. Impractical for multi-layer composite models.
  2. Numerical Differentiation (Finite Differences): $\frac{\partial f}{\partial x_i} \approx \frac{f(\mathbf{x} + \epsilon \mathbf{e}_i) - f(\mathbf{x})}{\epsilon}$. Requires $d + 1$ full forward evaluations. For 70 billion parameters, computing ONE gradient step would take 1,000 years!
  3. Symbolic Differentiation (e.g. SymPy, Mathematica): Manipulating algebraic trees. Suffers from catastrophic "expression swell."
  4. Automatic Differentiation (Autograd): Evaluates exact machine derivatives at machine precision by recursively applying the chain rule to the execution graph.

Why Deep Learning Uses Reverse-Mode Autograd (Backpropagation):

  • Forward-Mode Autograd (JVPs): Evaluates derivatives alongside activations using Dual Numbers ($a + b\epsilon$ where $\epsilon^2 = 0$). It requires 1 forward pass per input parameter. Optimal when inputs $n \ll \text{outputs } m$.
  • Reverse-Mode Autograd (VJPs): Executes 1 forward pass to evaluate activations and build the computational tape, then executes 1 single backward pass to compute the exact gradients of the scalar loss $\mathcal{L}$ with respect to ALL $d$ parameters simultaneously! Because deep learning has millions of inputs ($n \gg 1$) but only ONE scalar loss ($m = 1$), reverse-mode is infinitely superior.

class Value:
    """Stores a scalar value and its gradient in a computational tape."""
    __slots__ = ('data', 'grad', '_prev', '_op', '_backward')

    def __init__(self, data, _children=(), _op=''):
        self.data = float(data)
        self.grad = 0.0
        self._backward = lambda: None
        self._prev = set(_children)
        self._op = _op

    def __add__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data + other.data, (self, other), '+')
        def _backward():
            self.grad += 1.0 * out.grad
            other.grad += 1.0 * out.grad
        out._backward = _backward
        return out

    def __mul__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data * other.data, (self, other), '*')
        def _backward():
            self.grad += other.data * out.grad
            other.grad += self.data * out.grad
        out._backward = _backward
        return out

    def backward(self):
        # Topological sort of the computational graph
        topo = []
        visited = set()
        def build_topo(v):
            if v not in visited:
                visited.add(v)
                for child in v._prev:
                    build_topo(child)
                topo.append(v)
        build_topo(self)

        self.grad = 1.0
        for node in reversed(topo):
            node._backward()

    def __repr__(self):
        return f"Value(data={self.data:.4f}, grad={self.grad:.4f})"

if __name__ == "__main__":

    L.backward()

1. The Mathematics of Uncertainty

Deterministic software engineering operates in boolean binaries: a condition is either True or False, a pointer is either valid or null. Machine learning operates in continuous probability spaces: an autonomous vehicle never says "the obstacle ahead is definitely a stop sign"; it calculates a posterior probability distribution $P(\text{StopSign} \mid \text{Lidar}, \text{Camera}) = 0.987$. When dealing with sensor noise, missing features, and inherently stochastic real-world phenomena, probability is the universal mathematical grammar of artificial intelligence.

Kolmogorov's Axioms of Probability

Given a sample space $\Omega$ of all possible mutually exclusive elementary outcomes, an event space $\mathcal{F}$ of measurable subsets of $\Omega$, a valid probability measure $P: \mathcal{F} \to [0, 1]$ must satisfy three fundamental axioms formulated by Andrey Kolmogorov in 1933:

  1. Non-negativity: For any event $A \in \mathcal{F}$, $P(A) \ge 0$.
  2. Unit Measure: The probability of the entire sample space occurring is unity: $P(\Omega) = 1$.
  3. Countable Additivity: For any countable sequence of pairwise disjoint events ($A_i \cap A_j = \emptyset$ for all $i \neq j$): $$P\left(\bigcup_{i=1}^\infty A_i\right) = \sum_{i=1}^\infty P(A_i)$$

Joint, Marginal, and Conditional Probability

From these axioms arise the core operational rules governing multidimensional random variables:

  • Joint Probability $P(X = x, Y = y)$: The probability that random variable $X$ takes value $x$ AND random variable $Y$ takes value $y$ simultaneously.
  • Marginal Probability (Sum Rule): Summing (or integrating) out irrelevant nuisance variables from a joint distribution: $$P(X = x) = \sum_{y \in \mathcal{Y}} P(X = x, Y = y) \quad \text{(Discrete)}, \qquad P(X = x) = \int_{\mathcal{Y}} P(X = x, Y = y) \, dy \quad \text{(Continuous)}$$
  • Conditional Probability (Product Rule): The probability of event $A$ given that event $B$ has definitively occurred ($P(B) > 0$): $$P(A \mid B) = \frac{P(A \cap B)}{P(B)} \implies P(A \cap B) = P(A \mid B) P(B)$$
  • Chain Rule of Probability: Factoring any high-dimensional joint probability distribution into a cascade of univariate conditionals: $$P(X_1, X_2, \dots, X_n) = P(X_1) \prod_{i=2}^n P(X_i \mid X_1, \dots, X_{i-1})$$ This exact factorization forms the mathematical foundation of Auto-regressive Large Language Models (GPT, Claude, Llama), where the probability of a document is the product of token probabilities conditioned on preceding tokens!
  • Independence vs. Conditional Independence: Two variables $X$ and $Y$ are unconditionally independent ($X \perp Y$) if $P(X, Y) = P(X)P(Y)$. They are conditionally independent given $Z$ ($X \perp Y \mid Z$) if: $$P(X, Y \mid Z) = P(X \mid Z) P(Y \mid Z)$$ Conditional independence is the cornerstone of Graphical Models, Naive Bayes classifiers, and Markov Random Fields.

2. Expectation, Moments & Variance Mechanics

Probability distributions are high-dimensional objects. In practice, machine learning models optimize statistical summaries (moments) of these distributions.

The Expectation Operator ($\mathbb{E}$)

The expected value of a function $g(X)$ with respect to probability distribution $P(X)$ represents the probability-weighted average:

$$\mathbb{E}_{X \sim P}[g(X)] = \sum_{x \in \mathcal{X}} g(x) P(x) \quad \text{(Discrete)}, \qquad \mathbb{E}_{X \sim P}[g(X)] = \int_{\Omega} g(x) P(x) \, dx \quad \text{(Continuous)}$$

Crucial Properties of Expectation:

  1. Linearity of Expectation: For any random variables $X$ and $Y$ (regardless of whether they are independent or correlated) and constants $a, b \in \mathbb{R}$: $$\mathbb{E}[aX + bY] = a\mathbb{E}[X] + b\mathbb{E}[Y]$$
  2. Expectation of Independent Variables: If $X \perp Y$, then $\mathbb{E}[XY] = \mathbb{E}[X] \mathbb{E}[Y]$.
  3. Law of Total Expectation (Tower Property): $$\mathbb{E}[Y] = \mathbb{E}_{X}\left[ \mathbb{E}_{Y \mid X}[Y \mid X] \right]$$

Variance, Covariance, and the Correlation Matrix

Variance quantifies the expected squared dispersion of a random variable around its mean $\mu = \mathbb{E}[X]$:

$$\text{Var}(X) = \mathbb{E}\left[ (X - \mathbb{E}[X])^2 \right] = \mathbb{E}[X^2] - (\mathbb{E}[X])^2$$

Under linear scaling: $\text{Var}(aX + b) = a^2 \text{Var}(X)$. Adding a constant does not change spread; scaling by $a$ scales variance quadratically.

For two random variables $X$ and $Y$, the Covariance measures their linear co-movement:

$$\text{Cov}(X, Y) = \mathbb{E}\left[ (X - \mathbb{E}[X])(Y - \mathbb{E}[Y]) \right] = \mathbb{E}[XY] - \mathbb{E}[X]\mathbb{E}[Y]$$

Notice that $\text{Cov}(X, X) = \text{Var}(X)$. If $X \perp Y$, then $\text{Cov}(X, Y) = 0$. (Warning: zero covariance implies independence only if the variables are jointly Gaussian; in general non-linear cases, $\text{Cov}(X, Y) = 0$ does not imply independence!).

The Pearson Correlation Coefficient normalizes covariance by the product of standard deviations, yielding a scale-invariant metric in $[-1, 1]$:

$$\rho_{XY} = \frac{\text{Cov}(X, Y)}{\sigma_X \sigma_Y} = \frac{\text{Cov}(X, Y)}{\sqrt{\text{Var}(X)\text{Var}(Y)}}$$

The Law of Total Variance (Eve's Law): In hierarchical models and reinforcement learning, total variance decomposes into unexplained variance and explained variance: $$\text{Var}(Y) = \mathbb{E}_X\left[ \text{Var}(Y \mid X) \right] + \text{Var}_X\left( \mathbb{E}[Y \mid X] \right)$$

Geometry of the Multivariate Normal: The Mahalanobis Distance

In a Multivariate Normal distribution $\mathcal{N}(\boldsymbol{\mu}, \boldsymbol{\Sigma})$, the covariance matrix $\boldsymbol{\Sigma} \in \mathbb{R}^{d \times d}$ is symmetric positive semi-definite ($\boldsymbol{\Sigma} = \boldsymbol{\Sigma}^T$ and $\mathbf{z}^T \boldsymbol{\Sigma} \mathbf{z} \ge 0$). By the Spectral Theorem, $\boldsymbol{\Sigma}$ decomposes as:

$$\boldsymbol{\Sigma} = \mathbf{U} \boldsymbol{\Lambda} \mathbf{U}^T = \sum_{i=1}^d \lambda_i \mathbf{u}_i \mathbf{u}_i^T$$

Contours of constant probability density form hyper-ellipsoids centered at $\boldsymbol{\mu}$. The eigenvectors $\mathbf{u}_i$ define the principal axes of the ellipsoid, and the square roots of the eigenvalues $\sqrt{\lambda_i}$ define the lengths of the semi-axes (standard deviations along those orthogonal directions).

The term inside the exponent is the squared Mahalanobis Distance:

$$D_M^2(\mathbf{x}, \boldsymbol{\mu}) = (\mathbf{x} - \boldsymbol{\mu})^T \boldsymbol{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu})$$

Unlike standard Euclidean distance $\|\mathbf{x} - \boldsymbol{\mu}\|_2^2$, the Mahalanobis distance scales distances inversely by the variance in each direction and accounts for correlated features, making it indispensable for anomaly detection.

4. Bayesian Inference & The Four Pillars of Bayes

Bayes' Theorem converts a generative prior belief into an updated posterior belief after assimilating empirical data:

🏆 Bayes' Theorem Dissected for Machine Learning

$$P(\boldsymbol{\theta} \mid \mathcal{D}) = \frac{P(\mathcal{D} \mid \boldsymbol{\theta}) P(\boldsymbol{\theta})}{P(\mathcal{D})} = \frac{P(\mathcal{D} \mid \boldsymbol{\theta}) P(\boldsymbol{\theta})}{\int_{\boldsymbol{\Theta}} P(\mathcal{D} \mid \boldsymbol{\theta}') P(\boldsymbol{\theta}') \, d\boldsymbol{\theta}'}$$
  • $P(\boldsymbol{\theta})$: The Prior. Encapsulates our domain knowledge or regularizing inductive bias about parameters $\boldsymbol{\theta}$ before observing data $\mathcal{D}$.
  • $P(\mathcal{D} \mid \boldsymbol{\theta})$: The Likelihood. The probability of observing dataset $\mathcal{D}$ if the true underlying parameters were $\boldsymbol{\theta}$. Under i.i.d. sampling, $P(\mathcal{D} \mid \boldsymbol{\theta}) = \prod_{i=1}^N P(\mathbf{x}_i \mid \boldsymbol{\theta})$.
  • $P(\mathcal{D}) = \int P(\mathcal{D} \mid \boldsymbol{\theta}') P(\boldsymbol{\theta}') d\boldsymbol{\theta}'$: The Evidence (Marginal Likelihood). The normalizing constant ensuring the posterior integrates to 1. In deep learning with millions of parameters, computing this integral over $\mathbb{R}^{10^9}$ is intractable, necessitating MCMC or Variational Inference.
  • $P(\boldsymbol{\theta} \mid \mathcal{D})$: The Posterior Distribution. Our complete, uncertainty-aware updated belief over parameter space given the empirical evidence.

5. Estimation Theory: MLE, MAP & The Loss Function Bridge

In deep learning, we frequently summarize the posterior distribution with a single optimal point estimate $\hat{\boldsymbol{\theta}}$. The two primary point-estimation frameworks are:

1. Maximum Likelihood Estimation (MLE)

MLE seeks the parameter vector $\hat{\boldsymbol{\theta}}_{\text{MLE}}$ that maximizes the probability of generating the observed training dataset $\mathcal{D} = \{\mathbf{x}_1, \dots, \mathbf{x}_N\}$:

$$\hat{\boldsymbol{\theta}}_{\text{MLE}} = \arg\max_{\boldsymbol{\theta}} \prod_{i=1}^N P(\mathbf{x}_i \mid \boldsymbol{\theta}) = \arg\max_{\boldsymbol{\theta}} \sum_{i=1}^N \ln P(\mathbf{x}_i \mid \boldsymbol{\theta}) = \arg\min_{\boldsymbol{\theta}} \left[ -\sum_{i=1}^N \ln P(\mathbf{x}_i \mid \boldsymbol{\theta}) \right]$$

Minimizing Negative Log-Likelihood (NLL) is the foundational objective of supervised deep learning.

2. Maximum A Posteriori (MAP) Estimation

MAP incorporates prior beliefs $P(\boldsymbol{\theta})$ over parameters, finding the mode of the posterior distribution:

$$\hat{\boldsymbol{\theta}}_{\text{MAP}} = \arg\max_{\boldsymbol{\theta}} P(\boldsymbol{\theta} \mid \mathcal{D}) = \arg\max_{\boldsymbol{\theta}} \frac{P(\mathcal{D} \mid \boldsymbol{\theta}) P(\boldsymbol{\theta})}{P(\mathcal{D})}$$

Since the evidence $P(\mathcal{D})$ does not depend on $\boldsymbol{\theta}$, we drop it and take the natural log:

$$\hat{\boldsymbol{\theta}}_{\text{MAP}} = \arg\max_{\boldsymbol{\theta}} \left[ \ln P(\mathcal{D} \mid \boldsymbol{\theta}) + \ln P(\boldsymbol{\theta}) \right] = \arg\min_{\boldsymbol{\theta}} \left[ -\sum_{i=1}^N \ln P(\mathbf{x}_i \mid \boldsymbol{\theta}) - \ln P(\boldsymbol{\theta}) \right]$$

The Great Mathematical Bridge of AI:

  • Gaussian Noise $\implies$ Mean Squared Error (MSE): Assuming $y = f(\mathbf{x}) + \epsilon$ with $\epsilon \sim \mathcal{N}(0, \sigma^2)$, NLL is identically MSE.
  • Bernoulli Likelihood $\implies$ Binary Cross-Entropy (BCE): Assuming $y \sim \text{Bernoulli}(p)$, NLL is identically BCE loss.
  • Categorical Likelihood $\implies$ Multi-Class Categorical Cross-Entropy: Softmax + NLL is the cross-entropy loss used to train all neural language and vision classifiers.
  • Gaussian Prior on Weights $\implies L_2$ Regularization (Ridge / Weight Decay): If $P(\mathbf{w}) \sim \mathcal{N}(\mathbf{0}, \sigma_w^2 \mathbf{I})$, $-\ln P(\mathbf{w}) = \frac{1}{2\sigma_w^2} \|\mathbf{w}\|_2^2 + \text{const}$. MAP directly yields $L_2$ weight decay with $\lambda = \frac{\sigma^2}{\sigma_w^2}$!
  • Laplace Prior on Weights $\implies L_1$ Regularization (Lasso): If $P(\mathbf{w}) \propto \exp(-\frac{\|\mathbf{w}\|_1}{b})$, $-\ln P(\mathbf{w}) = \frac{1}{b} \|\mathbf{w}\|_1 + \text{const}$. The non-differentiable sharp peak at zero forces weights to exact numerical zero, producing sparse models!
Loss functions and regularizers are not empirical heuristics; they are the exact mathematical consequence of probabilistic likelihoods and priors!

6. Complete Mathematical Derivation: Gaussian MLE & Bessel's Bias Correction

Let $x_1, x_2, \dots, x_N \overset{\text{i.i.d.}}{\sim} \mathcal{N}(\mu, \sigma^2)$. We derive the Maximum Likelihood Estimators for both $\mu$ and $\sigma^2$, and prove whether they are biased or unbiased.

Derivation Step 1: Write the Joint Log-Likelihood

$$L(\mu, \sigma^2) = \prod_{i=1}^N \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left( -\frac{(x_i - \mu)^2}{2\sigma^2} \right)$$ $$\ell(\mu, \sigma^2) = \ln L = -\frac{N}{2} \ln(2\pi) - \frac{N}{2} \ln(\sigma^2) - \frac{1}{2\sigma^2} \sum_{i=1}^N (x_i - \mu)^2$$

Derivation Step 2: Solve for $\hat{\mu}_{\text{MLE}}$

Differentiate $\ell$ with respect to $\mu$ and set to zero:

$$\frac{\partial \ell}{\partial \mu} = -\frac{1}{2\sigma^2} \sum_{i=1}^N 2(x_i - \mu)(-1) = \frac{1}{\sigma^2} \sum_{i=1}^N (x_i - \mu) = 0$$ $$\sum_{i=1}^N x_i - N\mu = 0 \implies \hat{\mu}_{\text{MLE}} = \frac{1}{N} \sum_{i=1}^N x_i = \bar{x}$$

Is $\hat{\mu}_{\text{MLE}}$ unbiased? Check its expectation:

$$\mathbb{E}[\hat{\mu}_{\text{MLE}}] = \mathbb{E}\left[ \frac{1}{N} \sum_{i=1}^N x_i \right] = \frac{1}{N} \sum_{i=1}^N \mathbb{E}[x_i] = \frac{1}{N}(N\mu) = \mu$$

Since $\mathbb{E}[\hat{\mu}_{\text{MLE}}] = \mu$, the sample mean is an unbiased estimator.

Derivation Step 3: Solve for $\hat{\sigma}^2_{\text{MLE}}$

Differentiate $\ell$ with respect to $v = \sigma^2$ and set to zero:

$$\frac{\partial \ell}{\partial v} = -\frac{N}{2v} + \frac{1}{2v^2} \sum_{i=1}^N (x_i - \mu)^2 = 0 \implies -\frac{N}{2v} + \frac{1}{2v^2} \sum_{i=1}^N (x_i - \hat{\mu})^2 = 0$$ $$\frac{N}{2v} = \frac{1}{2v^2} \sum_{i=1}^N (x_i - \hat{\mu})^2 \implies \hat{\sigma}^2_{\text{MLE}} = \frac{1}{N} \sum_{i=1}^N (x_i - \bar{x})^2$$

Derivation Step 4: Prove the Bias of $\hat{\sigma}^2_{\text{MLE}}$ (Bessel's Correction)

Compute the expected value of $\hat{\sigma}^2_{\text{MLE}}$:

$$\mathbb{E}[\hat{\sigma}^2_{\text{MLE}}] = \mathbb{E}\left[ \frac{1}{N} \sum_{i=1}^N (x_i - \bar{x})^2 \right] = \frac{1}{N} \sum_{i=1}^N \mathbb{E}[(x_i - \bar{x})^2]$$

Expand $(x_i - \bar{x}) = (x_i - \mu) - (\bar{x} - \mu)$:

$$(x_i - \bar{x})^2 = (x_i - \mu)^2 - 2(x_i - \mu)(\bar{x} - \mu) + (\bar{x} - \mu)^2$$ $$\sum_{i=1}^N (x_i - \bar{x})^2 = \sum_{i=1}^N (x_i - \mu)^2 - 2(\bar{x} - \mu) \sum_{i=1}^N (x_i - \mu) + N(\bar{x} - \mu)^2$$

Since $\sum_{i=1}^N (x_i - \mu) = N(\bar{x} - \mu)$, this simplifies to:

$$\sum_{i=1}^N (x_i - \bar{x})^2 = \sum_{i=1}^N (x_i - \mu)^2 - N(\bar{x} - \mu)^2$$

Taking expectations:

$$\mathbb{E}\left[ \sum_{i=1}^N (x_i - \bar{x})^2 \right] = \sum_{i=1}^N \mathbb{E}[(x_i - \mu)^2] - N \mathbb{E}[(\bar{x} - \mu)^2]$$

Recall that $\mathbb{E}[(x_i - \mu)^2] = \text{Var}(x_i) = \sigma^2$, and $\mathbb{E}[(\bar{x} - \mu)^2] = \text{Var}(\bar{x}) = \frac{\sigma^2}{N}$:

$$\mathbb{E}\left[ \sum_{i=1}^N (x_i - \bar{x})^2 \right] = N\sigma^2 - N\left(\frac{\sigma^2}{N}\right) = N\sigma^2 - \sigma^2 = (N-1)\sigma^2$$

Dividing by $N$:

$$\mathbb{E}[\hat{\sigma}^2_{\text{MLE}}] = \frac{N-1}{N} \sigma^2$$

Conclusion: The MLE variance estimator systematically underestimates the true population variance by a factor of $\frac{N-1}{N}$ because the deviations are measured relative to the empirical sample mean $\bar{x}$ rather than the true unknown mean $\mu$ (consuming 1 degree of freedom). To obtain an unbiased estimator, we multiply by $\frac{N}{N-1}$, yielding Bessel's Correction:

$$s^2 = \frac{1}{N-1} \sum_{i=1}^N (x_i - \bar{x})^2 \implies \mathbb{E}[s^2] = \sigma^2$$

Problem 1.3.1 Easy Google Meta

QUESTION: A production payment network experiences fraudulent transactions at a base rate of $P(F) = 0.002$ ($0.2\%$). An automated AI fraud detector has a True Positive Rate (Sensitivity) of $P(+ \mid F) = 0.98$ and a False Positive Rate of $P(+ \mid \neg F) = 0.02$.

  1. A transaction flags positive ($+$). Compute the exact posterior probability $P(F \mid +)$ that the transaction is genuinely fraudulent.
  2. Suppose a secondary independent verification model also tests positive ($+_2$) on this flagged transaction, with identical sensitivity $0.98$ and false positive rate $0.02$. Compute the updated posterior probability $P(F \mid +, +_2)$.
✓ Complete Step-by-Step Numerical Solution

Step 1: Compute Posterior after First Positive Test:
By Bayes' Theorem: $$P(F \mid +) = \frac{P(+ \mid F) P(F)}{P(+)}$$ Expand denominator $P(+)$ using the Law of Total Probability ($P(\neg F) = 1 - 0.002 = 0.998$): $$P(+) = P(+ \mid F) P(F) + P(+ \mid \neg F) P(\neg F)$$ $$P(+) = (0.98 \times 0.002) + (0.02 \times 0.998) = 0.00196 + 0.01996 = 0.02192$$ Calculate posterior: $$P(F \mid +) = \frac{0.00196}{0.02192} \approx 0.089416 = 8.94\%$$ Insight: Despite a $98\%$ accurate test, an alarm is only genuine $\approx 8.94\%$ of the time because the base rate is so small ($1$ in $500$).

Step 2: Sequential Bayesian Updating after Second Positive Test:
In Bayesian inference, the posterior from the first test becomes the prior for the second test: $$P_{\text{new}}(F) = P(F \mid +) = 0.089416, \quad P_{\text{new}}(\neg F) = 1 - 0.089416 = 0.910584$$ Compute the new marginal probability of testing positive $P(+_2)$: $$P(+_2) = P(+_2 \mid F) P_{\text{new}}(F) + P(+_2 \mid \neg F) P_{\text{new}}(\neg F)$$ $$P(+_2) = (0.98 \times 0.089416) + (0.02 \times 0.910584) = 0.087628 + 0.018212 = 0.105840$$ Compute the updated posterior: $$P(F \mid +, +_2) = \frac{0.087628}{0.105840} \approx 0.8279 = 82.79\%$$ Result: Two consecutive independent positive tests skyrocket the confidence from $8.94\%$ to $82.79\%$!

Problem 1.3.2 Easy Apple

QUESTION: Given a dataset of $N=4$ two-dimensional feature points: $$\mathbf{x}_1 = \begin{bmatrix} 1 \\ 2 \end{bmatrix}, \quad \mathbf{x}_2 = \begin{bmatrix} 2 \\ 4 \end{bmatrix}, \quad \mathbf{x}_3 = \begin{bmatrix} 3 \\ 5 \end{bmatrix}, \quad \mathbf{x}_4 = \begin{bmatrix} 4 \\ 9 \end{bmatrix}$$ Compute step-by-step:

  1. The sample mean vector $\bar{\mathbf{x}} = [\bar{x}_1, \bar{x}_2]^T$.
  2. The unbiased sample covariance matrix $\mathbf{S} = \begin{bmatrix} s_{11} & s_{12} \\ s_{21} & s_{22} \end{bmatrix}$ (using $N-1$ denominator).
  3. The Pearson correlation coefficient $r_{12}$.
✓ Complete Step-by-Step Numerical Solution

Step 1: Compute Sample Mean Vector: $$\bar{x}_1 = \frac{1 + 2 + 3 + 4}{4} = \frac{10}{4} = 2.5$$ $$\bar{x}_2 = \frac{2 + 4 + 5 + 9}{4} = \frac{20}{4} = 5.0 \implies \bar{\mathbf{x}} = \begin{bmatrix} 2.5 \\ 5.0 \end{bmatrix}$$

Step 2: Compute Centered Deviation Vectors: $$\mathbf{x}_1 - \bar{\mathbf{x}} = \begin{bmatrix} -1.5 \\ -3.0 \end{bmatrix}, \quad \mathbf{x}_2 - \bar{\mathbf{x}} = \begin{bmatrix} -0.5 \\ -1.0 \end{bmatrix}, \quad \mathbf{x}_3 - \bar{\mathbf{x}} = \begin{bmatrix} 0.5 \\ 0.0 \end{bmatrix}, \quad \mathbf{x}_4 - \bar{\mathbf{x}} = \begin{bmatrix} 1.5 \\ 4.0 \end{bmatrix}$$

Step 3: Compute Covariance Entries with $N-1 = 3$: $$s_{11} = \text{Var}(X_1) = \frac{(-1.5)^2 + (-0.5)^2 + (0.5)^2 + (1.5)^2}{3} = \frac{2.25 + 0.25 + 0.25 + 2.25}{3} = \frac{5.0}{3} \approx 1.6667$$ $$s_{22} = \text{Var}(X_2) = \frac{(-3.0)^2 + (-1.0)^2 + (0.0)^2 + (4.0)^2}{3} = \frac{9.0 + 1.0 + 0.0 + 16.0}{3} = \frac{26.0}{3} \approx 8.6667$$ $$s_{12} = \text{Cov}(X_1, X_2) = \frac{(-1.5)(-3.0) + (-0.5)(-1.0) + (0.5)(0.0) + (1.5)(4.0)}{3} = \frac{4.5 + 0.5 + 0.0 + 6.0}{3} = \frac{11.0}{3} \approx 3.6667$$ $$\mathbf{S} = \begin{bmatrix} 5/3 & 11/3 \\ 11/3 & 26/3 \end{bmatrix} \approx \begin{bmatrix} 1.6667 & 3.6667 \\ 3.6667 & 8.6667 \end{bmatrix}$$

Step 4: Compute Pearson Correlation Coefficient: $$r_{12} = \frac{s_{12}}{\sqrt{s_{11} s_{22}}} = \frac{11/3}{\sqrt{(5/3)(26/3)}} = \frac{11}{\sqrt{130}} = \frac{11}{11.40175} \approx 0.9648$$ Result: $r_{12} \approx 0.965$, demonstrating an extremely strong positive linear relationship between the two features.

Problem 1.3.3 Medium Meta Netflix

QUESTION: An ad-serving platform logs impressions and clicks. Model the user click action as a Bernoulli random variable $Y \sim \text{Bernoulli}(p)$ where $P(Y=1) = p$ and $P(Y=0) = 1-p$. Given $N$ i.i.d. observations containing $k$ clicks and $N-k$ non-clicks:

  1. Derive the log-likelihood function $\ell(p)$ and the score function $S(p) = \frac{\partial \ell}{\partial p}$.
  2. Solve for the Maximum Likelihood Estimator $\hat{p}_{\text{MLE}}$ and prove strict concavity via the second derivative $\frac{\partial^2 \ell}{\partial p^2}$.
  3. For a new campaign with $k=42$ clicks out of $N=500$ impressions, compute $\hat{p}_{\text{MLE}}$ and construct the $95\%$ Wald Confidence Interval $\hat{p} \pm 1.96 \sqrt{\frac{\hat{p}(1-\hat{p})}{N}}$.
✓ Complete Step-by-Step Mathematical & Numerical Solution

Step 1: Formulate Likelihood and Log-Likelihood:
For $N$ independent observations $y_1, \dots, y_N \in \{0, 1\}$ with $k = \sum_{i=1}^N y_i$: $$L(p) = \prod_{i=1}^N p^{y_i} (1-p)^{1 - y_i} = p^k (1-p)^{N-k}$$ Take the natural logarithm to obtain the log-likelihood: $$\ell(p) = \ln L(p) = k \ln(p) + (N-k) \ln(1-p)$$ Differentiate with respect to $p$ to find the score function: $$S(p) = \frac{d\ell}{dp} = \frac{k}{p} - \frac{N-k}{1-p}$$

Step 2: Solve for $\hat{p}_{\text{MLE}}$ and Verify Global Maximum:
Set score to zero: $$\frac{k}{p} - \frac{N-k}{1-p} = 0 \implies k(1-p) = p(N-k) \implies k - kp = Np - kp \implies Np = k$$ $$\hat{p}_{\text{MLE}} = \frac{k}{N}$$ Check second derivative: $$\frac{d^2\ell}{dp^2} = -\frac{k}{p^2} - \frac{N-k}{(1-p)^2}$$ Since $p \in (0, 1)$, $k \ge 0$, and $N-k \ge 0$, both denominators are positive. Provided $0 < k < N$, $\frac{d^2\ell}{dp^2} < 0$ strictly for all $p \in (0, 1)$. The log-likelihood is strictly concave everywhere, guaranteeing that $\hat{p}_{\text{MLE}} = \frac{k}{N}$ is the unique global maximum.

Step 3: Numerical Computation & Confidence Interval:

Problem 1.3.5 Hard Google DeepMind Meta FAIR

QUESTION: Prove rigorously from first principles that Maximum A Posteriori (MAP) estimation of a linear regression model with Gaussian observation noise $y_i \mid \mathbf{x}_i, \mathbf{w} \sim \mathcal{N}(\mathbf{w}^T \mathbf{x}_i, \sigma^2)$ and an isotropic zero-mean Gaussian prior over weights $\mathbf{w} \sim \mathcal{N}(\mathbf{0}, \sigma_w^2 \mathbf{I})$ produces the exact Ridge Regression ($L_2$ Regularization) closed-form solution:

$$\hat{\mathbf{w}}_{\text{MAP}} = (\mathbf{X}^T \mathbf{X} + \lambda \mathbf{I})^{-1} \mathbf{X}^T \mathbf{y}$$

Explicitly derive the exact formula for the regularization hyperparameter $\lambda$ in terms of the noise variance $\sigma^2$ and prior variance $\sigma_w^2$.

✓ Complete Step-by-Step Mathematical Proof

Step 1: Formulate the Posterior via Bayes' Theorem:
$$P(\mathbf{w} \mid \mathbf{X}, \mathbf{y}) = \frac{P(\mathbf{y} \mid \mathbf{X}, \mathbf{w}) P(\mathbf{w})}{P(\mathbf{y} \mid \mathbf{X})}$$ Taking the negative logarithm (and discarding $P(\mathbf{y} \mid \mathbf{X})$ which does not depend on $\mathbf{w}$): $$-\ln P(\mathbf{w} \mid \mathbf{X}, \mathbf{y}) = -\ln P(\mathbf{y} \mid \mathbf{X}, \mathbf{w}) - \ln P(\mathbf{w}) + \text{const}$$

Step 2: Expand Likelihood and Prior:
Under i.i.d. Gaussian noise with variance $\sigma^2$, the likelihood over $N$ observations in matrix form is: $$P(\mathbf{y} \mid \mathbf{X}, \mathbf{w}) = \left(\frac{1}{2\pi\sigma^2}\right)^{N/2} \exp\left( -\frac{1}{2\sigma^2} \|\mathbf{y} - \mathbf{X}\mathbf{w}\|_2^2 \right)$$ $$-\ln P(\mathbf{y} \mid \mathbf{X}, \mathbf{w}) = \frac{1}{2\sigma^2} (\mathbf{y} - \mathbf{X}\mathbf{w})^T (\mathbf{y} - \mathbf{X}\mathbf{w}) + \frac{N}{2} \ln(2\pi\sigma^2)$$ The prior distribution over $d$-dimensional weight vector $\mathbf{w}$ is $\mathcal{N}(\mathbf{0}, \sigma_w^2 \mathbf{I})$: $$P(\mathbf{w}) = \left(\frac{1}{2\pi\sigma_w^2}\right)^{d/2} \exp\left( -\frac{1}{2\sigma_w^2} \mathbf{w}^T \mathbf{w} \right)$$ $$-\ln P(\mathbf{w}) = \frac{1}{2\sigma_w^2} \mathbf{w}^T \mathbf{w} + \frac{d}{2} \ln(2\pi\sigma_w^2)$$

Step 3: Combine and Minimize the Objective:
$$\hat{\mathbf{w}}_{\text{MAP}} = \arg\min_{\mathbf{w}} \left[ \frac{1}{2\sigma^2} (\mathbf{y} - \mathbf{X}\mathbf{w})^T (\mathbf{y} - \mathbf{X}\mathbf{w}) + \frac{1}{2\sigma_w^2} \mathbf{w}^T \mathbf{w} \right]$$ Multiply the entire expression by $2\sigma^2$: $$\hat{\mathbf{w}}_{\text{MAP}} = \arg\min_{\mathbf{w}} \left[ (\mathbf{y} - \mathbf{X}\mathbf{w})^T (\mathbf{y} - \mathbf{X}\mathbf{w}) + \frac{\sigma^2}{\sigma_w^2} \mathbf{w}^T \mathbf{w} \right]$$ Define $\lambda = \frac{\sigma^2}{\sigma_w^2}$. The objective function becomes: $$J(\mathbf{w}) = (\mathbf{y} - \mathbf{X}\mathbf{w})^T (\mathbf{y} - \mathbf{X}\mathbf{w}) + \lambda \mathbf{w}^T \mathbf{w}$$ This is the exact definition of the Ridge Regression objective function!

Step 4: Differentiate and Solve for $\mathbf{w}$:
Expand $J(\mathbf{w})$: $$J(\mathbf{w}) = \mathbf{y}^T \mathbf{y} - 2 \mathbf{w}^T \mathbf{X}^T \mathbf{y} + \mathbf{w}^T \mathbf{X}^T \mathbf{X} \mathbf{w} + \lambda \mathbf{w}^T \mathbf{w}$$ Compute gradient with respect to $\mathbf{w}$ using matrix calculus: $$\nabla_{\mathbf{w}} J(\mathbf{w}) = -2 \mathbf{X}^T \mathbf{y} + 2 \mathbf{X}^T \mathbf{X} \mathbf{w} + 2 \lambda \mathbf{w}$$ Set gradient to zero: $$\mathbf{X}^T \mathbf{X} \mathbf{w} + \lambda \mathbf{w} = \mathbf{X}^T \mathbf{y} \implies (\mathbf{X}^T \mathbf{X} + \lambda \mathbf{I}) \mathbf{w} = \mathbf{X}^T \mathbf{y}$$ Because $\mathbf{X}^T \mathbf{X}$ is positive semi-definite and $\lambda > 0$, $(\mathbf{X}^T \mathbf{X} + \lambda \mathbf{I})$ is strictly positive definite and always invertible: $$\hat{\mathbf{w}}_{\text{MAP}} = (\mathbf{X}^T \mathbf{X} + \lambda \mathbf{I})^{-1} \mathbf{X}^T \mathbf{y}, \quad \text{with } \lambda = \frac{\sigma^2}{\sigma_w^2}$$ Q.E.D. $L_2$ regularization is the direct analytical consequence of a Gaussian prior, where the regularizer $\lambda$ represents the ratio of measurement noise variance to prior weight variance!

QUESTION: In Gaussian Process Regression, Kalman Filtering, and Generative Diffusion Models, we partition a joint Gaussian random vector into observed variables $\mathbf{x}_2 \in \mathbb{R}^p$ and unobserved variables $\mathbf{x}_1 \in \mathbb{R}^q$:

$$\mathbf{x} = \begin{bmatrix} \mathbf{x}_1 \\ \mathbf{x}_2 \end{bmatrix} \sim \mathcal{N}\left( \begin{bmatrix} \boldsymbol{\mu}_1 \\ \boldsymbol{\mu}_2 \end{bmatrix}, \begin{bmatrix} \boldsymbol{\Sigma}_{11} & \boldsymbol{\Sigma}_{12} \\ \boldsymbol{\Sigma}_{21} & \boldsymbol{\Sigma}_{22} \end{bmatrix} \right)$$

✓ Complete Step-by-Step Mathematical Proof

Step 1: Define Linear Transformation of Uncorrelated Variables:
We construct a transformation that decorrelates $\mathbf{x}_1$ from $\mathbf{x}_2$. Let: $$\mathbf{z} = \mathbf{x}_1 - \mathbf{A} \mathbf{x}_2$$ where $\mathbf{A} \in \mathbb{R}^{q \times p}$ is a constant matrix chosen such that $\text{Cov}(\mathbf{z}, \mathbf{x}_2) = \mathbf{0}$.

Step 2: Exploit Independence of Jointly Gaussian Variables:
Because $\mathbf{x}_1$ and $\mathbf{x}_2$ are jointly Gaussian, $\mathbf{z}$ and $\mathbf{x}_2$ are also jointly Gaussian. For jointly Gaussian random vectors, zero covariance implies complete statistical independence: $$\mathbf{z} \perp \mathbf{x}_2$$ Therefore, the conditional distribution of $\mathbf{z}$ given $\mathbf{x}_2$ is identical to its unconditional marginal distribution: $$P(\mathbf{z} \mid \mathbf{x}_2) = P(\mathbf{z})$$

Step 3: Compute Mean and Covariance of $\mathbf{z}$: $$\boldsymbol{\mu}_z = \mathbb{E}[\mathbf{z}] = \mathbb{E}[\mathbf{x}_1] - \boldsymbol{\Sigma}_{12} \boldsymbol{\Sigma}_{22}^{-1} \mathbb{E}[\mathbf{x}_2] = \boldsymbol{\mu}_1 - \boldsymbol{\Sigma}_{12} \boldsymbol{\Sigma}_{22}^{-1} \boldsymbol{\mu}_2$$ $$\boldsymbol{\Sigma}_z = \text{Var}(\mathbf{z}) = \text{Var}(\mathbf{x}_1 - \mathbf{A}\mathbf{x}_2) = \text{Var}(\mathbf{x}_1) + \mathbf{A} \text{Var}(\mathbf{x}_2) \mathbf{A}^T - \mathbf{A} \text{Cov}(\mathbf{x}_2, \mathbf{x}_1) - \text{Cov}(\mathbf{x}_1, \mathbf{x}_2) \mathbf{A}^T$$ Substitute $\mathbf{A} = \boldsymbol{\Sigma}_{12} \boldsymbol{\Sigma}_{22}^{-1}$ and note $\text{Cov}(\mathbf{x}_2, \mathbf{x}_1) = \boldsymbol{\Sigma}_{21} = \boldsymbol{\Sigma}_{12}^T$: $$\boldsymbol{\Sigma}_z = \boldsymbol{\Sigma}_{11} + (\boldsymbol{\Sigma}_{12} \boldsymbol{\Sigma}_{22}^{-1}) \boldsymbol{\Sigma}_{22} (\boldsymbol{\Sigma}_{22}^{-1} \boldsymbol{\Sigma}_{21}) - 2 \boldsymbol{\Sigma}_{12} \boldsymbol{\Sigma}_{22}^{-1} \boldsymbol{\Sigma}_{21}$$ $$\boldsymbol{\Sigma}_z = \boldsymbol{\Sigma}_{11} + \boldsymbol{\Sigma}_{12} \boldsymbol{\Sigma}_{22}^{-1} \boldsymbol{\Sigma}_{21} - 2 \boldsymbol{\Sigma}_{12} \boldsymbol{\Sigma}_{22}^{-1} \boldsymbol{\Sigma}_{21} = \boldsymbol{\Sigma}_{11} - \boldsymbol{\Sigma}_{12} \boldsymbol{\Sigma}_{22}^{-1} \boldsymbol{\Sigma}_{21}$$

Step 4: Recover the Conditional Distribution of $\mathbf{x}_1 \mid \mathbf{x}_2$:
Since $\mathbf{x}_1 = \mathbf{z} + \boldsymbol{\Sigma}_{12} \boldsymbol{\Sigma}_{22}^{-1} \mathbf{x}_2$, and $\mathbf{x}_2$ is treated as a fixed constant condition: $$\mathbb{E}[\mathbf{x}_1 \mid \mathbf{x}_2] = \mathbb{E}[\mathbf{z} \mid \mathbf{x}_2] + \boldsymbol{\Sigma}_{12} \boldsymbol{\Sigma}_{22}^{-1} \mathbf{x}_2 = \boldsymbol{\mu}_z + \boldsymbol{\Sigma}_{12} \boldsymbol{\Sigma}_{22}^{-1} \mathbf{x}_2$$ $$\boldsymbol{\mu}_{1|2} = \boldsymbol{\mu}_1 + \boldsymbol{\Sigma}_{12} \boldsymbol{\Sigma}_{22}^{-1} (\mathbf{x}_2 - \boldsymbol{\mu}_2)$$ $$\boldsymbol{\Sigma}_{1|2} = \text{Var}(\mathbf{x}_1 \mid \mathbf{x}_2) = \text{Var}(\mathbf{z} \mid \mathbf{x}_2) = \boldsymbol{\Sigma}_z = \boldsymbol{\Sigma}_{11} - \boldsymbol{\Sigma}_{12} \boldsymbol{\Sigma}_{22}^{-1} \boldsymbol{\Sigma}_{21}$$ Q.E.D. The conditional distribution of a multivariate Gaussian is Gaussian, with mean shifted linearly by the residual $(\mathbf{x}_2 - \boldsymbol{\mu}_2)$ and covariance reduced by the Schur complement $\boldsymbol{\Sigma}_{12} \boldsymbol{\Sigma}_{22}^{-1} \boldsymbol{\Sigma}_{21}$!

import numpy as np

def simulate_bayesian_coin(true_bias=0.7, n_flips=1000):
    """
    Demonstrates Beta-Binomial conjugate Bayesian belief updating.
    Prior: Beta(alpha=1, beta=1) (Uniform prior)
    """
    np.random.seed(42)
    flips = np.random.binomial(n=1, p=true_bias, size=n_flips)

    alpha_prior, beta_prior = 1.0, 1.0 # Prior: completely uninformative
    
    # Observe flips sequentially
    heads = np.sum(flips)
    tails = n_flips - heads

    alpha_posterior = alpha_prior + heads
    beta_posterior = beta_prior + tails

    # Posterior Mean Estimate: E[theta] = alpha / (alpha + beta)
    estimated_bias = alpha_posterior / (alpha_posterior + beta_posterior)
    mle_bias = heads / n_flips

    print(f"True Probability   : {true_bias:.4f}")
    print(f"Observed Flips     : {n_flips} ({heads} Heads, {tails} Tails)")
    print(f"MLE Estimate       : {mle_bias:.4f}")
    print(f"Bayesian Posterior : {estimated_bias:.4f}")

if __name__ == "__main__":
    simulate_bayesian_coin(true_bias=0.7, n_flips=5000)

1. Quantifying Uncertainty: Surprise & Entropy

Before Claude Shannon published A Mathematical Theory of Communication in 1948, the concept of "information" was subjective, intuitive, and mathematically unquantifiable. Shannon established information theory as a rigorous mathematical science by defining the fundamental atom of uncertainty: Self-Information (Surprise).

The Axiomatic Derivation of Surprise

Consider an event $x$ with probability $P(x) \in [0, 1]$. How much information is revealed when $x$ occurs? Shannon demanded that a valid measure of surprise $I(x)$ satisfy four intuitive axioms:

  1. Non-negativity: Receiving information can never make us less informed: $I(x) \ge 0$.
  2. Certainty conveys Zero Information: If an event is guaranteed to happen ($P(x) = 1$), observing it reveals zero surprise: $I(x) = 0$. (e.g., Telling someone "the sun will rise tomorrow" conveys 0 bits).
  3. Monotonicity with Rarity: An uncommon event carries strictly more information than a common event: If $P(x_1) < P(x_2)$, then $I(x_1) > I(x_2)$.
  4. Additivity for Independent Events: If two statistically independent events $x$ and $y$ occur ($P(x, y) = P(x)P(y)$), the total surprise should be the sum of individual surprises: $I(x, y) = I(x) + I(y)$.

The only continuous mathematical function satisfying $f(u \cdot v) = f(u) + f(v)$ is the logarithm. Combined with the requirement that surprise decreases as probability increases, we obtain the unique definition of Shannon Surprise:

$$I(x) = -\log_b P(x) = \log_b\left(\frac{1}{P(x)}\right)$$
  • If base $b = 2$, surprise is measured in bits (shannons). One bit represents the uncertainty resolved by a fair coin flip ($-\log_2(0.5) = 1 \text{ bit}$).
  • If base $b = e$, surprise is measured in nats ($1 \text{ nat} = \frac{1}{\ln 2} \approx 1.4427 \text{ bits}$). Standard deep learning frameworks (PyTorch, TensorFlow) compute loss in nats.
  • If base $b = 10$, surprise is measured in hartleys (dits).

Shannon Entropy

The Shannon Entropy $H(P)$ of a discrete random variable $X$ is the expected value of surprise across its entire probability distribution $P$:

$$H(P) = \mathbb{E}_{x \sim P}[I(x)] = -\sum_{x \in \mathcal{X}} P(x) \log_2 P(x)$$

By convention, if $P(x) = 0$, we define $0 \log_2(0) = \lim_{p \to 0^+} p \log_2(p) = 0$ by L'Hôpital's rule.

Fundamental Bounds on Discrete Entropy:
For any discrete distribution with $K = |\mathcal{X}|$ distinct outcomes:

$$0 \le H(P) \le \log_2(K)$$
  • Deterministic Minimum ($H = 0$): If $P(x_1) = 1$ and $P(x_i) = 0$ for all $i \neq 1$, there is zero uncertainty. Outcome is completely predictable.
  • Uniform Maximum ($H = \log_2 K$): Uncertainty is maximized when all outcomes are equally probable: $P(x_i) = 1/K$. For an 8-sided fair die, $H = \log_2(8) = 3 \text{ bits}$.
Entropy represents the absolute theoretical limit of lossless data compression (Shannon's Source Coding Theorem): no code can compress a source to fewer than $H(P)$ bits per symbol on average!

Joint, Conditional, and Differential Entropy

Entropy extends naturally to systems of multiple random variables:

  • Joint Entropy $H(X, Y)$: Total uncertainty contained in the pair $(X, Y)$: $$H(X, Y) = -\sum_{x \in \mathcal{X}} \sum_{y \in \mathcal{Y}} P(x, y) \log_2 P(x, y)$$
  • Conditional Entropy $H(Y \mid X)$: The remaining uncertainty in $Y$ after observing $X$: $$H(Y \mid X) = \sum_{x \in \mathcal{X}} P(x) H(Y \mid X = x) = -\sum_{x \in \mathcal{X}} \sum_{y \in \mathcal{Y}} P(x, y) \log_2 P(y \mid x)$$
  • Chain Rule of Entropy: Total uncertainty decomposes as: $$H(X, Y) = H(X) + H(Y \mid X) = H(Y) + H(X \mid Y)$$
  • Differential Entropy (Continuous Variables): For a continuous random variable with PDF $f(x)$: $$h(X) = -\int_{-\infty}^\infty f(x) \ln f(x) \, dx$$ Critical Warning: Unlike discrete entropy, differential entropy $h(X)$ can be negative! For example, for a uniform distribution $U(0, a)$, $h(X) = \ln(a)$. If $a = 0.1$, $h(X) = \ln(0.1) \approx -2.30 \text{ nats}$. Differential entropy measures relative coordinate volume, not absolute bits of information.

2. Cross-Entropy & Kullback-Leibler (KL) Divergence

In machine learning, we have a true data distribution $P$ (e.g., empirical training labels) and a model's predicted distribution $Q_\theta$ (e.g., neural network softmax probabilities). How do we quantify the exact statistical divergence between what reality is ($P$) and what our model predicts ($Q$)?

Kullback-Leibler (KL) Divergence (Relative Entropy)

The KL Divergence $D_{\text{KL}}(P \parallel Q)$ measures the excess expected surprise incurred when encoding events distributed according to true distribution $P$ using an optimal compression code designed for model distribution $Q$:

$$D_{\text{KL}}(P \parallel Q) = \sum_{x \in \mathcal{X}} P(x) \log\left(\frac{P(x)}{Q(x)}\right) = \sum_{x \in \mathcal{X}} P(x) \log P(x) - \sum_{x \in \mathcal{X}} P(x) \log Q(x)$$

Notice the two terms: the first term is the negative entropy of the true distribution $-H(P)$, and the second term is defined as the Cross-Entropy $H(P, Q)$:

$$H(P, Q) = -\sum_{x \in \mathcal{X}} P(x) \log Q(x)$$

This yields the fundamental decomposition of information theory:

$$D_{\text{KL}}(P \parallel Q) = H(P, Q) - H(P) \implies H(P, Q) = H(P) + D_{\text{KL}}(P \parallel Q)$$

🏆 Why Neural Networks Minimize Cross-Entropy

In supervised learning, true targets $P$ are empirical constants fixed in the training dataset ($H(P)$ is a constant with respect to neural network weights $\theta$). Therefore:

$$\arg\min_\theta H(P, Q_\theta) \equiv \arg\min_\theta \left[ H(P) + D_{\text{KL}}(P \parallel Q_\theta) \right] \equiv \arg\min_\theta D_{\text{KL}}(P \parallel Q_\theta)$$

Minimizing cross-entropy loss is mathematically identical to minimizing the KL divergence between model predictions and ground truth! When cross-entropy equals entropy ($H(P, Q) = H(P)$), the model achieves perfection ($D_{\text{KL}} = 0$).

The Asymmetry of KL: Forward KL vs. Reverse KL

KL Divergence is not a metric distance because it violates symmetry ($D_{\text{KL}}(P \parallel Q) \neq D_{\text{KL}}(Q \parallel P)$) and the triangle inequality. This asymmetry creates two fundamentally distinct optimization behaviors in modern AI:

Property Forward KL: $D_{\text{KL}}(P \parallel Q) = \mathbb{E}_{P}\left[\ln \frac{P}{Q}\right]$ Reverse KL: $D_{\text{KL}}(Q \parallel P) = \mathbb{E}_{Q}\left[\ln \frac{Q}{P}\right]$
Penalty Behavior Zero-Avoiding (Mode-Covering): If $P(x) > 0$ but $Q(x) \to 0$, $P \ln(P/Q) \to \infty$. $Q$ is violently penalized for having zero probability where data exists. Zero-Forcing (Mode-Seeking): If $P(x) = 0$ but $Q(x) > 0$, $Q \ln(Q/P) \to \infty$. $Q$ is violently penalized for placing probability mass where data does not exist.
Fit on Multimodal $P$ $Q$ stretches out to cover all modes of $P$, placing probability mass in between modes (diffuse, over-dispersed). $Q$ collapses onto a single sharp mode of $P$, completely ignoring other modes (under-dispersed, sharp).
Primary AI Use Case Supervised Deep Learning, Maximum Likelihood Estimation, Knowledge Distillation (soft-target matching). Variational Autoencoders (ELBO optimization), Diffusion reverse-time posteriors, RLHF / PPO Policy Alignment (preventing reward hacking).

Jensen-Shannon Divergence (JSD)

To eliminate the asymmetry of KL divergence and guard against infinite penalties when supports do not overlap, the Jensen-Shannon Divergence averages the KL divergence to an intermediate mixture distribution $M = \frac{1}{2}(P + Q)$:

$$\text{JSD}(P \parallel Q) = \frac{1}{2} D_{\text{KL}}(P \parallel M) + \frac{1}{2} D_{\text{KL}}(Q \parallel M)$$
  • Symmetric: $\text{JSD}(P \parallel Q) = \text{JSD}(Q \parallel P)$.
  • Strictly bounded: $0 \le \text{JSD}(P \parallel Q) \le 1 \text{ bit}$ (or $\ln 2$ nats).
  • Metric Property: The square root $\sqrt{\text{JSD}(P \parallel Q)}$ is a true mathematical distance metric obeying the triangle inequality.
  • Original GAN Objective: Goodfellow et al. (2014) proved that training an optimal discriminator under minimax loss minimizes the JSD between data distribution $P_{\text{data}}$ and generator distribution $P_G$!

3. Mutual Information, Channel Capacity & Perplexity

Mutual Information (Information Gain)

The Mutual Information $I(X; Y)$ quantifies how much information one random variable conveys about another—or equivalently, the reduction in uncertainty of $X$ given knowledge of $Y$:

$$I(X; Y) = H(X) - H(X \mid Y) = H(Y) - H(Y \mid X) = H(X) + H(Y) - H(X, Y)$$

Expressed as a KL divergence:

$$I(X; Y) = D_{\text{KL}}\left( P(X, Y) \parallel P(X)P(Y) \right) = \sum_{x, y} P(x, y) \log\left( \frac{P(x, y)}{P(x)P(y)} \right)$$

Properties of Mutual Information:

  • Symmetric: $I(X; Y) = I(Y; X) \ge 0$.
  • $I(X; Y) = 0$ if and only if $X \perp Y$ are completely independent.
  • $I(X; X) = H(X)$: The mutual information of a variable with itself is its Shannon entropy (self-information).
  • Data Processing Inequality (DPI): For any Markov chain $X \to Y \to Z$, $I(X; Z) \le I(X; Y)$. No post-processing or neural network transformation of representations can create new information about input $X$!

Language Model Perplexity ($\text{PPL}$)

In Large Language Models, cross-entropy loss over a sequence of $T$ tokens is computed as $\mathcal{L} = -\frac{1}{T} \sum_{t=1}^T \ln P(w_t \mid w_{Perplexity:

$$\text{PPL} = \exp(\mathcal{L}) = e^{\mathcal{L}} \quad (\text{if using base } e), \qquad \text{PPL} = 2^{H(P, Q)} \quad (\text{if using base } 2)$$

Intuition of Perplexity: Perplexity represents the effective branching factor of the language model. A perplexity of $15.0$ means that at each token prediction, the model is as uncertain as if it were choosing uniformly at random among $15$ equally probable words. A perfect model that predicts every token with $100\%$ certainty has $\text{PPL} = 1.0$.

Step 1: Write the Negative KL Divergence: $$-D_{\text{KL}}(P \parallel Q) = -\sum_{x \in \mathcal{X}} P(x) \ln\left(\frac{P(x)}{Q(x)}\right) = \sum_{x \in \mathcal{X}} P(x) \ln\left(\frac{Q(x)}{P(x)}\right)$$ In expectation notation: $$-D_{\text{KL}}(P \parallel Q) = \mathbb{E}_{x \sim P}\left[ \ln\left(\frac{Q(x)}{P(x)}\right) \right]$$

Step 2: Apply Jensen's Inequality:
The natural logarithm function $f(t) = \ln(t)$ is strictly concave on $(0, \infty)$ because its second derivative is strictly negative: $f''(t) = -\frac{1}{t^2} < 0$.
By Jensen's Inequality for strictly concave functions: $$\mathbb{E}[f(T)] \le f(\mathbb{E}[T])$$ Let $T = \frac{Q(x)}{P(x)}$. Applying the inequality: $$\mathbb{E}_{x \sim P}\left[ \ln\left(\frac{Q(x)}{P(x)}\right) \right] \le \ln\left( \mathbb{E}_{x \sim P}\left[\frac{Q(x)}{P(x)}\right] \right)$$

Step 3: Evaluate the Inner Expectation: $$\mathbb{E}_{x \sim P}\left[\frac{Q(x)}{P(x)}\right] = \sum_{x \in \mathcal{X}} P(x) \frac{Q(x)}{P(x)} = \sum_{x \in \mathcal{X}} Q(x) = 1$$ Therefore: $$-D_{\text{KL}}(P \parallel Q) \le \ln(1) = 0 \implies D_{\text{KL}}(P \parallel Q) \ge 0$$

Step 4: Strict Equality Condition:
Because $f(t) = \ln(t)$ is strictly concave, equality holds in Jensen's inequality if and only if the random variable $T$ is degenerate (constant almost everywhere): $$\frac{Q(x)}{P(x)} = c \implies Q(x) = c P(x), \quad \forall x \in \mathcal{X}$$ Summing both sides over $\mathcal{X}$: $\sum Q(x) = c \sum P(x) \implies 1 = c(1) \implies c = 1$.
Therefore, $D_{\text{KL}}(P \parallel Q) = 0$ if and only if $P(x) = Q(x)$ for all $x \in \mathcal{X}$.

Step 5: Derive the Maximum Entropy Bound:
Let $Q$ be the uniform distribution over $K$ categories: $Q(x) = \frac{1}{K}$ for all $x$.
By Gibbs' inequality: $$D_{\text{KL}}(P \parallel U) = \sum_{x=1}^K P(x) \log_2\left( \frac{P(x)}{1/K} \right) \ge 0$$ $$\sum_{x=1}^K P(x) \log_2 P(x) - \sum_{x=1}^K P(x) \log_2\left(\frac{1}{K}\right) \ge 0$$ $$-H(P) - \log_2\left(\frac{1}{K}\right) \sum_{x=1}^K P(x) \ge 0 \implies -H(P) + \log_2(K)(1) \ge 0$$ $$\mathbf{H(P) \le \log_2(K)}$$ Q.E.D. import numpy as np

def compute_information_metrics(p: np.ndarray, q: np.ndarray, eps=1e-12):
    """
    Computes Shannon Entropy H(P), Cross-Entropy H(P, Q), and KL Divergence D_KL(P || Q).
    """
    p = np.clip(p / np.sum(p), eps, 1.0)
    q = np.clip(q / np.sum(q), eps, 1.0)

    # 1. Shannon Entropy: H(P) = -sum(P * log2(P))
    h_p = -np.sum(p * np.log2(p))

    # 2. Cross-Entropy: H(P, Q) = -sum(P * log2(Q))
    h_pq = -np.sum(p * np.log2(q))

    # 3. KL Divergence: D_KL(P || Q) = sum(P * log2(P / Q))
    kl_div = np.sum(p * np.log2(p / q))

    # 4. Symmetrized Jensen-Shannon Divergence: JSD = 0.5 * (KL(P||M) + KL(Q||M))
    m = 0.5 * (p + q)
    jsd = 0.5 * (np.sum(p * np.log2(p / m)) + np.sum(q * np.log2(q / m)))

    return {
        "H(P)": float(h_p),
        "H(P, Q)": float(h_pq),
        "D_KL(P || Q)": float(kl_div),
        "JSD(P, Q)": float(jsd),
        "Identity_Check": bool(np.isclose(h_pq, h_p + kl_div))
    }

if __name__ == "__main__":
    P = np.array([0.7, 0.2, 0.1])
    Q = np.array([0.5, 0.3, 0.2])
    metrics = compute_information_metrics(P, Q)
    print("Information Metrics:")
    for k, v in metrics.items():
        print(f"  {k:15s} : {v}")

1. The Geometry of Convexity

In general non-convex optimization (such as training multi-layer neural networks), finding the true global minimum is NP-hard: algorithms easily get trapped in sub-optimal local minima, meander through flat plateaus, or stall indefinitely on high-dimensional saddle points. However, in Convex Optimization, geometry guarantees that any local minimum is automatically a Global Minimum. Classical machine learning algorithms—Support Vector Machines, Logistic Regression, Lasso ($L_1$), Ridge ($L_2$), and Softmax regression—are all strictly convex optimization problems.

Convex Sets

A set $C \subseteq \mathbb{R}^d$ is convex if the line segment connecting any two arbitrary points in $C$ lies entirely within $C$:

$$\forall \mathbf{x}, \mathbf{y} \in C, \ \alpha \in [0, 1] \implies \alpha \mathbf{x} + (1 - \alpha) \mathbf{y} \in C$$

Fundamental convex sets in AI include:

  • Hyperplanes & Half-spaces: $\{\mathbf{x} \mid \mathbf{a}^T \mathbf{x} = b\}$ and $\{\mathbf{x} \mid \mathbf{a}^T \mathbf{x} \le b\}$ (linear decision boundaries).
  • Euclidean Balls & Ellipsoids: $\{\mathbf{x} \mid \|\mathbf{x} - \mathbf{x}_c\|_2 \le r\}$ and $\{\mathbf{x} \mid (\mathbf{x} - \mathbf{x}_c)^T \mathbf{P}^{-1} (\mathbf{x} - \mathbf{x}_c) \le 1\}$ ($\mathbf{P} \succ 0$).
  • The Probability Simplex: $\Delta^n = \{\mathbf{p} \in \mathbb{R}^n \mid \sum_{i=1}^n p_i = 1, \ p_i \ge 0\}$ (the space of valid categorical distributions).
  • Positive Semi-Definite Cone: $\mathbb{S}_+^n = \{\mathbf{X} \in \mathbb{R}^{n \times n} \mid \mathbf{X} = \mathbf{X}^T, \ \mathbf{z}^T \mathbf{X} \mathbf{z} \ge 0 \ \forall \mathbf{z}\}$ (the space of covariance matrices and kernel matrices).

Convex Functions

A function $f: C \to \mathbb{R}$ defined on a convex domain $C$ is convex if the chord connecting $( \mathbf{x}, f(\mathbf{x}) )$ and $( \mathbf{y}, f(\mathbf{y}) )$ lies entirely on or above the graph of $f$:

$$f(\alpha \mathbf{x} + (1 - \alpha) \mathbf{y}) \le \alpha f(\mathbf{x}) + (1 - \alpha) f(\mathbf{y}), \quad \forall \mathbf{x}, \mathbf{y} \in C, \ \alpha \in [0, 1]$$

Equivalently, a function is convex if and only if its Epigraph $\text{epi}(f) = \{(\mathbf{x}, t) \in \mathbb{R}^{d+1} \mid f(\mathbf{x}) \le t\}$ is a convex set.

First- and Second-Order Conditions for Convexity:

  • First-Order Condition (Global Underestimator): A continuously differentiable function $f$ is convex if and only if its first-order Taylor expansion forms a global lower bound everywhere: $$f(\mathbf{y}) \ge f(\mathbf{x}) + \nabla f(\mathbf{x})^T (\mathbf{y} - \mathbf{x}), \quad \forall \mathbf{x}, \mathbf{y} \in C$$ Geometric Meaning: The tangent hyperplane to a convex function always lies completely below the function graph!
  • Second-Order Condition (Positive Semi-Definite Curvature): A twice-differentiable function $f$ is convex if and only if its Hessian matrix is positive semi-definite everywhere: $$\nabla^2 f(\mathbf{x}) \succeq 0 \quad (\mathbf{z}^T \nabla^2 f(\mathbf{x}) \mathbf{z} \ge 0, \ \forall \mathbf{z} \in \mathbb{R}^d, \ \mathbf{x} \in C)$$
  • Strong Convexity: $f$ is $m$-strongly convex ($m > 0$) if $\nabla^2 f(\mathbf{x}) \succeq m \mathbf{I}$. Strongly convex functions have quadratic curvature bounded from below, guaranteeing unique global minima and linear convergence rates $\mathcal{O}((1 - m/L)^k)$ for gradient descent!

2. Constrained Optimization & Lagrange Duality

In production AI engineering, we rarely optimize objectives in an unconstrained vacuum: inference latency must be $\le 20\text{ms}$, model weight norms must be $\le C$, probabilities must sum to $1.0$. A standard mathematical optimization problem is formulated as:

$$\min_{\mathbf{x}} f_0(\mathbf{x}) \quad \text{subject to } \begin{cases} f_i(\mathbf{x}) \le 0, & i = 1, \dots, m \quad (\text{Inequality Constraints}) \\ h_j(\mathbf{x}) = 0, & j = 1, \dots, p \quad (\text{Equality Constraints}) \end{cases}$$

where $f_0, f_i, h_j: \mathbb{R}^d \to \mathbb{R}$. The set of all $\mathbf{x}$ satisfying all $m+p$ constraints is called the Feasible Set $\mathcal{D}_{\text{feas}}$. The primal optimal value is denoted $p^* = \min_{\mathbf{x} \in \mathcal{D}_{\text{feas}}} f_0(\mathbf{x})$.

The Lagrangian Function & Dual Problem

We incorporate constraints directly into the objective by defining the Lagrangian $\mathcal{L}: \mathbb{R}^d \times \mathbb{R}^m \times \mathbb{R}^p \to \mathbb{R}$ with Lagrange multiplier vectors $\boldsymbol{\lambda} \in \mathbb{R}^m$ (with $\lambda_i \ge 0$) and $\boldsymbol{\nu} \in \mathbb{R}^p$:

$$\mathcal{L}(\mathbf{x}, \boldsymbol{\lambda}, \boldsymbol{\nu}) = f_0(\mathbf{x}) + \sum_{i=1}^m \lambda_i f_i(\mathbf{x}) + \sum_{j=1}^p \nu_j h_j(\mathbf{x})$$

The Lagrange Dual Function $g(\boldsymbol{\lambda}, \boldsymbol{\nu})$ is the infimum of the Lagrangian over all primal variables $\mathbf{x}$:

$$g(\boldsymbol{\lambda}, \boldsymbol{\nu}) = \inf_{\mathbf{x} \in \mathcal{D}} \mathcal{L}(\mathbf{x}, \boldsymbol{\lambda}, \boldsymbol{\nu}) = \inf_{\mathbf{x} \in \mathcal{D}} \left[ f_0(\mathbf{x}) + \sum_{i=1}^m \lambda_i f_i(\mathbf{x}) + \sum_{j=1}^p \nu_j h_j(\mathbf{x}) \right]$$

🏆 Fundamental Properties of Lagrange Duality

  1. Universal Concavity of the Dual: The dual function $g(\boldsymbol{\lambda}, \boldsymbol{\nu})$ is the pointwise infimum of a family of affine functions in $(\boldsymbol{\lambda}, \boldsymbol{\nu})$. Therefore, $g(\boldsymbol{\lambda}, \boldsymbol{\nu})$ is ALWAYS concave, even if the primal objective $f_0$ and constraints $f_i$ are wildly non-convex! Maximizing the dual is always a convex optimization problem!
  2. Weak Duality ($d^* \le p^*$): For any feasible primal $\tilde{\mathbf{x}}$ and dual feasible $(\boldsymbol{\lambda} \ge 0, \boldsymbol{\nu})$, $g(\boldsymbol{\lambda}, \boldsymbol{\nu}) \le f_0(\tilde{\mathbf{x}})$. The maximum of the dual $d^* = \max_{\boldsymbol{\lambda} \ge 0, \boldsymbol{\nu}} g(\boldsymbol{\lambda}, \boldsymbol{\nu})$ is always a lower bound on the primal optimum: $$d^* \le p^*$$ The non-negative difference $(p^* - d^*) \ge 0$ is the Duality Gap.
  3. Strong Duality & Slater's Condition ($d^* = p^*$): If $p^* = d^*$, the duality gap is zero. For convex optimization problems, strong duality holds if Slater's Condition is satisfied: there exists at least one strictly feasible point $\mathbf{x} \in \text{relint}(\mathcal{D})$ such that: $$f_i(\mathbf{x}) < 0 \quad (\forall i = 1, \dots, m), \qquad h_j(\mathbf{x}) = 0 \quad (\forall j = 1, \dots, p)$$

3. The Karush-Kuhn-Tucker (KKT) Optimality Conditions

When strong duality holds and functions are differentiable, the primal optimal point $\mathbf{x}^*$ and dual optimal points $(\boldsymbol{\lambda}^*, \boldsymbol{\nu}^*)$ must satisfy four necessary conditions established by Harold W. Kuhn and Albert W. Tucker (1951) and William Karush (1939):

The 4 KKT Conditions

  1. Stationarity: The gradient of the Lagrangian with respect to primal variables vanishes: $$\nabla_{\mathbf{x}} \mathcal{L}(\mathbf{x}^*, \boldsymbol{\lambda}^*, \boldsymbol{\nu}^*) = \nabla f_0(\mathbf{x}^*) + \sum_{i=1}^m \lambda_i^* \nabla f_i(\mathbf{x}^*) + \sum_{j=1}^p \nu_j^* \nabla h_j(\mathbf{x}^*) = \mathbf{0}$$
  2. Primal Feasibility: The optimal point must satisfy all original constraints: $$f_i(\mathbf{x}^*) \le 0 \quad (\forall i=1,\dots,m), \qquad h_j(\mathbf{x}^*) = 0 \quad (\forall j=1,\dots,p)$$
  3. Dual Feasibility: Inequality multipliers must be non-negative: $$\lambda_i^* \ge 0 \quad (\forall i=1,\dots,m)$$
  4. Complementary Slackness: The product of multiplier and constraint is identically zero: $$\lambda_i^* f_i(\mathbf{x}^*) = 0 \quad (\forall i=1,\dots,m)$$

The Power of Complementary Slackness in Machine Learning

Condition 4 enforces that for every inequality constraint $i \in \{1, \dots, m\}$:

$$\text{Either } \lambda_i^* = 0 \quad \text{OR} \quad f_i(\mathbf{x}^*) = 0$$
  • Inactive Constraint ($f_i(\mathbf{x}^*) < 0$): The point lies strictly inside the constraint boundary. By complementary slackness, its multiplier must be zero ($\lambda_i^* = 0$). The constraint has zero influence on the solution.
  • Active Constraint ($f_i(\mathbf{x}^*) = 0$): The solution is pinned against the boundary wall, with multiplier $\lambda_i^* \ge 0$ representing the marginal shadow price / force exerted by the boundary.

The SVM Support Vector Revelation: In Support Vector Machines, $f_i(\mathbf{w}, b) = 1 - y_i(\mathbf{w}^T \mathbf{x}_i + b) \le 0$. For any training sample correctly classified outside the margin ($y_i(\mathbf{w}^T \mathbf{x}_i + b) > 1$), complementary slackness forces $\alpha_i^* = 0$! Only the tiny fraction of data points sitting directly on the margin boundary ($y_i(\mathbf{w}^T \mathbf{x}_i + b) = 1$) have $\alpha_i^* > 0$. These points are the Support Vectors—all other training points can be deleted from memory without changing the model!

Problem 1.5.5 Hard Google Brain Meta FAIR

QUESTION: In a Hard-Margin Support Vector Machine, we seek an optimal separating hyperplane $(\mathbf{w}, b)$ that separates two classes $\{(\mathbf{x}_i, y_i)\}_{i=1}^N$ ($y_i \in \{-1, +1\}$) with maximum geometric margin $\frac{2}{\|\mathbf{w}\|_2}$. This is formulated as the convex primal quadratic program:

$$\min_{\mathbf{w}, b} \frac{1}{2} \|\mathbf{w}\|_2^2 \quad \text{subject to } 1 - y_i(\mathbf{w}^T \mathbf{x}_i + b) \le 0, \quad \forall i=1,\dots,N$$
  1. Formulate the Lagrangian $\mathcal{L}(\mathbf{w}, b, \boldsymbol{\alpha})$ using dual multipliers $\alpha_i \ge 0$.
  2. Apply the KKT stationarity conditions to derive $\mathbf{w}^*$ in terms of $\boldsymbol{\alpha}$ and obtain the linear equality constraint on $\boldsymbol{\alpha}$.
  3. Substitute these back into the Lagrangian to eliminate all primal variables, deriving the complete Dual Optimization Problem.
  4. Explain how this dual derivation enables the Kernel Trick and why complementary slackness ensures mathematical sparsity.
✓ Complete Step-by-Step Mathematical Derivation

Step 1: Formulate the Lagrangian:
Associate a Lagrange multiplier $\alpha_i \ge 0$ with each of the $N$ inequality constraints: $$\mathcal{L}(\mathbf{w}, b, \boldsymbol{\alpha}) = \frac{1}{2} \|\mathbf{w}\|_2^2 + \sum_{i=1}^N \alpha_i \left[ 1 - y_i (\mathbf{w}^T \mathbf{x}_i + b) \right]$$ Expand the summation: $$\mathcal{L}(\mathbf{w}, b, \boldsymbol{\alpha}) = \frac{1}{2} \mathbf{w}^T \mathbf{w} + \sum_{i=1}^N \alpha_i - \sum_{i=1}^N \alpha_i y_i (\mathbf{w}^T \mathbf{x}_i) - b \sum_{i=1}^N \alpha_i y_i$$

Step 2: Apply KKT Stationarity Conditions:
Differentiate $\mathcal{L}$ with respect to $\mathbf{w}$ and set to $\mathbf{0}$: $$\nabla_{\mathbf{w}} \mathcal{L} = \mathbf{w} - \sum_{i=1}^N \alpha_i y_i \mathbf{x}_i = \mathbf{0} \implies \mathbf{w}^* = \sum_{i=1}^N \alpha_i y_i \mathbf{x}_i$$ Differentiate $\mathcal{L}$ with respect to $b$ and set to $0$: $$\frac{\partial \mathcal{L}}{\partial b} = -\sum_{i=1}^N \alpha_i y_i = 0 \implies \sum_{i=1}^N \alpha_i y_i = 0$$

Step 3: Substitute Back into Lagrangian:
First, since $\sum_{i=1}^N \alpha_i y_i = 0$, the bias term vanishes completely: $-b(0) = 0$.
Second, evaluate the quadratic norm of $\mathbf{w}^*$: $$\frac{1}{2} \mathbf{w}^{*T} \mathbf{w}^* = \frac{1}{2} \left( \sum_{i=1}^N \alpha_i y_i \mathbf{x}_i \right)^T \left( \sum_{j=1}^N \alpha_j y_j \mathbf{x}_j \right) = \frac{1}{2} \sum_{i=1}^N \sum_{j=1}^N \alpha_i \alpha_j y_i y_j (\mathbf{x}_i^T \mathbf{x}_j)$$ Third, evaluate the cross-term: $$-\sum_{i=1}^N \alpha_i y_i (\mathbf{w}^{*T} \mathbf{x}_i) = -\sum_{i=1}^N \sum_{j=1}^N \alpha_i \alpha_j y_i y_j (\mathbf{x}_i^T \mathbf{x}_j)$$ Combining $\frac{1}{2} \sum \sum - \sum \sum = -\frac{1}{2} \sum \sum$, the dual objective becomes: $$g(\boldsymbol{\alpha}) = \sum_{i=1}^N \alpha_i - \frac{1}{2} \sum_{i=1}^N \sum_{j=1}^N \alpha_i \alpha_j y_i y_j (\mathbf{x}_i^T \mathbf{x}_j)$$ This yields the famous SVM Dual Optimization Problem: $$\max_{\boldsymbol{\alpha}} \left[ \sum_{i=1}^N \alpha_i - \frac{1}{2} \sum_{i=1}^N \sum_{j=1}^N \alpha_i \alpha_j y_i y_j (\mathbf{x}_i \cdot \mathbf{x}_j) \right]$$ $$\text{subject to } \alpha_i \ge 0 \quad (\forall i=1,\dots,N), \qquad \sum_{i=1}^N \alpha_i y_i = 0$$

Step 4: The Kernel Trick & Complementary Slackness:

  • The Kernel Trick: Notice that input features $\mathbf{x}_i$ appear strictly as inner products $\mathbf{x}_i^T \mathbf{x}_j$. We can replace $\mathbf{x}_i^T \mathbf{x}_j$ with an arbitrary positive definite kernel function $K(\mathbf{x}_i, \mathbf{x}_j) = \phi(\mathbf{x}_i)^T \phi(\mathbf{x}_j)$ (e.g. Gaussian RBF $e^{-\gamma \|\mathbf{x}_i - \mathbf{x}_j\|^2}$). This maps data into an infinite-dimensional feature space without ever calculating or storing high-dimensional vectors!
  • Sparsity via Complementary Slackness: $\alpha_i [1 - y_i(\mathbf{w}^T \mathbf{x}_i + b)] = 0$. For any point correctly placed outside the margin ($y_i(\mathbf{w}^T \mathbf{x}_i + b) > 1$), $\alpha_i = 0$. Only data points lying directly on the margin boundary ($y_i(\mathbf{w}^T \mathbf{x}_i + b) = 1$) have $\alpha_i > 0$. These are the Support Vectors. In practice, $90\text{--}99\%$ of $\alpha_i$ are exact zeros!

Problem 1.5.6 Hard Apple Qualcomm

QUESTION: In multi-channel wireless communication and GPU resource scheduling, we allocate total power $P$ across $n$ independent parallel channels with noise power levels $\sigma_1^2, \dots, \sigma_n^2$ to maximize total Shannon channel capacity:

$$\max_{p_1, \dots, p_n} \sum_{i=1}^n \frac{1}{2} \ln\left( 1 + \frac{p_i}{\sigma_i^2} \right) \quad \text{subject to } \sum_{i=1}^n p_i \le P, \quad p_i \ge 0 \quad (\forall i=1,\dots,n)$$
  1. Use the KKT conditions to derive the famous Water-Filling Algorithm solution: $$p_i^* = \max\left(0, \ \frac{1}{\nu^*} - \sigma_i^2\right)$$ where $1/\nu^*$ is the equilibrium "water level".
  2. For $n = 3$ channels with noise variances $\boldsymbol{\sigma}^2 = [1.0, 2.0, 5.0]$ and total available power $P = 5.0$, solve numerically for the exact water level $1/\nu^*$ and optimal power allocations $p_1^*, p_2^*, p_3^*$.
✓ Complete Step-by-Step Mathematical & Numerical Solution

Step 1: KKT Derivation of Water-Filling:
Convert to minimization: $\min \sum_{i=1}^n -\frac{1}{2} \ln(1 + p_i/\sigma_i^2)$ subject to $\sum p_i - P \le 0$ and $-p_i \le 0$.
Lagrangian with multipliers $\nu \ge 0$ and $\lambda_i \ge 0$: $$\mathcal{L}(\mathbf{p}, \nu, \boldsymbol{\lambda}) = -\frac{1}{2} \sum_{i=1}^n \ln\left(1 + \frac{p_i}{\sigma_i^2}\right) + \nu \left(\sum_{i=1}^n p_i - P\right) - \sum_{i=1}^n \lambda_i p_i$$ KKT Stationarity with respect to $p_i$: $$\frac{\partial \mathcal{L}}{\partial p_i} = -\frac{1}{2} \cdot \frac{1/\sigma_i^2}{1 + p_i/\sigma_i^2} + \nu - \lambda_i = -\frac{1}{2(\sigma_i^2 + p_i)} + \nu - \lambda_i = 0$$ $$\lambda_i = \nu - \frac{1}{2(\sigma_i^2 + p_i)}$$ By complementary slackness $\lambda_i p_i = 0$ and dual feasibility $\lambda_i \ge 0$:

  • If channel $i$ receives positive power ($p_i > 0$), then $\lambda_i = 0 \implies \frac{1}{2(\sigma_i^2 + p_i)} = \nu \implies p_i = \frac{1}{2\nu} - \sigma_i^2$.
  • If channel $i$ receives zero power ($p_i = 0$), then $\lambda_i \ge 0 \implies \nu \ge \frac{1}{2\sigma_i^2} \implies \frac{1}{2\nu} \le \sigma_i^2$.
Defining the water level $W = \frac{1}{2\nu}$: $$p_i^* = \max(0, \ W - \sigma_i^2)$$ where $W$ is chosen such that total power constraint is satisfied: $\sum_{i=1}^n \max(0, W - \sigma_i^2) = P$.

Step 2: Numerical Solution for $\boldsymbol{\sigma}^2 = [1.0, 2.0, 5.0]$ and $P = 5.0$:
Sort noise levels in ascending order: $\sigma_1^2 = 1.0, \ \sigma_2^2 = 2.0, \ \sigma_3^2 = 5.0$.
Hypothesis 1: Assume all 3 channels are active ($p_1, p_2, p_3 > 0$): $$(W - 1.0) + (W - 2.0) + (W - 5.0) = 5.0 \implies 3W - 8.0 = 5.0 \implies 3W = 13.0 \implies W = \frac{13}{3} \approx 4.333$$ Check channel 3: $p_3 = W - \sigma_3^2 = 4.333 - 5.0 = -0.667 < 0$. Contradiction! (Channel 3 is too noisy and receives zero power: $p_3^* = 0$).
Hypothesis 2: Assume only channels 1 and 2 are active ($p_1, p_2 > 0, \ p_3 = 0$): $$(W - 1.0) + (W - 2.0) = 5.0 \implies 2W - 3.0 = 5.0 \implies 2W = 8.0 \implies \mathbf{W = 4.0}$$ Check validity: $$p_1^* = 4.0 - 1.0 = \mathbf{3.0} > 0 \quad \checkmark$$ $$p_2^* = 4.0 - 2.0 = \mathbf{2.0} > 0 \quad \checkmark$$ $$p_3^* = \max(0, 4.0 - 5.0) = \mathbf{0.0} \quad \checkmark$$ Total power check: $3.0 + 2.0 + 0.0 = 5.0 = P$. (Perfect match!).
Result: Optimal Water Level $W = 4.0$. Power allocations: $p_1^* = 3.0$, $p_2^* = 2.0$, $p_3^* = 0.0$.

QUESTION: Which of the following statements regarding Convex Optimization, Duality, and Slater's Condition is strictly mathematically FALSE?

Correct Option: C (The false statement)

Exhaustive Analysis of All Options:

  • Option C is FALSE: Convexity alone is NOT sufficient to guarantee strong duality! Strong duality requires a Constraint Qualification, most notably Slater's Condition (the existence of at least one strictly feasible interior point). For pathological convex problems (e.g. semidefinite programs with empty relative interiors), a non-zero duality gap $p^* - d^* > 0$ can and does occur.
  • Option A is TRUE: $g(\boldsymbol{\lambda}, \boldsymbol{\nu}) = \inf_{\mathbf{x}} [f_0(\mathbf{x}) + \boldsymbol{\lambda}^T \mathbf{f}(\mathbf{x}) + \boldsymbol{\nu}^T \mathbf{h}(\mathbf{x})]$. For any fixed $\mathbf{x}$, the expression inside is an affine (linear + constant) function of $(\boldsymbol{\lambda}, \boldsymbol{\nu})$. The pointwise infimum of any collection of concave/affine functions is always concave.
  • Option B is TRUE: Weak duality $d^* \le p^*$ is a universal theorem derived solely from the non-negativity of multipliers $\boldsymbol{\lambda} \ge 0$; it requires zero assumptions of convexity or smoothness.
  • Option D is TRUE: $\lambda_i^* f_i(\mathbf{x}^*) = 0$. Since $\lambda_i^* \ge 0$ and $f_i(\mathbf{x}^*) \le 0$, if $f_i(\mathbf{x}^*) < 0$, the only way for the product to be zero is $\lambda_i^* = 0$.

import numpy as np

def project_onto_simplex(v, z=1.0):
    """
    Exact Euclidean projection of vector v onto the simplex sum(w) = z, w >= 0.
    O(d log d) algorithm via sorted thresholding.
    """
    d = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - z
    ind = np.arange(1, d + 1)
    cond = u - cssv / ind > 0
    rho = ind[cond][-1]
    theta = cssv[cond][-1] / float(rho)
    return np.maximum(v - theta, 0)

def solve_constrained_allocation(returns, cov_matrix, lr=0.01, steps=200):
    """
    Minimizes risk: w^T Cov w subject to sum(w) = 1, w >= 0 (Markowitz Simplex).
    """
    d = len(returns) if returns is not None else cov_matrix.shape[0]
    w = np.ones(d) / d # Uniform initial allocation

    for step in range(steps):
        # Gradient of w^T Cov w with respect to w is: 2 * Cov * w
        grad = 2.0 * np.dot(cov_matrix, w)
        
        # Gradient step
        w_step = w - lr * grad
        
        # Euclidean projection onto simplex constraint
        w = project_onto_simplex(w_step, z=1.0)

    variance = float(np.dot(w.T, np.dot(cov_matrix, w)))
    return {"weights": w, "portfolio_variance": variance}

if __name__ == "__main__":
    Cov = np.array([[0.04, 0.01, 0.02],
                    [0.01, 0.09, 0.03],
                    [0.02, 0.03, 0.16]])
    res = solve_constrained_allocation(None, Cov)
    print("Optimal Simplex Allocation Weights:", np.round(res['weights'], 4))
    print(f"Minimized Portfolio Variance       : {res['portfolio_variance']:.6f}")
