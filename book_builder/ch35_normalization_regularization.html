Foundation • Core Pillar

1. The Signal Propagation Problem & Weight Initialization

Consider a linear layer $y = \sum_{i=1}^{n_{\text{in}}} w_i x_i$ where weights $w_i$ and inputs $x_i$ are independent random variables with zero mean ($\mathbb{E}[w_i] = 0, \mathbb{E}[x_i] = 0$). The variance of the output $y$ is:

$$\operatorname{Var}(y) = \sum_{i=1}^{n_{\text{in}}} \operatorname{Var}(w_i x_i) = \sum_{i=1}^{n_{\text{in}}} \left( \mathbb{E}[w_i^2 x_i^2] - (\mathbb{E}[w_i x_i])^2 \right) = n_{\text{in}} \operatorname{Var}(w) \operatorname{Var}(x)$$

To prevent activations from exponentially exploding or vanishing across depth, we require signal variance to be preserved: $\operatorname{Var}(y) = \operatorname{Var}(x) \implies n_{\text{in}} \operatorname{Var}(w) = 1 \implies \operatorname{Var}(w) = \frac{1}{n_{\text{in}}}$. Accounting for both the forward pass ($n_{\text{in}}$) and backward pass ($n_{\text{out}}$), Xavier (Glorot) Initialization (2010) sets:

$$\operatorname{Var}(w) = \frac{2}{n_{\text{in}} + n_{\text{out}}} \implies w \sim \mathcal{N}\left(0, \sqrt{\frac{2}{n_{\text{in}} + n_{\text{out}}}}\right)$$

🏆 Why Xavier Fails on ReLU: The Kaiming He Derivation (2015)

Xavier initialization assumes symmetric linear activations where $\mathbb{E}[x] = 0$. However, the Rectified Linear Unit (ReLU) clamps all negative inputs to zero ($\max(0, z)$). What happens to the second moment of a symmetric distribution when passed through ReLU?

$$\mathbb{E}[(\operatorname{ReLU}(z))^2] = \int_{-\infty}^0 (0)^2 p(z) dz + \int_0^\infty z^2 p(z) dz = 0 + \frac{1}{2} \int_{-\infty}^\infty z^2 p(z) dz = \mathbf{\frac{1}{2} \mathbb{E}[z^2]}$$

The Mathematical Consequence: Because ReLU zeroes out the entire negative halfplane, ReLU halves the variance of the signal at every single layer! Under Xavier initialization, after 30 layers of ReLU, the signal variance is diminished by a factor of:

$$\left(\frac{1}{2}\right)^{30} = \frac{1}{1,073,741,824} \approx 9.31 \times 10^{-10}$$

The signal is completely extinguished! To compensate for the 50% energy loss caused by ReLU, Kaiming He doubled the initialization variance:

$$\operatorname{Var}(w) = \frac{2}{n_{\text{in}}} \implies w \sim \mathcal{N}\left(0, \sqrt{\frac{2}{n_{\text{in}}}}\right)$$

2. The Normalization Taxonomy: BatchNorm, LayerNorm & RMSNorm

Even with optimal weight initialization, internal covariate shift and non-linear interactions cause activation distributions to drift during training. Normalization layers constrain activations to stable, well-conditioned manifolds.

Normalization Technique Mathematical Formula Normalization Axis Primary Production Domain
Batch Normalization (Ioffe & Szegedy, 2015) $\hat{x} = \frac{x - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}} \gamma + \beta$ Across batch dimension $N$ for each channel $(H, W)$ independently. Convolutional Neural Networks (ResNets, ConvNeXt). Fails when batch size $B \le 4$.
Layer Normalization (Ba et al., 2016) $\hat{x} = \frac{x - \mu_L}{\sqrt{\sigma_L^2 + \epsilon}} \odot \gamma + \beta$ Across feature channels $d$ for each token independently. Recurrent networks, BERT, original Transformer, ViT. Batch-size invariant.
RMSNorm (Zhang & Sennrich, 2019) $\bar{x} = \frac{x}{\operatorname{RMS}(\mathbf{x})} \odot \gamma, \quad \operatorname{RMS} = \sqrt{\frac{1}{d}\sum x_i^2 + \epsilon}$ Root mean square scaling across feature channels $d$ without mean-centering. The Universal Standard in Modern LLMs (LLaMA 2/3, Mistral, Gemma). 10–50% faster than LayerNorm.

3. Inverted Dropout (Srivastava et al., 2014)

Dropout prevents complex co-adaptation of neurons by randomly zeroing out activations with probability $p \in (0, 1)$ during training. In standard dropout, inference required multiplying all test-time weights by $(1 - p)$.

Inverted Dropout scales surviving activations by $\frac{1}{1 - p}$ during the training forward pass:

$$\tilde{h}_i = \begin{cases} \frac{h_i}{1 - p}, & \text{with probability } 1 - p \\ 0, & \text{with probability } p \end{cases}$$

Because $\mathbb{E}[\tilde{h}_i] = (1 - p) \left( \frac{h_i}{1 - p} \right) + p(0) = h_i$, the expected activation magnitude is strictly preserved during training. At inference time, dropout is disabled with zero latency overhead or weight modifications!

Problem 3.5.1 Level 1 • Direct Numerical Warm-Up Drill Google

QUESTION: A single sequence token produces a 4-dimensional activation vector: $$\mathbf{x} = [2.0, 4.0, 6.0, 8.0]^T$$ The layer uses Layer Normalization with learned gain parameters $\boldsymbol{\gamma} = [1.0, 1.0, 1.0, 1.0]^T$, learned biases $\boldsymbol{\beta} = [0.0, 0.0, 0.0, 0.0]^T$, and stability epsilon $\epsilon = 10^{-5}$.

  1. Calculate the mean $\mu$ across the feature dimensions.
  2. Calculate the variance $\sigma^2$ and standard deviation $\sqrt{\sigma^2 + \epsilon}$.
  3. Calculate the normalized output vector $\hat{\mathbf{x}} = \frac{\mathbf{x} - \mu}{\sqrt{\sigma^2 + \epsilon}} \odot \boldsymbol{\gamma} + \boldsymbol{\beta}$.
  4. Verify that $\sum_{i=1}^4 \hat{x}_i = 0$ and $\operatorname{Var}(\hat{\mathbf{x}}) = 1.0$.
✓ Complete Step-by-Step Arithmetic Solution

Step 1: Compute Feature Mean $\mu$:
$$\mu = \frac{1}{4} \sum_{i=1}^4 x_i = \frac{2.0 + 4.0 + 6.0 + 8.0}{4} = \frac{20.0}{4} = \mathbf{5.0000}$$

Step 2: Compute Variance and Standard Deviation:
Deviations from the mean:

  • $2.0 - 5.0 = -3.0 \implies (-3.0)^2 = 9.0$
  • $4.0 - 5.0 = -1.0 \implies (-1.0)^2 = 1.0$
  • $6.0 - 5.0 = +1.0 \implies (+1.0)^2 = 1.0$
  • $8.0 - 5.0 = +3.0 \implies (+3.0)^2 = 9.0$
$$\sigma^2 = \frac{9.0 + 1.0 + 1.0 + 9.0}{4} = \frac{20.0}{4} = \mathbf{5.0000}$$ Denominator: $$\sqrt{\sigma^2 + \epsilon} = \sqrt{5.0000 + 10^{-5}} \approx \sqrt{5.0} \approx \mathbf{2.23607}$$

Step 3: Compute Normalized Output Vector $\hat{\mathbf{x}}$:
With $\gamma_i = 1.0, \beta_i = 0.0$: $$\hat{x}_1 = \frac{2.0 - 5.0}{2.23607} = \frac{-3.0}{2.23607} \approx \mathbf{-1.3416}$$ $$\hat{x}_2 = \frac{4.0 - 5.0}{2.23607} = \frac{-1.0}{2.23607} \approx \mathbf{-0.4472}$$ $$\hat{x}_3 = \frac{6.0 - 5.0}{2.23607} = \frac{+1.0}{2.23607} \approx \mathbf{+0.4472}$$ $$\hat{x}_4 = \frac{8.0 - 5.0}{2.23607} = \frac{+3.0}{2.23607} \approx \mathbf{+1.3416}$$ $$\hat{\mathbf{x}} = \begin{pmatrix} -1.3416 \\ -0.4472 \\ +0.4472 \\ +1.3416 \end{pmatrix}$$

Step 4: Verification:
Sum of elements: $$\sum_{i=1}^4 \hat{x}_i = -1.3416 - 0.4472 + 0.4472 + 1.3416 = \mathbf{0.0000}$$ Variance: $$\operatorname{Var}(\hat{\mathbf{x}}) = \frac{(-1.3416)^2 + (-0.4472)^2 + (0.4472)^2 + (1.3416)^2}{4} = \frac{1.800 + 0.200 + 0.200 + 1.800}{4} = \frac{4.000}{4} = \mathbf{1.0000}$$ The activation vector is strictly standardized to zero mean and unit variance.

Problem 3.5.2 Level 1 • Direct Formula Drill Meta

QUESTION: A fully connected linear layer has $n_{\text{in}} = 784$ inputs and $n_{\text{out}} = 256$ outputs. Calculate the exact standard deviation $\sigma$ used for initializing weights under:

  1. Xavier (Glorot) Normal Initialization: $\sigma = \sqrt{\frac{2}{n_{\text{in}} + n_{\text{out}}}}$.
  2. Kaiming (He) Normal Initialization for standard ReLU ($\alpha = 0$): $\sigma = \sqrt{\frac{2}{n_{\text{in}}}}$.
  3. Kaiming Normal Initialization for LeakyReLU with negative slope $\alpha = 0.20$: $\sigma = \sqrt{\frac{2}{(1 + \alpha^2) n_{\text{in}}}}$.
✓ Complete Step-by-Step Mathematical Solution

Step 1: Xavier Normal Initialization:
$$n_{\text{in}} + n_{\text{out}} = 784 + 256 = 1040$$ $$\sigma_{\text{Xavier}} = \sqrt{\frac{2}{1040}} = \sqrt{\frac{1}{520}} \approx \sqrt{0.001923} \approx \mathbf{0.04385}$$

Step 2: Kaiming Normal Initialization (ReLU, $\alpha = 0$):
$$\sigma_{\text{Kaiming}} = \sqrt{\frac{2}{n_{\text{in}}}} = \sqrt{\frac{2}{784}} = \sqrt{\frac{1}{392}} \approx \sqrt{0.002551} \approx \mathbf{0.05051}$$ Notice that $\sigma_{\text{Kaiming}} > \sigma_{\text{Xavier}}$ because Kaiming intentionally injects higher initial variance to compensate for the $50\%$ energy loss caused by ReLU clipping.

Step 3: Kaiming Normal Initialization (LeakyReLU, $\alpha = 0.20$):
For LeakyReLU, negative inputs are multiplied by $\alpha = 0.20$: $$1 + \alpha^2 = 1 + (0.20)^2 = 1 + 0.04 = 1.04$$ $$\text{Denominator} = 1.04 \times 784 = 815.36$$ $$\sigma_{\text{LeakyReLU}} = \sqrt{\frac{2}{815.36}} \approx \sqrt{0.002453} \approx \mathbf{0.04952}$$ Because LeakyReLU allows $4\%$ of the negative energy to pass through ($\alpha^2 = 0.04$), the required initial variance compensation is slightly smaller than for pure ReLU.

Problem 3.5.3 Level 2 • Applied Engineering Trace Apple

QUESTION: A 1-dimensional Batch Normalization layer maintains running tracking statistics with momentum coefficient $m = 0.10$ (where $\mu_{\text{run}} \leftarrow (1 - m)\mu_{\text{run}} + m \mu_B$). Prior to training, running statistics are initialized at $\mu_{\text{run}}^{(0)} = 0.0$ and $\sigma^{2(0)}_{\text{run}} = 1.0$. The layer has learned parameters $\gamma = 2.0$ and $\beta = 1.0$, with $\epsilon = 10^{-5}$.

  1. A mini-batch of $N = 3$ samples arrives during training: $X = [1.0, 3.0, 5.0]^T$. Compute the batch mean $\mu_B$, batch variance $\sigma_B^2$, and the normalized training outputs $\hat{y}_i$.
  2. Compute the updated running statistics $\mu_{\text{run}}^{(1)}$ and $\sigma^{2(1)}_{\text{run}}$ after this training step.
  3. At test time, the model is switched to eval() mode. A single inference sample $x_{\text{test}} = 4.0$ arrives. Compute the final evaluation output using the running statistics.
✓ Complete Step-by-Step Training vs. Eval Trace

Step 1: Training Mode Forward Pass:
Batch mean: $$\mu_B = \frac{1.0 + 3.0 + 5.0}{3} = \frac{9.0}{3} = \mathbf{3.0000}$$ Batch variance: $$\sigma_B^2 = \frac{(1 - 3)^2 + (3 - 3)^2 + (5 - 3)^2}{3} = \frac{(-2)^2 + 0^2 + 2^2}{3} = \frac{4 + 0 + 4}{3} = \frac{8}{3} \approx \mathbf{2.6667}$$ Standard deviation $\sqrt{\sigma_B^2 + \epsilon} = \sqrt{2.6667} \approx 1.6330$.
Normalized outputs $\hat{y}_i = \gamma \left( \frac{x_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}} \right) + \beta$:

  • For $x_1 = 1.0$: $\hat{y}_1 = 2.0 \left(\frac{1.0 - 3.0}{1.6330}\right) + 1.0 = 2.0(-1.2247) + 1.0 = -2.4495 + 1.0 = \mathbf{-1.4495}$
  • For $x_2 = 3.0$: $\hat{y}_2 = 2.0 \left(\frac{3.0 - 3.0}{1.6330}\right) + 1.0 = 2.0(0) + 1.0 = \mathbf{+1.0000}$
  • For $x_3 = 5.0$: $\hat{y}_3 = 2.0 \left(\frac{5.0 - 3.0}{1.6330}\right) + 1.0 = 2.0(+1.2247) + 1.0 = +2.4495 + 1.0 = \mathbf{+3.4495}$

Step 2: Update Running Statistics:
Using momentum $m = 0.10$: $$\mu_{\text{run}}^{(1)} = (1 - 0.10)\mu_{\text{run}}^{(0)} + 0.10 \mu_B = 0.90(0.0) + 0.10(3.0) = \mathbf{0.3000}$$ $$\sigma^{2(1)}_{\text{run}} = (1 - 0.10)\sigma^{2(0)}_{\text{run}} + 0.10 \sigma_B^2 = 0.90(1.0) + 0.10(2.6667) = 0.90 + 0.2667 = \mathbf{1.1667}$$

Step 3: Inference Evaluation Mode on $x_{\text{test}} = 4.0$:
In eval() mode, the batch statistics are never used. The layer strictly uses the frozen running statistics: $$\hat{y}_{\text{test}} = \gamma \left( \frac{x_{\text{test}} - \mu_{\text{run}}^{(1)}}{\sqrt{\sigma^{2(1)}_{\text{run}} + \epsilon}} \right) + \beta$$ $$\sqrt{\sigma^{2(1)}_{\text{run}}} = \sqrt{1.1667} \approx 1.0801$$ $$\hat{y}_{\text{test}} = 2.0 \left( \frac{4.0 - 0.3000}{1.0801} \right) + 1.0 = 2.0 \left( \frac{3.7000}{1.0801} \right) + 1.0 = 2.0(3.4255) + 1.0 = 6.851 + 1.0 = \mathbf{7.851}$$

Problem 3.5.4 Level 2 • Algorithmic Tracing Amazon

QUESTION: A hidden layer activation vector is $\mathbf{h} = [1.5, -2.0, 3.5, 4.0]^T$. The model applies Inverted Dropout with dropout rate $p = 0.50$ (so survival probability is $q = 1 - p = 0.50$).

  1. Calculate the inverted scaling factor applied to active neurons during training.
  2. Suppose the pseudorandom binary mask samples $\mathbf{m} = [1, 0, 1, 0]^T$ (neurons 2 and 4 are dropped). Compute the resulting masked activation vector $\tilde{\mathbf{h}}$.
  3. Prove that the expected value of any activation $\tilde{h}_i$ under inverted dropout is identically equal to its original value: $\mathbb{E}[\tilde{h}_i] = h_i$.
  4. What scaling factor is applied during inference evaluation?
✓ Complete Step-by-Step Dropout Trace

Step 1: Compute Inverted Scaling Factor:
The scaling factor applied during training is: $$\text{Scale} = \frac{1}{1 - p} = \frac{1}{1 - 0.50} = \frac{1}{0.50} = \mathbf{2.0}$$

Step 2: Compute Masked Vector $\tilde{\mathbf{h}}$:
Multiply each element by $m_i \times \text{Scale} = m_i \times 2.0$:

  • $\tilde{h}_1 = 1.5 \times 1 \times 2.0 = \mathbf{3.0}$
  • $\tilde{h}_2 = -2.0 \times 0 \times 2.0 = \mathbf{0.0}$
  • $\tilde{h}_3 = 3.5 \times 1 \times 2.0 = \mathbf{7.0}$
  • $\tilde{h}_4 = 4.0 \times 0 \times 2.0 = \mathbf{0.0}$
$$\tilde{\mathbf{h}} = \begin{pmatrix} 3.0 \\ 0.0 \\ 7.0 \\ 0.0 \end{pmatrix}$$

Step 3: Expectation Proof:
The binary mask variable $M_i \sim \operatorname{Bernoulli}(1 - p)$. $$\tilde{h}_i = \frac{M_i}{1 - p} h_i$$ Taking expectations: $$\mathbb{E}[\tilde{h}_i] = \mathbb{E}\left[ \frac{M_i}{1 - p} h_i \right] = \frac{h_i}{1 - p} \mathbb{E}[M_i]$$ Since $\mathbb{E}[M_i] = 1 - p$: $$\mathbb{E}[\tilde{h}_i] = \frac{h_i}{1 - p} (1 - p) = \mathbf{h_i}$$ The expected energy of every activation is perfectly preserved across training.

Step 4: Inference Scaling:
At test time, the mask is removed ($\mathbf{m} = \mathbf{1}$) and the scaling factor is $1.0$ (no scaling whatsoever). Inverted dropout shifts the entire computational scaling burden to the training phase, ensuring inference executes with zero latency overhead.

Problem 3.5.5 Level 3 • FAANG / Research Lab Proof Google Meta

QUESTION: Prove Kaiming He's weight initialization theorem (2015) for deep networks with ReLU activations rigorously from first principles. Consider layer $l$ computing $y_l = \sum_{i=1}^{n_l} w_{l, i} x_{l, i}$, where $x_{l, i} = \operatorname{ReLU}(y_{l-1, i})$. Assume weights $w_{l, i}$ are i.i.d. with mean 0 and variance $\operatorname{Var}(w_l)$, independent of $x_{l, i}$, and pre-activations $y_{l-1}$ follow a symmetric distribution around zero. Prove that:

  1. $\operatorname{Var}(x_{l, i}) = \frac{1}{2} \operatorname{Var}(y_{l-1, i})$.
  2. To ensure signal variance remains constant across depth ($\operatorname{Var}(y_l) = \operatorname{Var}(y_{l-1})$), the weights must satisfy: $$\operatorname{Var}(w_l) = \frac{2}{n_l}$$
✓ Complete First-Principles Mathematical Proof

Step 1: Compute the Variance of the Pre-Activation $y_l$:
The layer computes $y_l = \sum_{i=1}^{n_l} w_{l, i} x_{l, i}$.
Since $w_{l, i}$ has mean zero ($\mathbb{E}[w] = 0$) and is independent of $x_{l, i}$: $$\mathbb{E}[y_l] = \sum_{i=1}^{n_l} \mathbb{E}[w_{l, i}] \mathbb{E}[x_{l, i}] = 0$$ The variance of $y_l$ is: $$\operatorname{Var}(y_l) = \mathbb{E}[y_l^2] - (\mathbb{E}[y_l])^2 = \mathbb{E}\left[ \left( \sum_{i=1}^{n_l} w_{l, i} x_{l, i} \right)^2 \right]$$ Because $w_{l, i} x_{l, i}$ are mutually independent for different indices $i \neq j$: $$\operatorname{Var}(y_l) = \sum_{i=1}^{n_l} \mathbb{E}[w_{l, i}^2] \mathbb{E}[x_{l, i}^2] = n_l \operatorname{Var}(w_l) \mathbb{E}[x_l^2]$$

Step 2: Relate $\mathbb{E}[x_l^2]$ to Pre-Activation Variance $\operatorname{Var}(y_{l-1})$:
Recall that $x_l = \operatorname{ReLU}(y_{l-1}) = \max(0, y_{l-1})$.
Evaluate the second moment $\mathbb{E}[x_l^2]$: $$\mathbb{E}[x_l^2] = \int_{-\infty}^\infty (\max(0, y_{l-1}))^2 p(y_{l-1}) dy_{l-1}$$ Split the integral at zero: $$\mathbb{E}[x_l^2] = \int_{-\infty}^0 (0)^2 p(y_{l-1}) dy_{l-1} + \int_0^\infty y_{l-1}^2 p(y_{l-1}) dy_{l-1} = \int_0^\infty y_{l-1}^2 p(y_{l-1}) dy_{l-1}$$ Since $p(y_{l-1})$ is a symmetric probability density centered around zero ($p(-y) = p(y)$): $$\int_0^\infty y_{l-1}^2 p(y_{l-1}) dy_{l-1} = \frac{1}{2} \int_{-\infty}^\infty y_{l-1}^2 p(y_{l-1}) dy_{l-1} = \frac{1}{2} \mathbb{E}[y_{l-1}^2]$$ Since $\mathbb{E}[y_{l-1}] = 0$, $\mathbb{E}[y_{l-1}^2] = \operatorname{Var}(y_{l-1})$. Therefore: $$\mathbb{E}[x_l^2] = \frac{1}{2} \operatorname{Var}(y_{l-1})$$

Step 3: Combine and Solve for Stable Variance:
Substitute the second moment of $x_l$ back into the variance of $y_l$: $$\operatorname{Var}(y_l) = n_l \operatorname{Var}(w_l) \left( \frac{1}{2} \operatorname{Var}(y_{l-1}) \right) = \left( \frac{1}{2} n_l \operatorname{Var}(w_l) \right) \operatorname{Var}(y_{l-1})$$ Across an $L$-layer network: $$\operatorname{Var}(y_L) = \operatorname{Var}(y_1) \prod_{l=2}^L \left( \frac{1}{2} n_l \operatorname{Var}(w_l) \right)$$ To ensure that the signal neither exponentially vanishes to zero nor explodes to infinity, the multiplier must be exactly 1: $$\frac{1}{2} n_l \operatorname{Var}(w_l) = 1 \implies \operatorname{Var}(w_l) = \frac{2}{n_l}$$ This proves Kaiming He's initialization variance formula. $\blacksquare$

Problem 3.5.6 Level 3 • FAANG / Research Lab Proof Google OpenAI

QUESTION: In modern Large Language Models (e.g. LLaMA 3), Root Mean Square Normalization (RMSNorm) is defined for vector $\mathbf{x} \in \mathbb{R}^d$ as: $$\bar{x}_i = \frac{x_i}{\operatorname{RMS}(\mathbf{x})} \gamma_i, \quad \text{where } \operatorname{RMS}(\mathbf{x}) = \sqrt{\frac{1}{d} \sum_{j=1}^d x_j^2 + \epsilon}$$ Given incoming backpropagated gradient $\mathbf{g} = \frac{\partial \mathcal{L}}{\partial \bar{\mathbf{x}}}$, derive the full vector-form analytical gradient $\frac{\partial \mathcal{L}}{\partial \mathbf{x}}$ and prove that the backpropagated error is strictly orthogonal to the forward activation vector $\mathbf{x}$.

✓ Complete First-Principles Mathematical Derivation

Step 1: Establish Forward Quantities:
Let $r = \operatorname{RMS}(\mathbf{x}) = \left(\frac{1}{d} \sum_{j=1}^d x_j^2 + \epsilon\right)^{1/2}$.
Then $\bar{x}_i = \frac{x_i}{r} \gamma_i$.
Let incoming gradient be $g_i = \frac{\partial \mathcal{L}}{\partial \bar{x}_i}$.

Step 2: Compute Partial Derivative $\frac{\partial \bar{x}_j}{\partial x_i}$:
$$\frac{\partial \bar{x}_j}{\partial x_i} = \gamma_j \frac{\partial}{\partial x_i} \left( \frac{x_j}{r} \right) = \gamma_j \left[ \frac{\delta_{ij}}{r} - \frac{x_j}{r^2} \frac{\partial r}{\partial x_i} \right]$$ Compute $\frac{\partial r}{\partial x_i}$: $$\frac{\partial r}{\partial x_i} = \frac{1}{2} \left(\frac{1}{d} \sum_{k=1}^d x_k^2 + \epsilon\right)^{-1/2} \left(\frac{2 x_i}{d}\right) = \frac{x_i}{d \cdot r}$$ Substituting: $$\frac{\partial \bar{x}_j}{\partial x_i} = \gamma_j \left[ \frac{\delta_{ij}}{r} - \frac{x_j x_i}{d \cdot r^3} \right]$$

Step 3: Sum Over All Downstream Paths:
By the chain rule: $$\frac{\partial \mathcal{L}}{\partial x_i} = \sum_{j=1}^d g_j \frac{\partial \bar{x}_j}{\partial x_i} = \sum_{j=1}^d g_j \gamma_j \left[ \frac{\delta_{ij}}{r} - \frac{x_j x_i}{d \cdot r^3} \right]$$ Splitting the sum: $$\frac{\partial \mathcal{L}}{\partial x_i} = \frac{g_i \gamma_i}{r} - \frac{x_i}{d \cdot r^3} \sum_{j=1}^d (g_j \gamma_j x_j)$$ Factoring out $\frac{1}{r}$: $$\frac{\partial \mathcal{L}}{\partial x_i} = \frac{1}{r} \left[ g_i \gamma_i - \frac{x_i}{d \cdot r^2} \sum_{j=1}^d (g_j \gamma_j x_j) \right]$$ In compact vector notation, defining $\mathbf{u} = \mathbf{g} \odot \boldsymbol{\gamma}$: $$\frac{\partial \mathcal{L}}{\partial \mathbf{x}} = \frac{1}{\operatorname{RMS}(\mathbf{x})} \left[ \mathbf{u} - \frac{\mathbf{u} \cdot \mathbf{x}}{d \cdot \operatorname{RMS}(\mathbf{x})^2} \mathbf{x} \right]$$

Step 4: Prove Orthogonality:
Take the inner product of $\frac{\partial \mathcal{L}}{\partial \mathbf{x}}$ with the forward vector $\mathbf{x}$: $$\left( \frac{\partial \mathcal{L}}{\partial \mathbf{x}} \right) \cdot \mathbf{x} = \frac{1}{r} \left[ \mathbf{u} \cdot \mathbf{x} - \frac{\mathbf{u} \cdot \mathbf{x}}{d \cdot r^2} (\mathbf{x} \cdot \mathbf{x}) \right]$$ Note that by definition: $$\mathbf{x} \cdot \mathbf{x} = \sum_{i=1}^d x_i^2 = d \cdot r^2 - d \epsilon \approx d \cdot r^2$$ Substituting $(\mathbf{x} \cdot \mathbf{x}) = d \cdot r^2$: $$\left( \frac{\partial \mathcal{L}}{\partial \mathbf{x}} \right) \cdot \mathbf{x} = \frac{1}{r} \left[ \mathbf{u} \cdot \mathbf{x} - \frac{\mathbf{u} \cdot \mathbf{x}}{d \cdot r^2} (d \cdot r^2) \right] = \frac{1}{r} [\mathbf{u} \cdot \mathbf{x} - \mathbf{u} \cdot \mathbf{x}] = \mathbf{0}$$ The gradient $\frac{\partial \mathcal{L}}{\partial \mathbf{x}}$ is strictly orthogonal to $\mathbf{x}$! This geometric property prevents activations from drifting along the radial scale dimension, ensuring intrinsic variance stability. $\blacksquare$

Problem 3.5.7 Level 4 • Conceptual Trap MCQ Google Meta

QUESTION: A computer vision team trains an object detection network using Batch Normalization with batch size $B = 128$. When deploying the model to an autonomous vehicle edge computer where camera frames are processed one-by-one in real time ($B = 1$), the model's Mean Average Precision (mAP) drops from $54\%$ to $1.2\%$ if the network is mistakenly left in training mode (model.train()). What causes this catastrophe?

  1. At batch size $B = 1$, the sample variance $\sigma_B^2 = \frac{1}{1} (x_1 - x_1)^2 = 0$. Dividing by $\sqrt{0 + \epsilon}$ multiplies activations by $1 / \sqrt{\epsilon} = 1000$, causing massive activation explosion.
  2. At $B = 1$, the GPU disables tensor cores, corrupting 16-bit floating point mantissas.
  3. BatchNorm requires $B \ge 32$ to satisfy the Central Limit Theorem; without it, the weights undergo stochastic gradient ascent.
  4. In training mode, the running mean and variance are locked, causing memory fragmentation.
✓ Correct Answer: A • Comprehensive Batch Size Dynamics Analysis

Detailed Analysis:
In training mode, Batch Normalization computes the mean and variance across the current mini-batch: $$\mu_B = \frac{1}{B} \sum_{i=1}^B x_i, \quad \sigma_B^2 = \frac{1}{B} \sum_{i=1}^B (x_i - \mu_B)^2$$ When batch size $B = 1$: $$\mu_B = x_1$$ $$\sigma_B^2 = (x_1 - x_1)^2 = \mathbf{0.0000}$$ Evaluating the normalized output: $$\hat{x}_1 = \frac{x_1 - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}} \gamma + \beta = \frac{x_1 - x_1}{\sqrt{0 + \epsilon}} \gamma + \beta = \frac{0}{\sqrt{\epsilon}} \gamma + \beta = \mathbf{\beta}$$ Notice what happens: The input $x_1$ is completely erased! The layer outputs the constant learned bias $\beta$ regardless of what image was fed into the camera!
Every single frame maps to the exact same constant feature map, completely blinding the detector and collapsing mAP to zero.
Fix:

  1. Always switch to model.eval() during inference so the network uses the frozen running statistics $(\mu_{\text{run}}, \sigma^2_{\text{run}})$.
  2. For architectures that must train with tiny micro-batches ($B \le 4$), use Group Normalization or Layer Normalization, which normalize across channel dimensions and are completely independent of batch size.

Why Other Options are False:

  • B is FALSE: Tensor cores process single vectors without corrupting registers; the issue is pure arithmetic cancellation ($x - x = 0$).
  • C is FALSE: While CLT improves estimator quality, the failure here is a deterministic mathematical identity: $\sigma_B^2 \equiv 0$ when $B=1$.
  • D is FALSE: Running statistics are updated, not locked, in training mode.

Problem 3.5.8 Level 4 • Assertion-Reasoning & Pre-LN vs Post-LN OpenAI Google

QUESTION: Evaluate the following Assertion and Reason regarding Transformer normalization architectures:

Assertion (A): Modern foundation Transformers (GPT-3, LLaMA, PaLM) strictly implement Pre-LayerNorm ($\mathbf{x}_{l+1} = \mathbf{x}_l + \operatorname{MHA}(\operatorname{LN}(\mathbf{x}_l))$) rather than the original Vaswani et al. (2017) Post-LayerNorm ($\mathbf{x}_{l+1} = \operatorname{LN}(\mathbf{x}_l + \operatorname{MHA}(\mathbf{x}_l))$) because Pre-LN stabilizes gradient propagation across 100+ layers without requiring delicate learning rate warmups.

Reason (R): In Pre-LayerNorm, the residual stream $\mathbf{x}_L = \mathbf{x}_0 + \sum_{l=1}^L f_l(\operatorname{LN}(\mathbf{x}_l))$ creates an unnormalized, clean highway where backpropagated gradients flow directly from the final layer to the initial token embeddings ($\frac{\partial \mathbf{x}_L}{\partial \mathbf{x}_0} = I + \dots$), whereas Post-LayerNorm repeatedly rescales the residual stream by compounding variance denominators, causing gradient vanishing/explosion in early layers.

  1. Both (A) and (R) are true, and (R) is the correct mathematical explanation of (A).
  2. Both (A) and (R) are true, but (R) is NOT the correct explanation of (A).
  3. (A) is true, but (R) is false.
  4. (A) is false, but (R) is true.
✓ Correct Answer: A • Comprehensive Residual Highway Analysis

Detailed Analysis:
Analysis of Post-LayerNorm (Vaswani et al., 2017):
The layer update is: $$\mathbf{x}_{l+1} = \operatorname{LN}(\mathbf{x}_l + \operatorname{SubLayer}(\mathbf{x}_l))$$ Notice that the normalization occurs after the residual addition.
Unrolling across $L$ layers: the input to layer $l$ is divided by the variance of the accumulated activations. Xiong et al. (2020) proved that in Post-LN, the gradient norm with respect to parameters in the earliest layers scales as: $$\|\nabla_{W_1} \mathcal{L}\| \propto \frac{1}{\sqrt{L}}$$ For deep Transformers ($L = 80$ or $96$), the gradient reaching the first layer is tiny. Training without a warm-up phase causes the optimizer to stall or explode because early layers cannot update effectively.

Analysis of Pre-LayerNorm (Modern Foundation Models):
The layer update is: $$\mathbf{x}_{l+1} = \mathbf{x}_l + \operatorname{SubLayer}(\operatorname{LN}(\mathbf{x}_l))$$ Unrolling this across all $L$ layers: $$\mathbf{x}_L = \mathbf{x}_0 + \sum_{l=0}^{L-1} \operatorname{SubLayer}(\operatorname{LN}(\mathbf{x}_l))$$ Differentiating $\mathbf{x}_L$ with respect to the initial embedding $\mathbf{x}_0$: $$\frac{\partial \mathbf{x}_L}{\partial \mathbf{x}_0} = I + \sum_{l=0}^{L-1} \frac{\partial \operatorname{SubLayer}(\operatorname{LN}(\mathbf{x}_l))}{\partial \mathbf{x}_0}$$ Notice the leading identity matrix $I$! The error signal from the final loss can propagate back to the input embedding in a single unattenuated step through the residual highway, completely bypassing the non-linear normalization denominators.
This guarantees that the expected gradient norm remains $O(1)$ across all depths, allowing models to scale reliably to 100+ layers.
Thus, (A) is true, and (R) provides the exact mathematical justification. $\blacksquare$

Code Lab 3.5 — LLaMA 3 RMSNorm Layer in PyTorch

🔗 View in GitHub: part3_neural_networks/ch35_normalization/rmsnorm_scratch.py

import torch
import torch.nn as nn

class RMSNormScratch(nn.Module):
    """
    Root Mean Square Layer Normalization (RMSNorm) as used in LLaMA 3.
    Eliminates mean-centering to reduce GPU memory operations.
    """
    def __init__(self, dim, eps=1e-6):
        super().__init__()
        self.eps = eps
        # Learned affine gain parameter gamma
        self.weight = nn.Parameter(torch.ones(dim))

    def _norm(self, x):
        # x shape: (..., dim)
        # Compute root mean square: sqrt(mean(x^2) + eps)
        return x * torch.rsqrt(x.pow(2).mean(-1, keepdim=True) + self.eps)

    def forward(self, x):
        # Cast to float32 for stable variance computation, then cast back
        output = self._norm(x.float()).type_as(x)
        return output * self.weight

if __name__ == "__main__":
    torch.manual_seed(42)
    x = torch.randn(2, 4, 128)  # Batch=2, Seq=4, Dim=128
    norm = RMSNormScratch(dim=128)
    out = norm(x)
    print(f"RMSNorm Output Shape: {out.shape} (Matches Input!)")
    print(f"Mean squared magnitude of normalized vector: {out[0, 0].pow(2).mean().item():.4f} (~1.0)")
