Foundation • Core Pillar

1. K-Means Clustering & Monotonic Convergence

In unsupervised learning, we are given an unlabeled dataset $X = \{\mathbf{x}_1, \dots, \mathbf{x}_N\} \subset \mathbb{R}^d$ without target labels $y$. The objective is to discover latent geometric structure, low-dimensional manifolds, or cluster memberships. $K$-Means partitions $X$ into $K$ disjoint subsets $C = \{C_1, \dots, C_K\}$ that minimize the Within-Cluster Sum of Squares (Inertia):

$$J(C, \boldsymbol{\mu}) = \sum_{k=1}^K \sum_{\mathbf{x}_i \in C_k} \|\mathbf{x}_i - \boldsymbol{\mu}_k\|_2^2$$

Where $\boldsymbol{\mu}_k \in \mathbb{R}^d$ denotes the prototype centroid of cluster $k$.

Lloyd's Alternating Minimization Algorithm

The optimization problem $\min_{C, \boldsymbol{\mu}} J(C, \boldsymbol{\mu})$ is NP-hard in general metric spaces. Lloyd's algorithm finds a local minimum via coordinate descent over two alternating steps:

  1. Assignment Step ($C \mid \boldsymbol{\mu}$): Hold centroids $\boldsymbol{\mu}_1, \dots, \boldsymbol{\mu}_K$ fixed. For each data point $\mathbf{x}_i$, assign it to the closest centroid under Euclidean metric: $$c_i = \arg\min_{k \in \{1,\dots,K\}} \|\mathbf{x}_i - \boldsymbol{\mu}_k\|_2^2 \implies C_k = \{\mathbf{x}_i : c_i = k\}$$
  2. Update Step ($\boldsymbol{\mu} \mid C$): Hold cluster assignments $C$ fixed. Find the optimal centroid $\boldsymbol{\mu}_k$ that minimizes inertia within cluster $C_k$: $$\nabla_{\boldsymbol{\mu}_k} J = \sum_{\mathbf{x}_i \in C_k} 2(\boldsymbol{\mu}_k - \mathbf{x}_i) = \mathbf{0} \implies \boldsymbol{\mu}_k = \frac{1}{|C_k|} \sum_{\mathbf{x}_i \in C_k} \mathbf{x}_i$$

Since both steps strictly decrease or leave unchanged the objective $J$, and there are at most $K^N$ distinct assignments of $N$ points into $K$ clusters, Lloyd's algorithm is guaranteed to converge in a finite number of iterations to a local minimum or saddle point.

2. The K-Means++ $D^2$ Initialization Theorem

Standard uniform random initialization suffers from catastrophic local minima traps: if multiple centroids are initialized near the same cluster, Lloyd's algorithm splits that cluster while leaving distant clusters merged together. Arthur & Vassilvitskii (2007) solved this with $K$-Means++, introducing a randomized distance-squared seeding mechanism.

🏆 The K-Means++ Seeding Algorithm & Approximation Bound

Arthur & Vassilvitskii proved that $K$-Means++ initialization achieves an expected cost within an $O(\log K)$ factor of the global optimal clustering cost $\phi_{\text{opt}}$:

$$\mathbb{E}[J_{\text{init}}] \le 8(\ln K + 2) \cdot J_{\text{opt}}$$

The exact algorithm proceeds as follows:

  1. Choose the first centroid $\boldsymbol{\mu}_1$ uniformly at random from dataset $X$.
  2. For each point $\mathbf{x}_i \in X$, compute its shortest squared Euclidean distance to any already chosen centroid: $$D(\mathbf{x}_i)^2 = \min_{j \in \{1,\dots,m\}} \|\mathbf{x}_i - \boldsymbol{\mu}_j\|_2^2$$
  3. Select the next centroid $\boldsymbol{\mu}_{m+1} = \mathbf{x}_i$ with probability proportional to $D(\mathbf{x}_i)^2$: $$P(\mathbf{x}_i) = \frac{D(\mathbf{x}_i)^2}{\sum_{j=1}^N D(\mathbf{x}_j)^2}$$
  4. Repeat Steps 2 and 3 until exactly $K$ centroids have been selected.

Intuition: Points that are already close to an existing centroid have $D(\mathbf{x}) \approx 0$ and have near-zero probability of being selected. Outlying or isolated clusters have massive $D(\mathbf{x})^2$ values, almost guaranteeing that each true cluster receives an initial center!

3. Principal Component Analysis (PCA): Dual Mathematical Formulations

High-dimensional data ($d \gg 100$) suffers from the Curse of Dimensionality: pairwise distances concentrate around the mean, volume grows exponentially ($V \propto r^d$), and sample density collapses. Principal Component Analysis (PCA) is the optimal linear dimensionality reduction technique. Remarkably, it can be derived from two completely independent geometric perspectives that yield the exact same subspace:

Perspective A: Maximum Projected Variance

Given centered data $X \in \mathbb{R}^{N \times d}$ ($\sum_{i=1}^N \mathbf{x}_i = \mathbf{0}$), we seek a unit projection vector $\mathbf{u} \in \mathbb{R}^d$ ($\|\mathbf{u}\|_2 = 1$) such that the variance of the projected scalar coordinates $z_i = \mathbf{u}^T \mathbf{x}_i$ is maximized:

$$\text{Var}(z) = \frac{1}{N} \sum_{i=1}^N (\mathbf{u}^T \mathbf{x}_i)^2 = \mathbf{u}^T \left( \frac{1}{N} X^T X \right) \mathbf{u} = \mathbf{u}^T \Sigma \mathbf{u}$$

Where $\Sigma = \frac{1}{N} X^T X$ is the $d \times d$ sample covariance matrix. Using the method of Lagrange multipliers:

$$\mathcal{L}(\mathbf{u}, \lambda) = \mathbf{u}^T \Sigma \mathbf{u} - \lambda (\mathbf{u}^T \mathbf{u} - 1)$$ $$\nabla_{\mathbf{u}} \mathcal{L} = 2 \Sigma \mathbf{u} - 2 \lambda \mathbf{u} = \mathbf{0} \implies \Sigma \mathbf{u} = \lambda \mathbf{u}$$

Thus, $\mathbf{u}$ must be an eigenvector of $\Sigma$. The projected variance is $\mathbf{u}^T \Sigma \mathbf{u} = \lambda \mathbf{u}^T \mathbf{u} = \lambda$. Therefore, to maximize variance, $\mathbf{u}_1$ must be the eigenvector corresponding to the largest eigenvalue $\lambda_1 = \lambda_{\max}(\Sigma)$.

Perspective B: Minimum Reconstruction Error

Alternatively, we seek an orthonormal basis $U_k = [\mathbf{u}_1, \dots, \mathbf{u}_k] \in \mathbb{R}^{d \times k}$ ($U_k^T U_k = I_k$) such that projecting data onto the $k$-dimensional subspace and reconstructing it minimizes the Frobenius reconstruction loss:

$$\min_{U_k} \frac{1}{N} \|X - X U_k U_k^T\|_F^2$$

By the Eckart-Young-Mirsky theorem, the optimal subspace $U_k$ is spanned by the top-$k$ eigenvectors of $\Sigma$, identical to Perspective A!

4. SVD vs. Eigendecomposition: Numerical Stability

In theoretical textbooks, PCA is introduced via the covariance eigendecomposition $\Sigma = \frac{1}{N} X^T X = V \Lambda V^T$. However, in production numerical computing (NumPy, SciPy, LAPACK), we never explicitly compute $X^T X$!

The Condition Number Catastrophe:
The condition number of matrix $A$ is $\kappa(A) = \frac{\sigma_{\max}(A)}{\sigma_{\min}(A)}$. Forming the Gramian matrix $X^T X$ squares the condition number: $$\kappa(X^T X) = \kappa(X)^2$$ If $X$ has condition number $\kappa(X) = 10^8$ (common in collinear data), then $\kappa(X^T X) = 10^{16}$, exhausting standard IEEE-754 64-bit floating-point precision ($\approx 16$ decimal digits) and causing complete catastrophic cancellation of smaller singular values! Instead, we perform Singular Value Decomposition (SVD) directly on centered $X$:

$$X = U \Sigma_{\text{svd}} V^T \implies X^T X = V \Sigma_{\text{svd}}^2 V^T$$

The right singular vectors $V$ are identical to the principal component loading directions, and the covariance eigenvalues are directly obtained via $\lambda_i = \frac{\sigma_i^2}{N}$ without ever squaring errors.

5. Non-Linear Manifolds & t-SNE (Van der Maaten & Hinton, 2008)

Linear PCA fails completely when data resides on non-linear curved manifolds (e.g., the Swiss Roll or concentric spheres). t-Distributed Stochastic Neighbor Embedding (t-SNE) maps high-dimensional points $\mathbf{x}_i \in \mathbb{R}^d$ to low-dimensional coordinates $\mathbf{y}_i \in \mathbb{R}^2$ while preserving local neighborhood probabilities.

High-Dimensional Gaussian Affinities

The probability that point $\mathbf{x}_i$ picks $\mathbf{x}_j$ as its neighbor under a Gaussian centered at $\mathbf{x}_i$ is:

$$p_{j|i} = \frac{\exp\left(-\frac{\|\mathbf{x}_i - \mathbf{x}_j\|^2}{2\sigma_i^2}\right)}{\sum_{k \neq i} \exp\left(-\frac{\|\mathbf{x}_i - \mathbf{x}_k\|^2}{2\sigma_i^2}\right)}, \quad p_{ii} = 0, \quad p_{ij} = \frac{p_{j|i} + p_{i|j}}{2N}$$

Where the variance $\sigma_i^2$ is determined via binary search to match a user-specified Perplexity: $\operatorname{Perp}(P_i) = 2^{H(P_i)} = 2^{-\sum_j p_{j|i} \log_2 p_{j|i}}$.

Low-Dimensional Student-t Affinities & The Crowding Problem

In high dimensions, the volume of a sphere grows as $r^d$. In 2D, the available volume is vastly smaller. If we used a Gaussian distribution in low dimensions, distant clusters would be forced to collide and overlap at the center—a failure mode known as the Crowding Problem. t-SNE solves this by using a heavy-tailed Student-t distribution with 1 degree of freedom (Cauchy distribution) for low-dimensional affinities:

$$q_{ij} = \frac{(1 + \|\mathbf{y}_i - \mathbf{y}_j\|^2)^{-1}}{\sum_{k \neq l} (1 + \|\mathbf{y}_k - \mathbf{y}_l\|^2)^{-1}}, \quad q_{ii} = 0$$

Because the Cauchy distribution decays polynomially ($\propto d^{-2}$) rather than exponentially ($\propto e^{-d^2}$), points that are moderately distant in high dimensions can be placed much further apart in the 2D map without incurring massive probability penalties.

The KL Divergence Objective & Gradient

t-SNE minimizes the Kullback-Leibler divergence between joint distributions $P$ and $Q$:

$$\mathcal{L}_{\text{t-SNE}} = D_{\text{KL}}(P \parallel Q) = \sum_{i \neq j} p_{ij} \log \frac{p_{ij}}{q_{ij}}$$

The analytic gradient with respect to the low-dimensional embedding $\mathbf{y}_i$ is remarkably intuitive:

$$\frac{\partial \mathcal{L}}{\partial \mathbf{y}_i} = 4 \sum_j (p_{ij} - q_{ij})(1 + \|\mathbf{y}_i - \mathbf{y}_j\|^2)^{-1} (\mathbf{y}_i - \mathbf{y}_j)$$

This acts as a physical system of springs: if $p_{ij} > q_{ij}$, an attractive force pulls points $\mathbf{y}_i$ and $\mathbf{y}_j$ together; if $p_{ij} < q_{ij}$, a repulsive force pushes them apart!

6. Quantitative Clustering Validation Metrics

Because unsupervised learning lacks ground-truth labels $y$, model evaluation requires internal geometric validation:

  • Inertia (Elbow Method): Sum of squared distances to nearest centroids $\sum_{i} \|\mathbf{x}_i - \boldsymbol{\mu}_{c_i}\|^2$. Plotting inertia vs. $K$ reveals an "elbow" where diminishing marginal returns set in.
  • Silhouette Coefficient: For sample $i$, let $a(i)$ be the mean intra-cluster distance, and $b(i)$ be the mean nearest-cluster distance: $$s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))} \in [-1, +1]$$ A score $s(i) \approx +1$ signifies dense, well-separated clusters; $s(i) \approx 0$ indicates points on decision boundaries; $s(i) < 0$ indicates incorrect cluster assignments.
  • Davies-Bouldin Index: Measures similarity between each cluster $i$ and its most similar cluster $j$: $R_{ij} = \frac{s_i + s_j}{d(\boldsymbol{\mu}_i, \boldsymbol{\mu}_j)}$. Lower Davies-Bouldin values indicate superior cluster separation.

Problem 2.7.1 Level 1 • Direct Numerical Warm-Up Drill Google

QUESTION: Consider a 2D dataset with 4 observations: $A = (1, 1)$, $B = (1, 3)$, $C = (5, 5)$, and $D = (7, 5)$. Suppose $K = 2$ and the algorithm is initialized with centroids $\boldsymbol{\mu}_1 = (2, 2)$ and $\boldsymbol{\mu}_2 = (6, 6)$.

  1. Compute the squared Euclidean distance from each data point to both initial centroids.
  2. Determine the cluster assignment for each point.
  3. Calculate the updated centroid coordinates $\boldsymbol{\mu}_1^{(1)}$ and $\boldsymbol{\mu}_2^{(1)}$ after one iteration of Lloyd's algorithm.
  4. Calculate the initial inertia $J^{(0)}$ and the new inertia $J^{(1)}$ after the update step.
✓ Complete Step-by-Step Arithmetic Solution

Step 1: Compute Squared Euclidean Distances:
For any point $\mathbf{x} = (x, y)$ and centroid $\boldsymbol{\mu} = (\mu_x, \mu_y)$, $d^2(\mathbf{x}, \boldsymbol{\mu}) = (x - \mu_x)^2 + (y - \mu_y)^2$:

  • Point $A(1, 1)$: $$d^2(A, \boldsymbol{\mu}_1) = (1 - 2)^2 + (1 - 2)^2 = (-1)^2 + (-1)^2 = 1 + 1 = 2$$ $$d^2(A, \boldsymbol{\mu}_2) = (1 - 6)^2 + (1 - 6)^2 = (-5)^2 + (-5)^2 = 25 + 25 = 50$$
  • Point $B(1, 3)$: $$d^2(B, \boldsymbol{\mu}_1) = (1 - 2)^2 + (3 - 2)^2 = (-1)^2 + 1^2 = 1 + 1 = 2$$ $$d^2(B, \boldsymbol{\mu}_2) = (1 - 6)^2 + (3 - 6)^2 = (-5)^2 + (-3)^2 = 25 + 9 = 34$$
  • Point $C(5, 5)$: $$d^2(C, \boldsymbol{\mu}_1) = (5 - 2)^2 + (5 - 2)^2 = 3^2 + 3^2 = 9 + 9 = 18$$ $$d^2(C, \boldsymbol{\mu}_2) = (5 - 6)^2 + (5 - 6)^2 = (-1)^2 + (-1)^2 = 1 + 1 = 2$$
  • Point $D(7, 5)$: $$d^2(D, \boldsymbol{\mu}_1) = (7 - 2)^2 + (5 - 2)^2 = 5^2 + 3^2 = 25 + 9 = 34$$ $$d^2(D, \boldsymbol{\mu}_2) = (7 - 6)^2 + (5 - 6)^2 = 1^2 + (-1)^2 = 1 + 1 = 2$$

Step 2: Assign Clusters:
Comparing distances:

  • For $A$: $d^2(A, \boldsymbol{\mu}_1) = 2 < 50 \implies A \in C_1$.
  • For $B$: $d^2(B, \boldsymbol{\mu}_1) = 2 < 34 \implies B \in C_1$.
  • For $C$: $d^2(C, \boldsymbol{\mu}_2) = 2 < 18 \implies C \in C_2$.
  • For $D$: $d^2(D, \boldsymbol{\mu}_2) = 2 < 34 \implies D \in C_2$.
Thus, $C_1 = \{A, B\}$ and $C_2 = \{C, D\}$.

Step 3: Update Centroids:
Compute the sample mean of assigned points: $$\boldsymbol{\mu}_1^{(1)} = \frac{A + B}{2} = \left( \frac{1 + 1}{2}, \frac{1 + 3}{2} \right) = (1.0, 2.0)$$ $$\boldsymbol{\mu}_2^{(1)} = \frac{C + D}{2} = \left( \frac{5 + 7}{2}, \frac{5 + 5}{2} \right) = (6.0, 5.0)$$

Step 4: Compute Inertias $J^{(0)}$ and $J^{(1)}$:
Initial inertia with respect to $\boldsymbol{\mu}^{(0)}$: $$J^{(0)} = d^2(A, \boldsymbol{\mu}_1) + d^2(B, \boldsymbol{\mu}_1) + d^2(C, \boldsymbol{\mu}_2) + d^2(D, \boldsymbol{\mu}_2) = 2 + 2 + 2 + 2 = 8.0$$ Updated inertia with respect to $\boldsymbol{\mu}^{(1)}$:

  • For $A(1, 1)$ to $\boldsymbol{\mu}_1^{(1)}(1, 2)$: $d^2 = (1-1)^2 + (1-2)^2 = 0 + 1 = 1$.
  • For $B(1, 3)$ to $\boldsymbol{\mu}_1^{(1)}(1, 2)$: $d^2 = (1-1)^2 + (3-2)^2 = 0 + 1 = 1$.
  • For $C(5, 5)$ to $\boldsymbol{\mu}_2^{(1)}(6, 5)$: $d^2 = (5-6)^2 + (5-5)^2 = 1 + 0 = 1$.
  • For $D(7, 5)$ to $\boldsymbol{\mu}_2^{(1)}(6, 5)$: $d^2 = (7-6)^2 + (5-5)^2 = 1 + 0 = 1$.
$$J^{(1)} = 1 + 1 + 1 + 1 = 4.0$$ The inertia drops from $8.0 \to 4.0$, confirming strict monotonic descent.

Problem 2.7.2 Level 1 • Direct Formula Drill Meta

QUESTION: A 2-dimensional centered dataset produces the sample covariance matrix: $$\Sigma = \begin{pmatrix} 5 & 2 \\ 2 & 2 \end{pmatrix}$$

  1. Find the characteristic polynomial and calculate both eigenvalues $\lambda_1, \lambda_2$ (with $\lambda_1 \ge \lambda_2$).
  2. Find the normalized principal eigenvector $\mathbf{u}_1$ corresponding to $\lambda_1$.
  3. Calculate the proportion of total variance explained by the first principal component.
✓ Complete Step-by-Step Eigendecomposition Solution

Step 1: Characteristic Equation:
Set $\det(\Sigma - \lambda I) = 0$: $$\det \begin{pmatrix} 5 - \lambda & 2 \\ 2 & 2 - \lambda \end{pmatrix} = (5 - \lambda)(2 - \lambda) - (2)(2) = 0$$ $$\lambda^2 - 7\lambda + 10 - 4 = 0 \implies \lambda^2 - 7\lambda + 6 = 0$$ Factoring the quadratic equation: $$(\lambda - 6)(\lambda - 1) = 0 \implies \lambda_1 = 6, \quad \lambda_2 = 1$$

Step 2: Compute Eigenvector for $\lambda_1 = 6$:
Solve $(\Sigma - 6I)\mathbf{u}_1 = \mathbf{0}$: $$\begin{pmatrix} 5 - 6 & 2 \\ 2 & 2 - 6 \end{pmatrix} \begin{pmatrix} u_{11} \\ u_{12} \end{pmatrix} = \begin{pmatrix} -1 & 2 \\ 2 & -4 \end{pmatrix} \begin{pmatrix} u_{11} \\ u_{12} \end{pmatrix} = \begin{pmatrix} 0 \\ 0 \end{pmatrix}$$ This yields the single independent equation $-u_{11} + 2u_{12} = 0 \implies u_{11} = 2u_{12}$.
Setting $u_{12} = 1$, the unnormalized vector is $\mathbf{v} = \begin{pmatrix} 2 \\ 1 \end{pmatrix}$.
Normalize to unit Euclidean norm: $$\|\mathbf{v}\|_2 = \sqrt{2^2 + 1^2} = \sqrt{5}$$ $$\mathbf{u}_1 = \begin{pmatrix} \frac{2}{\sqrt{5}} \\ \frac{1}{\sqrt{5}} \end{pmatrix} \approx \begin{pmatrix} 0.8944 \\ 0.4472 \end{pmatrix}$$

Step 3: Explained Variance Ratio:
Total variance is the trace of the covariance matrix: $$\operatorname{Tr}(\Sigma) = 5 + 2 = 7 = \lambda_1 + \lambda_2 = 6 + 1 = 7$$ The proportion of total variance captured by the 1st principal component is: $$\text{EVR}_1 = \frac{\lambda_1}{\lambda_1 + \lambda_2} = \frac{6}{6 + 1} = \frac{6}{7} \approx 0.8571 \quad (85.71\%)$$

Problem 2.7.3 Level 2 • Applied Engineering Trace Amazon

QUESTION: You are implementing the $K$-Means++ initialization algorithm on a 1D dataset: $$X = \{1, 3, 7, 15, 25\}$$ Suppose the first centroid is chosen at random as $\boldsymbol{\mu}_1 = 1$.

  1. Compute the shortest distance $D(x)$ and squared distance $D(x)^2$ from each point $x \in X$ to the nearest existing centroid.

  • $x_1 = 1$: $\min(0, 24) = 0 \implies D^2 = 0$
  • $x_2 = 3$: $\min(2, 22) = 2 \implies D^2 = 4$

New sum: $\sum D(x_i)^2 = 0 + 4 + 36 + 100 + 0 = 140$.
Point $15$ now has probability $P(15) = \frac{100}{140} \approx 71.43\%$ of being chosen as $\boldsymbol{\mu}_3$, precisely isolating the intermediate cluster!

Problem 2.7.4 Level 2 • Algorithmic Tracing & Projection Apple

QUESTION: You are given a centered 2D dataset of $N = 3$ samples: $$X = \begin{pmatrix} 2 & 1 \\ -2 & -1 \\ 0 & 0 \end{pmatrix}$$

  1. Compute the matrix product $X^T X$ and its eigenvalues $\lambda_1, \lambda_2$ and right singular vectors $\mathbf{v}_1, \mathbf{v}_2$.
  2. Project the dataset onto the 1-dimensional subspace spanned by the first principal component: compute coordinates $\mathbf{z} = X \mathbf{v}_1 \in \mathbb{R}^3$.
  3. Compute the reconstructed dataset $\hat{X} = \mathbf{z} \mathbf{v}_1^T \in \mathbb{R}^{3 \times 2}$.
  4. Compute the Frobenius reconstruction loss $\|X - \hat{X}\|_F^2$ and verify that it equals $\lambda_2$.
✓ Complete Step-by-Step Mathematical Solution

Step 1: Compute $X^T X$ and Singular Vectors:
$$X^T X = \begin{pmatrix} 2 & -2 & 0 \\ 1 & -1 & 0 \end{pmatrix} \begin{pmatrix} 2 & 1 \\ -2 & -1 \\ 0 & 0 \end{pmatrix} = \begin{pmatrix} (4+4+0) & (2+2+0) \\ (2+2+0) & (1+1+0) \end{pmatrix} = \begin{pmatrix} 8 & 4 \\ 4 & 2 \end{pmatrix}$$ Compute eigenvalues: $\det(X^T X - \lambda I) = (8 - \lambda)(2 - \lambda) - 16 = \lambda^2 - 10\lambda + 16 - 16 = \lambda(\lambda - 10) = 0$.
Thus: $$\lambda_1 = 10, \quad \lambda_2 = 0$$ Eigenvector for $\lambda_1 = 10$: $(X^T X - 10 I)\mathbf{v}_1 = \begin{pmatrix} -2 & 4 \\ 4 & -8 \end{pmatrix} \begin{pmatrix} v_{11} \\ v_{12} \end{pmatrix} = \mathbf{0} \implies v_{11} = 2 v_{12}$.
Normalizing: $\mathbf{v}_1 = \begin{pmatrix} \frac{2}{\sqrt{5}} \\ \frac{1}{\sqrt{5}} \end{pmatrix}$.
Eigenvector for $\lambda_2 = 0$: $8 v_{21} + 4 v_{22} = 0 \implies v_{22} = -2 v_{21}$.
Normalizing: $\mathbf{v}_2 = \begin{pmatrix} -\frac{1}{\sqrt{5}} \\ \frac{2}{\sqrt{5}} \end{pmatrix}$.

Step 2: Compute 1D Projection Coordinates $\mathbf{z}$:
$$\mathbf{z} = X \mathbf{v}_1 = \begin{pmatrix} 2 & 1 \\ -2 & -1 \\ 0 & 0 \end{pmatrix} \begin{pmatrix} \frac{2}{\sqrt{5}} \\ \frac{1}{\sqrt{5}} \end{pmatrix} = \begin{pmatrix} \frac{4 + 1}{\sqrt{5}} \\ \frac{-4 - 1}{\sqrt{5}} \\ 0 \end{pmatrix} = \begin{pmatrix} \frac{5}{\sqrt{5}} \\ -\frac{5}{\sqrt{5}} \\ 0 \end{pmatrix} = \begin{pmatrix} \sqrt{5} \\ -\sqrt{5} \\ 0 \end{pmatrix} \approx \begin{pmatrix} 2.236 \\ -2.236 \\ 0 \end{pmatrix}$$

Step 3: Compute Reconstructed Matrix $\hat{X}$:
$$\hat{X} = \mathbf{z} \mathbf{v}_1^T = \begin{pmatrix} \sqrt{5} \\ -\sqrt{5} \\ 0 \end{pmatrix} \begin{pmatrix} \frac{2}{\sqrt{5}} & \frac{1}{\sqrt{5}} \end{pmatrix} = \begin{pmatrix} \sqrt{5} \cdot \frac{2}{\sqrt{5}} & \sqrt{5} \cdot \frac{1}{\sqrt{5}} \\ -\sqrt{5} \cdot \frac{2}{\sqrt{5}} & -\sqrt{5} \cdot \frac{1}{\sqrt{5}} \\ 0 & 0 \end{pmatrix} = \begin{pmatrix} 2 & 1 \\ -2 & -1 \\ 0 & 0 \end{pmatrix}$$

Step 4: Compute Frobenius Reconstruction Loss:
Subtract $\hat{X}$ from $X$: $$X - \hat{X} = \begin{pmatrix} 2 & 1 \\ -2 & -1 \\ 0 & 0 \end{pmatrix} - \begin{pmatrix} 2 & 1 \\ -2 & -1 \\ 0 & 0 \end{pmatrix} = \begin{pmatrix} 0 & 0 \\ 0 & 0 \\ 0 & 0 \end{pmatrix}$$ $$\|X - \hat{X}\|_F^2 = 0$$ Since $\lambda_2 = 0$, the second principal component contains zero variance—all data points lie exactly along the line $y = \frac{1}{2}x$. Thus, the 1D PCA representation reconstructs the original dataset with zero reconstruction error, matching $\lambda_2 = 0$ identically.

Problem 2.7.5 Level 3 • FAANG / Research Lab Proof Google Meta

QUESTION: Prove rigorously from first principles that finding an orthonormal projection direction $\mathbf{u} \in \mathbb{R}^d$ ($\|\mathbf{u}\|_2 = 1$) that maximizes the sample variance of projected centered data is mathematically identical to finding the direction $\mathbf{u}$ that minimizes the mean squared reconstruction error.

✓ Complete First-Principles Mathematical Proof

Step 1: Setup and Geometric Projection:
Let $X = [\mathbf{x}_1, \dots, \mathbf{x}_N]^T \in \mathbb{R}^{N \times d}$ be centered, so $\sum_{i=1}^N \mathbf{x}_i = \mathbf{0}$.
For any unit vector $\mathbf{u} \in \mathbb{R}^d$ with $\|\mathbf{u}\|_2 = 1$, the scalar orthogonal projection of point $\mathbf{x}_i$ onto $\mathbf{u}$ is $z_i = \mathbf{u}^T \mathbf{x}_i$.
The reconstructed point in $\mathbb{R}^d$ is the projection vector $\hat{\mathbf{x}}_i = z_i \mathbf{u} = (\mathbf{u}^T \mathbf{x}_i) \mathbf{u}$.

Step 2: Expand the Mean Squared Reconstruction Error:
The mean squared reconstruction error is: $$\mathcal{E}(\mathbf{u}) = \frac{1}{N} \sum_{i=1}^N \|\mathbf{x}_i - \hat{\mathbf{x}}_i\|_2^2 = \frac{1}{N} \sum_{i=1}^N \|\mathbf{x}_i - (\mathbf{u}^T \mathbf{x}_i) \mathbf{u}\|_2^2$$ Expand the squared Euclidean norm using the vector inner product $\|\mathbf{a} - \mathbf{b}\|_2^2 = \|\mathbf{a}\|_2^2 - 2 \mathbf{a}^T \mathbf{b} + \|\mathbf{b}\|_2^2$: $$\|\mathbf{x}_i - (\mathbf{u}^T \mathbf{x}_i)\mathbf{u}\|_2^2 = \|\mathbf{x}_i\|_2^2 - 2 \mathbf{x}_i^T [(\mathbf{u}^T \mathbf{x}_i)\mathbf{u}] + \|(\mathbf{u}^T \mathbf{x}_i)\mathbf{u}\|_2^2$$ Since $\mathbf{u}^T \mathbf{x}_i$ is a scalar: $$\mathbf{x}_i^T [(\mathbf{u}^T \mathbf{x}_i)\mathbf{u}] = (\mathbf{u}^T \mathbf{x}_i)(\mathbf{x}_i^T \mathbf{u}) = (\mathbf{u}^T \mathbf{x}_i)^2$$ And because $\|\mathbf{u}\|_2 = 1$: $$\|(\mathbf{u}^T \mathbf{x}_i)\mathbf{u}\|_2^2 = (\mathbf{u}^T \mathbf{x}_i)^2 \|\mathbf{u}\|_2^2 = (\mathbf{u}^T \mathbf{x}_i)^2 \cdot 1 = (\mathbf{u}^T \mathbf{x}_i)^2$$ Substitute these into the expansion: $$\|\mathbf{x}_i - \hat{\mathbf{x}}_i\|_2^2 = \|\mathbf{x}_i\|_2^2 - 2(\mathbf{u}^T \mathbf{x}_i)^2 + (\mathbf{u}^T \mathbf{x}_i)^2 = \|\mathbf{x}_i\|_2^2 - (\mathbf{u}^T \mathbf{x}_i)^2$$

Step 3: Average Over All $N$ Data Points:
$$\mathcal{E}(\mathbf{u}) = \frac{1}{N} \sum_{i=1}^N \|\mathbf{x}_i\|_2^2 - \frac{1}{N} \sum_{i=1}^N (\mathbf{u}^T \mathbf{x}_i)^2$$ Notice the two components:

  1. The first term $\frac{1}{N} \sum_{i=1}^N \|\mathbf{x}_i\|_2^2 = \operatorname{Tr}(\Sigma)$ is the total sample variance of the original dataset, which is a fixed constant completely independent of $\mathbf{u}$.
  2. The second term $\frac{1}{N} \sum_{i=1}^N (\mathbf{u}^T \mathbf{x}_i)^2 = \mathbf{u}^T \left( \frac{1}{N} \sum_{i=1}^N \mathbf{x}_i \mathbf{x}_i^T \right) \mathbf{u} = \mathbf{u}^T \Sigma \mathbf{u}$ is precisely the projected sample variance $\text{Var}(z)$!
Therefore: $$\mathcal{E}(\mathbf{u}) = \text{Total Variance} - \mathbf{u}^T \Sigma \mathbf{u}$$

Step 4: Establish the Equivalence:
Because $\text{Total Variance}$ is constant: $$\arg\min_{\|\mathbf{u}\|_2 = 1} \mathcal{E}(\mathbf{u}) = \arg\min_{\|\mathbf{u}\|_2 = 1} \left( \text{Const} - \mathbf{u}^T \Sigma \mathbf{u} \right) = \arg\max_{\|\mathbf{u}\|_2 = 1} \mathbf{u}^T \Sigma \mathbf{u}$$ Thus, minimizing reconstruction error is mathematically identical to maximizing projected variance. Both perspectives lead to the exact same Rayleigh quotient and the exact same leading eigenvector of the sample covariance matrix $\Sigma$. $\blacksquare$

Problem 2.7.6 Level 3 • FAANG / Research Lab Proof Meta Amazon

QUESTION: Prove that Lloyd's alternating algorithm for $K$-Means clustering:

  1. Monotonically decreases the objective function $J(C, \boldsymbol{\mu})$ at every half-step.
  2. Is guaranteed to terminate in a finite number of steps, and can never enter an infinite cycle or oscillation.

✓ Complete Step-by-Step Mathematical Proof

Step 1: Monotonicity of the Assignment Step:
Let the centroids at iteration $t$ be $\boldsymbol{\mu}^{(t)} = (\boldsymbol{\mu}_1^{(t)}, \dots, \boldsymbol{\mu}_K^{(t)})$.
In the assignment step, cluster memberships $C^{(t+1)}$ are assigned according to the rule: $$c_i^{(t+1)} = \arg\min_{k \in \{1,\dots,K\}} \|\mathbf{x}_i - \boldsymbol{\mu}_k^{(t)}\|_2^2$$ By definition of the $\arg\min$ operator, for each point $i \in \{1, \dots, N\}$: $$\|\mathbf{x}_i - \boldsymbol{\mu}_{c_i^{(t+1)}}^{(t)}\|_2^2 \le \|\mathbf{x}_i - \boldsymbol{\mu}_{c_i^{(t)}}^{(t)}\|_2^2$$ Summing over all $N$ observations: $$J(C^{(t+1)}, \boldsymbol{\mu}^{(t)}) = \sum_{i=1}^N \|\mathbf{x}_i - \boldsymbol{\mu}_{c_i^{(t+1)}}^{(t)}\|_2^2 \le \sum_{i=1}^N \|\mathbf{x}_i - \boldsymbol{\mu}_{c_i^{(t)}}^{(t)}\|_2^2 = J(C^{(t)}, \boldsymbol{\mu}^{(t)})$$ Thus, the assignment step cannot increase $J$: $J(C^{(t+1)}, \boldsymbol{\mu}^{(t)}) \le J(C^{(t)}, \boldsymbol{\mu}^{(t)})$.

Step 2: Monotonicity of the Centroid Update Step:
Now fix the cluster assignments $C^{(t+1)}$. The new centroids are updated to $\boldsymbol{\mu}_k^{(t+1)} = \frac{1}{|C_k^{(t+1)}|} \sum_{\mathbf{x}_i \in C_k^{(t+1)}} \mathbf{x}_i$.
Consider the cluster cost function $f(\mathbf{m}) = \sum_{\mathbf{x}_i \in C_k^{(t+1)}} \|\mathbf{x}_i - \mathbf{m}\|_2^2$.
This is a strictly convex quadratic function of $\mathbf{m} \in \mathbb{R}^d$. Taking the gradient: $$\nabla_{\mathbf{m}} f = \sum_{\mathbf{x}_i \in C_k^{(t+1)}} 2(\mathbf{m} - \mathbf{x}_i) = 2 |C_k^{(t+1)}| \mathbf{m} - 2 \sum_{\mathbf{x}_i \in C_k^{(t+1)}} \mathbf{x}_i = \mathbf{0}$$ $$\implies \mathbf{m}^* = \frac{1}{|C_k^{(t+1)}|} \sum_{\mathbf{x}_i \in C_k^{(t+1)}} \mathbf{x}_i = \boldsymbol{\mu}_k^{(t+1)}$$ Since the Hessian is $\nabla^2 f = 2 |C_k^{(t+1)}| I \succ 0$, $\boldsymbol{\mu}_k^{(t+1)}$ is the unique global minimizer of $f(\mathbf{m})$.
Therefore, for any centroid configuration $\boldsymbol{\mu}^{(t)}$: $$J(C^{(t+1)}, \boldsymbol{\mu}^{(t+1)}) \le J(C^{(t+1)}, \boldsymbol{\mu}^{(t)})$$

Step 3: Combined Monotonic Descent:
Combining both inequalities: $$J(C^{(t+1)}, \boldsymbol{\mu}^{(t+1)}) \le J(C^{(t+1)}, \boldsymbol{\mu}^{(t)}) \le J(C^{(t)}, \boldsymbol{\mu}^{(t)})$$ The objective sequence $\{J^{(t)}\}_{t=1}^\infty$ is monotonically non-increasing and bounded below by $0$.

Step 4: Finite Termination and No Infinite Cycles:
A dataset of $N$ points can be partitioned into $K$ clusters in at most $K^N$ distinct ways (a finite number).
If the algorithm does not terminate, it must encounter a repeated partition $C^{(t_2)} = C^{(t_1)}$ for some $t_2 > t_1$.
However, if $C^{(t+1)} \neq C^{(t)}$ and there are no degenerate distance ties, the assignment step produces a strict decrease: $J(C^{(t+1)}, \boldsymbol{\mu}^{(t)}) < J(C^{(t)}, \boldsymbol{\mu}^{(t)})$.
A sequence that strictly decreases at every change can never revisit a previously visited state, because $J(C^{(t_2)}, \boldsymbol{\mu}^{(t_2)}) < J(C^{(t_1)}, \boldsymbol{\mu}^{(t_1)})$.
Since the state space of clusterings is finite ($|\mathcal{S}| \le K^N$) and the sequence of objective values strictly decreases, the algorithm must terminate in a finite number of iterations when $C^{(t+1)} = C^{(t)}$. $\blacksquare$

Problem 2.7.7 Level 4 • Conceptual Trap MCQ Google

QUESTION: A data scientist trains a PCA model on real estate data with two features:

  • Feature 1: Square Footage ($x_1 \in [500, 5000]$ sq ft, variance $\approx 1,000,000$).
  • Feature 2: Number of Bedrooms ($x_2 \in [1, 5]$, variance $\approx 1.2$).
The engineer forgets to apply StandardScaler and directly performs PCA. What will happen to the principal components?

  1. PCA is scale-invariant because eigenvectors are normalized to unit length ($\|\mathbf{u}\| = 1$); the components will correctly weight both features.
  2. The first principal component $\mathbf{u}_1$ will align almost perfectly with $[1, 0]^T$ (Square Footage), completely ignoring Bedrooms simply due to the arbitrary measurement units.
  3. The second principal component will capture $99.9\%$ of the variance because the smaller numerical range of Bedrooms allows for finer variance resolution.
  4. The covariance matrix becomes singular ($\det(\Sigma) = 0$), causing LAPACK SVD solvers to crash with a floating-point division by zero exception.
✓ Correct Answer: B • Comprehensive Distractor Analysis

Detailed Analysis:
PCA maximizes projected variance $\mathbf{u}^T \Sigma \mathbf{u}$.
The sample covariance matrix without standardization is: $$\Sigma = \begin{pmatrix} 1,000,000 & \text{Cov}(x_1, x_2) \\ \text{Cov}(x_1, x_2) & 1.2 \end{pmatrix}$$ Because $\operatorname{Var}(x_1) = 1,000,000 \gg \operatorname{Var}(x_2) = 1.2$, the diagonal is dominated by Feature 1 by a factor of almost $1,000,000:1$.
The leading eigenvalue $\lambda_1 \approx 1,000,000$, and the corresponding eigenvector $\mathbf{u}_1 \approx \begin{pmatrix} 1.0 \\ 0.0001 \end{pmatrix} \approx \begin{pmatrix} 1 \\ 0 \end{pmatrix}$.
The first principal component is simply a carbon copy of Square Footage. If Square Footage had instead been measured in square kilometers ($[0.000046, 0.00046]$ sq km, variance $\approx 10^{-8}$), the exact same physical feature would have had its contribution reduced to $0.00001\%$, and Bedrooms would have completely dominated!
Conclusion: PCA is NOT scale-invariant. Features must always be standardized to zero mean and unit variance ($z = \frac{x - \mu}{\sigma}$) prior to computing PCA.

Why Other Options are False:

  • A is FALSE: While the eigenvector $\mathbf{u}$ is normalized to unit length ($\|\mathbf{u}\|=1$), the objective being maximized is $\mathbf{u}^T \Sigma \mathbf{u}$. The magnitudes inside $\Sigma$ directly dictate which direction has the highest variance.
  • C is FALSE: PC1 captures the largest eigenvalue, which is $1,000,000$ ($99.9998\%$ of total variance). PC2 captures the remaining $\approx 1.2$ ($0.0002\%$).
  • D is FALSE: As long as the two features are not perfectly collinear, $\Sigma$ is symmetric positive definite and non-singular ($\det(\Sigma) > 0$). LAPACK executes without errors, but produces a practically useless projection.

Problem 2.7.8 Level 4 • Assertion-Reasoning & Voronoi Geometry Trap Google Meta

QUESTION: Evaluate the following Assertion and Reason regarding $K$-Means clustering geometry:

Assertion (A): Standard $K$-Means clustering with Euclidean distance will fail to separate two concentric spherical shells of data (an inner dense sphere surrounded by an outer spherical ring), regardless of how many iterations Lloyd's algorithm runs or what initialization is used for $K = 2$.

Reason (R): The assignment step of $K$-Means creates a Voronoi tessellation of the feature space, which restricts all decision boundaries between clusters to be linear hyperplanes, making it mathematically impossible to form closed, non-convex, or nested spherical boundary partitions.

  1. Both (A) and (R) are true, and (R) is the correct mathematical explanation of (A).
  2. Both (A) and (R) are true, but (R) is NOT the correct explanation of (A).
  3. (A) is true, but (R) is false.
  4. (A) is false, but (R) is true.
✓ Correct Answer: A • Comprehensive Geometric Proof

Detailed Analysis:
Analysis of Reason (R):
In $K$-Means, a point $\mathbf{x}$ is assigned to cluster 1 over cluster 2 if and only if: $$\|\mathbf{x} - \boldsymbol{\mu}_1\|_2^2 \le \|\mathbf{x} - \boldsymbol{\mu}_2\|_2^2$$ Expanding both sides: $$\|\mathbf{x}\|_2^2 - 2 \mathbf{x}^T \boldsymbol{\mu}_1 + \|\boldsymbol{\mu}_1\|_2^2 \le \|\mathbf{x}\|_2^2 - 2 \mathbf{x}^T \boldsymbol{\mu}_2 + \|\boldsymbol{\mu}_2\|_2^2$$ The quadratic term $\|\mathbf{x}\|_2^2$ cancels out identically on both sides: $$2(\boldsymbol{\mu}_2 - \boldsymbol{\mu}_1)^T \mathbf{x} + (\|\boldsymbol{\mu}_1\|_2^2 - \|\boldsymbol{\mu}_2\|_2^2) \le 0$$ Notice that this is a linear inequality in $\mathbf{x}$! The decision boundary between any two clusters is the perpendicular bisector hyperplane $\mathbf{w}^T \mathbf{x} + b = 0$, where $\mathbf{w} = 2(\boldsymbol{\mu}_2 - \boldsymbol{\mu}_1)$ and $b = \|\boldsymbol{\mu}_1\|_2^2 - \|\boldsymbol{\mu}_2\|_2^2$.
Each cluster region is the intersection of half-spaces defined by these hyperplanes, forming a convex Voronoi polyhedron. A convex set cannot enclose a hole or wrap around another set.
Thus, (R) is mathematically true.

Analysis of Assertion (A):
Separating an inner core from an outer ring requires a quadratic spherical boundary $\|\mathbf{x} - \mathbf{c}\|_2 = r$ (a sphere in $\mathbb{R}^d$), which is non-linear and non-convex. Because $K$-Means can only draw linear bisecting hyperplanes, any plane cutting through the dataset will slice both the inner core and the outer ring into two halves, misclassifying half of each structure.
Thus, (A) is true, and (R) provides the exact mathematical reason why $K$-Means fails.
Engineering Note: To cluster concentric rings or non-linear manifolds, one must use Kernel PCA, Spectral Clustering (which uses graph Laplacian eigenvectors), or DBSCAN (density-based connectivity).

7. Production Code Lab 2.7: SVD-Based PCA from First Principles

Below is a production implementation of SVD-based PCA in pure Python, calculating explained variance ratios without forming the ill-conditioned $X^T X$ covariance matrix.

Code Lab 2.7 — High-Stability SVD PCA Engine

🔗 View in GitHub: part2_classical_ml/ch27_unsupervised_learning/pca_scratch.py

import numpy as np

class PCAScratch:
    """
    High-stability Principal Component Analysis using Singular Value Decomposition.
    Avoids forming X^T X to prevent squaring the condition number.
    """
    def __init__(self, n_components=2):
        self.n_components = n_components
        self.components_ = None
        self.explained_variance_ratio_ = None
        self.mean_ = None

    def fit(self, X):
        N = X.shape[0]
        # 1. Center the data (zero-mean)
        self.mean_ = np.mean(X, axis=0)
        X_centered = X - self.mean_

        # 2. Compute SVD: X_centered = U * S * V^T
        # full_matrices=False computes economy SVD in O(N * d * min(N, d))
        U, S, Vt = np.linalg.svd(X_centered, full_matrices=False)

        # 3. Principal components are rows of Vt (columns of V)
        self.components_ = Vt[:self.n_components]

        # 4. Explained variance: lambda_i = S_i^2 / (N - 1)
        explained_variance = (S ** 2) / (N - 1)
        total_variance = np.sum(explained_variance)
        self.explained_variance_ratio_ = explained_variance[:self.n_components] / total_variance

    def transform(self, X):
        X_centered = X - self.mean_
        # Project onto top-k orthogonal components
        return X_centered @ self.components_.T

    def inverse_transform(self, Z):
        # Reconstruct high-dimensional points from low-dimensional projections
        return (Z @ self.components_) + self.mean_

if __name__ == "__main__":
    np.random.seed(42)
    X = np.random.randn(200, 10)
    pca = PCAScratch(n_components=3)
    pca.fit(X)
    X_proj = pca.transform(X)
    X_rec = pca.inverse_transform(X_proj)
    recon_error = np.mean((X - X_rec) ** 2)
    print(f"Projected Shape               : {X_proj.shape}")
    print(f"Explained Variance Ratios (3) : {np.round(pca.explained_variance_ratio_, 4)}")
    print(f"Total Variance Captured       : {np.sum(pca.explained_variance_ratio_)*100:.2f}%")
    print(f"Mean Squared Reconstruction   : {recon_error:.6f}")
