Foundation • Core Pillar

1. Biological Foundations to Artificial Modeling

In 1943, neurophysiologist Warren McCulloch and logician Walter Pitts formulated the first computational model of a biological neuron. In neurobiology, information flows through three primary anatomical structures:

  • Dendrites: Dense branching arborizations that receive incoming chemical neurotransmitters from presynaptic axon terminals across synaptic clefts.
  • Soma (Cell Body): Accumulates post-synaptic electrical potentials across the lipid bilayer membrane.
  • Axon & Axon Hillock: If the integrated electrical membrane potential exceeds an all-or-none firing threshold (approximately $-55 \text{ mV}$ from a resting potential of $-70 \text{ mV}$), voltage-gated sodium channels open rapidly, generating an electrical pulse (Action Potential) that propagates down the myelin-sheathed axon.

In 1958, Frank Rosenblatt (Cornell Aeronautical Laboratory) expanded McCulloch-Pitts threshold units into the Perceptron, introducing the first mathematical learning rule capable of automatically adjusting synaptic weights from empirical sensory data:

$$z = \mathbf{w}^T \mathbf{x} + b = \sum_{i=1}^d w_i x_i + b$$ $$\hat{y} = \operatorname{sgn}(z) = \begin{cases} +1, & \text{if } z \ge 0 \\ -1, & \text{if } z < 0 \end{cases}$$

Geometrically, the equation $\mathbf{w}^T \mathbf{x} + b = 0$ defines a $(d-1)$-dimensional linear decision hyperplane dividing $\mathbb{R}^d$ into two open halfspaces. The weight vector $\mathbf{w}$ is orthogonal to the hyperplane, pointing toward the positive halfspace.

The Perceptron Learning Algorithm

Given a training set $\mathcal{D} = \{(\mathbf{x}_i, y_i)\}_{i=1}^N$ with labels $y_i \in \{-1, +1\}$ and learning rate $\eta \in (0, 1]$:

  1. Initialize weight vector $\mathbf{w}^{(0)} = \mathbf{0}$ and bias $b^{(0)} = 0$.
  2. For each training example $(\mathbf{x}_i, y_i)$: compute prediction $\hat{y}_i = \operatorname{sgn}(\mathbf{w}^T \mathbf{x}_i + b)$.
  3. If $\hat{y}_i \neq y_i$ (a misclassification occurs), update parameters according to Rosenblatt's rule: $$\mathbf{w}^{(t+1)} = \mathbf{w}^{(t)} + \eta y_i \mathbf{x}_i$$ $$b^{(t+1)} = b^{(t)} + \eta y_i$$

Geometric Mechanics: If a positive sample ($y_i = +1$) was incorrectly predicted as negative ($\mathbf{w}^T \mathbf{x}_i \le 0$), adding $\mathbf{x}_i$ rotates $\mathbf{w}$ toward $\mathbf{x}_i$, increasing the inner product $\mathbf{w}^T \mathbf{x}_i$. If a negative sample was predicted as positive, subtracting $\mathbf{x}_i$ rotates $\mathbf{w}$ away from $\mathbf{x}_i$.

2. Novikoff's Perceptron Convergence Theorem (1962)

Does the perceptron learning rule always converge, or can it loop indefinitely? Albert Novikoff established that if a dataset is strictly linearly separable, the perceptron will terminate after a provably finite number of mistake updates.

🏆 Novikoff's Mistake Bound Theorem

Let $\mathcal{D} = \{(\mathbf{x}_i, y_i)\}_{i=1}^N$ be a dataset where all inputs are bounded within a ball of radius $R$: $\|\mathbf{x}_i\|_2 \le R$ for all $i$. Suppose there exists an optimal unit weight vector $\mathbf{w}^*$ ($\|\mathbf{w}^*\|_2 = 1$) that separates the data with geometric margin $\gamma > 0$:

$$y_i (\mathbf{w}^* \cdot \mathbf{x}_i) \ge \gamma, \quad \forall i \in \{1, \dots, N\}$$

Starting from initial weights $\mathbf{w}^{(0)} = \mathbf{0}$, the total number of mistake updates $k$ made by the perceptron learning rule is strictly bounded by:

$$k \le \left( \frac{R}{\gamma} \right)^2$$

Fundamental Insight: The bound depends exclusively on the geometric ratio of the data radius $R$ to the separation margin $\gamma$. It is completely independent of the input dimensionality $d$! Even in a $1,000,000$-dimensional space, if data has radius $R=10$ and margin $\gamma=1$, the perceptron converges in at most $(10/1)^2 = 100$ mistakes!

3. The 1969 AI Winter & The Minsky-Papert XOR Collapse

Following Rosenblatt's invention, unchecked hype dominated mainstream media. In 1969, MIT AI Laboratory founders Marvin Minsky and Seymour Papert published their seminal monograph Perceptrons, delivering a rigorous mathematical critique that brought neural network research to a sudden halt for over a decade.

Minsky and Papert proved that single-layer perceptrons are fundamentally incapable of computing simple non-linear logic functions, most notably Exclusive OR (XOR). The points $(0, 1)$ and $(1, 0)$ belong to class $1$, while $(0, 0)$ and $(1, 1)$ belong to class $0$. Because their convex hulls intersect, no linear hyperplane can ever separate them.

Overcoming the XOR Barrier with Multilayer Architectures

While a single linear threshold unit cannot compute XOR, a Multilayer Perceptron (MLP) with a single hidden layer solves XOR effortlessly by decomposing it into elementary logical gates:

$$\text{XOR}(x_1, x_2) = (x_1 \lor x_2) \land \neg(x_1 \land x_2) = \text{AND}(\text{OR}(x_1, x_2), \; \text{NAND}(x_1, x_2))$$

The hidden layer maps non-linearly separable inputs $\mathbf{x} \in \{0, 1\}^2$ into an intermediate hidden activation space $\mathbf{h} \in \{0, 1\}^2$ where the classes become linearly separable! However, because the step activation function $\operatorname{sgn}(z)$ has zero derivative everywhere and is discontinuous at zero, Rosenblatt's learning rule could not be extended to multilayer networks. Finding an algorithm to train multilayer networks had to wait until the rediscovery of Backpropagation in 1986 (Chapter 3.3).

Problem 3.1.1 Level 1 • Direct Numerical Warm-Up Drill Google

QUESTION: You are training a single-layer perceptron with initial weight vector $\mathbf{w}^{(0)} = [0.0, 0.0]^T$, initial bias $b^{(0)} = 0.0$, and learning rate $\eta = 1.0$. The classification rule is $\hat{y} = +1$ if $\mathbf{w}^T \mathbf{x} + b \ge 0$, else $-1$. You present the following three 2D training examples in sequence:

  1. $\mathbf{x}_1 = (2, 3)^T$ with label $y_1 = +1$
  2. $\mathbf{x}_2 = (1, 1)^T$ with label $y_2 = -1$
  3. $\mathbf{x}_3 = (4, 1)^T$ with label $y_3 = +1$

Compute the activation $z$, prediction $\hat{y}$, and parameter updates $(\mathbf{w}, b)$ for each step.

✓ Complete Step-by-Step Arithmetic Solution

Step 1: Presentation of Sample 1 ($\mathbf{x}_1 = [2, 3]^T, y_1 = +1$):
Current parameters: $\mathbf{w}^{(0)} = [0, 0]^T, b^{(0)} = 0$.
Compute linear activation: $$z_1 = \mathbf{w}^{(0)} \cdot \mathbf{x}_1 + b^{(0)} = 0(2) + 0(3) + 0 = 0.0$$ Prediction rule: since $z_1 = 0 \ge 0 \implies \hat{y}_1 = +1$.
Target label is $y_1 = +1$.
Since $\hat{y}_1 = y_1$, this is a correct prediction. No weight update occurs! $$\mathbf{w}^{(1)} = [0, 0]^T, \quad b^{(1)} = 0.0$$

Step 2: Presentation of Sample 2 ($\mathbf{x}_2 = [1, 1]^T, y_2 = -1$):
Current parameters: $\mathbf{w}^{(1)} = [0, 0]^T, b^{(1)} = 0$.
Compute linear activation: $$z_2 = \mathbf{w}^{(1)} \cdot \mathbf{x}_2 + b^{(1)} = 0(1) + 0(1) + 0 = 0.0$$ Prediction rule: $z_2 = 0 \ge 0 \implies \hat{y}_2 = +1$.
Target label is $y_2 = -1$.
Prediction is incorrect ($\hat{y}_2 \neq y_2$). Apply Rosenblatt update rule: $$\mathbf{w}^{(2)} = \mathbf{w}^{(1)} + \eta y_2 \mathbf{x}_2 = \begin{pmatrix} 0 \\ 0 \end{pmatrix} + 1.0(-1) \begin{pmatrix} 1 \\ 1 \end{pmatrix} = \begin{pmatrix} -1.0 \\ -1.0 \end{pmatrix}$$ $$b^{(2)} = b^{(1)} + \eta y_2 = 0 + 1.0(-1) = -1.0$$

Step 3: Presentation of Sample 3 ($\mathbf{x}_3 = [4, 1]^T, y_3 = +1$):
Current parameters: $\mathbf{w}^{(2)} = [-1.0, -1.0]^T, b^{(2)} = -1.0$.
Compute linear activation: $$z_3 = \mathbf{w}^{(2)} \cdot \mathbf{x}_3 + b^{(2)} = (-1.0)(4) + (-1.0)(1) + (-1.0) = -4.0 - 1.0 - 1.0 = -6.0$$ Prediction rule: $z_3 = -6.0 < 0 \implies \hat{y}_3 = -1$.
Target label is $y_3 = +1$.
Prediction is incorrect ($\hat{y}_3 \neq y_3$). Apply update rule: $$\mathbf{w}^{(3)} = \mathbf{w}^{(2)} + \eta y_3 \mathbf{x}_3 = \begin{pmatrix} -1.0 \\ -1.0 \end{pmatrix} + 1.0(+1) \begin{pmatrix} 4 \\ 1 \end{pmatrix} = \begin{pmatrix} +3.0 \\ 0.0 \end{pmatrix}$$ $$b^{(3)} = b^{(2)} + \eta y_3 = -1.0 + 1.0(+1) = 0.0$$

Final Verification:
The learned hyperplane is $3 x_1 + 0 x_2 + 0 = 0 \implies x_1 = 0$.
Testing point $\mathbf{x}_2 = [1, 1]$: $3(1) = 3 > 0 \implies \hat{y} = +1$ (still requires another epoch to adjust), illustrating the iterative nature of the algorithm.

Problem 3.1.2 Level 1 • Direct Formula Drill Meta

QUESTION: A 2-dimensional linearly separable classification dataset is bounded within an origin-centered ball of radius $R = 6.0$. A margin analysis demonstrates that the optimal separating hyperplane achieves a geometric margin of $\gamma = 0.40$.

  1. Calculate the theoretical upper bound on the maximum number of mistakes the perceptron will make starting from $\mathbf{w}^{(0)} = \mathbf{0}$.
  2. If data preprocessing normalizes all coordinates such that the radius shrinks to $R' = 3.0$ while preserving the relative margin $\frac{\gamma'}{R'} = \frac{\gamma}{R}$, what is the new mistake bound?
  3. If feature engineering expands the feature space to $d = 10,000$ dimensions without changing $R$ and $\gamma$, how does the mistake bound change?
✓ Complete Step-by-Step Mathematical Solution

Step 1: Compute Baseline Mistake Bound:
By Novikoff's theorem: $$k_{\max} \le \left( \frac{R}{\gamma} \right)^2$$ Given $R = 6.0$ and $\gamma = 0.40$: $$\frac{R}{\gamma} = \frac{6.0}{0.40} = 15.0$$ $$k_{\max} \le 15.0^2 = 225$$ The perceptron is guaranteed to converge in at most $225$ mistake updates.

Step 2: Effect of Uniform Rescaling:
If the data is uniformly scaled by a factor $c = 0.5$ ($R' = 3.0$ and $\gamma' = 0.20$): $$\frac{R'}{\gamma'} = \frac{3.0}{0.20} = 15.0 \implies k_{\max}' \le 15.0^2 = 225$$ The bound is scale-invariant under uniform coordinate dilation.

Step 3: Effect of High Dimensionality ($d = 10,000$):
Novikoff's formula $k \le (R/\gamma)^2$ contains zero dependence on dimension $d$. As long as $R = 6.0$ and $\gamma = 0.40$, the bound remains strictly $k \le 225$ mistakes, even in an infinite-dimensional reproducing kernel Hilbert space!

In the original input space $\mathbf{x}$, the two positive points $(0, 1)$ and $(1, 0)$ were crossed by the negative points $(0, 0)$ and $(1, 1)$.

QUESTION: Consider a 1-dimensional non-linearly separable dataset with $N = 3$ points on a line: $$x_1 = 1.0, \; y_1 = +1; \quad x_2 = 2.0, \; y_2 = -1; \quad x_3 = 3.0, \; y_3 = +1$$ Notice that negative sample $x_2$ is sandwiched between positive samples $x_1$ and $x_3$.
Starting from $w^{(0)} = 0.0$ and $b^{(0)} = 0.0$ with $\eta = 1.0$, trace the first 6 mistake updates of Rosenblatt's perceptron algorithm when samples are presented cyclically ($x_1 \to x_2 \to x_3 \to x_1 \dots$), and prove that the weights enter an infinite periodic limit cycle.

Step 1: Iteration Trace (Starting at $w=0, b=0$):
Decision rule: $\hat{y} = +1$ if $w x + b \ge 0$, else $-1$.

  • Step 1 (Sample $x_1 = 1, y_1 = +1$):
    $z = 0(1) + 0 = 0 \ge 0 \implies \hat{y} = +1$. Correct! No update. $(w, b) = (0, 0)$.
  • Step 2 (Sample $x_2 = 2, y_2 = -1$):
    $z = 0(2) + 0 = 0 \ge 0 \implies \hat{y} = +1$. Mistake ($y=-1$).

  • Step 3 (Sample $x_3 = 3, y_3 = +1$):
    $z = (-2)(3) - 1 = -7 < 0 \implies \hat{y} = -1$. Mistake ($y=+1$).
    $w \leftarrow -2 + 1(+1)(3) = +1.0$, $b \leftarrow -1 + 1(+1) = 0.0$. Current: $(w, b) = (+1, 0)$.
  • Step 4 (Sample $x_1 = 1, y_1 = +1$):
    $z = (1)(1) + 0 = +1 \ge 0 \implies \hat{y} = +1$. Correct! Current: $(w, b) = (+1, 0)$.
  • Step 5 (Sample $x_2 = 2, y_2 = -1$):
    $z = (1)(2) + 0 = +2 \ge 0 \implies \hat{y} = +1$. Mistake ($y=-1$).
    $w \leftarrow 1 + 1(-1)(2) = -1.0$, $b \leftarrow 0 + 1(-1) = -1.0$. Current: $(w, b) = (-1, -1)$.
  • Step 6 (Sample $x_3 = 3, y_3 = +1$):
    $z = (-1)(3) - 1 = -4 < 0 \implies \hat{y} = -1$. Mistake ($y=+1$).

Step 2: The Limit Cycle Pattern:
Notice the recurring structural alternation:

  • After seeing $x_3$, the model sets $w > 0, b = 0$. This correctly classifies $x_1$ and $x_3$, but causes a mistake on $x_2$!
  • Updating on $x_2$ subtracts $[2, 1]$, flipping $w < 0, b < 0$. This correctly classifies $x_2$, but immediately causes a mistake on $x_3$!
Because no single line can place points $1$ and $3$ on one side of a point while keeping point $2$ on the other, the perceptron updates endlessly, oscillating between positive and negative slope states without ever terminating.

Problem 3.1.5 Level 3 • FAANG / Research Lab Proof Google Meta

QUESTION: Prove Albert Novikoff's Perceptron Convergence Theorem (1962) rigorously from first principles. Assume dataset $\mathcal{D} = \{(\mathbf{x}_i, y_i)\}_{i=1}^N$ has bounded inputs $\|\mathbf{x}_i\|_2 \le R$ and is linearly separable through the origin by a unit vector $\mathbf{w}^*$ ($\|\mathbf{w}^*\|_2 = 1$) with margin $\gamma > 0$ such that $y_i(\mathbf{w}^* \cdot \mathbf{x}_i) \ge \gamma$ for all $i$. Prove that the perceptron makes at most $k \le \left(\frac{R}{\gamma}\right)^2$ updates before convergence.

✓ Complete First-Principles Mathematical Proof

Step 1: Perceptron Update Rule on Mistakes:
Let $\mathbf{w}^{(0)} = \mathbf{0}$. Let the sequence of misclassified examples encountered by the algorithm be denoted by index $t \in \{1, 2, \dots, k\}$.
When example $(\mathbf{x}_t, y_t)$ is misclassified, the current prediction satisfies $y_t (\mathbf{w}^{(t-1)} \cdot \mathbf{x}_t) \le 0$.
The update rule with $\eta = 1$ is: $$\mathbf{w}^{(t)} = \mathbf{w}^{(t-1)} + y_t \mathbf{x}_t$$

Step 2: Establish a Lower Bound on the Inner Product $\mathbf{w}^{(k)} \cdot \mathbf{w}^*$:
Take the inner product of the update equation with the optimal unit vector $\mathbf{w}^*$: $$\mathbf{w}^{(t)} \cdot \mathbf{w}^* = (\mathbf{w}^{(t-1)} + y_t \mathbf{x}_t) \cdot \mathbf{w}^* = (\mathbf{w}^{(t-1)} \cdot \mathbf{w}^*) + y_t (\mathbf{x}_t \cdot \mathbf{w}^*)$$ By the definition of geometric margin $\gamma$, $y_t (\mathbf{w}^* \cdot \mathbf{x}_t) \ge \gamma$. Therefore: $$\mathbf{w}^{(t)} \cdot \mathbf{w}^* \ge (\mathbf{w}^{(t-1)} \cdot \mathbf{w}^*) + \gamma$$ Summing this telescoping inequality over all $k$ updates, starting from $\mathbf{w}^{(0)} = \mathbf{0}$: $$\mathbf{w}^{(k)} \cdot \mathbf{w}^* \ge k \gamma$$

Step 3: Establish an Upper Bound on the Squared Norm $\|\mathbf{w}^{(k)}\|_2^2$:
Compute the squared Euclidean norm of $\mathbf{w}^{(t)}$: $$\|\mathbf{w}^{(t)}\|_2^2 = \|\mathbf{w}^{(t-1)} + y_t \mathbf{x}_t\|_2^2 = \|\mathbf{w}^{(t-1)}\|_2^2 + 2 y_t (\mathbf{w}^{(t-1)} \cdot \mathbf{x}_t) + y_t^2 \|\mathbf{x}_t\|_2^2$$ Recall that an update only occurs because $(\mathbf{x}_t, y_t)$ was a mistake, meaning $y_t (\mathbf{w}^{(t-1)} \cdot \mathbf{x}_t) \le 0$.
Furthermore, $y_t^2 = (\pm 1)^2 = 1$, and $\|\mathbf{x}_t\|_2 \le R \implies \|\mathbf{x}_t\|_2^2 \le R^2$. Therefore: $$\|\mathbf{w}^{(t)}\|_2^2 \le \|\mathbf{w}^{(t-1)}\|_2^2 + 2(0) + R^2 = \|\mathbf{w}^{(t-1)}\|_2^2 + R^2$$ Summing this telescoping inequality over all $k$ updates, starting from $\|\mathbf{w}^{(0)}\|_2^2 = 0$: $$\|\mathbf{w}^{(k)}\|_2^2 \le k R^2$$

Step 4: Bridge Lower and Upper Bounds via Cauchy-Schwarz:
By the Cauchy-Schwarz inequality, for any two vectors: $$(\mathbf{w}^{(k)} \cdot \mathbf{w}^*)^2 \le \|\mathbf{w}^{(k)}\|_2^2 \|\mathbf{w}^*\|_2^2$$ Since $\mathbf{w}^*$ is a unit vector, $\|\mathbf{w}^*\|_2^2 = 1$. Substituting the lower bound from Step 2 and upper bound from Step 3: $$(k \gamma)^2 \le (\mathbf{w}^{(k)} \cdot \mathbf{w}^*)^2 \le \|\mathbf{w}^{(k)}\|_2^2 \le k R^2$$ $$k^2 \gamma^2 \le k R^2$$ Dividing both sides by $k \gamma^2$ (since $k > 0$ and $\gamma > 0$): $$k \le \frac{R^2}{\gamma^2} = \left( \frac{R}{\gamma} \right)^2$$ The total number of mistake updates cannot exceed $(R/\gamma)^2$. Once this maximum count is reached, no further mistakes can occur, proving guaranteed convergence in finite steps. $\blacksquare$

Problem 3.1.6 Level 3 • FAANG / Research Lab Proof Google Amazon

QUESTION: Prove the Convex Hull Intersection Theorem for Linear Separability: A binary classification dataset $\mathcal{D} = X_+ \cup X_-$ is linearly separable by a hyperplane $\mathbf{w}^T \mathbf{x} + b = 0$ if and only if the convex hulls of the positive and negative points are disjoint: $$\operatorname{Conv}(X_+) \cap \operatorname{Conv}(X_-) = \emptyset$$ Using this theorem, prove why the XOR configuration can never be linearly separated.

✓ Complete Geometric Separation Proof

Step 1: Forward Direction ($\implies$):
Assume $X_+$ and $X_-$ are strictly linearly separated by hyperplane $\mathbf{w}^T \mathbf{x} + b = 0$.
Then for all $\mathbf{x}_+ \in X_+$, $\mathbf{w}^T \mathbf{x}_+ + b > 0$, and for all $\mathbf{x}_- \in X_-$, $\mathbf{w}^T \mathbf{x}_- + b < 0$.
Any point $\mathbf{p} \in \operatorname{Conv}(X_+)$ is a convex combination: $\mathbf{p} = \sum_{i} \alpha_i \mathbf{x}_{+,i}$ where $\alpha_i \ge 0, \sum_i \alpha_i = 1$.
Evaluating the linear form: $$\mathbf{w}^T \mathbf{p} + b = \mathbf{w}^T \left( \sum_i \alpha_i \mathbf{x}_{+,i} \right) + b \left( \sum_i \alpha_i \right) = \sum_i \alpha_i (\mathbf{w}^T \mathbf{x}_{+,i} + b)$$ Since each term $\mathbf{w}^T \mathbf{x}_{+,i} + b > 0$ and $\sum \alpha_i = 1$, the sum is strictly positive: $\mathbf{w}^T \mathbf{p} + b > 0$.
Similarly, for any $\mathbf{q} \in \operatorname{Conv}(X_-)$: $\mathbf{w}^T \mathbf{q} + b < 0$.
If there existed an intersection point $\mathbf{z} \in \operatorname{Conv}(X_+) \cap \operatorname{Conv}(X_-)$, it would have to satisfy both $\mathbf{w}^T \mathbf{z} + b > 0$ and $\mathbf{w}^T \mathbf{z} + b < 0$, an impossibility! Thus, $\operatorname{Conv}(X_+) \cap \operatorname{Conv}(X_-) = \emptyset$.

Step 2: Backward Direction ($\impliedby$):
By the Hyperplane Separation Theorem (Separating Axis Theorem for disjoint convex sets), if two sets $C_1 = \operatorname{Conv}(X_+)$ and $C_2 = \operatorname{Conv}(X_-)$ are non-empty, closed, bounded (compact) convex sets and $C_1 \cap C_2 = \emptyset$, there exists a non-zero vector $\mathbf{w}$ and scalar $b$ such that: $$\min_{\mathbf{x} \in C_1} (\mathbf{w}^T \mathbf{x} + b) > 0 > \max_{\mathbf{x} \in C_2} (\mathbf{w}^T \mathbf{x} + b)$$ Since $X_+ \subseteq C_1$ and $X_- \subseteq C_2$, the hyperplane $\mathbf{w}^T \mathbf{x} + b = 0$ strictly linearly separates $X_+$ and $X_-$.

Step 3: Application to XOR:
In the XOR problem: $$X_+ = \{(0, 1), (1, 0)\}, \quad X_- = \{(0, 0), (1, 1)\}$$ Let us construct their convex hulls:

  • $\operatorname{Conv}(X_+)$ is the line segment connecting $(0, 1)$ and $(1, 0)$: $$\mathbf{p}(\alpha) = \alpha \begin{pmatrix} 0 \\ 1 \end{pmatrix} + (1 - \alpha) \begin{pmatrix} 1 \\ 0 \end{pmatrix} = \begin{pmatrix} 1 - \alpha \\ \alpha \end{pmatrix}, \quad \alpha \in [0, 1]$$
  • $\operatorname{Conv}(X_-)$ is the line segment connecting $(0, 0)$ and $(1, 1)$: $$\mathbf{q}(\beta) = \beta \begin{pmatrix} 0 \\ 0 \end{pmatrix} + (1 - \beta) \begin{pmatrix} 1 \\ 1 \end{pmatrix} = \begin{pmatrix} 1 - \beta \\ 1 - \beta \end{pmatrix}, \quad \beta \in [0, 1]$$
Setting $\alpha = 0.5$ and $\beta = 0.5$: $$\mathbf{p}(0.5) = \begin{pmatrix} 0.5 \\ 0.5 \end{pmatrix}, \quad \mathbf{q}(0.5) = \begin{pmatrix} 0.5 \\ 0.5 \end{pmatrix}$$ Both line segments intersect at the center point $(0.5, 0.5)$! $$\operatorname{Conv}(X_+) \cap \operatorname{Conv}(X_-) = \{(0.5, 0.5)\} \neq \emptyset$$ Because the intersection is non-empty, linear separation is mathematically impossible. $\blacksquare$

Detailed Analysis:

When training with learning rate $\eta' = c \cdot \eta$ (where $c > 0$ is a scalar constant), the update rule at step $t$ is: $$\mathbf{w}'^{(t)} = \mathbf{w}'^{(t-1)} + c \eta y_t \mathbf{x}_t$$ Starting from $\mathbf{w}^{(0)} = \mathbf{0}$, by induction: $$\mathbf{w}'^{(t)} = c \cdot \mathbf{w}^{(t)}, \quad b'^{(t)} = c \cdot b^{(t)}$$ Now, evaluate the prediction on any candidate sample $\mathbf{x}$ using the primed parameters: $$\hat{y}' = \operatorname{sgn}(\mathbf{w}'^T \mathbf{x} + b') = \operatorname{sgn}(c \mathbf{w}^T \mathbf{x} + c b) = \operatorname{sgn}(c (\mathbf{w}^T \mathbf{x} + b))$$ Because $c > 0$ is strictly positive, the sign function is completely unaffected: $$\operatorname{sgn}(c \cdot z) = \operatorname{sgn}(z), \quad \forall c > 0$$ Therefore, $\hat{y}' \equiv \hat{y}$ for every single sample at every single iteration!
The perceptron misclassifies the exact same sequence of examples and terminates after the exact same number of mistakes.

Problem 3.1.8 Level 4 • Assertion-Reasoning & Parity Dimension Trap Google Meta

QUESTION: Evaluate the following Assertion and Reason regarding Boolean functions in higher dimensions:

Assertion (A): A single-layer perceptron $\hat{y} = \operatorname{sgn}(\mathbf{w}^T \mathbf{x} + b)$ cannot compute the $d$-bit parity function $f(\mathbf{x}) = x_1 \oplus x_2 \oplus \dots \oplus x_d$ for any dimension $d \ge 2$.

Reason (R): The $d$-bit parity function alternates output values on every adjacent vertex of the $d$-dimensional Boolean hypercube $\{0, 1\}^d$, requiring any separating boundary to isolate every adjacent pair of vertices, which cannot be achieved by any single linear hyperplane.

  1. Both (A) and (R) are true, and (R) is the correct mathematical explanation of (A).
  2. Both (A) and (R) are true, but (R) is NOT the correct explanation of (A).
  3. (A) is true, but (R) is false.
  4. (A) is false, but (R) is true.
✓ Correct Answer: A • Comprehensive Hypercube Proof

Detailed Analysis:
Analysis of Reason (R):
Consider the Boolean hypercube $\{0, 1\}^d$, which has $2^d$ vertices. Two vertices $\mathbf{u}, \mathbf{v} \in \{0, 1\}^d$ are adjacent (connected by an edge of length $1$) if and only if their Hamming distance is $1$ (they differ in exactly one coordinate bit).
The parity function is: $$f(\mathbf{x}) = \left(\sum_{i=1}^d x_i\right) \pmod 2$$ If $\mathbf{u}$ and $\mathbf{v}$ are adjacent, the sum $\sum x_i$ changes by exactly $\pm 1$.
Therefore, if $\mathbf{u}$ has even parity ($f=0$), $\mathbf{v}$ must have odd parity ($f=1$).
Every single edge of the hypercube connects a positive sample to a negative sample!
Reason (R) is true.

Analysis of Assertion (A):
Suppose a single linear hyperplane $\mathbf{w}^T \mathbf{x} + b = 0$ could separate even and odd parity vertices.
Then along every one of the $d \cdot 2^{d-1}$ edges of the hypercube, the hyperplane must cross between the two endpoints.
For $d = 2$, this reduces directly to the XOR problem (4 vertices, 4 edges forming a cycle), whose convex hulls intersect at $(0.5, 0.5)$.
For any $d \ge 2$, the center of mass of the $2^{d-1}$ even vertices is: $$\mathbf{c}_{\text{even}} = \frac{1}{2^{d-1}} \sum_{\mathbf{x} \in X_{\text{even}}} \mathbf{x} = \begin{pmatrix} 0.5 \\ 0.5 \\ \vdots \\ 0.5 \end{pmatrix}$$ And the center of mass of the $2^{d-1}$ odd vertices is: $$\mathbf{c}_{\text{odd}} = \frac{1}{2^{d-1}} \sum_{\mathbf{x} \in X_{\text{odd}}} \mathbf{x} = \begin{pmatrix} 0.5 \\ 0.5 \\ \vdots \\ 0.5 \end{pmatrix}$$ Both the positive and negative classes have the exact same centroid at $(0.5, \dots, 0.5)$!
Since their convex hulls intersect at this centroid ($\mathbf{c} \in \operatorname{Conv}(X_+) \cap \operatorname{Conv}(X_-)$), by the Convex Hull Separation Theorem (Problem 3.1.6), linear separation is mathematically impossible.
Thus, (A) is true, and (R) is the exact combinatorial explanation. $\blacksquare$

import numpy as np

class PerceptronScratch:
    """
    Rosenblatt's Perceptron with exact Novikoff convergence tracking.
    """
    def __init__(self, lr=1.0, max_epochs=100):
        self.lr = lr
        self.max_epochs = max_epochs
        self.w = None
        self.b = 0.0
        self.mistakes = 0

    def fit(self, X, y):
        # y must be in {-1, +1}
        N, d = X.shape
        self.w = np.zeros(d)
        self.b = 0.0
        self.mistakes = 0

        for epoch in range(self.max_epochs):
            converged = True
            for i in range(N):
                # Prediction: sgn(w^T x + b)
                pred = 1 if (np.dot(self.w, X[i]) + self.b) >= 0 else -1
                if pred != y[i]:
                    # Update rule on mistake
                    self.w += self.lr * y[i] * X[i]
                    self.b += self.lr * y[i]
                    self.mistakes += 1
                    converged = False

            if converged:
                print(f"Perceptron converged in epoch {epoch+1} with {self.mistakes} total mistakes!")
                return True

        print(f"Perceptron failed to converge after {self.max_epochs} epochs! (Non-linearly separable)")
        return False

    def predict(self, X):
        return np.where((X @ self.w + self.b) >= 0, 1, -1)

if __name__ == "__main__":
    # 1. Linearly Separable Logical AND
    X_and = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])
    y_and = np.array([-1, -1, -1, 1])

    print("--- Training on Logical AND ---")
    p_and = PerceptronScratch()
    p_and.fit(X_and, y_and)
    print(f"Learned AND Hyperplane: {p_and.w[0]:.1f}*x1 + {p_and.w[1]:.1f}*x2 + {p_and.b:.1f} = 0")

    # 2. Non-Linearly Separable Logical XOR
    X_xor = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])
    y_xor = np.array([-1, 1, 1, -1])

    print("\n--- Training on Logical XOR ---")
    p_xor = PerceptronScratch(max_epochs=20)
    p_xor.fit(X_xor, y_xor)
