Chapter 4.1

Convolutional Neural Networks

Convolutions, Strides, Receptive Fields & Residual Connections ✦

"The visual system of mammals is hierarchical, translating low-level edges into high-level semantic perception."

— David Hubel & Torsten Wiesel (Nobel Prize, 1981)

Foundation

Fully connected layers cannot scale to high-resolution computer vision. A modest $1024 \times 1024$ color image has over 3 million values; connecting this to a 1024-neuron hidden layer would require over 3 billion weight parameters for a single layer! Convolutional Neural Networks (CNNs) introduce two game-changing inductive biases: local receptive fields and translation-invariant weight sharing.

1. The Mathematics of 2D Convolution

Given an input image $I$ and a filter kernel $K$ of size $(K_h, K_w)$: $$S(i, j) = (I * K)(i, j) = \sum_{m=0}^{K_h-1} \sum_{n=0}^{K_w-1} I(i + m, j + n) K(m, n)$$ With padding $P$ and stride $S$, the output spatial dimension is: $$H_{\text{out}} = \left\lfloor \frac{H_{\text{in}} - K_h + 2P}{S} \right\rfloor + 1, \quad W_{\text{out}} = \left\lfloor \frac{W_{\text{in}} - K_w + 2P}{S} \right\rfloor + 1$$

Code Lab 4.1 — 2D Convolution Forward Pass from Scratch

🔗 View in GitHub: part4_deep_learning/ch41_cnn_vision/conv2d_from_scratch.py

import numpy as np

def conv2d_forward(X, W, b, stride=1, pad=0):
    N, C_in, H, W_in = X.shape
    C_out, _, K_h, K_w = W.shape
    X_pad = np.pad(X, ((0,0), (0,0), (pad,pad), (pad,pad))) if pad > 0 else X
    H_out = (H - K_h + 2*pad)//stride + 1
    W_out = (W_in - K_w + 2*pad)//stride + 1
    out = np.zeros((N, C_out, H_out, W_out))

    for n in range(N):
        for c in range(C_out):
            for h in range(H_out):
                for w in range(W_out):
                    patch = X_pad[n, :, h*stride:h*stride+K_h, w*stride:w*stride+K_w]
                    out[n, c, h, w] = np.sum(patch * W[c]) + b[c]
    return out
Chapter 4.2

RNNs & LSTMs

Sequential Modeling, Vanishing Gradients & The Constant Error Carousel ✦

"Memory is the scribe of the soul."

— Aristotle

Foundation

Standard feedforward networks assume all inputs are independent. Natural language, audio, speech, and stock prices are sequences where meaning depends on temporal order. Recurrent Neural Networks (RNNs) maintain an internal recurring hidden state $\mathbf{h}_t = \tanh(W_{hh}\mathbf{h}_{t-1} + W_{xh}\mathbf{x}_t + \mathbf{b})$.

1. The Vanishing Gradient Problem in Backpropagation Through Time (BPTT)

When unrolling an RNN across $T$ timesteps, the gradient of the loss $\mathcal{L}_T$ with respect to early hidden state $\mathbf{h}_1$ involves a chain of matrix multiplications: $$\frac{\partial \mathcal{L}_T}{\partial \mathbf{h}_1} = \frac{\partial \mathcal{L}_T}{\partial \mathbf{h}_T} \prod_{t=2}^T \frac{\partial \mathbf{h}_t}{\partial \mathbf{h}_{t-1}} = \frac{\partial \mathcal{L}_T}{\partial \mathbf{h}_T} \prod_{t=2}^T \text{diag}(1 - \mathbf{h}_t^2) W_{hh}^T$$ If the largest eigenvalue of $W_{hh}$ is less than 1, gradients vanish exponentially to zero as $T$ grows; if greater than 1, gradients explode to infinity. RNNs cannot retain long-term dependencies beyond 10–20 steps.

2. Long Short-Term Memory (LSTM): The Constant Error Carousel

Hochreiter and Schmidhuber (1997) designed the LSTM to maintain an uninterrupted additive highway called the Cell State $\mathbf{C}_t$, regulated by three multiplicative gates: $$\mathbf{f}_t = \sigma(W_f [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_f) \quad (\text{Forget Gate})$$ $$\mathbf{i}_t = \sigma(W_i [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_i) \quad (\text{Input Gate})$$ $$\tilde{\mathbf{C}}_t = \tanh(W_c [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_c) \quad (\text{Candidate State})$$ $$\mathbf{C}_t = \mathbf{f}_t \odot \mathbf{C}_{t-1} + \mathbf{i}_t \odot \tilde{\mathbf{C}}_t \quad (\text{Additive Cell Update})$$ $$\mathbf{o}_t = \sigma(W_o [\mathbf{h}_{t-1}, \mathbf{x}_t] + \mathbf{b}_o) \quad (\text{Output Gate})$$ $$\mathbf{h}_t = \mathbf{o}_t \odot \tanh(\mathbf{C}_t) \quad (\text{Hidden State Output})$$

Chapter 4.3

Attention & Seq2Seq

Eliminating the Fixed-Length Bottleneck Vector ✦

"Attention is the taking possession by the mind, in clear and vivid form, of one out of what seem several simultaneously possible objects or trains of thought."

— William James (1890)

Foundation

Early Sequence-to-Sequence (Seq2Seq) models compressed an entire 50-word input sentence into a single static context vector $\mathbf{v} \in \mathbb{R}^{512}$ before decoding. This created an information bottleneck: early words were forgotten, causing translation quality to degrade sharply on sentences longer than 15 words.

1. Bahdanau & Luong Attention

In 2014, Bahdanau et al. introduced Attention: instead of compressing everything into one vector, the decoder inspects all encoder hidden states $\mathbf{h}_1, \dots, \mathbf{h}_{T_x}$ and computes dynamic alignment scores $\alpha_{ij}$: $$e_{ij} = \mathbf{s}_{i-1}^T W_a \mathbf{h}_j \quad (\text{Alignment Score})$$ $$\alpha_{ij} = \frac{\exp(e_{ij})}{\sum_{k=1}^{T_x} \exp(e_{ik})} \quad (\text{Softmax Attention Weights})$$ $$\mathbf{c}_i = \sum_{j=1}^{T_x} \alpha_{ij} \mathbf{h}_j \quad (\text{Dynamic Context Vector})$$

Code Lab 4.3 — Scaled Dot-Product Attention from Scratch

🔗 View in GitHub: part4_deep_learning/ch43_attention_mechanisms/scaled_dot_product_attention.py

import numpy as np

def scaled_dot_product_attention(Q, K, V, mask=None):
    d_k = Q.shape[-1]
    scores = np.matmul(Q, np.swapaxes(K, -1, -2)) / np.sqrt(d_k)
    if mask is not None:
        scores = np.where(mask == 0, -1e9, scores)
    exp_s = np.exp(scores - np.max(scores, axis=-1, keepdims=True))
    weights = exp_s / np.sum(exp_s, axis=-1, keepdims=True)
    return np.matmul(weights, V), weights
Chapter 4.4

Transformers

Multi-Head Self-Attention & Modern Decoder Architectures ✦

"Attention is all you need."

— Ashish Vaswani et al. (2017)

Foundation

In 2017, the landmark paper "Attention Is All You Need" dismantled recurrent loops entirely. Recurrence enforced sequential $O(T)$ execution that prevented GPU parallelization. Transformers replaced recurrence with Self-Attention, processing all tokens simultaneously in $O(1)$ sequential operations.

1. Multi-Head Attention Mathematics

A single attention head risks averaging across multiple distinct semantic relationships. Multi-Head Attention projects Queries, Keys, and Values into $h$ independent subspaces of dimension $d_k = d_{\text{model}} / h$: $$\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h) W^O$$ $$\text{where } \text{head}_i = \text{Attention}(Q W_i^Q, K W_i^K, V W_i^V)$$

import torch
import torch.nn as nn

class TransformerBlock(nn.Module):
    def __init__(self, d_model=128, n_heads=4, ffn_dim=256):
        super().__init__()
        self.norm1 = nn.LayerNorm(d_model)
        self.attn = nn.MultiheadAttention(d_model, n_heads, batch_first=True)
        self.norm2 = nn.LayerNorm(d_model)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, ffn_dim),
            nn.GELU(),
            nn.Linear(ffn_dim, d_model)
        )

    def forward(self, x):
        # Pre-LN Residual Architecture
        x_norm = self.norm1(x)
        attn_out, _ = self.attn(x_norm, x_norm, x_norm)
        x = x + attn_out
        x = x + self.ffn(self.norm2(x))
        return x
Chapter 4.5

Generative Models

VAEs, GANs & Denoising Diffusion Probabilistic Models (DDPM) ✦

"What I cannot create, I do not understand."

— Richard Feynman

Foundation

Discriminative models estimate $P(y|\mathbf{x})$; generative models capture the joint distribution $P(\mathbf{x})$, enabling machines to create novel photorealistic images, synthetic audio, and molecular structures.

1. Variational Autoencoders (VAEs) & The Reparameterization Trick

A standard autoencoder maps inputs to deterministic latent points, leaving empty gaps in the latent space that decode into gibberish. VAEs (Kingma & Welling, 2013) map inputs to probability distributions $\mathcal{N}(\boldsymbol{\mu}, \text{diag}(\boldsymbol{\sigma}^2))$, regularized by a KL divergence penalty. To permit backpropagation through stochastic sampling: $$\mathbf{z} = \boldsymbol{\mu} + \boldsymbol{\sigma} \odot \boldsymbol{\epsilon}, \quad \text{where } \boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0}, I)$$

import numpy as np

def vae_reparameterize(mu, logvar):
    std = np.exp(0.5 * logvar)
    eps = np.random.randn(*mu.shape)
    return mu + eps * std

Audio & Speech

STFT Spectrograms, Mel-Filterbanks & Automatic Speech Recognition ✦

"Music is the pleasure the human mind experiences from counting without being aware that it is counting."

— Gottfried Wilhelm Leibniz

Foundation

Acoustic sound waves are 1D continuous pressure oscillations sampled at 16,000 or 44,100 Hz. By applying the Short-Time Fourier Transform (STFT) with overlapping window functions (Hanning), we project 1D audio into 2D time-frequency spectrograms, enabling modern Vision Transformers and CNNs to "see" sound.

🔗 View in GitHub: part4_deep_learning/ch46_audio_speech/spectrogram_and_audio_features.py

import numpy as np

def compute_spectrogram(waveform, frame_size=256, hop_size=128):
    window = np.hanning(frame_size)
    n_frames = 1 + (len(waveform) - frame_size) // hop_size
    return np.array([
        np.abs(np.fft.rfft(waveform[i*hop_size : i*hop_size + frame_size] * window))
        for i in range(n_frames)
    ]).T
