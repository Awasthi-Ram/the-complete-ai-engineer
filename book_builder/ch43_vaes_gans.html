Generative Modeling: VAEs & GANs

The Complete ELBO Derivation, Reparameterization Trick, Optimal Discriminators & WGAN-GP ✦

"What I cannot create, I do not understand."

— Richard Feynman

Foundation • Core Pillar

1. From Discrimination to Generation

A discriminative model estimates the conditional posterior $P(y \mid \mathbf{x})$, partitioning input space across predefined categorical boundaries. A Generative Model estimates the true underlying data distribution $P(\mathbf{x})$ (or joint distribution $P(\mathbf{x}, y)$). Once learned, an AI engineer can sample brand-new, photorealistic synthetic data points $\mathbf{x}_{\text{synthetic}} \sim P_{\text{model}}(\mathbf{x})$ that never existed in the empirical training corpus.

Why can we not simply generate synthetic images by picking random vectors from the latent bottleneck of a standard deterministic Autoencoder? In a standard autoencoder, the encoder projects training images into isolated, discrete manifolds in $\mathbb{R}^d$. The space between these manifolds is empty, unregularized, and chaotic; picking a vector from an unmapped coordinate generates meaningless high-frequency noise. Generative modeling requires enforcing a continuous, smooth probabilistic prior over the latent coordinate manifold.

2. Variational Autoencoders (VAEs): Kingma & Welling, 2013

A Variational Autoencoder (VAE) posits that observed high-dimensional data $\mathbf{x} \in \mathbb{R}^D$ is generated by an unobserved, lower-dimensional continuous latent variable $\mathbf{z} \in \mathbb{R}^d$ governed by a standard Gaussian prior:

$$p(\mathbf{z}) = \mathcal{N}(\mathbf{0}, \mathbf{I})$$

Data is generated via a parameterized decoder likelihood $p_\theta(\mathbf{x} \mid \mathbf{z})$. To learn the parameters $\theta$, we desire to maximize the marginal log-likelihood (evidence):

$$\ln p_\theta(\mathbf{x}) = \ln \int p_\theta(\mathbf{x}, \mathbf{z}) \, d\mathbf{z} = \ln \int p_\theta(\mathbf{x} \mid \mathbf{z}) p(\mathbf{z}) \, d\mathbf{z}$$

This integral is analytically intractable: in high-dimensional latent spaces (e.g. $d = 128$), computing this integral requires integrating over all of $\mathbb{R}^{128}$. To circumvent this, we introduce a variational recognition model (encoder) $q_\phi(\mathbf{z} \mid \mathbf{x})$ to approximate the intractable true posterior $p_\theta(\mathbf{z} \mid \mathbf{x})$.

🏆 First-Principles Mathematical Derivation of the ELBO

Consider the marginal log-evidence $\ln p_\theta(\mathbf{x})$. For any valid probability distribution $q_\phi(\mathbf{z} \mid \mathbf{x})$:

$$\ln p_\theta(\mathbf{x}) = \int q_\phi(\mathbf{z} \mid \mathbf{x}) \ln p_\theta(\mathbf{x}) \, d\mathbf{z} = \mathbb{E}_{q_\phi(\mathbf{z} \mid \mathbf{x})} \left[ \ln p_\theta(\mathbf{x}) \right]$$

Using Bayes' theorem, express $p_\theta(\mathbf{x}) = \frac{p_\theta(\mathbf{x}, \mathbf{z})}{p_\theta(\mathbf{z} \mid \mathbf{x})}$:

$$\ln p_\theta(\mathbf{x}) = \mathbb{E}_{q_\phi} \left[ \ln \frac{p_\theta(\mathbf{x}, \mathbf{z})}{p_\theta(\mathbf{z} \mid \mathbf{x})} \right]$$

Multiply and divide by $q_\phi(\mathbf{z} \mid \mathbf{x})$ inside the logarithm:

$$\ln p_\theta(\mathbf{x}) = \mathbb{E}_{q_\phi} \left[ \ln \left( \frac{p_\theta(\mathbf{x}, \mathbf{z})}{q_\phi(\mathbf{z} \mid \mathbf{x})} \cdot \frac{q_\phi(\mathbf{z} \mid \mathbf{x})}{p_\theta(\mathbf{z} \mid \mathbf{x})} \right) \right] = \mathbb{E}_{q_\phi} \left[ \ln \frac{p_\theta(\mathbf{x}, \mathbf{z})}{q_\phi(\mathbf{z} \mid \mathbf{x})} \right] + \mathbb{E}_{q_\phi} \left[ \ln \frac{q_\phi(\mathbf{z} \mid \mathbf{x})}{p_\theta(\mathbf{z} \mid \mathbf{x})} \right]$$

Recognize the second expectation as the Kullback-Leibler Divergence between the variational posterior and the true posterior:

$$\ln p_\theta(\mathbf{x}) = \underbrace{\mathbb{E}_{q_\phi(\mathbf{z} \mid \mathbf{x})} \left[ \ln \frac{p_\theta(\mathbf{x}, \mathbf{z})}{q_\phi(\mathbf{z} \mid \mathbf{x})} \right]}_{\text{ELBO}(\theta, \phi)} + \underbrace{D_{\text{KL}}\left( q_\phi(\mathbf{z} \mid \mathbf{x}) \;\parallel\; p_\theta(\mathbf{z} \mid \mathbf{x}) \right)}_{\ge 0}$$

Because the KL divergence is strictly non-negative ($D_{\text{KL}} \ge 0$), the first term forms a strict mathematical lower bound: the Evidence Lower Bound (ELBO):

$$\ln p_\theta(\mathbf{x}) \ge \operatorname{ELBO}(\theta, \phi)$$

Expanding $p_\theta(\mathbf{x}, \mathbf{z}) = p_\theta(\mathbf{x} \mid \mathbf{z}) p(\mathbf{z})$, the ELBO splits into two competing terms:

$$\operatorname{ELBO}(\theta, \phi) = \underbrace{\mathbb{E}_{q_\phi(\mathbf{z} \mid \mathbf{x})} \left[ \ln p_\theta(\mathbf{x} \mid \mathbf{z}) \right]}_{\text{Reconstruction Log-Likelihood}} - \underbrace{D_{\text{KL}}\left( q_\phi(\mathbf{z} \mid \mathbf{x}) \;\parallel\; p(\mathbf{z}) \right)}_{\text{Latent Prior Regularizer}}$$

Maximizing the ELBO simultaneously pushes the reconstruction fidelity higher while forcing the variational posterior $q_\phi(\mathbf{z} \mid \mathbf{x})$ to conform to the smooth standard Gaussian prior $p(\mathbf{z}) = \mathcal{N}(\mathbf{0}, \mathbf{I})$.

3. The Reparameterization Trick

To optimize the ELBO via backpropagation, we require gradients with respect to the encoder parameters $\phi$: $\nabla_\phi \mathbb{E}_{q_\phi(\mathbf{z} \mid \mathbf{x})} [\ln p_\theta(\mathbf{x} \mid \mathbf{z})]$. However, the expectation is taken with respect to the distribution $q_\phi$ whose parameters we are differentiating! Standard Monte Carlo sampling $\mathbf{z} \sim q_\phi(\mathbf{z} \mid \mathbf{x})$ is a stochastic discrete sampling operation with zero mathematical derivative.

The Coordinate Transformation Solution:
Kingma & Welling (2013) isolated the stochasticity by factoring the random variable into a deterministic, differentiable transformation of an independent noise source $\boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$:

$$\mathbf{z} = g_\phi(\mathbf{x}, \boldsymbol{\epsilon}) = \boldsymbol{\mu}_\phi(\mathbf{x}) + \boldsymbol{\sigma}_\phi(\mathbf{x}) \odot \boldsymbol{\epsilon}, \quad \text{where } \boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$$

By the Law of the Unconscious Statistician (LOTUS):

$$\nabla_\phi \mathbb{E}_{q_\phi(\mathbf{z} \mid \mathbf{x})} [f(\mathbf{z})] = \nabla_\phi \mathbb{E}_{p(\boldsymbol{\epsilon})} [f(g_\phi(\mathbf{x}, \boldsymbol{\epsilon}))] = \mathbb{E}_{p(\boldsymbol{\epsilon})} \left[ \nabla_\mathbf{z} f(\mathbf{z}) \cdot \nabla_\phi g_\phi(\mathbf{x}, \boldsymbol{\epsilon}) \right]$$

The derivative operator slips cleanly inside the expectation! Backpropagation flows through $\boldsymbol{\mu}_\phi(\mathbf{x})$ and $\boldsymbol{\sigma}_\phi(\mathbf{x})$ with zero gradient variance.

4. Generative Adversarial Networks (GANs) & WGAN-GP

In 2014, Ian Goodfellow et al. formulated generative modeling as a two-player zero-sum game between a Generator $G_\theta(\mathbf{z})$ and a Discriminator $D_\phi(\mathbf{x})$:

$$\min_G \max_D V(D, G) = \mathbb{E}_{\mathbf{x} \sim p_{\text{data}}} \left[ \ln D(\mathbf{x}) \right] + \mathbb{E}_{\mathbf{z} \sim p_z} \left[ \ln(1 - D(G(\mathbf{z}))) \right]$$

4.1 The Optimal Discriminator & Jensen-Shannon Divergence

For any fixed generator $G$, the optimal discriminator is derived by taking functional derivatives of $V(D, G)$ with respect to $D(\mathbf{x})$:

$$D^*(\mathbf{x}) = \frac{p_{\text{data}}(\mathbf{x})}{p_{\text{data}}(\mathbf{x}) + p_g(\mathbf{x})}$$

Substituting $D^*$ back into the minimax value function reveals the underlying mathematical objective:

$$V(D^*, G) = -\ln(4) + 2 \cdot D_{\text{JS}}\left( p_{\text{data}} \;\parallel\; p_g \right)$$

where $D_{\text{JS}}$ is the Jensen-Shannon Divergence. When the model distribution perfectly matches reality ($p_g = p_{\text{data}}$), $D^*(\mathbf{x}) = \frac{1}{2}$ everywhere, and $V(D^*, G) = -\ln 4 \approx -1.3863$.

4.2 The Vanishing Gradient Failure of Standard GANs

In high-dimensional spaces, real data $p_{\text{data}}$ and generated data $p_g$ lie on lower-dimensional manifolds that almost certainly have disjoint spatial support ($p_{\text{data}} \cap p_g = \emptyset$). When supports are disjoint, the Jensen-Shannon divergence is a flat constant: $D_{\text{JS}} = \ln 2$. The gradient $\nabla_\theta D_{\text{JS}}$ evaluates to exact zero! The discriminator saturates, leaving the generator with zero training signal.

4.3 Wasserstein GAN (WGAN) & Gradient Penalty (WGAN-GP)

Arjovsky et al. (2017) replaced JS-divergence with the Wasserstein-1 (Earth Mover's) Distance via the Kantorovich-Rubinstein duality:

$$W_1(P_r, P_g) = \sup_{\|D\|_L \le 1} \mathbb{E}_{\mathbf{x} \sim P_r}[D(\mathbf{x})] - \mathbb{E}_{\tilde{\mathbf{x}} \sim P_g}[D(\tilde{\mathbf{x}})]$$

where the Discriminator (now termed the Critic) is constrained to be 1-Lipschitz continuous: $|D(\mathbf{x}_1) - D(\mathbf{x}_2)| \le \|\mathbf{x}_1 - \mathbf{x}_2\|_2$.

To enforce the 1-Lipschitz constraint without weight clipping, Gulrajani et al. (2017) introduced the Gradient Penalty (WGAN-GP), penalizing the critic if the gradient norm deviates from 1 along linear interpolations $\hat{\mathbf{x}} = \epsilon \mathbf{x} + (1 - \epsilon) \tilde{\mathbf{x}}$:

$$\mathcal{L}_{\text{WGAN-GP}} = \underbrace{\mathbb{E}_{\tilde{\mathbf{x}}}[D(\tilde{\mathbf{x}})] - \mathbb{E}_{\mathbf{x}}[D(\mathbf{x})]}_{\text{Wasserstein Loss}} + \lambda \underbrace{\mathbb{E}_{\hat{\mathbf{x}}} \left[ \left( \|\nabla_{\hat{\mathbf{x}}} D(\hat{\mathbf{x}})\|_2 - 1 \right)^2 \right]}_{\text{Gradient Penalty}}$$

WGAN-GP provides continuous, monotonic gradients everywhere, completely eliminating mode collapse and training instability!

Problem 4.3.1 Hard Google Meta

QUESTION (Closed-Form Analytical Gaussian KL Divergence Proof): Prove that the Kullback-Leibler Divergence between the variational posterior $q_\phi(\mathbf{z} \mid \mathbf{x}) = \mathcal{N}(\boldsymbol{\mu}, \operatorname{diag}(\boldsymbol{\sigma}^2))$ and the standard Gaussian prior $p(\mathbf{z}) = \mathcal{N}(\mathbf{0}, \mathbf{I})$ in $\mathbb{R}^d$ evaluates to the closed-form equation:

$$D_{\text{KL}}\left( q_\phi(\mathbf{z} \mid \mathbf{x}) \parallel p(\mathbf{z}) \right) = -\frac{1}{2} \sum_{j=1}^d \left( 1 + \ln(\sigma_j^2) - \mu_j^2 - \sigma_j^2 \right)$$
✓ Complete First-Principles Mathematical Proof

Step 1: Factorize Across Dimensions: Because both $q_\phi(\mathbf{z} \mid \mathbf{x})$ and $p(\mathbf{z})$ have diagonal covariance matrices, the latent dimensions are mutually independent: $$q_\phi(\mathbf{z} \mid \mathbf{x}) = \prod_{j=1}^d q_j(z_j), \quad p(\mathbf{z}) = \prod_{j=1}^d p_j(z_j)$$ The multi-dimensional KL divergence decouples into the sum of $d$ single-variable Gaussian divergences: $$D_{\text{KL}}(q \parallel p) = \sum_{j=1}^d D_{\text{KL}}(q_j \parallel p_j) = \sum_{j=1}^d \int_{-\infty}^\infty q_j(z) \ln \frac{q_j(z)}{p_j(z)} \, dz$$

Step 2: Evaluate 1D Log Probability Densities: For a single dimension with $q(z) = \mathcal{N}(\mu, \sigma^2)$ and $p(z) = \mathcal{N}(0, 1)$: $$\ln q(z) = -\frac{1}{2} \ln(2\pi) - \frac{1}{2} \ln(\sigma^2) - \frac{(z - \mu)^2}{2\sigma^2}$$ $$\ln p(z) = -\frac{1}{2} \ln(2\pi) - \frac{z^2}{2}$$ Subtracting: $$\ln q(z) - \ln p(z) = -\frac{1}{2} \ln(\sigma^2) - \frac{(z - \mu)^2}{2\sigma^2} + \frac{z^2}{2}$$

Step 3: Integrate with Respect to $q(z)$: Taking the expectation $\mathbb{E}_{q(z)}[\ln q(z) - \ln p(z)]$: $$\mathbb{E}_q\left[ \frac{(z - \mu)^2}{2\sigma^2} \right] = \frac{\operatorname{Var}(z)}{2\sigma^2} = \frac{\sigma^2}{2\sigma^2} = \frac{1}{2}$$ $$\mathbb{E}_q\left[ \frac{z^2}{2} \right] = \frac{\operatorname{Var}(z) + (\mathbb{E}[z])^2}{2} = \frac{\sigma^2 + \mu^2}{2}$$ Combining the three terms: $$D_{\text{KL}}(q_j \parallel p_j) = -\frac{1}{2} \ln(\sigma^2) - \frac{1}{2} + \frac{\sigma^2 + \mu^2}{2} = -\frac{1}{2} \left( 1 + \ln(\sigma^2) - \mu^2 - \sigma^2 \right)$$ Summing over all $d$ dimensions: $$D_{\text{KL}}(q \parallel p) = -\frac{1}{2} \sum_{j=1}^d \left( 1 + \ln(\sigma_j^2) - \mu_j^2 - \sigma_j^2 \right) \quad \blacksquare$$ This closed form eliminates all numerical integration, computing in $\mathcal{O}(d)$ time on GPU hardware.

Problem 4.3.3 Hard Meta FAIR Apple

QUESTION (WGAN-GP Gradient Penalty Hand-Trace): Consider a 2D Critic network $D(\mathbf{x}) = x_1^2 + 2 x_2$. Let a real sample be $\mathbf{x} = [2.0, 1.0]^T$ and a generated fake sample be $\tilde{\mathbf{x}} = [0.0, 3.0]^T$. The gradient penalty interpolation parameter is sampled as $\epsilon = 0.5$.

  1. Calculate the interpolated point $\hat{\mathbf{x}} = \epsilon \mathbf{x} + (1 - \epsilon) \tilde{\mathbf{x}}$.
  2. Compute the gradient vector $\nabla_{\hat{\mathbf{x}}} D(\hat{\mathbf{x}})$ and its Euclidean norm $\|\nabla_{\hat{\mathbf{x}}} D(\hat{\mathbf{x}})\|_2$.
  3. Compute the exact scalar Gradient Penalty loss $\mathcal{L}_{\text{GP}} = \lambda \left( \|\nabla_{\hat{\mathbf{x}}} D(\hat{\mathbf{x}})\|_2 - 1 \right)^2$ with penalty weight $\lambda = 10.0$.
✓ Step-by-Step Gradient Penalty Trace

Step 1: Interpolation Point: $$\hat{\mathbf{x}} = 0.5 \begin{bmatrix} 2.0 \\ 1.0 \end{bmatrix} + 0.5 \begin{bmatrix} 0.0 \\ 3.0 \end{bmatrix} = \begin{bmatrix} 1.0 \\ 0.5 \end{bmatrix} + \begin{bmatrix} 0.0 \\ 1.5 \end{bmatrix} = \mathbf{\begin{bmatrix} 1.0 \\ 2.0 \end{bmatrix}}$$

Step 2: Gradient and Norm at $\hat{\mathbf{x}}$: Given $D(\mathbf{x}) = x_1^2 + 2 x_2$: $$\nabla_\mathbf{x} D(\mathbf{x}) = \begin{bmatrix} \frac{\partial D}{\partial x_1} \\ \frac{\partial D}{\partial x_2} \end{bmatrix} = \begin{bmatrix} 2 x_1 \\ 2 \end{bmatrix}$$ Evaluating at $\hat{\mathbf{x}} = [1.0, 2.0]^T$: $$\nabla_{\hat{\mathbf{x}}} D(\hat{\mathbf{x}}) = \begin{bmatrix} 2(1.0) \\ 2 \end{bmatrix} = \mathbf{\begin{bmatrix} 2.0 \\ 2.0 \end{bmatrix}}$$ Euclidean norm: $$\|\nabla_{\hat{\mathbf{x}}} D(\hat{\mathbf{x}})\|_2 = \sqrt{2.0^2 + 2.0^2} = \sqrt{4 + 4} = \sqrt{8} \approx \mathbf{2.82843}$$

Step 3: Gradient Penalty Evaluation: $$\mathcal{L}_{\text{GP}} = \lambda \left( \|\nabla D\|_2 - 1 \right)^2 = 10.0 \times \left( 2.82843 - 1.0 \right)^2 = 10.0 \times (1.82843)^2$$ $$(1.82843)^2 \approx 3.34315$$ $$\mathcal{L}_{\text{GP}} = 10.0 \times 3.34315 = \mathbf{33.4315}$$ Because the gradient norm ($\sqrt{8} \approx 2.83$) exceeds 1.0, the penalty heavily penalizes the Critic, driving the local slope back towards unit Lipschitz continuity.

Step 3: Total FID Score: $$\text{FID} = 5.0 + 2.0 = \mathbf{7.0000}$$ Notice that if $\boldsymbol{\mu}_g \to \boldsymbol{\mu}_r$ and $\boldsymbol{\Sigma}_g \to \boldsymbol{\Sigma}_r$, $\text{FID} \to 0$, indicating identical statistical distributions.

Problem 4.3.5 Hard Google Brain DeepMind

QUESTION (Mathematical Proof of Optimal Discriminator & JS Divergence): Consider Goodfellow et al.'s original GAN minimax objective:

$$V(D, G) = \int_{\mathbf{x}} \left[ p_{\text{data}}(\mathbf{x}) \ln D(\mathbf{x}) + p_g(\mathbf{x}) \ln(1 - D(\mathbf{x})) \right] d\mathbf{x}$$
  1. Prove that for any fixed generator $G$, the optimal discriminator $D^*(\mathbf{x})$ that maximizes $V(D, G)$ is: $$D^*(\mathbf{x}) = \frac{p_{\text{data}}(\mathbf{x})}{p_{\text{data}}(\mathbf{x}) + p_g(\mathbf{x})}$$
  2. Prove that substituting $D^*(\mathbf{x})$ into $V(D^*, G)$ reduces the objective to the Jensen-Shannon divergence: $$V(D^*, G) = -\ln 4 + 2 \cdot D_{\text{JS}}\left( p_{\text{data}} \parallel p_g \right)$$
  3. Deduce the global minimum of the virtual training criterion $C(G) = \max_D V(D, G)$ and show that it is achieved if and only if $p_g = p_{\text{data}}$.
✓ Complete First-Principles Mathematical Proof

Step 1: Maximizing the Objective for Fixed $G$: The objective $V(D, G)$ can be written as an integral over spatial coordinates $\mathbf{x}$: $$V(D, G) = \int_\mathbf{x} f(D(\mathbf{x})) \, d\mathbf{x}, \quad \text{where } f(y) = a \ln y + b \ln(1 - y)$$ with $a = p_{\text{data}}(\mathbf{x}) \ge 0$, $b = p_g(\mathbf{x}) \ge 0$, and $y = D(\mathbf{x}) \in (0, 1)$. To find the maximum of $f(y)$, set the first derivative to zero: $$\frac{df}{dy} = \frac{a}{y} - \frac{b}{1 - y} = 0 \implies \frac{a}{y} = \frac{b}{1 - y} \implies a(1 - y) = b y \implies a = (a + b) y$$ $$y^* = \frac{a}{a + b}$$ Checking second derivative: $\frac{d^2 f}{dy^2} = -\frac{a}{y^2} - \frac{b}{(1-y)^2} < 0$, confirming a unique global maximum. Substituting $a = p_{\text{data}}(\mathbf{x})$ and $b = p_g(\mathbf{x})$: $$D^*(\mathbf{x}) = \frac{p_{\text{data}}(\mathbf{x})}{p_{\text{data}}(\mathbf{x}) + p_g(\mathbf{x})} \quad \blacksquare$$

Step 2: Substitution into $V(D^*, G)$: Substitute $D^*$ and $1 - D^* = \frac{p_g}{p_{\text{data}} + p_g}$: $$V(D^*, G) = \int \left[ p_{\text{data}}(\mathbf{x}) \ln \left(\frac{p_{\text{data}}}{p_{\text{data}} + p_g}\right) + p_g(\mathbf{x}) \ln \left(\frac{p_g}{p_{\text{data}} + p_g}\right) \right] d\mathbf{x}$$ Multiply and divide the fractions inside the log by 2: $$\ln \left(\frac{p_{\text{data}}}{p_{\text{data}} + p_g}\right) = \ln \left(\frac{p_{\text{data}}}{\frac{p_{\text{data}} + p_g}{2}}\right) - \ln 2$$ $$\ln \left(\frac{p_g}{p_{\text{data}} + p_g}\right) = \ln \left(\frac{p_g}{\frac{p_{\text{data}} + p_g}{2}}\right) - \ln 2$$ Substituting these expressions back into the integral: $$V(D^*, G) = -\ln 2 \int p_{\text{data}}(\mathbf{x}) d\mathbf{x} - \ln 2 \int p_g(\mathbf{x}) d\mathbf{x} + \int p_{\text{data}} \ln \frac{p_{\text{data}}}{\frac{p_{\text{data}} + p_g}{2}} d\mathbf{x} + \int p_g \ln \frac{p_g}{\frac{p_{\text{data}} + p_g}{2}} d\mathbf{x}$$ Since $\int p_{\text{data}} = 1$ and $\int p_g = 1$: $$V(D^*, G) = -2 \ln 2 + D_{\text{KL}}\left( p_{\text{data}} \;\parallel\; \frac{p_{\text{data}} + p_g}{2} \right) + D_{\text{KL}}\left( p_g \;\parallel\; \frac{p_{\text{data}} + p_g}{2} \right)$$ By definition of the Jensen-Shannon Divergence $D_{\text{JS}}(P \parallel Q) = \frac{1}{2} D_{\text{KL}}(P \parallel M) + \frac{1}{2} D_{\text{KL}}(Q \parallel M)$ where $M = \frac{P+Q}{2}$: $$V(D^*, G) = -\ln 4 + 2 \cdot D_{\text{JS}}\left( p_{\text{data}} \;\parallel\; p_g \right) \quad \blacksquare$$

Step 3: Global Minimum: Since the Jensen-Shannon divergence is non-negative ($D_{\text{JS}} \ge 0$) and equals zero if and only if both distributions are identical ($p_g = p_{\text{data}}$): $$\min_G V(D^*, G) = -\ln 4 + 2(0) = \mathbf{-\ln 4 \approx -1.3863} \quad \blacksquare$$ The minimax game achieves its unique global optimum if and only if the generator perfectly replicates the true empirical data distribution.

Problem 4.3.6 Hard Meta Stanford

QUESTION (Mathematical Proof of Disjoint Support Gradient Vanishing in GANs vs. WGAN): In $\mathbb{R}^2$, let the true data distribution $P_r$ be uniform on a vertical unit line segment at $x = 0$: $P_r = (0, y)$ with $y \sim \mathcal{U}(0, 1)$. Let the generator distribution $P_\theta$ be uniform on a parallel vertical line segment at $x = \theta$: $P_\theta = (\theta, y)$ with $y \sim \mathcal{U}(0, 1)$, parameterized by scalar $\theta \in \mathbb{R}$.

  1. Prove that for all $\theta \ne 0$, the Jensen-Shannon Divergence is constant: $$D_{\text{JS}}(P_r \parallel P_\theta) = \ln 2$$ and deduce that the gradient $\frac{\partial}{\partial \theta} D_{\text{JS}}(P_r \parallel P_\theta) = 0$, proving that standard GANs provide zero gradient signal when supports do not overlap!
  2. Prove that the Wasserstein-1 (Earth Mover's) Distance is: $$W_1(P_r, P_\theta) = |\theta|$$ and show that its derivative $\frac{\partial}{\partial \theta} W_1(P_r, P_\theta) = \operatorname{sign}(\theta) \ne 0$ provides a continuous, non-zero gradient everywhere!
✓ Complete Geometric & Analytical Proof

Step 1: JS-Divergence Evaluation: When $\theta \ne 0$, the supports of $P_r$ (the line $x=0$) and $P_\theta$ (the line $x=\theta$) are completely disjoint: $$\operatorname{supp}(P_r) \cap \operatorname{supp}(P_\theta) = \emptyset$$ Let $M = \frac{P_r + P_\theta}{2}$. For any point $(0, y) \in \operatorname{supp}(P_r)$: $P_r(0, y) = 1$ and $M(0, y) = \frac{1}{2}$. Therefore: $$D_{\text{KL}}(P_r \parallel M) = \int_0^1 1 \cdot \ln\left(\frac{1}{1/2}\right) dy = \ln 2$$ Symmetrically: $$D_{\text{KL}}(P_\theta \parallel M) = \int_0^1 1 \cdot \ln\left(\frac{1}{1/2}\right) dy = \ln 2$$ The Jensen-Shannon Divergence evaluates to: $$D_{\text{JS}}(P_r \parallel P_\theta) = \frac{1}{2} D_{\text{KL}}(P_r \parallel M) + \frac{1}{2} D_{\text{KL}}(P_\theta \parallel M) = \frac{1}{2}(\ln 2) + \frac{1}{2}(\ln 2) = \mathbf{\ln 2 \approx 0.6931}$$ Notice that $D_{\text{JS}}$ is a flat constant function independent of $\theta$ for all $\theta \ne 0$! Taking the derivative with respect to parameter $\theta$: $$\frac{\partial}{\partial \theta} D_{\text{JS}}(P_r \parallel P_\theta) = \frac{\partial}{\partial \theta}(\ln 2) = \mathbf{0} \quad \blacksquare$$ The gradient vanishes identically! Even if the generated line is right next to the true data ($\theta = 0.001$), backpropagation delivers zero learning signal.

Step 2: Wasserstein Distance Evaluation: The Wasserstein-1 distance measures the minimum cost of transporting probability mass from $P_\theta$ to $P_r$: $$W_1(P_r, P_\theta) = \inf_{\gamma \in \Pi(P_r, P_\theta)} \mathbb{E}_{(\mathbf{x}, \mathbf{y}) \sim \gamma} \left[ \|\mathbf{x} - \mathbf{y}\|_2 \right]$$ For every point $(\theta, y) \sim P_\theta$, the optimal transport plan moves probability mass horizontally across the distance $|\theta|$ to $(0, y) \sim P_r$. The Euclidean transport distance is: $$\|(\theta, y) - (0, y)\|_2 = \sqrt{(\theta - 0)^2 + (y - y)^2} = \sqrt{\theta^2} = |\theta|$$ Integrating over all $y \in [0, 1]$: $$W_1(P_r, P_\theta) = \int_0^1 |\theta| dy = \mathbf{|\theta|} \quad \blacksquare$$ Differentiating with respect to $\theta$: $$\frac{\partial}{\partial \theta} W_1(P_r, P_\theta) = \frac{\partial}{\partial \theta}|\theta| = \operatorname{sign}(\theta) = \begin{cases} +1 & \text{if } \theta > 0 \\ -1 & \text{if } \theta < 0 \end{cases}$$ The gradient magnitude is strictly $\mathbf{1.0}$ everywhere! Regardless of how far apart the distributions are, gradient descent on $W_1$ drives $\theta \to 0$ at a constant, non-vanishing velocity. This proves mathematically why Wasserstein GANs eliminate mode collapse and vanishing gradients.

Code Lab 4.3 — Variational Autoencoder (VAE) Engine

🔗 View in GitHub: part4_deep_learning/ch43_vaes_gans/vae_scratch.py

import torch
import torch.nn as nn
import torch.nn.functional as F

class VAE(nn.Module):
    def __init__(self, in_features=784, latent_dim=32):
        super().__init__()
        # Encoder
        self.fc1 = nn.Linear(in_features, 256)
        self.fc_mu = nn.Linear(256, latent_dim)
        self.fc_logvar = nn.Linear(256, latent_dim)

        # Decoder
        self.fc3 = nn.Linear(latent_dim, 256)
        self.fc4 = nn.Linear(256, in_features)

    def encode(self, x):
        h = F.relu(self.fc1(x))
        return self.fc_mu(h), self.fc_logvar(h)

    def reparameterize(self, mu, logvar):
        # z = mu + std * eps, where eps ~ N(0, I)
        std = torch.exp(0.5 * logvar)
        eps = torch.randn_like(std)
        return mu + eps * std

    def decode(self, z):
        h = F.relu(self.fc3(z))
        return torch.sigmoid(self.fc4(h))

    def forward(self, x):
        mu, logvar = self.encode(x)
        z = self.reparameterize(mu, logvar)
        return self.decode(z), mu, logvar

def vae_loss_function(recon_x, x, mu, logvar):
    # Reconstruction loss (Binary Cross-Entropy)
    recon_loss = F.binary_cross_entropy(recon_x, x, reduction="sum")
    # Analytical KL Divergence: -0.5 * sum(1 + log(sigma^2) - mu^2 - sigma^2)
    kl_loss = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
    return recon_loss + kl_loss

if __name__ == "__main__":
    vae = VAE(in_features=784, latent_dim=20)
    x = torch.rand(4, 784)
    recon_x, mu, logvar = vae(x)
    loss = vae_loss_function(recon_x, x, mu, logvar)
    print(f"VAE Forward Loss: {loss.item():.2f}")
    # Sample new random generation from prior N(0, I)
    z_sample = torch.randn(1, 20)
    generated_img = vae.decode(z_sample)
    print(f"Generated Image Shape: {generated_img.shape}")
