1. Categorical Encoding Strategies & Empirical Bayes Smoothing

Machine learning models are mathematical operators on vector spaces $\mathbb{R}^d$: they cannot ingest raw string tokens like "device_iphone" or "postal_code_94103". Translating discrete symbols into numerical vectors without injecting spurious bias is a foundational engineering discipline.

The Spectrum of Categorical Encodings

  • One-Hot Encoding: Maps each category $c \in \{1, \dots, K\}$ to a standard basis indicator vector $\mathbf{e}_c \in \{0, 1\}^K$. When cardinality is low ($K \le 10$), one-hot encoding introduces zero ordering assumptions. However, for high cardinality ($K \ge 10,000$, such as user IDs or IP addresses), it creates ultra-sparse, high-dimensional matrices that exhaust memory caches and trigger the curse of dimensionality.
  • Label / Ordinal Encoding: Assigns integers $0, 1, 2, \dots, K-1$. This artificially imposes a Euclidean metric: it asserts that $\text{Category 2} > \text{Category 1}$ and $\|\text{Cat 2} - \text{Cat 1}\| = \|\text{Cat 1} - \text{Cat 0}\|$. While tree-based algorithms can split on arbitrary thresholds, linear models and neural networks suffer fatal inductive distortions.
  • Frequency / Count Encoding: Replaces each category with its empirical marginal probability $P(c) = \frac{n_c}{N}$. Useful for capturing the "common vs. rare" signal, but assigns identical values to distinct categories that happen to have equal frequency.
  • Smoothed Target Encoding (Empirical Bayes Shrinkage): Replaces category $c$ with the expected value of target $y$ within that category, smoothed toward the global prior mean $\bar{y}_{\text{global}}$: $$\hat{x}_c = \lambda(n_c) \bar{y}_c + (1 - \lambda(n_c)) \bar{y}_{\text{global}} = \frac{n_c \bar{y}_c + m \cdot \bar{y}_{\text{global}}}{n_c + m}$$ Where $n_c$ is the sample count of category $c$, and $m$ is the prior smoothing parameter. If $n_c \to 0$ (rare category), the weight shifts entirely to the prior $\bar{y}_{\text{global}}$; if $n_c \gg m$ (frequent category), it trusts the empirical category mean $\bar{y}_c$.
  • The Hashing Trick (Feature Hashing): Maps arbitrary categorical strings directly into a fixed-size integer index $h(s) \pmod B$ using a uniform hash function (e.g., MurmurHash3). This allows streaming online learning over unbounded vocabularies in constant $O(1)$ memory. By the Birthday Paradox, the expected number of hash collisions across $n$ unique tokens in a hash table of size $B$ is approximately $\mathbb{E}[\text{collisions}] \approx \frac{n^2}{2B}$.

2. Numerical Normalization, Outlier Geometry & Power Transforms

When features operate on vastly different physical scales (e.g., Annual Income in $100,000s vs. Age in years $[18, 75]$), optimization surfaces become severely eccentric ellipsoidal ravines. Gradient descent zig-zags wildly across steep directions while stalling along flat directions, and distance-based models (KNN, SVM, K-Means) become completely dominated by high-variance features.

Scaler Mathematical Formula Sensitivity to Outliers Production Best Use Case
StandardScaler (Z-score) $z = \frac{x - \mu}{\sigma}$ High ($\mu$ and $\sigma$ are corrupted by extreme values) Normally distributed features, ridge/lasso regularization.
MinMaxScaler $x' = \frac{x - x_{\min}}{x_{\max} - x_{\min}}$ Extreme (A single outlier squashes $99.9\%$ of data into $[0, 0.01]$) Bounded image pixels $[0, 255] \to [0, 1]$, bounded neural activations.
RobustScaler $x' = \frac{x - \text{median}(x)}{\text{IQR}(x)} = \frac{x - Q_2}{Q_3 - Q_1}$ Zero (Median and Interquartile Range are robust to outliers) Default choice for real-world tabular data with heavy tails.

Power Transforms: The Box-Cox Transformation

Many linear and parametric models assume features are normally distributed. When features exhibit severe right-skewness (e.g., revenue, page views, click latency), the Box-Cox Power Transformation finds the optimal parameter $\lambda$ that maps strictly positive features $x > 0$ onto a Gaussian distribution:

$$y^{(\lambda)} = \begin{cases} \frac{x^\lambda - 1}{\lambda}, & \text{if } \lambda \neq 0 \\ \ln(x), & \text{if } \lambda = 0 \end{cases}$$

The optimal parameter $\lambda$ is estimated via maximum likelihood by maximizing the profile log-likelihood:

$$\ell(\lambda) = -\frac{N}{2} \ln(\hat{\sigma}^2(\lambda)) + (\lambda - 1) \sum_{i=1}^N \ln(x_i)$$

Where $\hat{\sigma}^2(\lambda) = \frac{1}{N} \sum_{i=1}^N (y_i^{(\lambda)} - \bar{y}^{(\lambda)})^2$. (For data with negative or zero values, the Yeo-Johnson transformation extends this formulation).

3. Missing Data Mechanisms: MCAR, MAR, and MNAR

Handling missing values (NaN) requires understanding the generative mechanism behind the absence of data:

  • Missing Completely at Random (MCAR): The probability of missingness is entirely independent of observed and unobserved data: $P(M \mid X_{\text{obs}}, X_{\text{mis}}) = P(M)$. Example: A blood sample tube is accidentally dropped on the laboratory floor. Simple mean or median imputation does not introduce structural bias.
  • Missing at Random (MAR): The missingness depends systematically on observed features, but not on the missing value itself: $P(M \mid X_{\text{obs}}, X_{\text{mis}}) = P(M \mid X_{\text{obs}})$. Example: Older patients are less likely to record blood pressure in an app, but conditional on Age, missingness is random. MICE (Multivariate Imputation by Chained Equations) or KNN imputation reconstructs MAR distributions effectively.
  • Missing Not at Random (MNAR): The missingness directly depends on the unobserved value itself: $P(M \mid X_{\text{obs}}, X_{\text{mis}}) \neq P(M \mid X_{\text{obs}})$. Example: High-income individuals refuse to disclose their salary on survey forms. Imputing the median destroys the signal! In MNAR scenarios, appending a Missing Indicator Column ($I_m = 1$ if missing else $0$) alongside median imputation is essential to preserve the missingness signal.

4. The Cardinal Sin of ML: Data Leakage

Data Leakage occurs when information from outside the training dataset (test labels, future timestamps, or unpartitioned entity groups) is inadvertently leaked into the model training pipeline. Leaky models exhibit spectacular 99.8% metrics in offline validation, but catastrophically collapse upon deployment to live production.

🚨 The Four Primary Vectors of Data Leakage

  1. Preprocessor Contamination (Fit-Before-Split): Fitting a scaler, imputer, or target encoder on the entire dataset before splitting into train/test: $$\text{FATAL ANTI-PATTERN: } \quad \text{scaler.fit}(X_{\text{all}}) \implies \text{test samples pollute } \mu \text{ and } \sigma!$$ Correct Protocol: Always split raw data first. Call scaler.fit(X_train), and then use scaler.transform(X_test) using exclusively the training statistics!
  2. In-Sample Target Leakage: Using features that are direct consequences of the target variable. For example, in a loan default model, including the feature collection_agency_referral_date—which is only generated after the loan has defaulted!
  3. Temporal (Lookahead) Leakage: In time-series and financial models, using future moving averages, future min/max windows, or shuffle-based cross-validation across time boundaries. Time-series cross-validation must always strictly preserve causality (Purged Walk-Forward Splitting).
  4. Group / Entity Contamination: In healthcare or audio datasets where multiple measurements come from the same patient or user. A random split places recordings of Patient A in both train and test sets. The model memorizes Patient A's unique vocal timbre or anatomical anomalies rather than learning disease pathology, failing completely on new patients. GroupKFold is mandatory.

QUESTION: You are training a customer churn prediction model on a dataset with global churn rate $\bar{y}_{\text{global}} = 0.20$ (20% churn). You apply Empirical Bayes Smoothed Target Encoding with smoothing parameter $m = 10$ to the categorical feature City: $$\hat{x}_c = \frac{n_c \bar{y}_c + m \cdot \bar{y}_{\text{global}}}{n_c + m}$$

  1. City Omaha has $n_{\text{Omaha}} = 5$ customers, of whom $2$ churned ($\bar{y}_{\text{Omaha}} = 0.40$). Compute the exact smoothed target encoded value $\hat{x}_{\text{Omaha}}$.
  2. City Seattle has $n_{\text{Seattle}} = 190$ customers, of whom $19$ churned ($\bar{y}_{\text{Seattle}} = 0.10$). Compute the exact smoothed target encoded value $\hat{x}_{\text{Seattle}}$.
  3. Explain the shrinkage behavior observed between the rare city (Omaha) and the high-volume city (Seattle).
✓ Complete Step-by-Step Arithmetic Solution

Step 1: Compute Smoothed Encoding for Omaha:
Given: $n_c = 5$, $\bar{y}_c = 0.40$, $m = 10$, $\bar{y}_{\text{global}} = 0.20$.
$$\hat{x}_{\text{Omaha}} = \frac{(5 \times 0.40) + (10 \times 0.20)}{5 + 10} = \frac{2.0 + 2.0}{15} = \frac{4.0}{15} \approx 0.2667 \quad (26.67\%)$$

Step 2: Compute Smoothed Encoding for Seattle:
Given: $n_c = 190$, $\bar{y}_c = 0.10$, $m = 10$, $\bar{y}_{\text{global}} = 0.20$.
$$\hat{x}_{\text{Seattle}} = \frac{(190 \times 0.10) + (10 \times 0.20)}{190 + 10} = \frac{19.0 + 2.0}{200} = \frac{21.0}{200} = 0.1050 \quad (10.50\%)$$

Step 3: Shrinkage Interpretation:

  • For Omaha, $n_c = 5$ is much smaller than $m = 10$. The empirical mean of $0.40$ is unreliable due to small sample noise. The smoothing pulls the estimate from $0.40$ down to $0.2667$, shrinking by $66.7\%$ toward the global prior of $0.20$.
  • For Seattle, $n_c = 190$ is vastly larger than $m = 10$. The category has strong statistical evidence. The smoothing only shifts the estimate from $0.1000$ to $0.1050$ (a tiny $5\%$ shrinkage toward the prior).
This confirms that Empirical Bayes smoothing dynamically protects against small-sample variance while honoring large-sample statistical evidence.

Problem 2.8.2 Level 1 • Direct Formula Drill Meta

QUESTION: Consider a dataset of 5 observations for a server latency metric (in milliseconds): $$X = [10, 12, 14, 16, 1000]$$ Notice the extreme outlier at $1000$ ms.

Step 1: Compute Mean and Standard Deviation:

  • $(10 - 210.4)^2 = (-200.4)^2 = 40160.16$
  • $(12 - 210.4)^2 = (-198.4)^2 = 39362.56$
  • $(14 - 210.4)^2 = (-196.4)^2 = 38572.96$
  • $(16 - 210.4)^2 = (-194.4)^2 = 37791.36$
  • $(1000 - 210.4)^2 = (789.6)^2 = 623468.16$

Step 2: Compute Median, Quartiles, and IQR:
Sorted dataset: $[10, 12, 14, 16, 1000]$.

  • Median $Q_2 = 14$ (middle element).
  • Lower half: $[10, 12] \implies Q_1 = \frac{10 + 12}{2} = 11$.
  • Upper half: $[16, 1000] \implies Q_3 = \frac{16 + 1000}{2} = 508$ (or with standard midpoint interpolation on indices, $Q_1 = 11, Q_3 = 16$). Using quartile interpolation: $Q_1 = 11$, $Q_3 = 16 \implies \text{IQR} = 16 - 11 = 5$.

Step 4: RobustScaler Transformation of $x = 12$:
With $\text{median} = 14$ and $\text{IQR} = 5$: $$x' = \frac{12 - 14}{5} = \frac{-2}{5} = -0.4000$$ The other points map to: $10 \to -0.80$, $14 \to 0.00$, $16 \to +0.40$. The spacing between consecutive typical points ($10, 12, 14, 16$) is preserved at exactly $0.40$ units!

Step 5: Architectural Comparison:
StandardScaler allows the single outlier ($1000$) to heavily corrupt $\mu$ and inflate $\sigma$, collapsing the variance of normal operating data down to zero. RobustScaler uses rank-based statistics ($Q_1, Q_2, Q_3$), completely immunizing the typical data points from the outlier.

QUESTION: You are implementing one iteration of Multivariate Imputation by Chained Equations (MICE) on a bivariate dataset with $N = 4$ observations where $X_1$ contains a missing entry:

Step 2: Fit OLS Regression on Complete Cases:
Using complete samples $\{1, 2, 4\}$:

  • Sample 1: $x_{2,1} = 1.0, x_{1,1} = 2.0$
  • Sample 2: $x_{2,2} = 2.0, x_{1,2} = 4.0$
  • Sample 4: $x_{2,4} = 4.0, x_{1,4} = 8.0$

Problem 2.8.5 Level 3 • FAANG / Research Lab Proof Google Meta

QUESTION: Prove mathematically that when naive (in-sample) target encoding without smoothing is applied to a high-cardinality categorical feature where each category is unique to a single sample ($n_c = 1$, such as User_ID), any linear classifier or single-split decision tree achieves 100% training classification accuracy on binary labels, but exhibits an expected accuracy equal to random chance on unseen test data.

✓ Complete Mathematical Proof of Target Leakage

Step 1: Formal Formulation of In-Sample Target Encoding:
Let dataset $D = \{(\mathbf{x}_i, y_i)\}_{i=1}^N$ where $y_i \in \{0, 1\}$.
Let $c_i$ be a unique identifier feature such that $c_i \neq c_j$ for all $i \neq j$. That is, the frequency count $n_c = 1$ for every unique category $c$.
In naive in-sample target encoding, the category representation $\hat{x}_i$ is defined as the empirical sample mean of the target for category $c_i$: $$\hat{x}_i = \frac{1}{n_{c_i}} \sum_{j: c_j = c_i} y_j$$ Since $n_{c_i} = 1$, the only sample belonging to category $c_i$ is sample $i$ itself!

Step 2: Training Set Feature Calculation:
Evaluating the summation for each sample $i$: $$\hat{x}_i = \frac{1}{1} y_i = y_i$$ The engineered feature $\hat{x}_i$ is identically equal to the ground-truth target label: $$\hat{x}_i = \begin{cases} 1, & \text{if } y_i = 1 \\ 0, & \text{if } y_i = 0 \end{cases}$$

Step 3: Training Accuracy of a Trivial Linear Split:
Consider a trivial linear model or 1-split decision tree with decision rule: $$\hat{y}_i = \begin{cases} 1, & \text{if } \hat{x}_i \ge 0.5 \\ 0, & \text{if } \hat{x}_i < 0.5 \end{cases}$$ Since $\hat{x}_i = y_i$, for every sample $i \in \{1, \dots, N\}$: $$\hat{y}_i = y_i \implies \text{Training Accuracy} = \frac{1}{N} \sum_{i=1}^N \mathbb{I}(\hat{y}_i = y_i) = 1.0 \quad (100\%)$$ The model achieves zero training empirical risk without learning any generalized relationship.

Step 4: Generalization to Unseen Test Data:
Now consider an unseen test sample $(\mathbf{x}_{\text{test}}, y_{\text{test}})$.
Because $c_{\text{test}}$ is a new unique user ID never seen in the training dataset ($c_{\text{test}} \notin \{c_1, \dots, c_N\}$), the mapping table contains no entry for $c_{\text{test}}$.
Standard fallback assigns the global training mean $\hat{x}_{\text{test}} = \bar{y}_{\text{global}} = \frac{1}{N} \sum_{i=1}^N y_i = p$.
Since $\hat{x}_{\text{test}}$ is a constant $p$ for all test samples:

  • If $p \ge 0.5$, the model predicts $\hat{y}_{\text{test}} = 1$ for all test samples. Expected test accuracy is $P(Y=1) = p$.
  • If $p < 0.5$, the model predicts $\hat{y}_{\text{test}} = 0$ for all test samples. Expected test accuracy is $P(Y=0) = 1 - p$.
  • For a balanced dataset ($p = 0.5$), the expected test accuracy is exactly $50\%$ (random chance).
The model learned an exact mathematical identity on the training set through in-sample target leakage ($\hat{x} \equiv y$), completely destroying its out-of-sample generalization. $\blacksquare$

Problem 2.8.6 Level 3 • FAANG / Research Lab Proof Google

QUESTION: Starting from the assumption that the Box-Cox transformed variable $y_i^{(\lambda)} = \frac{x_i^\lambda - 1}{\lambda}$ follows a univariate Gaussian distribution $y^{(\lambda)} \sim \mathcal{N}(\mu, \sigma^2)$, derive the full Jacobian of the transformation and prove that the profile log-likelihood for estimating $\lambda$ is: $$\ell(\lambda) = -\frac{N}{2} \ln(\hat{\sigma}^2(\lambda)) + (\lambda - 1) \sum_{i=1}^N \ln(x_i)$$

✓ Complete First-Principles Derivation

Step 1: Density of the Transformed Variable:
Let $y_i^{(\lambda)} \sim \mathcal{N}(\mu, \sigma^2)$. The probability density function of $y_i^{(\lambda)}$ is: $$f_Y(y_i^{(\lambda)}) = \frac{1}{\sqrt{2\pi \sigma^2}} \exp\left( -\frac{(y_i^{(\lambda)} - \mu)^2}{2\sigma^2} \right)$$ By the change-of-variables theorem, the probability density function in terms of the original variable $x_i$ is: $$f_X(x_i) = f_Y(y_i^{(\lambda)}) \cdot \left| \frac{d y_i^{(\lambda)}}{d x_i} \right|$$

Step 2: Compute the Jacobian Determinant:
Differentiating the Box-Cox transformation with respect to $x_i$: $$\frac{d y_i^{(\lambda)}}{d x_i} = \frac{d}{d x_i} \left( \frac{x_i^\lambda - 1}{\lambda} \right) = \frac{1}{\lambda} (\lambda x_i^{\lambda - 1}) = x_i^{\lambda - 1}$$ For an i.i.d. dataset of $N$ observations, the overall Jacobian factor is: $$J = \prod_{i=1}^N \left| \frac{d y_i^{(\lambda)}}{d x_i} \right| = \prod_{i=1}^N x_i^{\lambda - 1}$$

Step 3: Construct the Full Likelihood Function:
$$L(\mu, \sigma^2, \lambda) = \prod_{i=1}^N \left[ \frac{1}{\sqrt{2\pi \sigma^2}} \exp\left( -\frac{(y_i^{(\lambda)} - \mu)^2}{2\sigma^2} \right) \cdot x_i^{\lambda - 1} \right]$$ Taking the natural logarithm: $$\ln L = -\frac{N}{2} \ln(2\pi) - \frac{N}{2} \ln(\sigma^2) - \frac{1}{2\sigma^2} \sum_{i=1}^N (y_i^{(\lambda)} - \mu)^2 + \sum_{i=1}^N (\lambda - 1) \ln(x_i)$$

Step 4: Maximize with Respect to $\mu$ and $\sigma^2$:
For any fixed $\lambda$, the maximum likelihood estimates for $\mu$ and $\sigma^2$ are standard Gaussian MLEs: $$\hat{\mu}(\lambda) = \frac{1}{N} \sum_{i=1}^N y_i^{(\lambda)}$$ $$\hat{\sigma}^2(\lambda) = \frac{1}{N} \sum_{i=1}^N (y_i^{(\lambda)} - \hat{\mu}(\lambda))^2$$ Substituting $\hat{\mu}$ and $\hat{\sigma}^2$ back into the third term of the log-likelihood: $$-\frac{1}{2 \hat{\sigma}^2} \sum_{i=1}^N (y_i^{(\lambda)} - \hat{\mu})^2 = -\frac{1}{2 \hat{\sigma}^2} (N \hat{\sigma}^2) = -\frac{N}{2}$$

Step 5: Form the Concentrated Profile Log-Likelihood:
Substituting $\hat{\mu}$ and $\hat{\sigma}^2$ into $\ln L$ and omitting additive constants independent of $\lambda$ ($-\frac{N}{2} \ln(2\pi) - \frac{N}{2}$): $$\ell(\lambda) = -\frac{N}{2} \ln(\hat{\sigma}^2(\lambda)) + (\lambda - 1) \sum_{i=1}^N \ln(x_i)$$ This profile log-likelihood is a 1-dimensional scalar function of $\lambda$ and can be maximized via golden-section search or Brent's method. $\blacksquare$

Problem 2.8.7 Level 4 • Conceptual Trap MCQ Google Meta

QUESTION: A machine learning team trains a deep neural network to detect rare pulmonary diseases from 10,000 chest X-ray images collected from 2,000 unique hospital patients (each patient contributed an average of 5 X-rays taken over different follow-up visits). The engineer performs a standard random 80/20 train/test split across the 10,000 images, achieves a phenomenal test AUC of 0.985, and deploys the model to a new partner hospital. At the new hospital, the model's AUC drops to 0.540 (virtually random guessing). What was the fundamental flaw?

  1. The test set was too small to provide statistical power, causing severe estimator variance.
  2. Group / Patient-level data leakage: because the split was randomized over images rather than patients, images from the same patient appeared in both train and test sets, allowing the network to memorize unique patient anatomical signatures rather than generalized disease features.
  3. The model suffered from gradient vanishing because the learning rate was not scaled inversely with the patient count.
  4. StandardScaler was fitted on the training images, causing color palette drift on the partner hospital's X-ray scanner.
✓ Correct Answer: B • Comprehensive Distractor Analysis

Detailed Analysis:
This is a classic, catastrophic example of Group / Entity Data Leakage in medical imaging and speech recognition. Each patient's chest anatomy has unique, highly distinctive idiosyncratic features (rib cage geometry, heart shape, lung volume, bone density, surgical staples, pacemakers).
When images are randomly split:

  • Patient 104's X-rays from visits 1, 2, 4 are in the training set.
  • Patient 104's X-rays from visits 3 and 5 end up in the test set.
Deep convolutional networks have millions of parameters and are extraordinarily capable of memorizing patient identities. Instead of learning subtle lung opacity signatures (the disease), the network simply learned: "This unique rib cage shape belongs to Patient 104, who was labeled positive in training $\implies$ output 1.0".
When deployed to a new hospital, every patient is a brand-new identity never seen before. The model's identity-lookup trick fails completely, and performance collapses to 0.54.
Mitigation: You must always use GroupKFold partitioned on patient_id, ensuring that all images from any given patient belong exclusively to either the training set or the test set.

Why Other Options are False:

  • A is FALSE: A test set of 2,000 images has very high statistical power; the confidence interval width is $\pm 0.015$, not a collapse from 0.985 to 0.540.
  • C is FALSE: Learning rate scaling has nothing to do with offline test vs. live hospital generalization disparity.
  • D is FALSE: While domain shift across scanners can reduce performance moderately (e.g., from 0.98 to 0.88), a total collapse to near-random performance (0.54) on an offline 0.985 model is the undeniable signature of identity leakage.

Problem 2.8.8 Level 4 • Assertion-Reasoning & MNAR Imputation Amazon

QUESTION: Evaluate the following Assertion and Reason regarding missing data imputation:

Assertion (A): When dealing with Missing Not at Random (MNAR) tabular features, replacing missing values with the median while simultaneously appending a binary indicator column ($I_m = 1$ if missing, $0$ otherwise) preserves critical predictive capacity that unconditional median imputation alone destroys.

Reason (R): Under the MNAR mechanism, the condition $P(M = 1 \mid X_{\text{obs}}, X_{\text{mis}}) \neq P(M = 1 \mid X_{\text{obs}})$ holds, meaning the missingness status itself carries non-zero mutual information with respect to the target variable $y$, which the binary indicator column explicitly preserves as an independent feature.

  1. Both (A) and (R) are true, and (R) is the correct mathematical explanation of (A).
  2. Both (A) and (R) are true, but (R) is NOT the correct explanation of (A).
  3. (A) is true, but (R) is false.
  4. (A) is false, but (R) is true.
✓ Correct Answer: A • Comprehensive Analysis of MNAR Signals

Detailed Analysis:
Analysis of Reason (R):
By definition, Missing Not at Random (MNAR) means that whether a feature is missing depends directly on the unobserved value itself, or on an unmeasured latent variable that is correlated with the outcome $y$.
For example:

  • In loan underwriting, applicants who deliberately leave "Annual Income" blank frequently have very low or zero income.
  • In intensive care unit (ICU) data, doctors only order a serum lactate lab test if the patient is already showing symptoms of acute sepsis. The absence of the test ($M = 1$) indicates the patient is healthy; the presence of the test ($M = 0$) indicates potential critical illness!
Thus, the binary indicator variable $I_m = \mathbb{I}(X \text{ is missing})$ has high mutual information with the target: $I(I_m; Y) > 0$. Reason (R) is true.

Analysis of Assertion (A):
If an engineer merely executes SimpleImputer(strategy='median') without an indicator column, every missing entry is overwritten with the median value of the observed cohort.
This completely destroys the information that the value was missing in the first place! The model cannot distinguish between a patient whose lactate was measured and was normal ($1.5$ mmol/L) vs. a patient whose test was never ordered because they were asymptomatic.
By adding $I_m = 1$ (e.g. SimpleImputer(add_indicator=True) in scikit-learn), the model can learn two distinct parameters: $$\hat{y} = w_1 X_{\text{imputed}} + w_m I_m + b$$ When $I_m = 1$, $w_m$ acts as a dedicated bias correction for missingness. Thus, (A) is true, and (R) correctly explains why the indicator is essential.

Code Lab 2.8 — Out-of-Fold Target Encoder from Scratch

import numpy as np
from sklearn.model_selection import KFold

class OutOfFoldTargetEncoder:
    """
    Computes smoothed out-of-fold target encodings preventing label leakage.
    Applies empirical Bayes shrinkage toward the global target mean.
    """
    def __init__(self, n_splits=5, smoothing=10.0):
        self.n_splits = n_splits
        self.smoothing = smoothing
        self.global_mean_ = None
        self.mapping_ = {}

    def fit_transform(self, categories, y):
        self.global_mean_ = np.mean(y)
        encoded = np.zeros(len(categories))
        kf = KFold(n_splits=self.n_splits, shuffle=True, random_state=42)

        # 1. Compute Out-of-Fold encodings for training
        for train_idx, val_idx in kf.split(categories):
            cat_train, y_train = categories[train_idx], y[train_idx]
            cat_val = categories[val_idx]

            # Compute stats on K-1 folds
            unique_cats = np.unique(cat_train)
            fold_map = {}
            for c in unique_cats:
                y_c = y_train[cat_train == c]
                n_c = len(y_c)
                smoothed = (np.sum(y_c) + self.smoothing * self.global_mean_) / (n_c + self.smoothing)
                fold_map[c] = smoothed

            # Apply to validation fold
            encoded[val_idx] = np.array([fold_map.get(c, self.global_mean_) for c in cat_val])

        # 2. Compute full training mappings for inference transform
        unique_cats = np.unique(categories)
        for c in unique_cats:
            y_c = y[categories == c]
            n_c = len(y_c)
            self.mapping_[c] = (np.sum(y_c) + self.smoothing * self.global_mean_) / (n_c + self.smoothing)

        return encoded

    def transform(self, categories):
        return np.array([self.mapping_.get(c, self.global_mean_) for c in categories])

if __name__ == "__main__":
    cats = np.array(["electronics", "clothing", "electronics", "home", "clothing", "electronics", "home", "books"])
    labels = np.array([1, 0, 1, 0, 0, 0, 1, 0])
    encoder = OutOfFoldTargetEncoder(n_splits=3, smoothing=5.0)
    encoded_train = encoder.fit_transform(cats, labels)
    print("Out-of-Fold Encoded Training Array:\n", np.round(encoded_train, 4))
    test_cats = np.array(["electronics", "rare_luxury_auto"])
    print("Transformed Inference Array:\n", np.round(encoder.transform(test_cats), 4))
