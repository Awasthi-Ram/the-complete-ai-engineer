Essential AI Engineering Glossary

  • Agentic RAG: An advanced retrieval pattern where an autonomous agent dynamically plans, decomposes multi-part queries, invokes search and compute tools, evaluates retrieval quality, and self-corrects before synthesizing responses.
  • Autograd: Reverse-mode automatic differentiation tracking operations on computational tensors to compute exact vector-Jacobian products via the chain rule.
  • Backpropagation Through Time (BPTT): Unrolling a sequential recurrent computational graph across $T$ discrete timesteps to accumulate parameter gradients.
  • Bellman Equation: The foundational recursive relation in Reinforcement Learning decomposing value functions into immediate rewards plus discounted expected downstream returns: $V(s) = \max_a \sum_{s'} P(s'|s,a)[R(s,a,s') + \gamma V(s')]$.
  • BERT (Bidirectional Encoder Representations from Transformers): An encoder-only Transformer pre-trained with Masked Language Modeling (MLM) and Next Sentence Prediction (NSP), capturing deep bidirectional context across all tokens.
  • Bi-Encoder: A Siamese architecture encoding query and document into separate dense vectors offline, enabling sub-millisecond Maximum Inner Product Search (MIPS) at billion scale.
  • BPE (Byte-Pair Encoding): Subword tokenization algorithm that iteratively merges the most frequent adjacent character or byte pairs into single vocabulary tokens.
  • Cross-Encoder: An architecture concatenating query and document into a single token sequence, computing all-to-all bidirectional cross-attention for high-precision neural re-ranking.
  • Data Leakage: An evaluation catastrophe where information from the test or target dataset contaminates the training feature pipeline.
  • Deep Q-Networks (DQN): An RL algorithm parameterizing the action-value function $Q(s, a; \theta)$ using deep neural networks stabilized by Experience Replay buffers and Target Networks.
  • DoRA (Weight-Decomposed Low-Rank Adaptation): Parameter-efficient fine-tuning decomposing pre-trained weights into magnitude vectors and directional LoRA matrices, bridging the performance gap with full fine-tuning.
  • FastText: Word representation model representing words as bags of character $n$-grams, enabling rich embeddings for out-of-vocabulary (OOV) tokens and morphologically complex words.
  • FlashAttention: An exact IO-aware attention algorithm computing Softmax incrementally inside fast on-chip SRAM via tiling, eliminating quadratic HBM memory reads/writes.
  • GGUF: The binary file format developed by Georgi Gerganov for fast, single-file loading and quantized local inference of LLMs on CPUs and edge devices with llama.cpp.
  • GloVe (Global Vectors): An unsupervised embedding algorithm fitting log-bilinear vector dot products to log co-occurrence frequencies from the global corpus matrix via weighted least squares.
  • GQA (Grouped-Query Attention): An attention variant where multiple query heads share a smaller number of key-value heads, reducing KV Cache memory footprint by $4\times$ to $8\times$ with near-zero degradation.
  • Inductive Bias: The set of prior mathematical assumptions an algorithm makes about problem geometry (e.g., spatial translation invariance in CNNs, permutation equivariance in Transformers).
  • KV Cache: An inference optimization that caches Key and Value tensors in GPU memory across decoding steps to avoid redundant quadratic matrix multiplications.
  • LangGraph: A cyclic graph-based multi-agent orchestration framework built on the Pregel computation model, supporting persistent checkpointers, time-travel, and human-in-the-loop gates.
  • LCEL (LangChain Expression Language): A declarative, Unix-style composition protocol for building streaming, concurrent, and resilient LLM pipelines using the Runnable interface.
  • LoRA (Low-Rank Adaptation): Freezes pre-trained base model weights $W_0$ and injects trainable rank-decomposition matrices $B \times A$, reducing trainable parameters by over $99\%$.
  • LSTM (Long Short-Term Memory): A recurrent neural cell with forget, input, and output gates protecting an uninterrupted linear cell state highway from vanishing gradients.
  • Markov Decision Process (MDP): A 5-tuple $(\mathcal{S}, \mathcal{A}, P, R, \gamma)$ formalizing sequential decision making where state transitions satisfy the Markov property.
  • MCP (Model Context Protocol): An open, standardized JSON-RPC protocol defining bidirectional client-host communication between LLM agents and sandboxed external tools.
  • PPO (Proximal Policy Optimization): An on-policy actor-critic algorithm utilizing a clipped surrogate objective to prevent destabilizing large policy updates during RLHF.
  • PSI (Population Stability Index): A statistical metric measuring divergence between baseline training distributions and production inference distributions for drift detection.
  • RAG (Retrieval-Augmented Generation): Augmenting LLM prompts with semantically retrieved context chunks from non-parametric vector databases and knowledge graphs.
  • RAGAS: The quantitative evaluation framework assessing RAG pipelines across Faithfulness, Answer Relevance, Context Precision, and Context Recall.
  • ReAct: An autonomous agent framework interleaving Reasoning (Thought) and Acting (Tool execution) in an iterative loop.
  • RoPE (Rotary Position Embedding): Encodes relative token positions by rotating 2D coordinate slices of query and key vectors in the complex plane.
  • Self-RAG: A framework training models to generate adaptive reflection tokens to dynamically control when to retrieve, critique retrieval quality, and verify output faithfulness.
  • SVD (Singular Value Decomposition): Factorization of matrix $A$ into $U \Sigma V^T$, providing the mathematically optimal low-rank matrix approximation.
  • SwiGLU: Gated linear unit activation $\text{Swish}(\mathbf{x}W_{\text{gate}}) \odot (\mathbf{x}W_{\text{up}}) W_{\text{down}}$ widely used in frontier LLMs (LLaMA-3, Mistral, PaLM).
  • TF-IDF: Term Frequency-Inverse Document Frequency, a classic statistical measure evaluating keyword uniqueness across a document collection.
  • Word2Vec: Mikolov's continuous text representation architectures (Continuous Bag-of-Words and Skip-Gram) trained with Negative Sampling on unigram frequencies to the 0.75 power.
  • ZeRO (Zero Redundancy Optimizer): A memory optimization dividing optimizer states (ZeRO-1), gradients (ZeRO-2), and model parameters (ZeRO-3) across data-parallel ranks to train trillion-parameter models.
