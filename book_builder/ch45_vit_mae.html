Foundation • Core Pillar

1. An Image Is Worth 16x16 Words: ViT (Dosovitskiy et al., Google 2020)

For decades, computer vision was synonymous with convolutions. In 2020, Google Research shattered this paradigm by introducing the Vision Transformer (ViT), demonstrating that the standard Transformer architecture—applied directly to sequences of image patches with minimal modifications—could outperform state-of-the-art CNNs on ImageNet.

The Inductive Bias Trade-Off

  • Convolutional Networks (CNNs): Possess strong, hardcoded inductive biases: local connectivity ($3 \times 3$ windows) and translation equivariance. CNNs excel when training data is scarce, but their rigid local inductive bias acts as an architectural ceiling when training on hundreds of millions of images.
  • Vision Transformers (ViT): Possess virtually zero spatial inductive bias. Self-attention connects any pixel in the top-left corner directly to any pixel in the bottom-right corner starting from Layer 1. When pre-trained on massive datasets (JFT-300M), ViT scales far beyond CNN performance limits.

2. The Patch Embedding Transformation

How do we convert a continuous 2D image $X \in \mathbb{R}^{H \times W \times C}$ into a 1D sequence of discrete tokens acceptable by a Transformer?

📐 Mathematical Formulation of Patch Projections

Given an image $X \in \mathbb{R}^{H \times W \times C}$ and patch resolution $P \times P$ (typically $16 \times 16$):

  1. The total number of sequence patches $N$ is: $$N = \frac{H \cdot W}{P^2}$$ Example: For a $224 \times 224$ image with $P = 16$: $N = \frac{224 \times 224}{256} = \mathbf{196 \text{ patches}}$.
  2. Each 2D patch is flattened into a 1D vector $\mathbf{x}_p^i \in \mathbb{R}^{P^2 C} = \mathbb{R}^{16 \times 16 \times 3} = \mathbb{R}^{768}$.
  3. Each patch is projected into hidden dimension $D$ via a learned linear embedding matrix $\mathbf{E} \in \mathbb{R}^{(P^2 C) \times D}$.
  4. A learnable classification token $\mathbf{x}_{\text{class}}$ (identical to BERT's [CLS]) is prepended to the sequence.
  5. Learned 1D positional embeddings $\mathbf{E}_{\text{pos}} \in \mathbb{R}^{(N + 1) \times D}$ are added to preserve spatial geometry: $$\mathbf{z}_0 = \left[ \mathbf{x}_{\text{class}}; \, \mathbf{x}_p^1 \mathbf{E}; \, \mathbf{x}_p^2 \mathbf{E}; \, \dots; \, \mathbf{x}_p^N \mathbf{E} \right] + \mathbf{E}_{\text{pos}}$$

3. Masked Autoencoders (MAE): He et al., Meta 2021

How do we pre-train Vision Transformers without human labels? In NLP, BERT succeeded by masking $15\%$ of words. When Kaiming He et al. applied this to images, masking $15\%$ produced poor representations. Why? Because images have massive spatial redundancy: neighboring pixels are nearly identical, allowing a model to reconstruct a missing $16 \times 16$ patch by simple local pixel interpolation without understanding high-level visual concepts!

The MAE Paradigm: The 75% Masking Ratio & Asymmetric Architecture
Kaiming He et al. discovered that vision requires masking a staggering $75\%$ to $80\%$ of image patches! Masking $75\%$ eliminates local interpolation, forcing the network to understand holistic scene geometry (e.g. inferring that an eye requires a forehead, nose, and cheek).

The Asymmetric Compute Engine:

  • The deep, heavy ViT Encoder processes only the 25% visible patches! This slashes training FLOPs and memory by $4\times$!
  • A lightweight, shallow Decoder takes the processed visible representations, inserts learnable [MASK] tokens for the missing 75%, and reconstructs the raw pixels with Mean Squared Error loss.

FAANG & Tier-1 AI Interview Problems — Vision Transformers

Problem 4.5.1 Medium Google Meta

QUESTION: Why does natural language masked pre-training (BERT) use a 15% masking ratio, whereas visual masked autoencoding (MAE) requires a 75% to 80% masking ratio? Contrast the information density of human language vs. photographic pixels.

✓ Complete Step-by-Step Architectural Solution

Step 1: Information Density Differences:

  • Language is High-Density & Symbolic: Words are human-generated symbols concentrated with rich semantic meaning. A single missing word in a 10-word sentence (10% masking) can alter the entire meaning (e.g., removing "not" in "The drug is not safe"). Masking 75% of words destroys the grammatical structure, reducing language to uninterpretable gibberish.
  • Images are Low-Density & Spatially Redundant: Photographic pixels are continuous physical sensor readings. Neighboring pixels in a sky, wall, or coat are nearly identical. Masking only 15% allows the network to fill in missing patches via trivial interpolation of adjacent border pixels without learning semantic representations.

Step 2: The Thermodynamic Challenge of 75% Masking:
By masking 75% of patches, adjacent spatial hints are eliminated. To reconstruct the missing pixels of a dog's hind leg when only its ear and front paw are visible, the network is forced to learn an internal 3D structural model of canine anatomy! This creates rich visual representations that transfer effortlessly to downstream detection and segmentation tasks.

4. Production Code Lab 4.5: ViT Patch Embedding in PyTorch

Below is a clean, production-grade PyTorch implementation of the Vision Transformer Patch Embedding layer and [CLS] token concatenation.

Code Lab 4.5 — Vision Transformer Patch Embedding Engine

🔗 View in GitHub: part4_deep_learning/ch45_vit_mae/vit_patch_embed.py

import torch
import torch.nn as nn

class PatchEmbedding(nn.Module):
    """
    Splits image into non-overlapping patches and projects to hidden dimension D.
    Implemented efficiently as a 2D convolution with kernel_size=stride=patch_size!
    """
    def __init__(self, img_size=224, patch_size=16, in_channels=3, embed_dim=768):
        super().__init__()
        self.img_size = img_size
        self.patch_size = patch_size
        self.num_patches = (img_size // patch_size) ** 2

        # 2D Conv projection: Kernel and stride equal to patch size!
        self.proj = nn.Conv2d(in_channels, embed_dim, kernel_size=patch_size, stride=patch_size)

        # Learnable [CLS] token and 1D positional embeddings
        self.cls_token = nn.Parameter(torch.zeros(1, 1, embed_dim))
        self.pos_embed = nn.Parameter(torch.zeros(1, self.num_patches + 1, embed_dim))

    def forward(self, x):
        B, C, H, W = x.shape
        # (B, D, H/P, W/P) -> (B, D, N) -> (B, N, D)
        x = self.proj(x).flatten(2).transpose(1, 2)

        # Prepend [CLS] token across batch
        cls_tokens = self.cls_token.expand(B, -1, -1)
        x = torch.cat((cls_tokens, x), dim=1) # (B, N+1, D)

        # Add learned positional embeddings
        x = x + self.pos_embed
        return x

if __name__ == "__main__":
    patch_embed = PatchEmbedding(img_size=224, patch_size=16, in_channels=3, embed_dim=768)
    img = torch.randn(2, 3, 224, 224) # Batch of 2 images
    tokens = patch_embed(img)
    print(f"ViT Input Image Shape  : {img.shape}")
    print(f"ViT Output Tokens Shape: {tokens.shape} (196 patches + 1 [CLS] token = 197 tokens of dim 768!)")
