1. An Image Is Worth 16x16 Words: ViT (Dosovitskiy et al., Google 2020)

For over three decades, computer vision was synonymous with convolutional neural networks (LeNet, AlexNet, ResNet). In late 2020, Google Research shattered this monopoly with the Vision Transformer (ViT), demonstrating that the standard Transformer architecture—applied directly to sequences of non-overlapping image patches with zero convolutional inductive biases—could match or exceed state-of-the-art CNNs on ImageNet-1K and ImageNet-21K.

1.1 The Inductive Bias Dichotomy

Attribute Convolutional Neural Networks (CNNs) Vision Transformers (ViT)
Spatial Inductive Bias Extremely strong: hardcoded $3 \times 3$ locality & translation equivariance Virtually zero: global self-attention connects any pixel to any other from Layer 1
Receptive Field Growth Grows linearly with depth: $RF_l = RF_{l-1} + (K - 1) j_{l-1}$ Infinite from Layer 1: global all-to-all attention across all patches
Small Dataset Regime (< 1M images) Superior: strong inductive bias prevents overfitting on small data Inferior: easily overfits without massive regularizers
Massive Dataset Regime (> 100M images) Saturates: rigid inductive bias acts as an architectural ceiling Scales linearly: performance scales continuously with compute and data volume

2. The Patch Embedding Transformation & Architecture

Standard Transformer architectures accept a 1D sequence of discrete token vectors $\mathbf{Z} \in \mathbb{R}^{N \times D}$. To ingest a continuous 2D image $\mathbf{X} \in \mathbb{R}^{H \times W \times C}$, ViT partitions the image into non-overlapping spatial patches of size $P \times P$ (typically $P = 16$ or $P = 14$):

📐 Mathematical Formulation of ViT Sequence Construction

  1. Sequence Length Determination: The number of patches $N$ is: $$N = \frac{H \cdot W}{P^2}$$ Example: An image of resolution $224 \times 224$ with $P = 16$ yields $N = \frac{224 \times 224}{256} = \mathbf{196 \text{ visual tokens}}$.
  2. Linear Patch Projection: Each 2D patch is flattened into a 1D vector $\mathbf{x}_p^i \in \mathbb{R}^{P^2 C} = \mathbb{R}^{16 \times 16 \times 3} = \mathbb{R}^{768}$, and projected into hidden dimension $D$ via a learned embedding matrix $\mathbf{E} \in \mathbb{R}^{(P^2 C) \times D}$: $$\mathbf{e}_i = \mathbf{x}_p^i \mathbf{E} \in \mathbb{R}^D$$ In practice, this is implemented as a 2D convolution with kernel_size=P, stride=P!
  3. The Classification Token ([CLS]): To perform image-level classification without arbitrarily favoring any individual spatial patch, a learnable token embedding $\mathbf{x}_{\text{class}} \in \mathbb{R}^D$ is prepended to the patch sequence, expanding sequence length to $N + 1$.
  4. 1D Learnable Positional Embeddings: Because self-attention is permutation-invariant, spatial geometry is injected via learned 1D position vectors $\mathbf{E}_{\text{pos}} \in \mathbb{R}^{(N + 1) \times D}$: $$\mathbf{z}_0 = \left[ \mathbf{x}_{\text{class}}; \, \mathbf{e}_1; \, \mathbf{e}_2; \, \dots; \, \mathbf{e}_N \right] + \mathbf{E}_{\text{pos}}$$

3. Swin Transformer: Shifted Windows for Hierarchical Vision

Standard ViT has two major limitations for dense prediction tasks (detection and segmentation):

  1. Quadratic Computational Complexity: Global self-attention across $N = \frac{HW}{P^2}$ patches has complexity $\mathcal{O}(N^2 D) = \mathcal{O}\left( \frac{H^2 W^2}{P^4} D \right)$. For high-resolution images ($1024 \times 1024$), $N = 4096$, requiring billions of attention operations per layer.
  2. Single-Scale Representations: ViT maintains a constant sequence length $N$ throughout all layers, unlike CNNs which produce multi-scale feature pyramids ($1/4, 1/8, 1/16, 1/32$).

Liu et al. (2021) introduced the Swin Transformer (Shifted Window Transformer):

  • Local Window Self-Attention: The image is partitioned into non-overlapping local windows of size $M \times M$ (typically $M = 7$). Self-attention is computed strictly within each local window, reducing computational complexity from quadratic to linear: $$\text{FLOPs}_{\text{Swin}} = 4 H W D + 2 M^2 H W D = \mathcal{O}(H W)$$
  • Shifted Window Partitioning: In alternating layers, window boundaries are shifted by $(\lfloor M/2 \rfloor, \lfloor M/2 \rfloor)$ pixels. This allows self-attention in layer $l+1$ to cross the boundaries of windows from layer $l$, enabling global context exchange with zero extra FLOPs via an efficient cyclic-shifting attention mask.

4. Masked Autoencoders (MAE): He et al., Meta 2021

In natural language processing, BERT succeeded by masking $15\%$ of tokens. However, directly applying $15\%$ masking to vision models yields poor representations. Photographic images have massive spatial redundancy: neighboring pixels are nearly identical. Masking $15\%$ allows the network to fill in missing patches via trivial interpolation of neighboring pixels without learning semantic representations!

The MAE Paradigm: The 75% Masking Ratio & Asymmetric Architecture
Kaiming He et al. discovered that vision requires masking a staggering $75\%$ to $80\%$ of image patches! Masking $75\%$ eliminates local interpolation, forcing the network to infer holistic visual semantics (e.g., predicting that an eye necessitates a forehead, nose, and cheek).

The Asymmetric Compute Architecture:

  • Encoder on Visible Patches Only: The deep, heavy ViT Encoder processes only the remaining 25% unmasked patches! Because self-attention is quadratic, running on $N/4$ tokens reduces encoder attention compute by a factor of $(\frac{1}{4})^2 = \mathbf{16\times}$!
  • Lightweight Decoder: A shallow decoder receives the processed visible embeddings, pads the sequence with learned, shared [MASK] tokens at the missing 75% coordinates, adds positional embeddings, and reconstructs the original raw pixels using Mean Squared Error loss.

Problem 4.5.1 Medium Google Meta

QUESTION (15% BERT vs. 75% MAE Masking Ratio Analysis): Why does natural language masked pre-training (BERT) use a 15% masking ratio, whereas visual masked autoencoding (MAE) requires a 75% to 80% masking ratio? Analyze the differences in information density, semantic abstraction, and entropy.

✓ Complete Information-Theoretic & Architectural Solution

Step 1: Information Density & Spatial Redundancy:

  • Natural Language (High Density, Discrete Symbols): Words are human-invented discrete symbols packed with compressed semantic entropy. Removing a single word from a 10-word sentence (10% masking) can invert the logical truth value (e.g. masking "not" in "The patient was not infected"). Masking $75\%$ of words leaves isolated disconnected nouns, destroying grammar and syntactic context, making language reconstruction ill-posed.
  • Natural Images (Low Density, Continuous Signals): Natural images consist of continuous spatial light intensity measurements. Adjacent pixels have correlation coefficients $\rho > 0.95$. In a $16 \times 16$ patch of sky, grass, or skin, masking only $15\%$ leaves adjacent boundary pixels visible. The network can reconstruct the missing pixels via simple bicubic boundary interpolation without understanding object semantics!

Step 2: The Thermodynamic Challenge of 75% Masking: By masking $75\%$ of patches (erasing 3 out of every 4 patches):

  • Local boundary hints are completely destroyed.
  • To reconstruct missing pixels of a car's wheel when only a fragment of the roof and windshield are visible, the network must learn an internal structural 3D world model of automotive geometry, illumination, and physics.
  • This forces the ViT encoder to learn high-level semantic representations that transfer seamlessly to downstream visual recognition.

The patch size is $P = 16 \times 16$, and the model hidden dimension is $D = 768$ with $h = 12$ attention heads (head dimension $d_k = 64$).

  1. Calculate the number of patches $N$ and the total sequence length fed into the Transformer encoder.
  2. Calculate the parameter count of the linear patch projection layer $\mathbf{E}$ (without bias).
  3. Calculate the FLOP count (Multiply-Accumulate operations) for a single Multi-Head Self-Attention (MHSA) layer on this sequence length.
✓ Step-by-Step ViT Hardware & Dimension Trace

Step 1: Patch and Sequence Sizing: Input image: $384 \times 384$. Patch size: $16 \times 16$. $$N = \frac{H \times W}{P^2} = \frac{384 \times 384}{16 \times 16} = 24 \times 24 = \mathbf{576 \text{ patches}}$$ Total sequence length including the prepended learnable [CLS] token: $$L = N + 1 = 576 + 1 = \mathbf{577 \text{ tokens}}$$

Step 2: Linear Patch Projection Parameters: Each $16 \times 16 \times 3$ patch has dimension $d_{\text{patch}} = 16 \times 16 \times 3 = 768$. Projecting from $d_{\text{patch}} = 768$ to model dimension $D = 768$: $$P_{\text{proj}} = d_{\text{patch}} \times D = 768 \times 768 = \mathbf{589,824 \text{ parameters}} \quad (\approx 0.59 \text{ M})$$

Step 3: MHSA Multiply-Accumulate Operations (MACs): For sequence length $L = 577$ and hidden dimension $D = 768$:

  1. Linear Projections for $\mathbf{Q}, \mathbf{K}, \mathbf{V}$ and Output: Four projections of size $D \times D$: $$\text{MACs}_{\text{proj}} = 4 \times (L \times D \times D) = 4 \times 577 \times 768^2 = 4 \times 577 \times 589,824 = \mathbf{1,361,313,792 \text{ MACs}}$$
  2. Attention Matrix Multiplications ($\mathbf{Q}\mathbf{K}^T$ and $\mathbf{A}\mathbf{V}$): For $h = 12$ heads with head dimension $d_k = 64$: $$\text{MACs}_{\mathbf{Q}\mathbf{K}^T} = h \times (L \times d_k \times L) = L^2 \times (h \cdot d_k) = L^2 D = 577^2 \times 768 = 332,929 \times 768 = \mathbf{255,689,472 \text{ MACs}}$$ $$\text{MACs}_{\mathbf{A}\mathbf{V}} = L^2 D = \mathbf{255,689,472 \text{ MACs}}$$
Total MHSA MACs per layer: $$\text{Total MACs} = 1,361,313,792 + 255,689,472 + 255,689,472 = \mathbf{1,872,692,736 \text{ MACs}} \quad (\approx 1.87 \text{ GMACs})$$

Problem 4.5.3 Hard Meta FAIR Google

QUESTION (2D Bicubic Positional Embedding Interpolation Algorithm): A Vision Transformer pre-trained on $224 \times 224$ images with patch size $P = 16$ has a 1D positional embedding tensor $\mathbf{E}_{\text{pos}} \in \mathbb{R}^{197 \times 768}$ (1 [CLS] token + 196 patch tokens arranged in a $14 \times 14$ grid). You want to fine-tune this model on high-resolution images of size $448 \times 448$, which requires $N_{\text{new}} = 28 \times 28 = 784$ spatial patches ($785$ total tokens).

  1. Why can we not simply initialize the new 785 positional embeddings randomly?
  2. Formulate the exact step-by-step tensor algorithm to interpolate $\mathbf{E}_{\text{pos}}$ from $197 \to 785$ using 2D bicubic interpolation while preserving the [CLS] embedding.
✓ Complete Architectural & PyTorch Implementation Solution

Step 1: Why Random Initialization Fails: Positional embeddings encode spatial coordinate geometry (e.g. patch 0 is adjacent to patch 1 and above patch 14). During pre-training across hundreds of millions of images, the self-attention heads learn precise spatial distance metrics. Discarding $\mathbf{E}_{\text{pos}}$ and initializing randomly destroys all learned spatial priors, causing catastrophic forgetting and requiring dozens of additional training epochs to recover.

Step 2: 2D Bicubic Resampling Algorithm:

  1. Separate [CLS] Token: Extract the classification token embedding (index 0), which has no 2D spatial coordinate: $$\mathbf{e}_{\text{cls}} = \mathbf{E}_{\text{pos}}[0:1, :] \in \mathbb{R}^{1 \times D}$$ Extract the spatial patch embeddings: $$\mathbf{E}_{\text{spatial}} = \mathbf{E}_{\text{pos}}[1:, :] \in \mathbb{R}^{196 \times D}$$
  2. Reshape to 2D Spatial Grid: Reshape the 196 1D tokens into their original $14 \times 14$ 2D spatial arrangement, and permute for PyTorch interpolation format $(B, C, H, W)$: $$\mathbf{E}_{\text{grid}} = \mathbf{E}_{\text{spatial}}.\text{reshape}(1, 14, 14, D).\text{permute}(0, 3, 1, 2) \in \mathbb{R}^{1 \times D \times 14 \times 14}$$
  3. Apply 2D Bicubic Interpolation: Interpolate the spatial grid from $14 \times 14 \to 28 \times 28$ using align_corners=False: $$\mathbf{E}_{\text{new\_grid}} = \text{F.interpolate}(\mathbf{E}_{\text{grid}}, \text{size}=(28, 28), \text{mode}=\text{"bicubic"}, \text{align\_corners}=\text{False}) \in \mathbb{R}^{1 \times D \times 28 \times 28}$$
  4. Flatten and Recombine: Permute and flatten back into a sequence of 784 spatial tokens: $$\mathbf{E}_{\text{new\_spatial}} = \mathbf{E}_{\text{new\_grid}}.\text{permute}(0, 2, 3, 1).\text{reshape}(1, 784, D) \in \mathbb{R}^{1 \times 784 \times D}$$ Concatenate the preserved [CLS] token back at index 0: $$\mathbf{E}_{\text{pos\_final}} = \left[ \mathbf{e}_{\text{cls}} \;\|\; \mathbf{E}_{\text{new\_spatial}} \right] \in \mathbb{R}^{1 \times 785 \times D}$$
The resulting positional embeddings smoothly extrapolate 2D spatial continuity across the higher resolution grid.

Problem 4.5.4 Hard Microsoft Research NVIDIA

QUESTION (Swin Transformer Shifted Window Masking Hand-Trace): Consider an $8 \times 8$ feature map partitioned into $2 \times 2$ regular windows of size $M = 4 \times 4$. In the next layer, the windows are shifted by displacement $(\lfloor M/2 \rfloor, \lfloor M/2 \rfloor) = (2, 2)$ pixels.

  1. Illustrate how the cyclic shift maps the $8 \times 8$ spatial grid into 9 sub-regions labeled $0$ through $8$.
  2. Explain why naive self-attention inside the shifted $4 \times 4$ windows causes invalid cross-boundary attention between non-adjacent spatial regions.
  3. Construct the attention masking rule that allows all windows to be processed simultaneously in a single batched GEMM without cross-boundary contamination.
✓ Complete Swin Cyclic Shift & Masking Solution

Step 1: Cyclic Shift Partitioning: An $8 \times 8$ grid has indices $0 \dots 7$ horizontally and vertically. Shifting window boundaries by $(2, 2)$ splits the grid into non-uniform corner/edge regions:

  • Top-left: $2 \times 2$
  • Top-right: $2 \times 6$
  • Bottom-left: $6 \times 2$
  • Bottom-right: $6 \times 6$
To preserve efficient $4 \times 4$ window computation, Swin applies a cyclic roll: pixels in the top 2 rows are rolled to the bottom, and pixels in the left 2 columns are rolled to the right. This packs the feature map back into four regular $4 \times 4$ windows!

Step 2: The Cross-Boundary Leakage Problem: After cyclic rolling, a single $4 \times 4$ window at the bottom-right contains sub-regions that originally came from completely opposite sides of the image (e.g. top-left corner pixels and bottom-right corner pixels now sit inside the same $4 \times 4$ window)! If standard self-attention $\operatorname{Softmax}(\mathbf{Q}\mathbf{K}^T / \sqrt{d_k})\mathbf{V}$ is computed, top-left pixels will attend to bottom-right pixels, falsely hallucinating strong spatial adjacency where none exists.

Step 3: The Masked Self-Attention Solution: Each pixel is assigned a sub-region ID $\in \{0, 1, \dots, 8\}$. For two tokens $i$ and $j$ inside the same window: $$\mathbf{M}_{ij} = \begin{cases} 0 & \text{if } \text{region}(i) = \text{region}(j) \quad (\text{valid same-subregion attention}) \\ -100.0 & \text{if } \text{region}(i) \ne \text{region}(j) \quad (\text{invalid cross-boundary attention}) \end{cases}$$ The attention calculation adds this mask before softmax: $$\operatorname{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \operatorname{Softmax}\left( \frac{\mathbf{Q}\mathbf{K}^T}{\sqrt{d_k}} + \mathbf{M} \right) \mathbf{V}$$ Because $\exp(-100.0) \approx 0.0$, invalid cross-boundary pairs receive exact zero attention weight! After self-attention, a reverse cyclic roll restores original pixel coordinates. This allows computing multi-window self-attention in a single parallel CUDA kernel without cross-boundary contamination.

Problem 4.5.5 Hard Google Brain DeepMind

QUESTION (Mathematical Proof of Pixel-Level vs. Patch-Level Attention Complexity): Consider an image of spatial dimension $H \times W$ and feature channels $C$.

  1. Prove that standard pixel-level self-attention has computational complexity $\Theta(H^2 W^2 D)$ and memory complexity $\Theta(H^2 W^2)$ per layer, demonstrating why full pixel self-attention is computationally impossible for high-resolution images.
  2. Prove that ViT patch-level self-attention with patch size $P \times P$ reduces the attention matrix memory by a factor of exactly $\mathbf{P^4}$.
  3. For an image of size $1024 \times 1024$ with $P = 16$, calculate the exact numerical reduction in attention matrix entries.
✓ Complete First-Principles Mathematical Proof

Step 1: Pixel-Level Self-Attention Complexity: At pixel level, every pixel is treated as a token: $$N_{\text{pixel}} = H \times W$$ The Query, Key, and Value matrices have dimension $\mathbf{Q}, \mathbf{K} \in \mathbb{R}^{(HW) \times D}$. Computing the full attention matrix $\mathbf{A} = \mathbf{Q}\mathbf{K}^T$: $$\mathbf{A} \in \mathbb{R}^{(HW) \times (HW)} = \mathbb{R}^{H^2 W^2}$$ Each matrix multiplication requires $H W \times D \times H W = H^2 W^2 D$ operations: $$\text{Compute Complexity} = \Theta(H^2 W^2 D), \quad \text{Memory Footprint} = \Theta(H^2 W^2) \quad \blacksquare$$ For a modest $1024 \times 1024$ image: $H W = 1,048,576$ pixels. The attention matrix would contain: $$N^2 = (1,048,576)^2 \approx \mathbf{1.10 \times 10^{12} \text{ entries (1.1 Trillion floats!)}}$$ At 2 bytes per FP16 number, storing a single attention matrix requires 2.2 Terabytes of VRAM! Pixel-level self-attention is physically impossible on modern GPU clusters.

Step 2: Patch-Level Attention Scaling Proof: By grouping pixels into non-overlapping patches of size $P \times P$, the sequence length becomes: $$N_{\text{patch}} = \frac{H W}{P^2}$$ The patch-level attention matrix $\mathbf{A}_{\text{patch}}$ has size: $$\text{Size}(\mathbf{A}_{\text{patch}}) = N_{\text{patch}}^2 = \left(\frac{HW}{P^2}\right)^2 = \frac{H^2 W^2}{P^4}$$ Taking the ratio of pixel-level to patch-level attention matrix size: $$\text{Compression Factor} = \frac{H^2 W^2}{\frac{H^2 W^2}{P^4}} = \mathbf{P^4} \quad \blacksquare$$

Step 3: Numerical Evaluation for $P = 16$: For standard patch size $P = 16$: $$\text{Compression Factor} = P^4 = 16^4 = \mathbf{65,536\times}$$ For the $1024 \times 1024$ image: $$N_{\text{patch}} = \frac{1024 \times 1024}{16 \times 16} = 64 \times 64 = 4,096 \text{ tokens}$$ The patch attention matrix size is: $$N_{\text{patch}}^2 = 4,096^2 = \mathbf{16,777,216 \text{ entries}}$$ In FP16, storing this matrix requires merely $16.78 \times 10^6 \times 2 \text{ bytes} \approx \mathbf{33.5 \text{ Megabytes}}$! Patchification reduces memory from an impossible 2.2 Terabytes down to 33.5 MB, making Transformer vision computationally tractable.

Problem 4.5.6 Hard Meta FAIR Stanford

QUESTION (Mathematical Proof of Asymmetric Masked Autoencoder Compute Efficiency): In Masked Autoencoders (He et al., 2021), an image has $N$ total patches. A fraction $\rho \in (0, 1)$ of patches are masked (typically $\rho = 0.75$), leaving $(1 - \rho)N$ visible patches. The encoder has $L_{\text{enc}}$ Transformer blocks of dimension $D_{\text{enc}}$, while the decoder has $L_{\text{dec}}$ Transformer blocks of dimension $D_{\text{dec}}$ ($D_{\text{dec}} \ll D_{\text{enc}}$, $L_{\text{dec}} \ll L_{\text{enc}}$).

  1. Prove that the encoder self-attention FLOPs scale as $(1 - \rho)^2$, yielding an exact $16\times$ reduction in encoder self-attention compute when $\rho = 0.75$.
  2. Prove that the linear projection and MLP FLOPs in the encoder scale as $(1 - \rho)$, yielding a $4\times$ reduction.
  3. Contrast this with standard BERT pre-training where all tokens (both masked and unmasked) pass through the encoder, and explain why MAE's asymmetric design makes self-supervised visual pre-training computationally feasible.
✓ Complete First-Principles Complexity Proof

Step 1: Encoder Self-Attention Scaling Proof: The sequence length entering the MAE encoder is $N_{\text{vis}} = (1 - \rho) N$. In each encoder block, computing attention weights $\mathbf{Q}\mathbf{K}^T$ and context $\mathbf{A}\mathbf{V}$ requires $2 N_{\text{vis}}^2 D_{\text{enc}}$ FLOPs: $$\text{FLOPs}_{\text{attn}}(\rho) = 2 \left( (1 - \rho) N \right)^2 D_{\text{enc}} = (1 - \rho)^2 \cdot \left( 2 N^2 D_{\text{enc}} \right) = (1 - \rho)^2 \cdot \text{FLOPs}_{\text{full}}$$ For masking ratio $\rho = 0.75 = \frac{3}{4}$, the visible fraction is $1 - \rho = 0.25 = \frac{1}{4}$: $$\text{Ratio} = (1 - 0.75)^2 = \left(\frac{1}{4}\right)^2 = \mathbf{\frac{1}{16} = 0.0625} \quad \blacksquare$$ The encoder self-attention compute drops by a factor of $16\times$ ($93.75\%$ savings).

Step 2: Linear Projection and MLP Scaling Proof: The linear projection layers ($\mathbf{Q}, \mathbf{K}, \mathbf{V}$ projections, output projection, and 2-layer MLP feedforward network with intermediate dimension $4 D_{\text{enc}}$) operate on each token independently: $$\text{FLOPs}_{\text{linear}}(\rho) = N_{\text{vis}} \times \left( 4 D_{\text{enc}}^2 + 8 D_{\text{enc}}^2 \right) = (1 - \rho) N \cdot 12 D_{\text{enc}}^2 = (1 - \rho) \cdot \text{FLOPs}_{\text{full}}$$ For $\rho = 0.75$: $$\text{Ratio} = 1 - 0.75 = \mathbf{\frac{1}{4} = 0.25} \quad \blacksquare$$ Linear projection and MLP FLOPs drop by exactly $4\times$ ($75\%$ savings).

Step 3: Contrast with BERT: In BERT (Devlin et al., 2018), when $15\%$ of tokens are masked, the encoder still processes the full sequence of $N$ tokens by replacing masked words with a learned [MASK] embedding. If MAE adopted BERT's strategy, the heavy ViT-Large encoder ($L=24, D=1024$) would process all $N = 196$ tokens. By physically removing the 75% masked tokens from the input list, the heavy encoder operates strictly on only 49 tokens! Only the tiny, lightweight decoder ($L=8, D=512$) processes all 196 tokens. This asymmetric pipeline slashes total training time by $> 70\%$, enabling self-supervised visual pre-training on thousands of GPU-hours rather than months.

Problem 4.5.7 Medium OpenAI Tesla

QUESTION (ViT Inductive Bias and Dataset Scaling Trap): When trained from scratch on the standard ImageNet-1K dataset (1.2 million images) without heavy data augmentation, a standard ViT-Base model achieves $77.9\%$ accuracy, which is significantly worse than a standard ResNet-50 ($80.2\%$). However, when pre-trained on Google's private JFT-300M dataset (300 million images), ViT achieves $88.5\%$, vastly outperforming ResNet. What fundamental theoretical principle explains this phenomenon?

  • (A) ViT suffers from gradient vanishing on small datasets; JFT-300M uses FP64 precision to prevent it.
  • (B) The Inductive Bias Trade-off: Convolutions possess hardcoded 2D translation equivariance and local connectivity, allowing CNNs to learn sample-efficient representations from small datasets ($1.2\text{M}$ images). ViT has no spatial inductive biases and must learn the concept of 2D visual geometry from scratch. On small datasets, ViT overfits; on massive datasets ($300\text{M}$ images), the lack of restrictive inductive biases allows ViT to discover visual representations with capacity far exceeding CNNs.
  • (C) ResNet cannot process images larger than $224 \times 224$ pixels.
  • (D) ViT requires batch sizes greater than 100,000 to compute positive eigenvalues.
✓ Correct Answer: (B)

Exhaustive Architectural Analysis:

  • (B) is CORRECT: Convolutions incorporate two built-in physical assumptions about the visual world: (1) adjacent pixels correlate locally, and (2) features are identical regardless of spatial location (translation equivariance). Because these assumptions are hardcoded into the network topology, CNNs do not need to spend training capacity learning basic spatial continuity; they generalize well with only $1.2\text{M}$ images. In contrast, Vision Transformers treat images as arbitrary sets of tokens; early ViT layers must discover from raw data that patch $(0, 1)$ is physically adjacent to patch $(0, 2)$! On small datasets, this excessive parameter freedom leads to severe overfitting. However, on massive datasets (JFT-300M), CNNs saturate because their rigid local receptive fields prevent them from modeling arbitrary long-range correlations, whereas ViT's unconstrained global self-attention scales continuously with compute and data volume.
  • (A) is INCORRECT: ViT uses standard LayerNorm and residual connections; gradient vanishing is not the cause of poor small-data performance.
  • (C) is INCORRECT: ResNet fully supports arbitrary resolution through adaptive average pooling.
  • (D) is INCORRECT: ViT trains effectively with standard mini-batch sizes ($B = 512$ to $4096$).

QUESTION (Patch Normalization in Masked Autoencoders): In the MAE paper (He et al., 2021), the authors discovered that computing the reconstruction loss on Normalized Patches (normalizing each target patch by subtracting its mean and dividing by its standard deviation) significantly improves downstream linear probing and fine-tuning accuracy. Why does patch normalization enhance representation learning?

  • (A) It reduces the byte size of the image tensor by $50\%$.
  • (B) Without normalization, the reconstruction MSE loss is dominated by trivial low-frequency illumination differences (e.g. predicting whether a patch is bright sunlight vs dark shadow). By normalizing each patch to zero mean and unit variance, the MSE loss forces the decoder to reconstruct high-frequency spatial structures, textures, and edges, preventing the model from taking the shortcut of predicting uniform background luminance.
  • (C) It prevents the decoder from dividing by zero during attention softmax.
  • (D) Patch normalization converts RGB values to HSV color space.

Exhaustive Self-Supervised Vision Analysis:

  • (B) is CORRECT: In natural imagery, global illumination and low-frequency shading account for the vast majority of pixel variance. Below is a clean, production-grade PyTorch implementation of the Vision Transformer Patch Embedding layer and [CLS] token concatenation.

Code Lab 4.5 — Vision Transformer Patch Embedding Engine

🔗 View in GitHub: part4_deep_learning/ch45_vit_mae/vit_patch_embed.py

import torch
import torch.nn as nn

class PatchEmbedding(nn.Module):
    """
    Splits image into non-overlapping patches and projects to hidden dimension D.
    Implemented efficiently as a 2D convolution with kernel_size=stride=patch_size!
    """
    def __init__(self, img_size=224, patch_size=16, in_channels=3, embed_dim=768):
        super().__init__()
        self.img_size = img_size
        self.patch_size = patch_size
        self.num_patches = (img_size // patch_size) ** 2

        # 2D Conv projection: Kernel and stride equal to patch size!
        self.proj = nn.Conv2d(in_channels, embed_dim, kernel_size=patch_size, stride=patch_size)

        # Learnable [CLS] token and 1D positional embeddings
        self.cls_token = nn.Parameter(torch.zeros(1, 1, embed_dim))
        self.pos_embed = nn.Parameter(torch.zeros(1, self.num_patches + 1, embed_dim))

    def forward(self, x):
        B, C, H, W = x.shape
        # (B, D, H/P, W/P) -> (B, D, N) -> (B, N, D)
        x = self.proj(x).flatten(2).transpose(1, 2)

        # Prepend [CLS] token across batch
        cls_tokens = self.cls_token.expand(B, -1, -1)
        x = torch.cat((cls_tokens, x), dim=1) # (B, N+1, D)

        # Add learned positional embeddings
        x = x + self.pos_embed
        return x
