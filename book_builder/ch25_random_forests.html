1. The Mathematics of Ensemble Variance Reduction

Individual decision trees are high-variance, low-bias estimators: a minor perturbation to the training dataset completely alters the split thresholds throughout the entire tree hierarchy. How can we eliminate this structural instability without sacrificing non-linear capacity?

The Variance of Averaged Correlated Estimators

Suppose we train $B$ separate estimators $\hat{f}_1, \hat{f}_2, \dots, \hat{f}_B$, each with identical variance $\text{Var}(\hat{f}_i) = \sigma^2$ and positive pairwise correlation $\text{Corr}(\hat{f}_i, \hat{f}_j) = \rho \in [0, 1]$ for all $i \neq j$. Consider the ensemble average estimator $\bar{f} = \frac{1}{B} \sum_{i=1}^B \hat{f}_i$. The total variance of the ensemble is:

$$\text{Var}(\bar{f}) = \text{Var}\left( \frac{1}{B} \sum_{i=1}^B \hat{f}_i \right) = \frac{1}{B^2} \left[ \sum_{i=1}^B \text{Var}(\hat{f}_i) + \sum_{i=1}^B \sum_{j \neq i}^B \text{Cov}(\hat{f}_i, \hat{f}_j) \right]$$

Substitute $\text{Var}(\hat{f}_i) = \sigma^2$ and $\text{Cov}(\hat{f}_i, \hat{f}_j) = \rho \sigma^2$ across all $B(B-1)$ off-diagonal pairs:

$$\text{Var}(\bar{f}) = \frac{1}{B^2} \left[ B \sigma^2 + B(B - 1) \rho \sigma^2 \right] = \frac{\sigma^2}{B} + \frac{B - 1}{B} \rho \sigma^2$$ $$\text{Var}(\bar{f}) = \rho \sigma^2 + \frac{1 - \rho}{B} \sigma^2$$

The Fundamental Law of Ensembles:

  • As the number of trees grows large ($B \to \infty$), the second term vanishes: $\lim_{B \to \infty} \frac{1 - \rho}{B} \sigma^2 = 0$.
  • The remaining variance is strictly bounded from below by the pairwise correlation: $\lim_{B \to \infty} \text{Var}(\bar{f}) = \mathbf{\rho \sigma^2}$.
Critical Engineering Implication: If all trees make identical predictions ($\rho = 1$), averaging 10,000 trees achieves zero variance reduction! To minimize error, an ensemble algorithm must actively decorrelate the base learners (minimize $\rho$) while keeping individual model strength high!

2. Bootstrap Aggregation (Bagging) & The 63.2% Theorem

Bootstrap Aggregation (Bagging) decorrelates trees by training each tree on an independently drawn bootstrap sample: drawing $N$ samples from dataset $\mathcal{D}$ of size $N$ with replacement.

📐 The 63.2% Bootstrap Theorem Dissected

When sampling $N$ items with replacement from a dataset of size $N$, what is the probability that any specific sample $i$ is NEVER selected?

  1. On any individual random draw, the probability of NOT selecting sample $i$ is: $$P(\text{Not picked in 1 draw}) = 1 - \frac{1}{N}$$
  2. Since all $N$ draws are mutually independent, the probability of NOT being picked in all $N$ draws is: $$P(\text{Excluded from bootstrap}) = \left( 1 - \frac{1}{N} \right)^N$$
  3. Taking the calculus limit as dataset size $N \to \infty$ (using the definition of the mathematical constant $e$): $$\lim_{N \to \infty} \left( 1 - \frac{1}{N} \right)^N = e^{-1} = \frac{1}{e} \approx 0.367879 = \mathbf{36.8\%}$$

Conversely, the probability that sample $i$ appears at least once in the bootstrap sample is $1 - e^{-1} \approx \mathbf{63.2\%}$!

Out-of-Bag (OOB) Validation Error

Because each tree leaves out approximately $36.8\%$ of the dataset, these unselected samples are called Out-of-Bag (OOB) samples. For every training sample $\mathbf{x}_i$, we can evaluate its prediction using only the subset of trees that never saw $\mathbf{x}_i$ during training:

$$\hat{y}_i^{\text{OOB}} = \arg\max_k \sum_{b: \mathbf{x}_i \notin \mathcal{D}_b} \mathbb{I}(\hat{f}_b(\mathbf{x}_i) = k)$$

This provides an unbiased, built-in cross-validation score without setting aside an explicit test set or executing computationally expensive $K$-Fold cross-validation.

3. Random Forests & Dual Feature Importance Metrics

Bagging alone is insufficient when one feature is overwhelmingly strong (e.g. account balance in fraud detection): every single bootstrap tree will pick that same dominant feature at the root node, causing high tree correlation $\rho$.

Random Forests (Breiman, 2001) introduce a second layer of randomization: at every candidate split, the tree is forbidden from searching across all $d$ features. Instead, it randomly selects a small subset of $m$ features:

$$m = \lfloor \sqrt{d} \rfloor \quad (\text{Classification}), \qquad m = \lfloor d / 3 \rfloor \quad (\text{Regression})$$

By forcing trees to split on suboptimal surrogate features, Random Forests drastically reduce pairwise tree correlation $\rho$, driving ensemble variance down to near zero.

Mean Decrease in Impurity (MDI) vs. Permutation Feature Importance (MDA)

Property Mean Decrease in Impurity (MDI / Gini Importance) Mean Decrease in Accuracy (MDA / Permutation Importance)
Mechanism Sums all Gini impurity reductions $\Delta I$ across all nodes where feature $j$ splits, weighted by sample proportion. Permutes (shuffles) values of feature $j$ on OOB samples and measures the drop in prediction accuracy.
Computational Cost $\mathcal{O}(1)$ (computed for free during tree training). $\mathcal{O}(B \cdot N)$ (requires evaluating all trees on shuffled OOB data).
Critical Trap Severe Cardinality Bias: Heavily inflates numerical features with many unique values (e.g. IDs or timestamps) even if completely uninformative! Unbiased: True gold standard. Shuffling a noise feature has zero impact on OOB accuracy regardless of cardinality.

✓ Complete Step-by-Step Numerical Solution

Step 1: Variance under Complete Independence ($\rho = 0$): $$\text{Var}(\bar{f}) = \frac{\sigma^2}{B} = \frac{2.0}{50} = \mathbf{0.0400}$$ Averaging 50 independent trees slashes variance by $98\%$.

Step 2: Variance under Correlation $\rho = 0.25$: $$\text{Var}(\bar{f}) = \rho \sigma^2 + \frac{1 - \rho}{B} \sigma^2$$ $$\text{Var}(\bar{f}) = (0.25)(2.0) + \frac{1 - 0.25}{50}(2.0) = 0.50 + \frac{0.75 \times 2.0}{50} = 0.50 + \frac{1.50}{50} = 0.50 + 0.03 = \mathbf{0.5300}$$

Step 3: Asymptotic Limit as $B \to \infty$: $$\lim_{B \to \infty} \text{Var}(\bar{f}) = \rho \sigma^2 = 0.25 \times 2.0 = \mathbf{0.5000}$$ Result: Increasing $B$ from 50 to $\infty$ can only reduce variance from $0.53$ to $0.50$. The only way to achieve further gains is to decorrelate features (reducing $\rho$).

Problem 2.5.5 Hard Google DeepMind Meta

QUESTION: Prove Condorcet's Jury Theorem for ensemble classification from first principles. Let $B = 2m + 1$ independent binary classifiers each have probability $p > 0.5$ of voting correctly. Prove that:

  1. The ensemble majority vote accuracy $P_B$ is strictly greater than the individual accuracy: $P_B > p$.
  2. As the number of classifiers $B \to \infty$, the ensemble accuracy converges to absolute certainty: $\lim_{B \to \infty} P_B = 1.0$.
✓ Complete Step-by-Step Mathematical Proof

Step 1: Formulate the Probability of Correct Majority Vote:
Let $k$ be the number of correct votes out of $B = 2m + 1$ trials. Majority vote succeeds if $k \ge m + 1$: $$P_B = \sum_{k=m+1}^{2m+1} \binom{2m+1}{k} p^k (1 - p)^{2m+1-k}$$

Step 2: Compare $P_{2m+1}$ with $P_{2m-1}$ (Inductive Step):
Adding 2 voters to an ensemble of $2m-1$ voters changes the majority outcome if and only if the original $2m-1$ voters were tied or 1 vote away: $$P_{2m+1} - P_{2m-1} = \binom{2m-1}{m} p^m (1-p)^m (2p - 1)$$ Since $p > 0.5$, $(2p - 1) > 0$. Furthermore, $p^m (1-p)^m > 0$ and $\binom{2m-1}{m} > 0$.
Therefore: $$P_{2m+1} - P_{2m-1} > 0$$ The sequence of ensemble accuracies $P_{2m+1}$ is strictly monotonically increasing with $B$, proving $P_B > p$ for all $B > 1$.

Step 3: Evaluate the Limit as $B \to \infty$ via Chernoff Bound:
Let $X_i \in \{0, 1\}$ indicate whether voter $i$ is correct, with mean $\mu = p > 0.5$.
The ensemble majority fails if $\frac{1}{B} \sum_{i=1}^B X_i \le 0.5$.
By Hoeffding's Inequality: $$P\left( \frac{1}{B} \sum_{i=1}^B X_i - p \le -(p - 0.5) \right) \le \exp\left( -2 B (p - 0.5)^2 \right)$$ Since $p > 0.5$, $(p - 0.5)^2 > 0$. Therefore: $$P(\text{Ensemble Error}) \le \exp\left( -2 B (p - 0.5)^2 \right) \xrightarrow{B \to \infty} 0$$ $$\lim_{B \to \infty} P_B = 1 - 0 = \mathbf{1.0}$$ Q.E.D. The ensemble majority vote accuracy converges exponentially to $100\%$ certainty as $B \to \infty$!

Problem 2.5.6 Hard OpenAI Anthropic

QUESTION: Prove why Random Forests do not overfit as the number of trees $B$ approaches infinity ($B \to \infty$), whereas Gradient Boosted Trees (GBDT) can overfit severely if $B$ is set too large.

✓ Complete Step-by-Step Mathematical Analysis

Step 1: Random Forests Generalization Error Bound (Breiman, 2001):
In a Random Forest, the ensemble prediction is an unweighted average of independently trained randomized trees $\bar{f}(\mathbf{x}) = \frac{1}{B} \sum_{b=1}^B T_b(\mathbf{x})$.
By the Strong Law of Large Numbers, as $B \to \infty$: $$\frac{1}{B} \sum_{b=1}^B T_b(\mathbf{x}) \xrightarrow{\text{a.s.}} \mathbb{E}_\Theta[T(\mathbf{x}; \Theta)]$$ where $\Theta$ represents the random vector of bootstrap rows and split features.
Breiman proved that the generalization error $\text{PE}^*$ of a Random Forest is upper-bounded by: $$\text{PE}^* \le \frac{\bar{\rho}(1 - s^2)}{s^2}$$ where $\bar{\rho}$ is the average correlation between trees, and $s$ is the margin strength of individual trees.
Crucial Takeaway: Adding more trees does NOT increase model capacity; it merely yields a more accurate numerical Monte Carlo approximation of the underlying expectation $\mathbb{E}_\Theta[T(\mathbf{x}; \Theta)]$. After reaching ~300 to 500 trees, test error plateaus completely.

Step 2: Contrast with Gradient Boosted Trees (GBDT):
In Gradient Boosting, trees are added sequentially to fit the residual errors of prior trees: $$F_B(\mathbf{x}) = F_{B-1}(\mathbf{x}) + \eta T_B(\mathbf{x})$$ Each new tree specifically targets the unexplained residuals $y_i - F_{B-1}(\mathbf{x}_i)$. As $B \to \infty$, the boosting ensemble begins memorizing the random measurement noise $\epsilon_i$ of individual training samples, driving training error to zero while causing test error to explode! Boosting requires early stopping, whereas Random Forests can have $B$ set arbitrarily large.

Exhaustive Analysis of All Options:

5. Production Code Lab 2.5: Random Forest with OOB Scoring from Scratch

Below is a production implementation of a Random Forest Classifier implementing row bootstrapping, random feature subspace selection, and Out-of-Bag validation.

Code Lab 2.5 — Random Forest & Out-of-Bag Evaluator

🔗 View in GitHub: part2_classical_ml/ch25_random_forests/random_forest_scratch.py

import numpy as np
from collections import Counter

class RandomForestClassifierScratch:
    def __init__(self, n_estimators=20, max_depth=6, min_samples_split=2):
        self.n_estimators = n_estimators
        self.max_depth = max_depth
        self.min_samples_split = min_samples_split
        self.trees = []
        self.tree_features = []
        self.oob_score_ = None

    def _bootstrap_sample(self, X, y):
        N = X.shape[0]
        indices = np.random.choice(N, size=N, replace=True)
        oob_indices = np.setdiff1d(np.arange(N), np.unique(indices))
        return X[indices], y[indices], oob_indices

    def fit(self, X, y):
        from sklearn.tree import DecisionTreeClassifier
        N, d = X.shape
        max_features = max(1, int(np.sqrt(d)))
        
        oob_predictions = {i: [] for i in range(N)}

        for _ in range(self.n_estimators):
            X_boot, y_boot, oob_idx = self._bootstrap_sample(X, y)
            
            # Select random feature subspace
            feat_idx = np.random.choice(d, size=max_features, replace=False)
            
            tree = DecisionTreeClassifier(max_depth=self.max_depth, min_samples_split=self.min_samples_split)
            tree.fit(X_boot[:, feat_idx], y_boot)

            self.trees.append(tree)
            self.tree_features.append(feat_idx)

            # Record predictions for OOB samples
            if len(oob_idx) > 0:
                preds = tree.predict(X[oob_idx][:, feat_idx])
                for idx, pred in zip(oob_idx, preds):
                    oob_predictions[idx].append(pred)

        # Compute OOB score
        correct = 0
        total = 0
        for i in range(N):
            if len(oob_predictions[i]) > 0:
                majority_vote = Counter(oob_predictions[i]).most_common(1)[0][0]
                if majority_vote == y[i]:
                    correct += 1
                total += 1

        self.oob_score_ = correct / total if total > 0 else 0.0

    def predict(self, X):
        tree_preds = np.array([
            tree.predict(X[:, feat_idx])
            for tree, feat_idx in zip(self.trees, self.tree_features)
        ])
        # Majority voting along axis 0
        final_preds = [Counter(tree_preds[:, i]).most_common(1)[0][0] for i in range(X.shape[0])]
        return np.array(final_preds)

if __name__ == "__main__":
    from sklearn.datasets import load_breast_cancer
    data = load_breast_cancer()
    X, y = data.data, data.target
    rf = RandomForestClassifierScratch(n_estimators=30, max_depth=5)
    rf.fit(X, y)
    preds = rf.predict(X)
    print(f"Random Forest Training Accuracy: {np.mean(preds == y) * 100:.2f}%")
    print(f"Out-of-Bag (OOB) Accuracy Score: {rf.oob_score_ * 100:.2f}%")
