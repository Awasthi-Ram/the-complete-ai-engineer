"Prediction is very difficult, especially if it's about the future."

Foundation • Core Pillar

1. From Linear Output to Calibrated Probability

Why can we not simply use linear regression $y = \mathbf{w}^T \mathbf{x} + b$ for binary classification ($y \in \{0, 1\}$)?

  1. Unbounded Range: A linear combination $\mathbf{w}^T \mathbf{x} + b$ maps to $(-\infty, +\infty)$. For extreme feature values, it predicts values like $-1.8$ or $+2.4$, violating the fundamental Kolmogorov axioms of probability.
  2. Distortion by Outliers: Squaring errors on points that are extremely well classified (e.g., $y=1$ and $\hat{y}=4.0$) exerts a massive penalty $(4.0 - 1.0)^2 = 9.0$, forcing the decision boundary to rotate and corrupting classification accuracy on borderline points.

The Log-Odds (Logit) Transformation

To map a bounded probability $p \in (0, 1)$ smoothly onto the entire real line $(-\infty, +\infty)$, we first define the Odds Ratio—the ratio of success probability to failure probability:

$$\text{Odds} = \frac{p}{1 - p} \in (0, +\infty)$$

Taking the natural logarithm yields the Logit (Log-Odds) function:

$$\text{logit}(p) = \ln\left(\frac{p}{1 - p}\right) = \mathbf{w}^T \mathbf{x} + b$$

Solving algebraically for $p$:

$$\frac{p}{1 - p} = e^{\mathbf{w}^T \mathbf{x} + b} \implies p = e^{\mathbf{w}^T \mathbf{x} + b} (1 - p) = e^{\mathbf{w}^T \mathbf{x} + b} - p e^{\mathbf{w}^T \mathbf{x} + b}$$ $$p (1 + e^{\mathbf{w}^T \mathbf{x} + b}) = e^{\mathbf{w}^T \mathbf{x} + b} \implies p = \frac{e^{\mathbf{w}^T \mathbf{x} + b}}{1 + e^{\mathbf{w}^T \mathbf{x} + b}} = \frac{1}{1 + e^{-(\mathbf{w}^T \mathbf{x} + b)}} = \sigma(\mathbf{w}^T \mathbf{x} + b)$$

This derives the Sigmoid (Logistic) Function $\sigma(z) = \frac{1}{1 + e^{-z}}$!

The Crucial Sigmoid Derivative Identity:

$$\sigma'(z) = \frac{d}{dz} (1 + e^{-z})^{-1} = -(1 + e^{-z})^{-2} (-e^{-z}) = \frac{1}{1 + e^{-z}} \cdot \frac{e^{-z}}{1 + e^{-z}} = \sigma(z) (1 - \sigma(z))$$

The derivative of the sigmoid is simply its own output multiplied by $(1 - \text{output})$!

2. Maximum Likelihood & Binary Cross-Entropy Loss

Assuming independent training samples, the likelihood of observing binary targets $y_i \in \{0, 1\}$ with predicted probabilities $p_i = \sigma(\mathbf{w}^T \mathbf{x}_i)$ is modeled by the Bernoulli PMF:

$$L(\mathbf{w}) = \prod_{i=1}^N P(y_i \mid \mathbf{x}_i; \mathbf{w}) = \prod_{i=1}^N p_i^{y_i} (1 - p_i)^{1 - y_i}$$

Taking the natural logarithm and dividing by $-N$ yields the Binary Cross-Entropy (BCE) Loss:

$$\mathcal{L}(\mathbf{w}) = -\frac{1}{N} \ln L(\mathbf{w}) = -\frac{1}{N} \sum_{i=1}^N \left[ y_i \ln(p_i) + (1 - y_i) \ln(1 - p_i) \right]$$

Deriving the Gradient Vector

Let $z_i = \mathbf{w}^T \mathbf{x}_i$. Applying the multivariable chain rule:

$$\frac{\partial \mathcal{L}}{\partial \mathbf{w}} = \frac{1}{N} \sum_{i=1}^N \frac{\partial \mathcal{L}_i}{\partial p_i} \frac{\partial p_i}{\partial z_i} \frac{\partial z_i}{\partial \mathbf{w}}$$
  • $\frac{\partial \mathcal{L}_i}{\partial p_i} = -\frac{y_i}{p_i} + \frac{1 - y_i}{1 - p_i} = \frac{p_i - y_i}{p_i (1 - p_i)}$
  • $\frac{\partial p_i}{\partial z_i} = p_i (1 - p_i)$
  • $\frac{\partial z_i}{\partial \mathbf{w}} = \mathbf{x}_i$

Notice how the term $p_i(1 - p_i)$ in the denominator cancels out with the sigmoid derivative:

$$\nabla_{\mathbf{w}} \mathcal{L}(\mathbf{w}) = \frac{1}{N} \sum_{i=1}^N \left( \frac{p_i - y_i}{p_i(1-p_i)} \right) \left( p_i(1-p_i) \right) \mathbf{x}_i = \frac{1}{N} \sum_{i=1}^N (p_i - y_i) \mathbf{x}_i$$

In matrix notation:

$$\nabla_{\mathbf{w}} \mathcal{L}(\mathbf{w}) = \frac{1}{N} \mathbf{X}^T (\mathbf{p} - \mathbf{y})$$

This matches the algebraic form of the linear regression gradient $\frac{1}{N} \mathbf{X}^T (\hat{\mathbf{y}} - \mathbf{y})$!

3. Second-Order Optimization: Iteratively Reweighted Least Squares (IRLS)

First-order gradient descent updates weights as $\mathbf{w}^{(t+1)} = \mathbf{w}^{(t)} - \eta \nabla \mathcal{L}$. However, because Logistic Regression is twice-differentiable and strictly convex, we can apply Newton's Method to converge quadratically in 5 to 8 steps:

$$\mathbf{w}^{(t+1)} = \mathbf{w}^{(t)} - \mathbf{H}^{-1} \nabla \mathcal{L}(\mathbf{w}^{(t)})$$

Recall the Hessian matrix derived in Problem 2.3.1:

$$\mathbf{H} = \frac{1}{N} \mathbf{X}^T \mathbf{D} \mathbf{X}, \quad \text{where } \mathbf{D} = \text{diag}(p_1(1-p_1), \dots, p_N(1-p_N))$$

Substituting the gradient and Hessian into Newton's update:

$$\mathbf{w}^{(t+1)} = \mathbf{w}^{(t)} - (\mathbf{X}^T \mathbf{D} \mathbf{X})^{-1} \mathbf{X}^T (\mathbf{p} - \mathbf{y})$$ $$\mathbf{w}^{(t+1)} = (\mathbf{X}^T \mathbf{D} \mathbf{X})^{-1} \left[ \mathbf{X}^T \mathbf{D} \mathbf{X} \mathbf{w}^{(t)} - \mathbf{X}^T (\mathbf{p} - \mathbf{y}) \right] = (\mathbf{X}^T \mathbf{D} \mathbf{X})^{-1} \mathbf{X}^T \mathbf{D} \left[ \mathbf{X} \mathbf{w}^{(t)} - \mathbf{D}^{-1}(\mathbf{p} - \mathbf{y}) \right]$$

Define the adjusted response vector $\mathbf{z}^{(t)} = \mathbf{X}\mathbf{w}^{(t)} - \mathbf{D}^{-1}(\mathbf{p} - \mathbf{y})$. Then:

$$\mathbf{w}^{(t+1)} = (\mathbf{X}^T \mathbf{D} \mathbf{X})^{-1} \mathbf{X}^T \mathbf{D} \mathbf{z}^{(t)}$$

Notice that this is the exact closed-form solution to a Weighted Least Squares (WLS) problem with diagonal weight matrix $\mathbf{D}$! Because the weights $\mathbf{D}$ depend on the current predictions $\mathbf{p}^{(t)}$, the weights must be recomputed on every step—hence the name Iteratively Reweighted Least Squares (IRLS).

4. Multi-Class Generalization: Softmax (Multinomial) Regression

For $K > 2$ mutually exclusive classes, target labels are one-hot vectors $\mathbf{y}_i \in \{0, 1\}^K$. The model maintains a weight vector $\mathbf{w}_k$ for each class, computing class logits $z_{ik} = \mathbf{w}_k^T \mathbf{x}_i$. The probability distribution over classes is given by the Softmax Function:

$$P(y_i = k \mid \mathbf{x}_i) = p_{ik} = \frac{\exp(\mathbf{w}_k^T \mathbf{x}_i)}{\sum_{j=1}^K \exp(\mathbf{w}_j^T \mathbf{x}_i)}$$

The Multi-Class Categorical Cross-Entropy loss is:

$$\mathcal{L}(\mathbf{W}) = -\frac{1}{N} \sum_{i=1}^N \sum_{k=1}^K y_{ik} \ln(p_{ik})$$

The gradient with respect to class weight vector $\mathbf{w}_k$ is:

$$\nabla_{\mathbf{w}_k} \mathcal{L} = \frac{1}{N} \sum_{i=1}^N (p_{ik} - y_{ik}) \mathbf{x}_i \implies \nabla_{\mathbf{W}} \mathcal{L} = \frac{1}{N} \mathbf{X}^T (\mathbf{P} - \mathbf{Y})$$

Problem 2.3.5 Hard Google Brain Meta FAIR

QUESTION: For Multi-Class Softmax Regression with $K$ classes, class probabilities are given by: $$p_k = \frac{\exp(\mathbf{w}_k^T \mathbf{x})}{\sum_{j=1}^K \exp(\mathbf{w}_j^T \mathbf{x})}$$

  1. Derive the partial derivative of class probability $p_i$ with respect to logit $z_j = \mathbf{w}_j^T \mathbf{x}$, proving: $$\frac{\partial p_i}{\partial z_j} = p_i (\delta_{ij} - p_j)$$ where $\delta_{ij}$ is the Kronecker delta.
  2. Using this identity, derive the complete gradient of the Cross-Entropy loss $\mathcal{L} = -\sum_{k=1}^K y_k \ln(p_k)$ with respect to the weight vector $\mathbf{w}_j$, proving $\nabla_{\mathbf{w}_j} \mathcal{L} = (p_j - y_j)\mathbf{x}$.
✓ Complete Step-by-Step Mathematical Derivation

Step 1: Differentiate Softmax with Respect to Logits:
Let $S = \sum_{j=1}^K e^{z_j}$. Then $p_i = \frac{e^{z_i}}{S}$.
Apply the quotient rule $\frac{d}{dz_j} [u/v] = \frac{u' v - u v'}{v^2}$:

  • Case 1 ($i = j$): $$\frac{\partial p_i}{\partial z_i} = \frac{(e^{z_i}) S - (e^{z_i})(e^{z_i})}{S^2} = \frac{e^{z_i}}{S} - \left(\frac{e^{z_i}}{S}\right)^2 = p_i - p_i^2 = p_i(1 - p_i)$$
  • Case 2 ($i \neq j$): $$\frac{\partial p_i}{\partial z_j} = \frac{(0) S - (e^{z_i})(e^{z_j})}{S^2} = -\frac{e^{z_i}}{S} \cdot \frac{e^{z_j}}{S} = -p_i p_j$$
Combining both cases using the Kronecker delta $\delta_{ij} = \begin{cases} 1 & \text{if } i=j \\ 0 & \text{if } i \neq j \end{cases}$: $$\frac{\partial p_i}{\partial z_j} = p_i (\delta_{ij} - p_j)$$

Step 2: Differentiate Cross-Entropy Loss:
$$\frac{\partial \mathcal{L}}{\partial z_j} = \sum_{k=1}^K \frac{\partial \mathcal{L}}{\partial p_k} \frac{\partial p_k}{\partial z_j}$$ Since $\mathcal{L} = -\sum_{k=1}^K y_k \ln(p_k)$, we have $\frac{\partial \mathcal{L}}{\partial p_k} = -\frac{y_k}{p_k}$.
Substitute into the sum: $$\frac{\partial \mathcal{L}}{\partial z_j} = \sum_{k=1}^K \left(-\frac{y_k}{p_k}\right) \left[ p_k (\delta_{kj} - p_j) \right] = -\sum_{k=1}^K y_k (\delta_{kj} - p_j) = -\sum_{k=1}^K y_k \delta_{kj} + p_j \sum_{k=1}^K y_k$$ Since $\mathbf{y}$ is a one-hot distribution, $\sum_{k=1}^K y_k = 1$, and $\sum_{k=1}^K y_k \delta_{kj} = y_j$: $$\frac{\partial \mathcal{L}}{\partial z_j} = -y_j + p_j(1) = \mathbf{p_j - y_j}$$ Now apply chain rule to weight vector $\mathbf{w}_j$ ($z_j = \mathbf{w}_j^T \mathbf{x} \implies \frac{\partial z_j}{\partial \mathbf{w}_j} = \mathbf{x}$): $$\nabla_{\mathbf{w}_j} \mathcal{L} = \frac{\partial \mathcal{L}}{\partial z_j} \frac{\partial z_j}{\partial \mathbf{w}_j} = \mathbf{(p_j - y_j) \mathbf{x}}$$ Q.E.D. The multi-class gradient for class $j$ is simply the prediction residual $(p_j - y_j)$ times the feature vector $\mathbf{x}$!

Problem 2.3.6 Hard DeepMind

QUESTION: The Separation Problem (Hauck-Donner Effect): Suppose a binary dataset is strictly linearly separable, meaning there exists a hyperplane $(\mathbf{w}^*, b^*)$ such that $y_i(\mathbf{w}^{*T} \mathbf{x}_i + b^*) > 0$ for all $i=1,\dots,N$.

  1. Prove that the Maximum Likelihood estimator $\hat{\mathbf{w}}_{\text{MLE}}$ does not exist at any finite coordinates ($\|\hat{\mathbf{w}}_{\text{MLE}}\|_2 \to \infty$).
  2. Explain the practical engineering danger of this phenomenon in deep learning and logistic regression pipelines, and prove how $L_2$ regularization mathematically cures it.
✓ Complete Step-by-Step Mathematical Proof

Step 1: Divergence of MLE on Separable Data:
If data is strictly separable, scaling the separating vector by an arbitrary positive scalar $c > 0$ ($\mathbf{w} = c \mathbf{w}^*$) maintains perfect separation.
Examine the predicted probabilities for positive points ($y_i = 1$): $$p_i(c) = \sigma(c (\mathbf{w}^{*T} \mathbf{x}_i + b^*)) = \frac{1}{1 + e^{-c \cdot \Delta_i}}, \quad \text{where } \Delta_i = (\mathbf{w}^{*T} \mathbf{x}_i + b^*) > 0$$ As $c \to \infty$, $e^{-c \Delta_i} \to 0$, so $p_i(c) \to 1.0$.
Similarly for negative points ($y_i = 0$), $p_i(c) \to 0.0 \implies (1 - p_i(c)) \to 1.0$.
Examine the Negative Log-Likelihood: $$\lim_{c \to \infty} \mathcal{L}(c \mathbf{w}^*) = -\frac{1}{N} \sum_{i=1}^N \left[ y_i \ln(1) + (1-y_i) \ln(1) \right] = 0$$ The infimum of the loss is $0$, but this loss is never attained for any finite weights $\mathbf{w}$! Any optimization algorithm (gradient descent) will run indefinitely, pushing weights toward $\infty$.

Step 2: Engineering Impact & $L_2$ Regularization Cure:
As $\|\mathbf{w}\| \to \infty$:

  • Probabilities saturate at $0.0$ and $1.0$. The model becomes severely overconfident and uncalibrated.
  • The sigmoid derivative $\sigma'(z) \to 0$, causing vanishing gradients.
  • Standard errors of weights explode, triggering numerical instability in Wald tests (the Hauck-Donner effect).
Adding $L_2$ regularization creates a penalized objective: $$\mathcal{L}_{\text{Ridge}}(\mathbf{w}) = \mathcal{L}(\mathbf{w}) + \frac{\lambda}{2} \|\mathbf{w}\|_2^2$$ As $\|\mathbf{w}\| \to \infty$, the penalty $\frac{\lambda}{2} \|\mathbf{w}\|_2^2 \to \infty$. By the Extreme Value Theorem, the penalized objective is coercive and strictly convex, guaranteeing a unique finite global minimum $\mathbf{w}^*_{\text{reg}}$!

Problem 2.3.7 Medium Google

QUESTION: Both Logistic Regression and Linear Discriminant Analysis (LDA) produce linear decision boundaries in feature space. Which of the following statements correctly captures their key mathematical difference?

  1. Logistic Regression is a generative model that assumes features are Gaussian, whereas LDA is a discriminative model that makes no distributional assumptions.
  2. LDA is a generative model that assumes features $\mathbf{x} \mid y$ follow multivariate normal distributions with shared covariance $\boldsymbol{\Sigma}$, whereas Logistic Regression is a discriminative model that makes no assumptions about feature distributions.
  3. Logistic Regression cannot handle more than 2 classes, whereas LDA generalizes to arbitrary numbers of classes.
  4. LDA minimizes cross-entropy loss, whereas Logistic Regression minimizes hinge loss.
✓ Complete Conceptual Analysis & Explanation

Correct Option: B

Exhaustive Analysis of All Options:

  • Option B is TRUE: LDA models the joint probability $P(\mathbf{x}, y) = P(\mathbf{x} \mid y) P(y)$, assuming $P(\mathbf{x} \mid y=k) \sim \mathcal{N}(\boldsymbol{\mu}_k, \boldsymbol{\Sigma})$ with an identical shared covariance matrix across all classes. Under these Gaussian assumptions, Bayes' rule yields linear log-odds. Logistic Regression is discriminative: it models $P(y \mid \mathbf{x})$ directly without making any assumptions about $P(\mathbf{x})$ (features can be binary, skewed, categorical, or multimodal).

Problem 2.3.8 Hard Microsoft

QUESTION: Consider the following Assertion (A) and Reason (R):

Assertion (A): When training unregularized binary logistic regression via gradient descent on a dataset where one class is completely linearly separable from the other, the training loss approaches zero, but the model's predicted probabilities will become increasingly uncalibrated over epochs.

Reason (R): Because the gradient $\nabla_{\mathbf{w}} \mathcal{L} = \frac{1}{N} \mathbf{X}^T (\mathbf{p} - \mathbf{y})$ drives all probabilities toward $p_i \to y_i \in \{0, 1\}$, the weight vector norm $\|\mathbf{w}\|_2$ grows without bound, artificially pushing all sigmoid inputs into saturated extremes.

  1. Both (A) and (R) are true, and (R) is the correct explanation of (A).
  2. Both (A) and (R) are true, but (R) is NOT the correct explanation of (A).
  3. (A) is true, but (R) is false.
  4. (A) is false, but (R) is true.
✓ Complete Conceptual Analysis & Explanation

Correct Option: A

Exhaustive Analysis of Assertion & Reason:

  • Assertion (A) is TRUE: As proven in Problem 2.3.6, on separable data, unregularized gradient descent continues pushing weights toward infinity ($\|\mathbf{w}\| \to \infty$) to reduce loss from $0.001$ to $0.0001$. As a result, the model assigns probabilities of $0.99999$ or $0.00001$ even to points that lie very close to the decision boundary, destroying probability calibration.
  • Reason (R) is TRUE: The gradient is driven by the residual $(\mathbf{p} - \mathbf{y})$. Since $p_i = \sigma(\mathbf{w}^T \mathbf{x}_i) = 1$ is only achieved at $z \to \infty$, the gradient can never equal zero at any finite point. The optimizer continues stepping in the direction of the separating vector, driving $\|\mathbf{w}\| \to \infty$.
  • Furthermore, Reason (R) is the precise mathematical mechanism causing Assertion (A).

Code Lab 2.3 — Logistic Regression & Second-Order IRLS Solver

import numpy as np

class LogisticRegressionIRLS:
    def __init__(self, max_iter=20, tol=1e-6):
        self.max_iter = max_iter
        self.tol = tol
        self.w = None

    def _sigmoid(self, z):
        return 1.0 / (1.0 + np.exp(-np.clip(z, -250, 250)))

    def fit(self, X, y):
        N, d = X.shape
        X_b = np.c_[np.ones((N, 1)), X]
        self.w = np.zeros(d + 1)

        for iteration in range(self.max_iter):
            p = self._sigmoid(X_b @ self.w)
            
            # Gradient: (1/N) * X^T (p - y)
            grad = (X_b.T @ (p - y)) / N

            # Hessian: (1/N) * X^T D X, where D = p * (1 - p)
            D = p * (1.0 - p)
            # Efficient computation without allocating NxN diagonal matrix:
            H = (X_b.T * D) @ X_b / N + 1e-5 * np.eye(d + 1) # Regularization for invertibility

            # Newton-Raphson update: w = w - H^-1 * grad
            delta_w = np.linalg.solve(H, grad)
            self.w -= delta_w

            if np.linalg.norm(delta_w) < self.tol:
                print(f"Newton-Raphson converged in {iteration+1} iterations!")
                break

    def predict_proba(self, X):
        X_b = np.c_[np.ones((X.shape[0], 1)), X]
        return self._sigmoid(X_b @ self.w)

    def predict(self, X, threshold=0.5):
        return (self.predict_proba(X) >= threshold).astype(int)

if __name__ == "__main__":
    np.random.seed(42)
    # Generate 2D separable synthetic classification data
    X1 = np.random.randn(100, 2) + np.array([2.0, 2.0])
    X2 = np.random.randn(100, 2) + np.array([-2.0, -2.0])
    X = np.vstack([X1, X2])
    y = np.array([1]*100 + [0]*100)

    model = LogisticRegressionIRLS()
    model.fit(X, y)
    print("Fitted Weights [b, w1, w2]:", np.round(model.w, 4))
    
    preds = model.predict(X)
    acc = np.mean(preds == y)
    print(f"Classification Accuracy   : {acc * 100:.1f}%")
