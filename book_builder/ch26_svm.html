1. The Maximum Margin Principle

Given a linearly separable dataset of positive ($y_i = +1$) and negative ($y_i = -1$) points, there exist infinitely many separating hyperplanes that achieve $100\%$ training accuracy. Which one is mathematically optimal?

Figure 2.6.1: Support Vector Machines. Left: The maximum margin separating hyperplane maximizing margin width $2/\|\mathbf{w}\|_2$ bounded by support vectors. Right: The Kernel Trick implicitly projecting non-linearly separable circular data into higher-dimensional space where a linear hyperplane achieves complete separation.

Vladimir Vapnik proved through Statistical Learning Theory (VC Dimension) that the hyperplane that maximizes the geometric margin to the closest training points minimizes the structural risk upper bound on unseen data.

Functional vs. Geometric Margin

  • Functional Margin: $\hat{\gamma}_i = y_i (\mathbf{w}^T \mathbf{x}_i + b)$. If $\hat{\gamma}_i > 0$, sample $i$ is correctly classified. However, scaling $\mathbf{w} \to 2\mathbf{w}$ and $b \to 2b$ doubles $\hat{\gamma}_i$ without changing the physical decision boundary.
  • Geometric Margin: The true perpendicular Euclidean distance from point $\mathbf{x}_i$ to the hyperplane $\mathbf{w}^T \mathbf{x} + b = 0$: $$\gamma_i = \frac{y_i (\mathbf{w}^T \mathbf{x}_i + b)}{\|\mathbf{w}\|_2}$$ The geometric margin is scale-invariant: scaling $\mathbf{w}$ and $b$ by scalar $c > 0$ cancels out in the numerator and denominator.

To eliminate scale ambiguity, we enforce the canonical normalization such that the closest data points (the Support Vectors) satisfy $|\mathbf{w}^T \mathbf{x}_i + b| = 1$:

$$y_i (\mathbf{w}^T \mathbf{x}_i + b) \ge 1, \quad \forall i=1,\dots,N$$

The total geometric margin between the positive margin boundary ($\mathbf{w}^T \mathbf{x}_+ + b = +1$) and negative margin boundary ($\mathbf{w}^T \mathbf{x}_- + b = -1$) is:

$$\text{Margin Width} = \frac{\mathbf{w}^T (\mathbf{x}_+ - \mathbf{x}_-)}{\|\mathbf{w}\|_2} = \frac{(\mathbf{w}^T \mathbf{x}_+ + b) - (\mathbf{w}^T \mathbf{x}_- + b)}{\|\mathbf{w}\|_2} = \frac{1 - (-1)}{\|\mathbf{w}\|_2} = \frac{2}{\|\mathbf{w}\|_2}$$

Maximizing the margin $\frac{2}{\|\mathbf{w}\|_2}$ is identical to minimizing $\frac{1}{2} \|\mathbf{w}\|_2^2$, formulating the Hard-Margin Primal Problem:

$$\min_{\mathbf{w}, b} \frac{1}{2} \|\mathbf{w}\|_2^2 \quad \text{subject to } y_i (\mathbf{w}^T \mathbf{x}_i + b) \ge 1, \quad \forall i=1,\dots,N$$

2. Soft-Margin SVM, Slack Variables & The Box Constraint

Real-world data is rarely strictly linearly separable due to noise and class overlap. We introduce non-negative Slack Variables $\xi_i \ge 0$, which allow samples to penetrate the margin boundary at a linear penalty:

$$\min_{\mathbf{w}, b, \boldsymbol{\xi}} \frac{1}{2} \|\mathbf{w}\|_2^2 + C \sum_{i=1}^N \xi_i \quad \text{subject to } y_i (\mathbf{w}^T \mathbf{x}_i + b) \ge 1 - \xi_i, \quad \xi_i \ge 0$$

where $C > 0$ is the regularization parameter governing the bias-variance trade-off (large $C$ penalizes slack heavily, producing narrow margins; small $C$ permits more violations, producing wider margins).

KKT Optimality & The Support Vector Classification

Associate Lagrange multipliers $\alpha_i \ge 0$ with the margin constraints and $\mu_i \ge 0$ with the non-negativity constraints $\xi_i \ge 0$:

$$\mathcal{L}(\mathbf{w}, b, \boldsymbol{\xi}, \boldsymbol{\alpha}, \boldsymbol{\mu}) = \frac{1}{2} \|\mathbf{w}\|_2^2 + C \sum_{i=1}^N \xi_i - \sum_{i=1}^N \alpha_i \left[ y_i (\mathbf{w}^T \mathbf{x}_i + b) - 1 + \xi_i \right] - \sum_{i=1}^N \mu_i \xi_i$$

KKT Stationarity conditions:

$$\nabla_{\mathbf{w}} \mathcal{L} = \mathbf{w} - \sum_{i=1}^N \alpha_i y_i \mathbf{x}_i = \mathbf{0} \implies \mathbf{w} = \sum_{i=1}^N \alpha_i y_i \mathbf{x}_i$$ $$\frac{\partial \mathcal{L}}{\partial b} = -\sum_{i=1}^N \alpha_i y_i = 0 \implies \sum_{i=1}^N \alpha_i y_i = 0$$ $$\frac{\partial \mathcal{L}}{\partial \xi_i} = C - \alpha_i - \mu_i = 0 \implies \alpha_i + \mu_i = C$$

Because $\mu_i \ge 0$, this enforces the famous Box Constraint on the dual multipliers:

$$0 \le \alpha_i \le C$$

Complementary slackness conditions: $\alpha_i [y_i(\mathbf{w}^T \mathbf{x}_i + b) - 1 + \xi_i] = 0$ and $\mu_i \xi_i = 0$. This categorizes every training sample into three distinct geometric regimes:

  1. Non-Support Vectors ($\alpha_i = 0$): $\mu_i = C \implies \xi_i = 0$. The point lies strictly on the correct side of the margin ($y_i(\mathbf{w}^T \mathbf{x}_i + b) > 1$). It exerts zero influence on the decision boundary.
  2. Free (Unbounded) Support Vectors ($0 < \alpha_i < C$): $\mu_i > 0 \implies \xi_i = 0$. The point lies directly on the margin boundary ($y_i(\mathbf{w}^T \mathbf{x}_i + b) = 1$). These points strictly define the orientation of $\mathbf{w}$ and are used to compute the exact intercept $b$!
  3. Bounded Support Vectors ($\alpha_i = C$): $\mu_i = 0 \implies \xi_i > 0$. The point violates the margin boundary (either inside the margin $0 < \xi_i \le 1$, or misclassified $\xi_i > 1$).

3. The Kernel Trick & Mercer's Theorem

In the dual formulation, the optimization objective and inference prediction depend strictly on inner products:

$$\hat{y}(\mathbf{x}) = \text{sign}\left( \mathbf{w}^T \mathbf{x} + b \right) = \text{sign}\left( \sum_{i=1}^N \alpha_i y_i (\mathbf{x}_i \cdot \mathbf{x}) + b \right)$$

To learn non-linear boundaries, we map inputs into a higher-dimensional feature space $\phi(\mathbf{x})$. The Kernel Trick replaces the inner product $\phi(\mathbf{x}_i)^T \phi(\mathbf{x}_j)$ with a direct function $K(\mathbf{x}_i, \mathbf{x}_j)$ evaluated in input space without ever calculating the high-dimensional coordinates!

🏆 Mercer's Theorem (1909)

A continuous, symmetric kernel function $K: \mathcal{X} \times \mathcal{X} \to \mathbb{R}$ corresponds to a valid inner product in some Reproducing Kernel Hilbert Space (RKHS) $\langle \phi(\mathbf{x}), \phi(\mathbf{z}) \rangle$ if and only if the Kernel Gram Matrix $\mathbf{K} \in \mathbb{R}^{N \times N}$ is Positive Semi-Definite for all finite datasets:

$$\mathbf{c}^T \mathbf{K} \mathbf{c} = \sum_{i=1}^N \sum_{j=1}^N c_i c_j K(\mathbf{x}_i, \mathbf{x}_j) \ge 0, \quad \forall \mathbf{c} \in \mathbb{R}^N$$

Canonical Machine Learning Kernels

  • Linear Kernel: $K(\mathbf{x}, \mathbf{z}) = \mathbf{x}^T \mathbf{z}$.
  • Polynomial Kernel: $K(\mathbf{x}, \mathbf{z}) = (\mathbf{x}^T \mathbf{z} + c)^d$. Expands into all monomial interaction terms up to degree $d$.
  • Radial Basis Function (RBF / Gaussian) Kernel: $$K(\mathbf{x}, \mathbf{z}) = \exp\left( -\gamma \|\mathbf{x} - \mathbf{z}\|_2^2 \right), \quad \gamma = \frac{1}{2\sigma^2}$$ Projects data into an infinite-dimensional Hilbert space ($\mathbb{R}^\infty$).

Problem 2.6.1 Easy Google

QUESTION: In a 2D linearly separable problem, the optimal separating hyperplane has parameter vector $\mathbf{w} = [3.0, 4.0]^T$ and bias $b = -2.0$.

  1. Calculate the Euclidean norm $\|\mathbf{w}\|_2$.
  2. Compute the total geometric margin width $\frac{2}{\|\mathbf{w}\|_2}$.
  3. For a new query point $\mathbf{x}_{\text{query}} = [2.0, 1.0]^T$, compute its functional margin and its perpendicular distance to the decision boundary.
✓ Complete Step-by-Step Numerical Solution

Step 1: Compute Euclidean Norm: $$\|\mathbf{w}\|_2 = \sqrt{3.0^2 + 4.0^2} = \sqrt{9 + 16} = \sqrt{25} = \mathbf{5.0}$$

Step 2: Compute Total Margin Width: $$\text{Margin Width} = \frac{2}{\|\mathbf{w}\|_2} = \frac{2}{5.0} = \mathbf{0.40}$$

Step 3: Distance of Query Point:
Evaluate linear combination: $$\mathbf{w}^T \mathbf{x}_{\text{query}} + b = (3.0 \times 2.0) + (4.0 \times 1.0) - 2.0 = 6.0 + 4.0 - 2.0 = \mathbf{+8.0}$$ Perpendicular distance: $$d = \frac{|\mathbf{w}^T \mathbf{x}_{\text{query}} + b|}{\|\mathbf{w}\|_2} = \frac{8.0}{5.0} = \mathbf{1.60}$$ Result: The query point lies $1.60$ units from the decision boundary, well outside the positive margin ($1.60 > 0.20$).

Problem 2.6.2 Easy Meta

QUESTION: Two vectors in $\mathbb{R}^2$ are $\mathbf{x} = [1.0, 3.0]^T$ and $\mathbf{z} = [4.0, -1.0]^T$. Compute:

  1. The Linear Kernel $K_{\text{lin}}(\mathbf{x}, \mathbf{z}) = \mathbf{x}^T \mathbf{z}$.
  2. The Polynomial Kernel of degree $d = 2$ with $c = 1.0$: $K_{\text{poly}}(\mathbf{x}, \mathbf{z}) = (\mathbf{x}^T \mathbf{z} + 1)^2$.
  3. The RBF Kernel with $\gamma = 0.1$: $K_{\text{RBF}}(\mathbf{x}, \mathbf{z}) = \exp(-\gamma \|\mathbf{x} - \mathbf{z}\|_2^2)$.
✓ Complete Step-by-Step Numerical Solution

Step 1: Linear Kernel: $$K_{\text{lin}}(\mathbf{x}, \mathbf{z}) = (1.0 \times 4.0) + (3.0 \times -1.0) = 4.0 - 3.0 = \mathbf{1.0}$$

Step 2: Polynomial Kernel: $$K_{\text{poly}}(\mathbf{x}, \mathbf{z}) = (1.0 + 1)^2 = 2^2 = \mathbf{4.0}$$

Step 3: RBF Kernel:
Squared Euclidean distance: $$\|\mathbf{x} - \mathbf{z}\|_2^2 = (1 - 4)^2 + (3 - (-1))^2 = (-3)^2 + (4)^2 = 9 + 16 = 25.0$$ Evaluate exponential with $\gamma = 0.1$: $$K_{\text{RBF}} = \exp(-0.1 \times 25.0) = \exp(-2.5) \approx \mathbf{0.08208}$$

QUESTION: A Soft-Margin SVM with $C = 5.0$ is trained on a binary classification dataset. An inspection of the optimal dual multipliers $\boldsymbol{\alpha}^*$ and slack variables $\boldsymbol{\xi}^*$ reveals:

Sample $i$$y_i$Feature $\mathbf{x}_i$Multiplier $\alpha_i^*$Slack $\xi_i^*$

  1. Classify each of the 4 samples as a Non-Support Vector, Free Support Vector, or Bounded Support Vector.

Step 1: Classify Points based on $\alpha_i^*$:

  • Sample 1 ($\alpha_1^* = 0.0$): Non-Support Vector. Strictly outside margin ($y_1(\mathbf{w}^T \mathbf{x}_1 + b) > 1$).

Problem 2.6.4 Medium Amazon

QUESTION: In John Platt's Sequential Minimal Optimization (SMO) algorithm, we optimize two Lagrange multipliers $\alpha_1$ and $\alpha_2$ simultaneously while keeping all other multipliers fixed. Given labels $y_1 = +1$ and $y_2 = -1$, and box constraint $C = 4.0$. The current multipliers are $\alpha_1^{(0)} = 1.0$ and $\alpha_2^{(0)} = 2.0$.

  1. Express the linear equality constraint governing $\alpha_1$ and $\alpha_2$.
  2. Compute the lower bound $L$ and upper bound $H$ used to clip $\alpha_2^{\text{new}}$ to satisfy the box constraints $0 \le \alpha_1, \alpha_2 \le C$.
✓ Complete Step-by-Step Mathematical Derivation

Step 1: Equality Constraint:
The SVM dual constraint is $\sum_{i=1}^N \alpha_i y_i = 0$. Holding $\alpha_3, \dots, \alpha_N$ fixed: $$\alpha_1 y_1 + \alpha_2 y_2 = -\sum_{i=3}^N \alpha_i y_i = k \quad (\text{constant})$$ With $y_1 = +1$ and $y_2 = -1$: $$\alpha_1(1) + \alpha_2(-1) = k \implies \alpha_1 - \alpha_2 = k$$ Using current values $\alpha_1^{(0)} = 1.0$ and $\alpha_2^{(0)} = 2.0$: $$k = 1.0 - 2.0 = -1.0 \implies \alpha_1 = \alpha_2 - 1.0$$

Step 2: Determine Clipping Bounds for $\alpha_2$:
Both multipliers must satisfy the box constraints: $$0 \le \alpha_2 \le C \quad \text{AND} \quad 0 \le \alpha_1 \le C$$ Substitute $\alpha_1 = \alpha_2 + k$: $$0 \le \alpha_2 + k \le C \implies -k \le \alpha_2 \le C - k$$ Combine with $0 \le \alpha_2 \le C$: $$L = \max(0, \ -k) = \max(0, \ -(-1.0)) = \max(0, 1.0) = \mathbf{1.0}$$ $$H = \min(C, \ C - k) = \min(4.0, \ 4.0 - (-1.0)) = \min(4.0, 5.0) = \mathbf{4.0}$$ Result: Any updated $\alpha_2^{\text{unc}}$ must be clipped into interval $[L, H] = [1.0, 4.0]$ to preserve dual feasibility!

Problem 2.6.5 Hard Google DeepMind Meta FAIR

QUESTION: Prove mathematically that the 1D Radial Basis Function (RBF) Kernel: $$K(x, z) = \exp\left( -\frac{(x - z)^2}{2} \right)$$ corresponds to an inner product in an infinite-dimensional Hilbert space $\phi(x)^T \phi(z)$. Explicitly construct the infinite feature mapping vector $\phi(x) \in \mathbb{R}^\infty$.

✓ Complete Step-by-Step Mathematical Proof

Step 1: Expand the Squared Euclidean Difference: $$(x - z)^2 = x^2 - 2xz + z^2 \implies -\frac{(x - z)^2}{2} = -\frac{x^2}{2} + xz - \frac{z^2}{2}$$ Factorize the exponential: $$K(x, z) = \exp\left(-\frac{x^2}{2}\right) \exp(xz) \exp\left(-\frac{z^2}{2}\right)$$

Step 2: Apply the Taylor Series Expansion of the Exponential Function:
Recall the infinite Taylor series of $e^u$: $$e^u = \sum_{k=0}^\infty \frac{u^k}{k!} = 1 + u + \frac{u^2}{2!} + \frac{u^3}{3!} + \dots$$ Applying this with $u = xz$: $$\exp(xz) = \sum_{k=0}^\infty \frac{(xz)^k}{k!} = \sum_{k=0}^\infty \frac{x^k z^k}{k!} = \sum_{k=0}^\infty \left( \frac{x^k}{\sqrt{k!}} \right) \left( \frac{z^k}{\sqrt{k!}} \right)$$

Step 3: Factorize into an Infinite-Dimensional Inner Product: $$K(x, z) = \sum_{k=0}^\infty \left[ \exp\left(-\frac{x^2}{2}\right) \frac{x^k}{\sqrt{k!}} \right] \left[ \exp\left(-\frac{z^2}{2}\right) \frac{z^k}{\sqrt{k!}} \right]$$ Define the infinite-dimensional feature map $\phi(x)$: $$\phi(x) = \exp\left(-\frac{x^2}{2}\right) \begin{bmatrix} 1, & x, & \frac{x^2}{\sqrt{2!}}, & \frac{x^3}{\sqrt{3!}}, & \dots, & \frac{x^k}{\sqrt{k!}}, & \dots \end{bmatrix}^T \in \mathbb{R}^\infty$$ Then the kernel is identically the inner product: $$K(x, z) = \langle \phi(x), \phi(z) \rangle = \phi(x)^T \phi(z)$$ Q.E.D. The RBF kernel maps inputs into an infinite-dimensional polynomial basis, enabling infinite non-linear capacity in $\mathcal{O}(d)$ evaluation time!

Problem 2.6.6 Hard OpenAI

QUESTION: Prove that the homogeneous quadratic polynomial kernel $K(\mathbf{x}, \mathbf{z}) = (\mathbf{x}^T \mathbf{z})^2$ for 2D vectors $\mathbf{x} = [x_1, x_2]^T$ and $\mathbf{z} = [z_1, z_2]^T$ satisfies Mercer's Theorem by explicitly constructing its feature mapping $\phi(\mathbf{x}) \in \mathbb{R}^3$.

✓ Complete Step-by-Step Mathematical Proof

Step 1: Expand the Algebraic Expression: $$K(\mathbf{x}, \mathbf{z}) = (\mathbf{x}^T \mathbf{z})^2 = (x_1 z_1 + x_2 z_2)^2$$ $$= (x_1 z_1)^2 + 2 (x_1 z_1)(x_2 z_2) + (x_2 z_2)^2$$ $$= x_1^2 z_1^2 + 2 x_1 x_2 z_1 z_2 + x_2^2 z_2^2$$

Step 2: Factorize into Inner Product: $$K(\mathbf{x}, \mathbf{z}) = (x_1^2)(z_1^2) + (\sqrt{2} x_1 x_2)(\sqrt{2} z_1 z_2) + (x_2^2)(z_2^2)$$ Define the 3-dimensional feature map: $$\phi(\mathbf{x}) = \begin{bmatrix} x_1^2 \\ \sqrt{2} x_1 x_2 \\ x_2^2 \end{bmatrix} \in \mathbb{R}^3$$ Then: $$\phi(\mathbf{x})^T \phi(\mathbf{z}) = x_1^2 z_1^2 + 2 x_1 x_2 z_1 z_2 + x_2^2 z_2^2 = (\mathbf{x}^T \mathbf{z})^2 = K(\mathbf{x}, \mathbf{z})$$ Q.E.D. The kernel corresponds to an inner product in $\mathbb{R}^3$, proving Mercer's condition directly.

Problem 2.6.7 Medium Google

QUESTION: What happens to the decision boundary and generalization performance of an RBF Support Vector Machine when the kernel bandwidth parameter $\gamma = \frac{1}{2\sigma^2}$ is set to an extremely large value ($\gamma \to \infty$)?

  1. The decision boundary becomes linear, and the model severely underfits.
  2. The kernel matrix becomes the identity matrix $\mathbf{K} \to \mathbf{I}$, each training sample forms an isolated Gaussian spike, and the model severely overfits.
  3. The geometric margin increases to infinity, eliminating all support vectors.
  4. The optimization problem becomes non-convex, causing SMO to oscillate.
✓ Complete Conceptual Analysis & Explanation

Correct Option: B

Exhaustive Analysis of All Options:

  • Option B is TRUE: $K(\mathbf{x}_i, \mathbf{x}_j) = \exp(-\gamma \|\mathbf{x}_i - \mathbf{x}_j\|^2)$. For any $i \neq j$, as $\gamma \to \infty$, $-\gamma \|\mathbf{x}_i - \mathbf{x}_j\|^2 \to -\infty \implies K(\mathbf{x}_i, \mathbf{x}_j) \to 0$. Meanwhile, $K(\mathbf{x}_i, \mathbf{x}_i) = e^0 = 1$. The Gram matrix becomes $\mathbf{K} = \mathbf{I}_N$. The decision boundary wraps tightly around each positive training point as an isolated needle-like island, causing catastrophic overfitting (high variance).
  • Option A is FALSE: Small $\gamma \to 0$ makes the boundary flat/linear (underfitting).
  • Option C is FALSE: Large $\gamma$ shrinks margin width toward zero.
  • Option D is FALSE: The SVM dual remains strictly convex for any positive definite kernel.

5. Production Code Lab 2.6: Pegasos Stochastic Subgradient SVM

Below is an industrial implementation of the Pegasos (Primal Estimated sub-GrAdient SOlver for SVM) algorithm, training a linear Support Vector Machine in $O(N)$ time via stochastic subgradient descent.

Code Lab 2.6 — Pegasos Linear SVM from Scratch

🔗 View in GitHub: part2_classical_ml/ch26_svm/pegasos_svm_scratch.py

import numpy as np

class PegasosSVMScratch:
    def __init__(self, lambda_param=1e-3, n_epochs=50):
        self.lambda_param = lambda_param
        self.n_epochs = n_epochs
        self.w = None
        self.b = 0.0

    def fit(self, X, y):
        # y must be in {-1, +1}
        N, d = X.shape
        self.w = np.zeros(d)
        t = 0

        for epoch in range(self.n_epochs):
            indices = np.random.permutation(N)
            for i in indices:
                t += 1
                eta = 1.0 / (self.lambda_param * t) # Decaying learning rate
                x_i, y_i = X[i], y[i]

                # Functional margin condition: y_i * (w^T x_i + b) < 1
                if y_i * (np.dot(self.w, x_i) + self.b) < 1.0:
                    # Subgradient step: w = (1 - eta * lambda) * w + eta * y_i * x_i
                    self.w = (1.0 - eta * self.lambda_param) * self.w + eta * y_i * x_i
                    self.b += eta * y_i
                else:
                    # Margin satisfied: shrink w only
                    self.w = (1.0 - eta * self.lambda_param) * self.w

    def predict(self, X):
        return np.sign(np.dot(X, self.w) + self.b).astype(int)

if __name__ == "__main__":
    from sklearn.datasets import make_blobs
    X, y = make_blobs(n_samples=400, centers=2, random_state=42)
    y = np.where(y == 0, -1, 1)

    svm = PegasosSVMScratch(lambda_param=1e-2, n_epochs=30)
    svm.fit(X, y)
    preds = svm.predict(X)
    print(f"Pegasos SVM Accuracy: {np.mean(preds == y) * 100:.2f}%")
