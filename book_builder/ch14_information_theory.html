1. Quantifying Uncertainty: Surprise & Entropy

Before Claude Shannon published A Mathematical Theory of Communication in 1948, the concept of "information" was subjective, intuitive, and mathematically unquantifiable. Shannon established information theory as a rigorous mathematical science by defining the fundamental atom of uncertainty: Self-Information (Surprise).

The Axiomatic Derivation of Surprise

Consider an event $x$ with probability $P(x) \in [0, 1]$. How much information is revealed when $x$ occurs? Shannon demanded that a valid measure of surprise $I(x)$ satisfy four intuitive axioms:

  1. Non-negativity: Receiving information can never make us less informed: $I(x) \ge 0$.
  2. Certainty conveys Zero Information: If an event is guaranteed to happen ($P(x) = 1$), observing it reveals zero surprise: $I(x) = 0$. (e.g., Telling someone "the sun will rise tomorrow" conveys 0 bits).
  3. Monotonicity with Rarity: An uncommon event carries strictly more information than a common event: If $P(x_1) < P(x_2)$, then $I(x_1) > I(x_2)$.
  4. Additivity for Independent Events: If two statistically independent events $x$ and $y$ occur ($P(x, y) = P(x)P(y)$), the total surprise should be the sum of individual surprises: $I(x, y) = I(x) + I(y)$.

The only continuous mathematical function satisfying $f(u \cdot v) = f(u) + f(v)$ is the logarithm. Combined with the requirement that surprise decreases as probability increases, we obtain the unique definition of Shannon Surprise:

$$I(x) = -\log_b P(x) = \log_b\left(\frac{1}{P(x)}\right)$$
  • If base $b = 2$, surprise is measured in bits (shannons). One bit represents the uncertainty resolved by a fair coin flip ($-\log_2(0.5) = 1 \text{ bit}$).
  • If base $b = e$, surprise is measured in nats ($1 \text{ nat} = \frac{1}{\ln 2} \approx 1.4427 \text{ bits}$). Standard deep learning frameworks (PyTorch, TensorFlow) compute loss in nats.
  • If base $b = 10$, surprise is measured in hartleys (dits).

Shannon Entropy

The Shannon Entropy $H(P)$ of a discrete random variable $X$ is the expected value of surprise across its entire probability distribution $P$:

$$H(P) = \mathbb{E}_{x \sim P}[I(x)] = -\sum_{x \in \mathcal{X}} P(x) \log_2 P(x)$$

By convention, if $P(x) = 0$, we define $0 \log_2(0) = \lim_{p \to 0^+} p \log_2(p) = 0$ by L'Hôpital's rule.

Fundamental Bounds on Discrete Entropy:
For any discrete distribution with $K = |\mathcal{X}|$ distinct outcomes:

$$0 \le H(P) \le \log_2(K)$$
  • Deterministic Minimum ($H = 0$): If $P(x_1) = 1$ and $P(x_i) = 0$ for all $i \neq 1$, there is zero uncertainty. Outcome is completely predictable.
  • Uniform Maximum ($H = \log_2 K$): Uncertainty is maximized when all outcomes are equally probable: $P(x_i) = 1/K$. For an 8-sided fair die, $H = \log_2(8) = 3 \text{ bits}$.
Entropy represents the absolute theoretical limit of lossless data compression (Shannon's Source Coding Theorem): no code can compress a source to fewer than $H(P)$ bits per symbol on average!

Joint, Conditional, and Differential Entropy

Entropy extends naturally to systems of multiple random variables:

  • Joint Entropy $H(X, Y)$: Total uncertainty contained in the pair $(X, Y)$: $$H(X, Y) = -\sum_{x \in \mathcal{X}} \sum_{y \in \mathcal{Y}} P(x, y) \log_2 P(x, y)$$
  • Conditional Entropy $H(Y \mid X)$: The remaining uncertainty in $Y$ after observing $X$: $$H(Y \mid X) = \sum_{x \in \mathcal{X}} P(x) H(Y \mid X = x) = -\sum_{x \in \mathcal{X}} \sum_{y \in \mathcal{Y}} P(x, y) \log_2 P(y \mid x)$$
  • Chain Rule of Entropy: Total uncertainty decomposes as: $$H(X, Y) = H(X) + H(Y \mid X) = H(Y) + H(X \mid Y)$$
  • Differential Entropy (Continuous Variables): For a continuous random variable with PDF $f(x)$: $$h(X) = -\int_{-\infty}^\infty f(x) \ln f(x) \, dx$$ Critical Warning: Unlike discrete entropy, differential entropy $h(X)$ can be negative! For example, for a uniform distribution $U(0, a)$, $h(X) = \ln(a)$. If $a = 0.1$, $h(X) = \ln(0.1) \approx -2.30 \text{ nats}$. Differential entropy measures relative coordinate volume, not absolute bits of information.

2. Cross-Entropy & Kullback-Leibler (KL) Divergence

In machine learning, we have a true data distribution $P$ (e.g., empirical training labels) and a model's predicted distribution $Q_\theta$ (e.g., neural network softmax probabilities). How do we quantify the exact statistical divergence between what reality is ($P$) and what our model predicts ($Q$)?

Kullback-Leibler (KL) Divergence (Relative Entropy)

The KL Divergence $D_{\text{KL}}(P \parallel Q)$ measures the excess expected surprise incurred when encoding events distributed according to true distribution $P$ using an optimal compression code designed for model distribution $Q$:

$$D_{\text{KL}}(P \parallel Q) = \sum_{x \in \mathcal{X}} P(x) \log\left(\frac{P(x)}{Q(x)}\right) = \sum_{x \in \mathcal{X}} P(x) \log P(x) - \sum_{x \in \mathcal{X}} P(x) \log Q(x)$$

Notice the two terms: the first term is the negative entropy of the true distribution $-H(P)$, and the second term is defined as the Cross-Entropy $H(P, Q)$:

$$H(P, Q) = -\sum_{x \in \mathcal{X}} P(x) \log Q(x)$$

This yields the fundamental decomposition of information theory:

$$D_{\text{KL}}(P \parallel Q) = H(P, Q) - H(P) \implies H(P, Q) = H(P) + D_{\text{KL}}(P \parallel Q)$$

🏆 Why Neural Networks Minimize Cross-Entropy

In supervised learning, true targets $P$ are empirical constants fixed in the training dataset ($H(P)$ is a constant with respect to neural network weights $\theta$). Therefore:

$$\arg\min_\theta H(P, Q_\theta) \equiv \arg\min_\theta \left[ H(P) + D_{\text{KL}}(P \parallel Q_\theta) \right] \equiv \arg\min_\theta D_{\text{KL}}(P \parallel Q_\theta)$$

Minimizing cross-entropy loss is mathematically identical to minimizing the KL divergence between model predictions and ground truth! When cross-entropy equals entropy ($H(P, Q) = H(P)$), the model achieves perfection ($D_{\text{KL}} = 0$).

The Asymmetry of KL: Forward KL vs. Reverse KL

KL Divergence is not a metric distance because it violates symmetry ($D_{\text{KL}}(P \parallel Q) \neq D_{\text{KL}}(Q \parallel P)$) and the triangle inequality. This asymmetry creates two fundamentally distinct optimization behaviors in modern AI:

Property Forward KL: $D_{\text{KL}}(P \parallel Q) = \mathbb{E}_{P}\left[\ln \frac{P}{Q}\right]$ Reverse KL: $D_{\text{KL}}(Q \parallel P) = \mathbb{E}_{Q}\left[\ln \frac{Q}{P}\right]$
Penalty Behavior Zero-Avoiding (Mode-Covering): If $P(x) > 0$ but $Q(x) \to 0$, $P \ln(P/Q) \to \infty$. $Q$ is violently penalized for having zero probability where data exists. Zero-Forcing (Mode-Seeking): If $P(x) = 0$ but $Q(x) > 0$, $Q \ln(Q/P) \to \infty$. $Q$ is violently penalized for placing probability mass where data does not exist.
Fit on Multimodal $P$ $Q$ stretches out to cover all modes of $P$, placing probability mass in between modes (diffuse, over-dispersed). $Q$ collapses onto a single sharp mode of $P$, completely ignoring other modes (under-dispersed, sharp).
Primary AI Use Case Supervised Deep Learning, Maximum Likelihood Estimation, Knowledge Distillation (soft-target matching). Variational Autoencoders (ELBO optimization), Diffusion reverse-time posteriors, RLHF / PPO Policy Alignment (preventing reward hacking).

Jensen-Shannon Divergence (JSD)

To eliminate the asymmetry of KL divergence and guard against infinite penalties when supports do not overlap, the Jensen-Shannon Divergence averages the KL divergence to an intermediate mixture distribution $M = \frac{1}{2}(P + Q)$:

$$\text{JSD}(P \parallel Q) = \frac{1}{2} D_{\text{KL}}(P \parallel M) + \frac{1}{2} D_{\text{KL}}(Q \parallel M)$$
  • Symmetric: $\text{JSD}(P \parallel Q) = \text{JSD}(Q \parallel P)$.
  • Strictly bounded: $0 \le \text{JSD}(P \parallel Q) \le 1 \text{ bit}$ (or $\ln 2$ nats).
  • Metric Property: The square root $\sqrt{\text{JSD}(P \parallel Q)}$ is a true mathematical distance metric obeying the triangle inequality.
  • Original GAN Objective: Goodfellow et al. (2014) proved that training an optimal discriminator under minimax loss minimizes the JSD between data distribution $P_{\text{data}}$ and generator distribution $P_G$!

3. Mutual Information, Channel Capacity & Perplexity

Mutual Information (Information Gain)

The Mutual Information $I(X; Y)$ quantifies how much information one random variable conveys about another—or equivalently, the reduction in uncertainty of $X$ given knowledge of $Y$:

$$I(X; Y) = H(X) - H(X \mid Y) = H(Y) - H(Y \mid X) = H(X) + H(Y) - H(X, Y)$$

Expressed as a KL divergence:

$$I(X; Y) = D_{\text{KL}}\left( P(X, Y) \parallel P(X)P(Y) \right) = \sum_{x, y} P(x, y) \log\left( \frac{P(x, y)}{P(x)P(y)} \right)$$

Properties of Mutual Information:

  • Symmetric: $I(X; Y) = I(Y; X) \ge 0$.
  • $I(X; Y) = 0$ if and only if $X \perp Y$ are completely independent.
  • $I(X; X) = H(X)$: The mutual information of a variable with itself is its Shannon entropy (self-information).
  • Data Processing Inequality (DPI): For any Markov chain $X \to Y \to Z$, $I(X; Z) \le I(X; Y)$. No post-processing or neural network transformation of representations can create new information about input $X$!

Language Model Perplexity ($\text{PPL}$)

In Large Language Models, cross-entropy loss over a sequence of $T$ tokens is computed as $\mathcal{L} = -\frac{1}{T} \sum_{t=1}^T \ln P(w_t \mid w_{Perplexity:

$$\text{PPL} = \exp(\mathcal{L}) = e^{\mathcal{L}} \quad (\text{if using base } e), \qquad \text{PPL} = 2^{H(P, Q)} \quad (\text{if using base } 2)$$

Intuition of Perplexity: Perplexity represents the effective branching factor of the language model. A perplexity of $15.0$ means that at each token prediction, the model is as uncertain as if it were choosing uniformly at random among $15$ equally probable words. A perfect model that predicts every token with $100\%$ certainty has $\text{PPL} = 1.0$.

Problem 1.4.1 Easy Google

QUESTION: A language model token vocabulary contains $4$ specialized control tokens $V = \{[\text{PAD}], [\text{BOS}], [\text{EOS}], [\text{UNK}]\}$ with empirical probabilities: $$P([\text{PAD}]) = 0.50, \quad P([\text{BOS}]) = 0.25, \quad P([\text{EOS}]) = 0.125, \quad P([\text{UNK}]) = 0.125$$

  1. Compute the individual self-information (surprise) $I(x)$ of each token in bits.
  2. Compute the total Shannon entropy $H(P)$ of this token distribution in bits.
  3. What is the maximum theoretical entropy possible for a 4-token vocabulary, and what is the entropy efficiency $\eta = \frac{H(P)}{H_{\max}}$?
✓ Complete Step-by-Step Numerical Solution

Step 1: Compute Individual Surprise in Bits:
Using $I(x) = -\log_2 P(x)$: $$I([\text{PAD}]) = -\log_2(0.50) = -\log_2(2^{-1}) = 1.0 \text{ bit}$$ $$I([\text{BOS}]) = -\log_2(0.25) = -\log_2(2^{-2}) = 2.0 \text{ bits}$$ $$I([\text{EOS}]) = -\log_2(0.125) = -\log_2(2^{-3}) = 3.0 \text{ bits}$$ $$I([\text{UNK}]) = -\log_2(0.125) = -\log_2(2^{-3}) = 3.0 \text{ bits}$$

Step 2: Compute Total Shannon Entropy $H(P)$: $$H(P) = \sum_{x \in V} P(x) I(x)$$ $$H(P) = (0.50 \times 1.0) + (0.25 \times 2.0) + (0.125 \times 3.0) + (0.125 \times 3.0)$$ $$H(P) = 0.50 + 0.50 + 0.375 + 0.375 = 1.75 \text{ bits}$$ Result: The average uncertainty per emitted token is exactly $1.75$ bits.

Step 3: Compute Maximum Entropy and Efficiency:
For $|V| = 4$, maximum entropy is achieved under a uniform distribution $P(x_i) = 1/4$: $$H_{\max} = \log_2(|V|) = \log_2(4) = 2.0 \text{ bits}$$ Entropy efficiency: $$\eta = \frac{H(P)}{H_{\max}} = \frac{1.75}{2.00} = 0.875 = 87.5\%$$ Insight: An optimal Huffman code for this vocabulary would assign 1 bit to PAD, 2 bits to BOS, and 3 bits each to EOS and UNK, achieving an expected code length of exactly $1.75$ bits/token, perfectly matching the Shannon bound!

Problem 1.4.2 Easy Meta Apple

QUESTION: In a 3-class classification problem ($K=3$), the ground truth label is class 1: $P = [1.0, 0.0, 0.0]$. Two candidate models produce the following softmax predictions: $$\mathbf{q}_A = [0.80, 0.15, 0.05], \qquad \mathbf{q}_B = [0.40, 0.30, 0.30]$$

  1. Compute the categorical cross-entropy loss $H(P, \mathbf{q}_A)$ and $H(P, \mathbf{q}_B)$ in natural units (nats).
  2. Compute the KL divergences $D_{\text{KL}}(P \parallel \mathbf{q}_A)$ and $D_{\text{KL}}(P \parallel \mathbf{q}_B)$.
  3. Convert the loss of both models into language model Perplexity ($\text{PPL} = e^H$).
✓ Complete Step-by-Step Numerical Solution

Step 1: Compute Cross-Entropy Loss in Nats:
For a one-hot distribution $P$, cross-entropy simplifies to the negative log probability of the correct class ($k=1$): $$H(P, \mathbf{q}) = -\sum_{k=1}^3 P(k) \ln q_k = -\ln(q_1)$$ $$H(P, \mathbf{q}_A) = -\ln(0.80) \approx 0.22314 \text{ nats}$$ $$H(P, \mathbf{q}_B) = -\ln(0.40) \approx 0.91629 \text{ nats}$$

Step 2: Compute KL Divergence:
Recall the identity: $D_{\text{KL}}(P \parallel Q) = H(P, Q) - H(P)$.
Since $P$ is a deterministic one-hot vector ($[1, 0, 0]$), its ground-truth entropy is zero: $$H(P) = -1.0 \ln(1.0) - 0 - 0 = 0 \text{ nats}$$ Therefore, KL divergence is identically equal to cross-entropy loss: $$D_{\text{KL}}(P \parallel \mathbf{q}_A) = H(P, \mathbf{q}_A) - 0 = 0.22314 \text{ nats}$$ $$D_{\text{KL}}(P \parallel \mathbf{q}_B) = H(P, \mathbf{q}_B) - 0 = 0.91629 \text{ nats}$$

Step 3: Compute Perplexity ($\text{PPL} = e^{\mathcal{L}}$): $$\text{PPL}_A = e^{0.22314} = \frac{1}{0.80} = 1.250$$ $$\text{PPL}_B = e^{0.91629} = \frac{1}{0.40} = 2.500$$ Result: Model A has a perplexity of $1.25$ (near certainty), whereas Model B has a perplexity of $2.50$ (effectively guessing between 2 to 3 classes).

QUESTION: In LLM text generation, temperature scaling modulates the entropy of next-token sampling: $$q_i(T) = \frac{\exp(z_i / T)}{\sum_{j=1}^K \exp(z_j / T)}$$ Given a 3-token logit vector $\mathbf{z} = [4.0, 2.0, 1.0]^T$:

  1. Compute the probability distribution $\mathbf{q}(T)$ and its Shannon entropy $H(\mathbf{q})$ in bits at temperature $T = 0.5$ (Low temperature / High confidence).
  2. Compute $\mathbf{q}(T)$ and $H(\mathbf{q})$ at temperature $T = 1.0$ (Standard).
  3. Compute $\mathbf{q}(T)$ and $H(\mathbf{q})$ at temperature $T = 5.0$ (High temperature / Creative sampling).
  4. Prove mathematically what happens to entropy as $T \to 0^+$ and as $T \to \infty$.
✓ Complete Step-by-Step Algorithmic Trace

Step 1: Temperature $T = 0.5$:
Scaled logits: $\mathbf{z} / 0.5 = [8.0, 4.0, 2.0]$.
Subtract max ($8.0$) for numerical stability: $\mathbf{z}' = [0.0, -4.0, -6.0]$.
Exponentials: $e^0 = 1.0, \ e^{-4} \approx 0.018316, \ e^{-6} \approx 0.002479$.
Sum = $1.020795$.
Probabilities: $$q_1 = \frac{1.0}{1.020795} \approx 0.97963, \quad q_2 = \frac{0.018316}{1.020795} \approx 0.01794, \quad q_3 = \frac{0.002479}{1.020795} \approx 0.00243$$ Entropy $H = -\sum q_i \log_2(q_i)$: $$H(T=0.5) = -(0.97963 \times (-0.02967) + 0.01794 \times (-5.7998) + 0.00243 \times (-8.6853))$$ $$H(T=0.5) = 0.02906 + 0.10405 + 0.02111 \approx \mathbf{0.1542 \text{ bits}}$$

Step 2: Temperature $T = 1.0$:
Logits: $\mathbf{z} = [4.0, 2.0, 1.0]$. Subtract max ($4.0$): $\mathbf{z}' = [0.0, -2.0, -3.0]$.
Exponentials: $e^0 = 1.0, \ e^{-2} \approx 0.135335, \ e^{-3} \approx 0.049787$.
Sum = $1.185122$.
Probabilities: $$q_1 = \frac{1.0}{1.185122} \approx 0.84379, \quad q_2 \approx 0.11419, \quad q_3 \approx 0.04201$$ Entropy: $$H(T=1.0) = -(0.84379 \log_2 0.84379 + 0.11419 \log_2 0.11419 + 0.04201 \log_2 0.04201)$$ $$H(T=1.0) = -(0.84379(-0.24507) + 0.11419(-3.13047) + 0.04201(-4.57311)) \approx \mathbf{0.7563 \text{ bits}}$$

Step 3: Temperature $T = 5.0$:
Scaled logits: $\mathbf{z} / 5 = [0.80, 0.40, 0.20]$. Subtract max ($0.80$): $[0.0, -0.40, -0.60]$.
Exponentials: $e^0 = 1.0, \ e^{-0.40} \approx 0.67032, \ e^{-0.60} \approx 0.54881$.
Sum = $2.21913$.
Probabilities: $$q_1 = \frac{1.0}{2.21913} \approx 0.45063, \quad q_2 \approx 0.30206, \quad q_3 \approx 0.24731$$ Entropy: $$H(T=5.0) = -(0.45063 \log_2 0.45063 + 0.30206 \log_2 0.30206 + 0.24731 \log_2 0.24731) \approx \mathbf{1.5238 \text{ bits}}$$

Step 4: Limits as $T \to 0^+$ and $T \to \infty$:

  • As $T \to 0^+$: $\frac{z_1 - z_j}{T} \to \infty$ for all $j \neq 1$. The largest logit dominates completely ($q_1 \to 1, q_j \to 0$). The distribution collapses to an argmax one-hot vector: $$\lim_{T \to 0^+} H(\mathbf{q}(T)) = \mathbf{0 \text{ bits}} \quad (\text{Pure greedy decoding})$$

Problem 1.4.4 Medium Amazon

QUESTION: An e-commerce fraud detection system evaluates whether an account feature $X \in \{0, 1\}$ (Device is a Known Emulator) predicts fraudulent transaction $Y \in \{0, 1\}$. An empirical audit of $N = 100$ transactions produces the following joint contingency counts:

Counts$Y = 0$ (Legit)$Y = 1$ (Fraud)
$X = 0$ (Real Device)$45$$5$
$X = 1$ (Emulator)$5$$45$

Compute step-by-step in bits:

  1. The marginal distributions $P(X)$ and $P(Y)$, and their individual Shannon entropies $H(X)$ and $H(Y)$.
  2. The joint entropy $H(X, Y)$.
  3. The conditional entropy $H(Y \mid X)$ and the Mutual Information $I(X; Y)$.
✓ Complete Step-by-Step Mathematical Solution

Step 1: Compute Probabilities and Marginal Entropies:
Total samples = $100$. $$P(X=0) = \frac{45 + 5}{100} = 0.50, \quad P(X=1) = \frac{5 + 45}{100} = 0.50$$ $$P(Y=0) = \frac{45 + 5}{100} = 0.50, \quad P(Y=1) = \frac{5 + 45}{100} = 0.50$$ Both marginal distributions are fair coin flips: $$H(X) = -\left( 0.5 \log_2(0.5) + 0.5 \log_2(0.5) \right) = 1.0 \text{ bit}$$ $$H(Y) = -\left( 0.5 \log_2(0.5) + 0.5 \log_2(0.5) \right) = 1.0 \text{ bit}$$

Step 2: Compute Joint Entropy $H(X, Y)$:
Joint probabilities: $P(0, 0) = 0.45, \ P(0, 1) = 0.05, \ P(1, 0) = 0.05, \ P(1, 1) = 0.45$. $$H(X, Y) = -\sum_{x, y} P(x, y) \log_2 P(x, y)$$ $$H(X, Y) = -2 \left[ 0.45 \log_2(0.45) \right] - 2 \left[ 0.05 \log_2(0.05) \right]$$ $$\log_2(0.45) \approx -1.15200, \quad \log_2(0.05) \approx -4.32193$$ $$H(X, Y) = -2(0.45 \times -1.15200) - 2(0.05 \times -4.32193) = 1.03680 + 0.43219 = \mathbf{1.46899 \text{ bits}}$$

Step 3: Compute Conditional Entropy & Mutual Information:
Using the chain rule $H(Y \mid X) = H(X, Y) - H(X)$: $$H(Y \mid X) = 1.46899 - 1.00000 = \mathbf{0.46899 \text{ bits}}$$ Mutual Information: $$I(X; Y) = H(Y) - H(Y \mid X) = 1.00000 - 0.46899 = \mathbf{0.53101 \text{ bits}}$$ Engineering Interpretation: Knowing whether the transaction originated on an emulator resolves $0.531$ bits ($53.1\%$) of the fraud uncertainty, proving it is a high-priority feature for the fraud classification model.

Problem 1.4.5 Hard Google DeepMind OpenAI

QUESTION: Prove Gibbs' Inequality from first principles: prove that for any two discrete probability distributions $P$ and $Q$ defined on support $\mathcal{X}$, the KL Divergence is strictly non-negative: $$D_{\text{KL}}(P \parallel Q) \ge 0$$ with equality $D_{\text{KL}}(P \parallel Q) = 0$ if and only if $P(x) = Q(x)$ for all $x \in \mathcal{X}$. From this, derive the fundamental upper bound on discrete entropy: $H(P) \le \log_2(K)$ where $K = |\mathcal{X}|$.

✓ Complete Step-by-Step Mathematical Proof

Step 1: Write the Negative KL Divergence: $$-D_{\text{KL}}(P \parallel Q) = -\sum_{x \in \mathcal{X}} P(x) \ln\left(\frac{P(x)}{Q(x)}\right) = \sum_{x \in \mathcal{X}} P(x) \ln\left(\frac{Q(x)}{P(x)}\right)$$ In expectation notation: $$-D_{\text{KL}}(P \parallel Q) = \mathbb{E}_{x \sim P}\left[ \ln\left(\frac{Q(x)}{P(x)}\right) \right]$$

Step 2: Apply Jensen's Inequality:
The natural logarithm function $f(t) = \ln(t)$ is strictly concave on $(0, \infty)$ because its second derivative is strictly negative: $f''(t) = -\frac{1}{t^2} < 0$.
By Jensen's Inequality for strictly concave functions: $$\mathbb{E}[f(T)] \le f(\mathbb{E}[T])$$ Let $T = \frac{Q(x)}{P(x)}$. Applying the inequality: $$\mathbb{E}_{x \sim P}\left[ \ln\left(\frac{Q(x)}{P(x)}\right) \right] \le \ln\left( \mathbb{E}_{x \sim P}\left[\frac{Q(x)}{P(x)}\right] \right)$$

Step 3: Evaluate the Inner Expectation: $$\mathbb{E}_{x \sim P}\left[\frac{Q(x)}{P(x)}\right] = \sum_{x \in \mathcal{X}} P(x) \frac{Q(x)}{P(x)} = \sum_{x \in \mathcal{X}} Q(x) = 1$$ Therefore: $$-D_{\text{KL}}(P \parallel Q) \le \ln(1) = 0 \implies D_{\text{KL}}(P \parallel Q) \ge 0$$

Step 4: Strict Equality Condition:
Because $f(t) = \ln(t)$ is strictly concave, equality holds in Jensen's inequality if and only if the random variable $T$ is degenerate (constant almost everywhere): $$\frac{Q(x)}{P(x)} = c \implies Q(x) = c P(x), \quad \forall x \in \mathcal{X}$$ Summing both sides over $\mathcal{X}$: $\sum Q(x) = c \sum P(x) \implies 1 = c(1) \implies c = 1$.
Therefore, $D_{\text{KL}}(P \parallel Q) = 0$ if and only if $P(x) = Q(x)$ for all $x \in \mathcal{X}$.

Step 5: Derive the Maximum Entropy Bound:
Let $Q$ be the uniform distribution over $K$ categories: $Q(x) = \frac{1}{K}$ for all $x$.
By Gibbs' inequality: $$D_{\text{KL}}(P \parallel U) = \sum_{x=1}^K P(x) \log_2\left( \frac{P(x)}{1/K} \right) \ge 0$$ $$\sum_{x=1}^K P(x) \log_2 P(x) - \sum_{x=1}^K P(x) \log_2\left(\frac{1}{K}\right) \ge 0$$ $$-H(P) - \log_2\left(\frac{1}{K}\right) \sum_{x=1}^K P(x) \ge 0 \implies -H(P) + \log_2(K)(1) \ge 0$$ $$\mathbf{H(P) \le \log_2(K)}$$ Q.E.D. The KL divergence is strictly non-negative, and discrete entropy is upper-bounded by $\log_2(K)$, with equality if and only if $P$ is the uniform distribution!

Problem 1.4.6 Hard Meta FAIR Anthropic

QUESTION: Let true distribution $P(x)$ be a symmetric bimodal 1D Gaussian mixture: $$P(x) = \frac{1}{2} \mathcal{N}(-\mu_0, \sigma_0^2) + \frac{1}{2} \mathcal{N}(\mu_0, \sigma_0^2), \quad \text{where } \mu_0 = 3, \ \sigma_0^2 = 1$$ We approximate $P(x)$ using a unimodal Gaussian $Q(x) = \mathcal{N}(\mu, \sigma^2)$.

  1. Find the optimal parameters $(\mu^*, \sigma^{2*})$ that minimize the Forward KL $D_{\text{KL}}(P \parallel Q)$.
  2. Describe the optimal parameters that minimize the Reverse KL $D_{\text{KL}}(Q \parallel P)$.
  3. Explain the critical engineering implications of this divergence choice for Variational Autoencoders (VAEs), Generative Diffusion Models, and RLHF Policy Optimization.
✓ Complete Step-by-Step Mathematical Analysis

Step 1: Forward KL Minimization ($D_{\text{KL}}(P \parallel Q)$):
Minimizing $D_{\text{KL}}(P \parallel Q)$ with respect to $Q$ is mathematically identical to Maximum Likelihood Estimation: $$\arg\min_Q D_{\text{KL}}(P \parallel Q) = \arg\min_Q \mathbb{E}_{x \sim P}[-\ln Q(x)]$$ For a Gaussian family $Q \sim \mathcal{N}(\mu, \sigma^2)$, the optimal parameters are the exact sample moments under $P$: $$\mu^* = \mathbb{E}_{P}[X], \qquad \sigma^{2*} = \text{Var}_P(X)$$ By symmetry around the origin: $$\mu^* = \frac{1}{2}(-\mu_0) + \frac{1}{2}(\mu_0) = \mathbf{0}$$ By the Law of Total Variance: $$\sigma^{2*} = \mathbb{E}_P[X^2] - (\mathbb{E}_P[X])^2 = \left[ \frac{1}{2}((-\mu_0)^2 + \sigma_0^2) + \frac{1}{2}((\mu_0)^2 + \sigma_0^2) \right] - 0$$ $$\sigma^{2*} = \mu_0^2 + \sigma_0^2 = 3^2 + 1 = 9 + 1 = \mathbf{10}$$ Forward KL Result: $Q(x) = \mathcal{N}(0, 10)$. $Q$ is placed at the center with massive variance ($\sigma \approx 3.16$) to cover both peaks (Mode-Covering).

Step 2: Reverse KL Minimization ($D_{\text{KL}}(Q \parallel P)$):
$$D_{\text{KL}}(Q \parallel P) = \int Q(x) \ln\left(\frac{Q(x)}{P(x)}\right) dx$$ If $Q(x)$ places probability mass near $x = 0$ (the valley where $P(x) \approx 0$), the penalty $\ln(Q(x)/P(x))$ explodes toward $+\infty$.
To avoid this infinite penalty, $Q(x)$ must choose one mode and collapse onto it: $$\mu^* \approx +3 \quad (\text{or } \mu^* \approx -3), \qquad \sigma^{2*} \approx \sigma_0^2 = 1$$ Reverse KL Result: $Q(x) \approx \mathcal{N}(3, 1)$ or $\mathcal{N}(-3, 1)$. $Q$ completely ignores one half of the universe to fit the chosen peak with extreme precision (Mode-Seeking / Zero-Forcing).

Step 3: Engineering Implications for Production AI:

  • VAEs & Latent Variable Models: The Evidence Lower Bound (ELBO) optimizes the Reverse KL $D_{\text{KL}}(q_\phi(z \mid x) \parallel p(z))$. This causes posterior collapse where the approximate posterior ignores certain latent dimensions.
  • RLHF & PPO in Large Language Models: In RLHF, the PPO policy objective includes a penalty term $-\beta D_{\text{KL}}(\pi_\theta \parallel \pi_{\text{ref}})$. Because this uses Reverse KL (expectation over current policy $\pi_\theta$), the fine-tuned model seeks high-reward modes while avoiding generating tokens that the reference model considers impossible ($P_{\text{ref}} = 0$).
  • Knowledge Distillation: Distilling a giant Teacher model into a small Student model uses Forward KL (expectation over Teacher distribution), forcing the Student to preserve all modes and general knowledge rather than over-specializing.

Problem 1.4.7 Medium Google

QUESTION: Which of the following statements correctly explains why differential entropy $h(X) = -\int f(x) \ln f(x) dx$ for a continuous random variable can be negative, whereas discrete Shannon entropy $H(X)$ is strictly non-negative?

  1. Differential entropy violates Kolmogorov's first axiom of non-negativity.
  2. A continuous probability density function $f(x)$ can exceed $1$, causing $\ln f(x) > 0$ and producing a negative integral.
  3. Negative differential entropy occurs only when the covariance matrix $\boldsymbol{\Sigma}$ has negative eigenvalues.
  4. Differential entropy is undefined for continuous distributions with bounded support.
✓ Complete Conceptual Analysis & Explanation

Correct Option: B

Exhaustive Analysis of All Options:

  • Option B is TRUE: In discrete probability, probabilities are probabilities of individual events, so $0 \le P(x) \le 1 \implies \log P(x) \le 0 \implies -\sum P \log P \ge 0$. In continuous probability, $f(x)$ is a probability density (units of $1/\text{unit}$), not a probability. For concentrated distributions (e.g., $X \sim U(0, 0.01)$), $f(x) = 100$ on $[0, 0.01]$. Thus $\ln f(x) = \ln(100) \approx 4.605 > 0$, yielding $h(X) = -\int_0^{0.01} 100 \ln(100) dx = -\ln(100) \approx -4.605 \text{ nats}$.
  • Option A is FALSE: Differential entropy is an information-theoretic functional, not a probability measure; Kolmogorov's axioms apply to probability measures, not entropy.
  • Option C is FALSE: Valid covariance matrices are symmetric positive semi-definite and cannot have negative eigenvalues. Differential entropy of a Gaussian is $h(X) = \frac{1}{2} \ln(2\pi e \sigma^2)$, which is negative whenever $\sigma^2 < \frac{1}{2\pi e} \approx 0.0585$, even with perfectly positive variance.
  • Option D is FALSE: Differential entropy is well-defined for bounded support distributions (e.g., Uniform, Beta).

Problem 1.4.8 Hard DeepMind

QUESTION: Consider the following Assertion (A) and Reason (R):

Assertion (A): If an LLM is evaluating a test document and its token cross-entropy loss drops from $3.0$ nats to $2.0$ nats per token, its effective vocabulary perplexity drops by a factor of approximately $2.718$ ($e$).

Reason (R): By the Data Processing Inequality, stacking additional transformer attention layers guarantees that the mutual information between the hidden representations and the target label monotonically increases with network depth.

  1. Both (A) and (R) are true, and (R) is the correct explanation of (A).
  2. Both (A) and (R) are true, but (R) is NOT the correct explanation of (A).
  3. (A) is true, but (R) is false.
  4. (A) is false, but (R) is true.
✓ Complete Conceptual Analysis & Explanation

Correct Option: C

Exhaustive Analysis of Assertion & Reason:

  • Assertion (A) is TRUE: Perplexity is defined as $\text{PPL} = e^{\mathcal{L}}$ when loss is measured in nats. At loss $\mathcal{L}_1 = 3.0$, $\text{PPL}_1 = e^3 \approx 20.086$. At loss $\mathcal{L}_2 = 2.0$, $\text{PPL}_2 = e^2 \approx 7.389$. The ratio is $\frac{\text{PPL}_1}{\text{PPL}_2} = \frac{e^3}{e^2} = e^1 \approx 2.718$. Every 1-nat reduction in cross-entropy shrinks the effective search space by factor $e$.
  • Reason (R) is FALSE: The Data Processing Inequality states that for any Markov chain $X \to H_1 \to H_2 \dots \to H_L \to Y$, mutual information cannot increase: $I(X; H_{l+1}) \le I(X; H_l)$. Deep layers cannot magically create new mutual information about the input; they can only discard task-irrelevant nuisance variables (compression) to make the remaining task-relevant information linearly separable.
  • Therefore, Assertion (A) is true, but Reason (R) is completely false.

import numpy as np

def compute_information_metrics(p: np.ndarray, q: np.ndarray, eps=1e-12):
    """
    Computes Shannon Entropy H(P), Cross-Entropy H(P, Q), and KL Divergence D_KL(P || Q).
    """
    p = np.clip(p / np.sum(p), eps, 1.0)
    q = np.clip(q / np.sum(q), eps, 1.0)

    # 1. Shannon Entropy: H(P) = -sum(P * log2(P))
    h_p = -np.sum(p * np.log2(p))

    # 2. Cross-Entropy: H(P, Q) = -sum(P * log2(Q))
    h_pq = -np.sum(p * np.log2(q))

    # 3. KL Divergence: D_KL(P || Q) = sum(P * log2(P / Q))
    kl_div = np.sum(p * np.log2(p / q))

    # 4. Symmetrized Jensen-Shannon Divergence: JSD = 0.5 * (KL(P||M) + KL(Q||M))
    m = 0.5 * (p + q)
    jsd = 0.5 * (np.sum(p * np.log2(p / m)) + np.sum(q * np.log2(q / m)))

    return {
        "H(P)": float(h_p),
        "H(P, Q)": float(h_pq),
        "D_KL(P || Q)": float(kl_div),
        "JSD(P, Q)": float(jsd),
        "Identity_Check": bool(np.isclose(h_pq, h_p + kl_div))
    }

if __name__ == "__main__":
    P = np.array([0.7, 0.2, 0.1])
    Q = np.array([0.5, 0.3, 0.2])
    metrics = compute_information_metrics(P, Q)
    print("Information Metrics:")
    for k, v in metrics.items():
        print(f"  {k:15s} : {v}")
