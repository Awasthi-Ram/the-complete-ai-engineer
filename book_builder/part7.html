1. The Industrial Multi-Stage Recommendation Funnel

On platforms like YouTube, TikTok, Instagram, and Netflix, the catalog contains hundreds of millions or billions of items, consumed by hundreds of millions of active users. Running a complex deep neural network over 1,000,000,000 items for every user interaction is physically impossible (requiring millions of GPU hours per second).

Stage Input $\to$ Output Scale Latency SLA Architecture & Objective
Stage 1: Retrieval (Candidate Generation) $10^9 \to 10^3\text{ items}$ $< 10\text{ ms}$ Two-Tower Dual Encoders, ScaNN/HNSW MIPS vector search. High Recall@K.
Stage 2: Scoring (Heavy Ranking) $10^3 \to 50\text{ items}$ $< 25\text{ ms}$ Meta DLRM, DeepFM, Transformer Cross-Networks. High GAUC, LogLoss on CTR.
Stage 3: Re-Ranking & Diversity $50 \to 10\text{ items}$ $< 5\text{ ms}$ Maximal Marginal Relevance (MMR), DPP, freshness boosting, deduplication.

2. Two-Tower Neural Networks (Google YouTube 2016, 2019)

How does Stage 1 retrieve 1,000 items from 1,000,000,000 candidates in under 10 milliseconds? The solution is the Two-Tower Neural Architecture:

Figure 7.1.1: Two-Tower deep retrieval architecture. The User/Query Tower and Item/Candidate Tower project disparate feature spaces into a shared $d$-dimensional embedding space, enabling sub-10ms candidate retrieval across billions of candidate items via Approximate Nearest Neighbor (HNSW) search.

📐 Mathematical Formulation of the Two-Tower Architecture

  • User Tower: A deep neural network $f_\theta(\mathbf{x}_{\text{user}})$ mapping dynamic user context (watch history, search queries, device, time) to an embedding vector $\mathbf{u} \in \mathbb{R}^d$: $$\mathbf{u} = \frac{f_\theta(\mathbf{x}_{\text{user}})}{\|f_\theta(\mathbf{x}_{\text{user}})\|_2}$$
  • Item Tower: A deep neural network $g_\phi(\mathbf{y}_{\text{item}})$ mapping item features (video title, tags, channel, visual embeddings) to an embedding vector $\mathbf{v} \in \mathbb{R}^d$: $$\mathbf{v} = \frac{g_\phi(\mathbf{y}_{\text{item}})}{\|g_\phi(\mathbf{y}_{\text{item}})\|_2}$$
  • Relevance Scoring Function: The dot product (cosine similarity) between user and item vectors: $$s(\mathbf{u}, \mathbf{v}) = \mathbf{u}^T \mathbf{v} = \sum_{i=1}^d u_i v_i$$

The Computational Breakthrough: Because the item tower $g_\phi(\mathbf{y}_{\text{item}})$ does not depend on user features, item embeddings for all 1 billion videos are pre-computed offline once and indexed into an Approximate Nearest Neighbor (ANN) vector database!

At inference time, when a user opens the app:

  1. The system evaluates only the User Tower once ($O(1)$ forward pass, $\approx 2\text{ ms}$).
  2. The resulting vector $\mathbf{u}$ queries the pre-computed 1-billion item ANN index via maximum inner product search (MIPS), retrieving the top 1,000 candidates in $3\text{ ms}$!

3. Meta DLRM: Hybrid Parallelism & Feature Interactions

While Two-Tower models excel at retrieval, they cannot model explicit cross-features (e.g. user.device == item.target_os). In Stage 2, platforms deploy Meta DLRM (Deep Learning Recommendation Model):

  • Categorical Features: Millions of IDs (User ID, Video ID, Channel ID) map to giant Embedding Tables containing billions of parameters (often $200\text{ GB}$ to $1\text{ TB}$ of memory).
  • Dense Numerical Features: Fed into a Bottom MLP producing a dense latent vector $\mathbf{x}_{\text{dense}} \in \mathbb{R}^D$.
  • Feature Interaction Layer: Computes the pairwise dot products between the dense representation and all $K$ retrieved categorical embedding vectors: $$\mathbf{z}_{i, j} = \mathbf{e}_i^T \mathbf{e}_j \quad \forall 0 \le i < j \le K$$ producing $\frac{K(K+1)}{2}$ interaction scalars, concatenated with $\mathbf{x}_{\text{dense}}$ and processed by the Top MLP.
  • Hybrid Parallelism Architecture: Because embedding tables are too massive to fit on one GPU, DLRM distributes tables across GPUs via Model Parallelism, while replicating the MLPs via Data Parallelism. The two halves communicate across NVLink via an All-to-All collective communication primitive.

4. In-Batch Negative Sampling & LogQ De-biasing

In recommendation training, true negative interactions (videos a user hated) are rarely explicit. We treat unobserved items as negatives using In-Batch Negative Sampling. In a mini-batch of $B$ positive pairs $\{(\mathbf{u}_i, \mathbf{v}_i)\}_{i=1}^B$, item $\mathbf{v}_j$ ($j \neq i$) serves as a negative for user $\mathbf{u}_i$:

$$\mathcal{L} = -\frac{1}{B} \sum_{i=1}^B \ln \frac{\exp(\mathbf{u}_i^T \mathbf{v}_i / \tau)}{\sum_{j=1}^B \exp(\mathbf{u}_i^T \mathbf{v}_j / \tau)}$$

The Popularity Bias Trap: Viral videos watched by 10% of users appear in 10% of training batches. Consequently, popular videos are sampled as negatives far more frequently than niche videos! The model penalizes popular items excessively.

The LogQ Correction (Yi et al., Google 2019): Let $p_j$ be the marginal sampling frequency of item $j$. We subtract $\ln p_j$ from logits prior to Softmax:

$$s'_{i, j} = \frac{\mathbf{u}_i^T \mathbf{v}_j}{\tau} - \ln p_j$$

By subtracting $\ln p_j$, popular items receive a corrective positive offset during probability calculation, restoring unbiased maximum likelihood estimation across both viral and long-tail niche items!

Problem 7.1.2 Medium Google Netflix

QUESTION: A Two-Tower retrieval model is trained using in-batch sampled softmax on a mini-batch of $B = 3$ users and items. The temperature is $\tau = 0.5$.

The raw dot-product similarity matrix $S = U V^T$ is:

$$S = \begin{bmatrix} 0.80 & 0.60 & 0.20 \\ 0.50 & 0.90 & 0.10 \\ 0.70 & 0.40 & 0.85 \end{bmatrix}$$

The item background sampling probabilities are $p = [0.60, 0.30, 0.10]$ (Item 1 is a viral video, Item 2 is moderately popular, Item 3 is a long-tail niche video).

Tasks:

  1. For User 1 (Row 1), calculate the uncorrected softmax probabilities $P_{\text{uncorr}}(y = j \mid u_1)$ across the 3 items.
  2. Compute the logarithmic sampling penalties $\ln p_j$ for each item to 4 decimal places.
  3. Apply the LogQ correction: $s'_{i, j} = \frac{S_{i, j}}{\tau} - \ln p_j$. Calculate the corrected logits for User 1.
  4. Calculate the LogQ-corrected softmax probabilities $P_{\text{corr}}(y = j \mid u_1)$ and demonstrate how LogQ resolves popularity bias.
✓ Step-by-Step LogQ Correction Arithmetic

Step 1: Uncorrected Softmax Probabilities for User 1:
Raw logits for User 1 scaled by temperature $\tau = 0.5$: $$z_{1, j} = \frac{S_{1, j}}{\tau} = \frac{S_{1, j}}{0.5} = 2 \times S_{1, j}$$ $$z_{1, 1} = 2 \times 0.80 = 1.60$$ $$z_{1, 2} = 2 \times 0.60 = 1.20$$ $$z_{1, 3} = 2 \times 0.20 = 0.40$$ Exponentiating scaled logits: $$e^{1.60} \approx 4.9530, \quad e^{1.20} \approx 3.3201, \quad e^{0.40} \approx 1.4918$$ Sum of exponentials: $$\Sigma_{\text{uncorr}} = 4.9530 + 3.3201 + 1.4918 = 9.7649$$ Uncorrected probabilities: $$P_{\text{uncorr}}(1) = \frac{4.9530}{9.7649} \approx \mathbf{0.5072} \quad (50.72\%)$$ $$P_{\text{uncorr}}(2) = \frac{3.3201}{9.7649} \approx \mathbf{0.3400} \quad (34.00\%)$$ $$P_{\text{uncorr}}(3) = \frac{1.4918}{9.7649} \approx \mathbf{0.1528} \quad (15.28\%)$$

Step 2: Logarithmic Sampling Penalties:
Given marginal frequencies $p = [0.60, 0.30, 0.10]$: $$\ln p_1 = \ln(0.60) \approx -0.5108$$ $$\ln p_2 = \ln(0.30) \approx -1.2040$$ $$\ln p_3 = \ln(0.10) \approx -2.3026$$

Step 3: Corrected Logits Calculation:
The LogQ correction subtracts $\ln p_j$ from each logit: $$s'_{1, j} = z_{1, j} - \ln p_j$$ $$s'_{1, 1} = 1.60 - (-0.5108) = 1.60 + 0.5108 = \mathbf{2.1108}$$ $$s'_{1, 2} = 1.20 - (-1.2040) = 1.20 + 1.2040 = \mathbf{2.4040}$$ $$s'_{1, 3} = 0.40 - (-2.3026) = 0.40 + 2.3026 = \mathbf{2.7026}$$ Crucial Observation: Notice that because Item 3 is rare ($p_3 = 0.10$), $-\ln(p_3) = +2.3026$ adds a massive corrective boost, elevating Item 3's logit from the lowest ($0.40$) to the highest ($2.7026$)!

Step 4: LogQ-Corrected Softmax Probabilities:
Exponentiating corrected logits: $$e^{2.1108} \approx 8.2548$$ $$e^{2.4040} \approx 11.0674$$ $$e^{2.7026} \approx 14.9182$$ Sum of corrected exponentials: $$\Sigma_{\text{corr}} = 8.2548 + 11.0674 + 14.9182 = 34.2404$$ Corrected probabilities: $$P_{\text{corr}}(1) = \frac{8.2548}{34.2404} \approx \mathbf{0.2411} \quad (24.11\%)$$ $$P_{\text{corr}}(2) = \frac{11.0674}{34.2404} \approx \mathbf{0.3232} \quad (32.32\%)$$ $$P_{\text{corr}}(3) = \frac{14.9182}{34.2404} \approx \mathbf{0.4357} \quad (43.57\%)$$ Conclusion: In uncorrected training, the viral item's raw dot product dominated ($50.72\%$). The LogQ correction accounts for the fact that Item 1 appeared in the batch primarily due to high background popularity, whereas Item 3's co-occurrence with User 1 is a strong, genuine personalized preference signal, appropriately boosting Item 3's probability to $43.57\%$!

Problem 7.1.5 Expert Google Meta

QUESTION: In extreme multi-class classification and Two-Tower retrieval over a catalog of $N$ items ($N \gg 10^8$), computing the exact partition function $\sum_{j=1}^N \exp(s(u, v_j))$ is computationally intractable. To train the model, we draw a small subset of $K$ negative items from a proposal distribution $Q$ with probabilities $q(j) > 0$.

Tasks:

  1. State the full-catalog cross-entropy loss $\mathcal{L}_{\text{full}}(u, v_+)$ for positive interaction $(u, v_+)$.
  2. Formulate the importance sampling estimator of the partition function $Z(u) = \sum_{j=1}^N \exp(s(u, v_j))$.
  3. Prove that setting corrected logits $s'(u, v_j) = s(u, v_j) - \ln q(j)$ in the Sampled Softmax loss yields an asymptotically unbiased estimator of the true gradient $\nabla_\theta \mathcal{L}_{\text{full}}$ as sample size $K \to \infty$.
✓ Mathematical Proof of LogQ Asymptotic Unbiasedness

Step 1: Full-Catalog Cross-Entropy Loss:
For user vector $u$ and true positive item $v_+$: $$\mathcal{L}_{\text{full}}(u, v_+) = -\ln P(y = + \mid u) = -s(u, v_+) + \ln \sum_{j=1}^N \exp(s(u, v_j))$$ The gradient with respect to model parameters $\theta$ is: $$\nabla_\theta \mathcal{L}_{\text{full}} = -\nabla_\theta s(u, v_+) + \sum_{j=1}^N P(j \mid u) \nabla_\theta s(u, v_j)$$ where $P(j \mid u) = \frac{\exp(s(u, v_j))}{\sum_{k=1}^N \exp(s(u, v_k))}$.

Step 2: Importance Sampling Formulation of the Partition Function:
Rewrite the partition function $Z(u)$ as an expectation under proposal distribution $Q$: $$Z(u) = \sum_{j=1}^N \exp(s(u, v_j)) = \sum_{j=1}^N q(j) \cdot \frac{\exp(s(u, v_j))}{q(j)} = \mathbb{E}_{j \sim Q} \left[ \frac{\exp(s(u, v_j))}{q(j)} \right]$$ Given $K$ independent negative samples $\mathcal{S}_{\text{neg}} = \{v_{(1)}, \dots, v_{(K)}\}$ drawn from $Q$, plus the positive item $v_+$: The unbiased Monte Carlo importance sampling estimator of $Z(u)$ is: $$\widehat{Z}(u) = \frac{1}{K} \sum_{k=1}^K \frac{\exp(s(u, v_{(k)}))}{q(k)}$$

Step 3: Derivation of the LogQ Corrected Logit:
Observe that: $$\frac{\exp(s(u, v_j))}{q(j)} = \exp\big( s(u, v_j) - \ln q(j) \big)$$ Define the corrected logit as: $$s'(u, v_j) \triangleq s(u, v_j) - \ln q(j)$$ Then the Monte Carlo estimator becomes: $$\widehat{Z}(u) = \frac{1}{K} \sum_{k=1}^K \exp(s'(u, v_{(k)}))$$ Substituting this estimator into the Sampled Softmax probability for item $i \in \{+\} \cup \mathcal{S}_{\text{neg}}$: $$\widehat{P}(i \mid u) = \frac{\exp(s'(u, v_i))}{\sum_{j \in \{+\} \cup \mathcal{S}_{\text{neg}}} \exp(s'(u, v_j))}$$ By the Strong Law of Large Numbers, as $K \to \infty$: $$\frac{1}{K} \sum_{k=1}^K \exp(s'(u, v_{(k)})) \xrightarrow{a.s.} \sum_{j=1}^N \exp(s(u, v_j)) = Z(u)$$ Consequently: $$\lim_{K \to \infty} \nabla_\theta \mathcal{L}_{\text{sampled}} = -\nabla_\theta s(u, v_+) + \sum_{j=1}^N \frac{\exp(s(u, v_j))}{Z(u)} \nabla_\theta s(u, v_j) = \nabla_\theta \mathcal{L}_{\text{full}}$$ Q.E.D. Subtracting $\ln q(j)$ from the raw dot-product logits exactly counteracts the non-uniform proposal sampling bias, guaranteeing asymptotically unbiased gradient convergence!

Problem 7.1.6 Expert Netflix Spotify

QUESTION: In Stage 3 re-ranking, platforms maximize user satisfaction by balancing individual item relevance with catalog diversity using Maximal Marginal Relevance (MMR).

Let $\mathcal{V}$ be the candidate set of items. For a selected subset $S \subseteq \mathcal{V}$, consider the Facility Location diversity formulation:

$$F(S) = \sum_{i \in \mathcal{V}} \max_{j \in S} \text{Sim}(i, j)$$

where $\text{Sim}(i, j) \ge 0$ is a symmetric similarity measure.

Tasks:

  1. State the formal definition of a Monotone Submodular Set Function.
  2. Prove that $F(S)$ is monotone increasing and submodular on $2^{\mathcal{V}}$.
  3. Using the Nemhauser-Wolsey-Fisher (1978) theorem, prove that the greedy MMR selection algorithm: $$v^* = \arg\max_{v \in \mathcal{V} \setminus S} \left( F(S \cup \{v\}) - F(S) \right)$$ is guaranteed to achieve at least a $(1 - 1/e) \approx 63.2\%$ approximation of the globally optimal diverse subset under cardinality constraint $|S| \le k$.
✓ Mathematical Proof of Submodularity & Greedy Approximation Bound

Step 1: Definition of Monotone Submodularity:
A set function $F: 2^{\mathcal{V}} \to \mathbb{R}$ is:

  • Monotone: If for all $A \subseteq B \subseteq \mathcal{V}$, $F(A) \le F(B)$.
  • Submodular: If for all $A \subseteq B \subseteq \mathcal{V}$ and all elements $x \in \mathcal{V} \setminus B$, the marginal gain satisfies the diminishing returns property: $$F(A \cup \{x\}) - F(A) \ge F(B \cup \{x\}) - F(B)$$

Step 2: Proof that $F(S)$ is Monotone Submodular:
Recall $F(S) = \sum_{i \in \mathcal{V}} f_i(S)$, where $f_i(S) = \max_{j \in S} \text{Sim}(i, j)$.
Since a non-negative linear combination of submodular functions is submodular, it suffices to prove that each component $f_i(S)$ is submodular.

Proof of Monotonicity:
Let $A \subseteq B$. Since $A \subseteq B$, the candidate pool for the maximum is larger in $B$: $$f_i(A) = \max_{j \in A} \text{Sim}(i, j) \le \max_{j \in B} \text{Sim}(i, j) = f_i(B)$$ Thus $f_i(S)$ is monotone non-decreasing.

Proof of Diminishing Returns (Submodularity):
Let $A \subseteq B$ and $x \notin B$. The marginal gain of adding $x$ to set $S$ is: $$\Delta_i(x \mid S) = f_i(S \cup \{x\}) - f_i(S) = \max\left( \max_{j \in S} \text{Sim}(i, j), \text{Sim}(i, x) \right) - \max_{j \in S} \text{Sim}(i, j)$$ Let $m_S = \max_{j \in S} \text{Sim}(i, j)$. Then: $$\Delta_i(x \mid S) = \max(m_S, \text{Sim}(i, x)) - m_S = \max(0, \text{Sim}(i, x) - m_S)$$ Since $A \subseteq B$, monotonicity implies $m_A \le m_B$.
Observe that the function $g(m) = \max(0, c - m)$ is non-increasing with respect to $m$.
Since $m_A \le m_B$: $$\max(0, \text{Sim}(i, x) - m_A) \ge \max(0, \text{Sim}(i, x) - m_B)$$ $$\Delta_i(x \mid A) \ge \Delta_i(x \mid B)$$ Summing over all $i \in \mathcal{V}$: $$F(A \cup \{x\}) - F(A) \ge F(B \cup \{x\}) - F(B)$$ Q.E.D. $F(S)$ is strictly monotone submodular!

Step 3: Proof of the $(1 - 1/e)$ Greedy Approximation Bound:
Let $S^*$ be the optimal subset of size $k$ that maximizes $F(S)$, and let $S_t$ be the set chosen by the greedy algorithm at step $t \in \{0, 1, \dots, k\}$ ($S_0 = \emptyset$).
By submodularity and monotonicity, for any set $S$: $$F(S^*) \le F(S) + \sum_{v \in S^* \setminus S} \big(F(S \cup \{v\}) - F(S)\big)$$ Since $|S^* \setminus S| \le k$, by the pigeonhole principle there exists at least one element $v \in S^*$ such that: $$F(S \cup \{v\}) - F(S) \ge \frac{F(S^*) - F(S)}{k}$$ Because the greedy algorithm selects the element $v^*$ that maximizes this marginal gain: $$F(S_{t+1}) - F(S_t) \ge \frac{1}{k}\big(F(S^*) - F(S_t)\big)$$ Rearranging: $$F(S^*) - F(S_{t+1}) \le \left(1 - \frac{1}{k}\right) \big(F(S^*) - F(S_t)\big)$$ Applying this recurrence relation inductively from $t = 0$ to $k$: $$F(S^*) - F(S_k) \le \left(1 - \frac{1}{k}\right)^k \big(F(S^*) - F(S_0)\big)$$ Using the fundamental calculus limit inequality $(1 - 1/k)^k \le e^{-1}$ for all $k \ge 1$, and since $F(S_0) = F(\emptyset) \ge 0$: $$F(S^*) - F(S_k) \le e^{-1} F(S^*)$$ $$F(S_k) \ge \left(1 - \frac{1}{e}\right) F(S^*) \approx 0.6321 \cdot F(S^*)$$ Q.E.D. The greedy MMR selection algorithm is mathematically guaranteed to achieve at least 63.2% of the globally optimal recommendation diversity!

import torch
import torch.nn as nn
import torch.nn.functional as F

class LogQTwoTowerRecSys(nn.Module):
    def __init__(self, user_dim: int, item_dim: int, embed_dim: int = 128, temperature: float = 0.07):
        super().__init__()
        self.temperature = temperature

        # User Tower MLP
        self.user_tower = nn.Sequential(
            nn.Linear(user_dim, 256),
            nn.BatchNorm1d(256),
            nn.ReLU(),
            nn.Linear(256, embed_dim)
        )

        # Item Tower MLP
        self.item_tower = nn.Sequential(
            nn.Linear(item_dim, 256),
            nn.BatchNorm1d(256),
            nn.ReLU(),
            nn.Linear(256, embed_dim)
        )

    def forward(self, user_features: torch.Tensor, item_features: torch.Tensor, 
                item_sampling_probs: torch.Tensor = None) -> tuple[torch.Tensor, torch.Tensor]:
        # 1. Project into shared embedding space & L2-normalize
        u = F.normalize(self.user_tower(user_features), p=2, dim=-1)
        v = F.normalize(self.item_tower(item_features), p=2, dim=-1)

        # 2. Compute similarity matrix: (B, B)
        # S[i, j] represents similarity between user i and item j
        raw_logits = torch.matmul(u, v.T) / self.temperature

        # 3. Apply LogQ Correction: logits'[i, j] = logits[i, j] - ln(p_j)
        if item_sampling_probs is not None:
            # item_sampling_probs has shape (B,)
            log_q = torch.log(item_sampling_probs.clamp(min=1e-8)).unsqueeze(0) # (1, B)
            corrected_logits = raw_logits - log_q
        else:
            corrected_logits = raw_logits

        # 4. In-batch targets: Diagonal elements are true positive pairs!
        labels = torch.arange(user_features.size(0), device=user_features.device)
        loss = F.cross_entropy(corrected_logits, labels)
        
        return loss, corrected_logits

if __name__ == "__main__":
    torch.manual_seed(42)
    B = 4
    user_feats = torch.randn(B, 32)
    item_feats = torch.randn(B, 64)
    # Background sampling probabilities (Item 0 is viral, Item 3 is niche)
    sampling_probs = torch.tensor([0.60, 0.25, 0.10, 0.05])

    model = LogQTwoTowerRecSys(user_dim=32, item_dim=64, embed_dim=128)
    loss, logits = model(user_feats, item_feats, item_sampling_probs=sampling_probs)
    print(f"Two-Tower LogQ-Corrected Loss: {loss.item():.4f}")

Foundation • Core Pillar

1. The Exact k-NN Complexity Wall

In modern enterprise AI systems (Retrieval-Augmented Generation, visual search, and recommendation engines), data is represented as high-dimensional embedding vectors ($d \in [512, 1536]$). Finding the exact $k$-nearest neighbors via a brute-force linear scan (Flat Index) requires evaluating:

$$\text{FLOPs per Query} = N \cdot d \cdot 2$$

For a catalog of $N = 100,000,000$ vectors of dimension $d = 1,536$ in standard IEEE FP32 ($4 \text{ bytes}$):

$$\text{Raw Memory Footprint} = 100 \times 10^6 \times 1,536 \times 4 \text{ bytes} \approx \mathbf{614.4 \text{ Gigabytes of RAM}}!$$

A single query takes over 8 seconds on a multi-core CPU. To achieve interactive sub-15ms search across billions of items, we must abandon exact linear scans in favor of Approximate Nearest Neighbor (ANN) Search, which trades a negligible $1\%$ to $2\%$ drop in recall for a $1,000\times$ speedup.

2. Hierarchical Navigable Small World (HNSW): Malkov & Yashunin, 2018

HNSW is the gold standard graph-based ANN algorithm, deployed in Pinecone, Milvus, Qdrant, and Weaviate. Inspired by the 1D Skip List, HNSW constructs a multi-layer geometric proximity graph:

🌐 The Multi-Layer Proximity Graph Architecture

  • Top Layers ($l_{\max}$): Contain a sparse subset of vectors connected by long-range geometric links. Queries take massive "high-speed jumps" across the global coordinate space. Layer assignment follows an exponential decay: $$l = \lfloor -\ln(\text{uniform}(0, 1)) \cdot m_L \rfloor, \quad \text{where } m_L = \frac{1}{\ln M}$$
  • Bottom Layer (Layer 0): Contains all $N$ vectors connected by dense, short-range local links ($2M$ maximum edges).

The Query Routing Algorithm:

  1. Start at the designated global entry point at top layer $l_{\max}$.
  2. Perform greedy local routing: evaluate distance to all neighbors of the current node; hop to the neighbor closest to the query vector $\mathbf{q}$.
  3. When a local minimum is reached on layer $l$, drop vertically to the same node on layer $l-1$.
  4. Repeat greedy routing until reaching Layer 0, where a bounded beam search of width efSearch discovers the top-$k$ nearest neighbors!

Search Complexity: Reduces search time from linear $O(N)$ down to logarithmic $O(\log N)$! However, storing graph edge lists requires significant auxiliary RAM ($1.5\times$ to $2\times$ raw vector size).

3. Inverted File with Product Quantization (IVF-PQ)

When dataset scale reaches billions of vectors, even storing raw vectors in RAM becomes economically unfeasible. Product Quantization (PQ - Jégou et al., 2011) solves this via lossy vector compression:

The Mechanics of Product Quantization (PQ):

  1. A $d$-dimensional vector is split into $m$ distinct sub-vectors of length $d^* = d/m$ (e.g. A 768-dim vector is split into $m = 64$ sub-vectors of dimension 12).
  2. For each sub-vector space, K-Means clusters the training data into $K = 256$ centroids.
  3. Because $256 = 2^8$, each centroid index fits into exactly 1 single byte (uint8)!
  4. Each sub-vector is replaced by the 1-byte index of its nearest centroid.

The Compression Miracle: A 768-dimensional float32 vector ($3,072 \text{ bytes}$) is compressed into $m = 64$ bytes: a staggering $48\times$ memory reduction!

Asymmetric Distance Computation (ADC): At query time, the query vector $\mathbf{q}$ is NOT quantized. The server computes the distance between $\mathbf{q}$'s sub-vectors and the $256$ codebook centroids once, building a tiny lookup table. Evaluating the distance to a database vector requires only $m$ table lookups and additions—with zero floating-point multiplications!

✓ Mathematical Proof of Logarithmic HNSW Complexity

Step 1: Proof of Layer Assignment Probability:
Let $\xi \sim \text{Uniform}(0, 1)$. The maximum layer assigned is $l_v = \lfloor -\ln(\xi) \cdot m_L \rfloor$.
For any integer $l \ge 0$: $$l_v \ge l \iff -\ln(\xi) \cdot m_L \ge l \iff -\ln(\xi) \ge \frac{l}{m_L} \iff \ln(\xi) \le -\frac{l}{m_L}$$ Exponentiating both sides: $$\xi \le \exp\left(-\frac{l}{m_L}\right)$$ Since $\xi \sim \text{Uniform}(0, 1)$, $P(\xi \le z) = z$ for $z \in [0, 1]$. Therefore: $$P(l_v \ge l) = \exp\left(-\frac{l}{m_L}\right)$$ Substituting $m_L = \frac{1}{\ln M}$: $$P(l_v \ge l) = \exp\left(-l \ln M\right) = \exp\left(\ln M^{-l}\right) = \mathbf{M^{-l}}$$ Q.E.D. The probability of surviving to layer $l$ decays exponentially as $1 / M^l$, perfectly mirroring a geometric distribution with parameter $p = 1 - 1/M$.

Step 2: Expected Maximum Layer $\mathbb{E}[l_{\max}]$:
Let $N$ nodes be independently assigned layers $l_1, \dots, l_N$. The maximum layer is $l_{\max} = \max_{1 \le i \le N} l_i$.
The cumulative distribution function of $l_{\max}$ is: $$P(l_{\max} < l) = \prod_{i=1}^N P(l_i < l) = \big(1 - P(l_i \ge l)\big)^N = \left(1 - M^{-l}\right)^N$$ Using the expectation formula for non-negative discrete random variables: $$\mathbb{E}[l_{\max}] = \sum_{l=1}^\infty P(l_{\max} \ge l) = \sum_{l=1}^\infty \left[ 1 - \left(1 - M^{-l}\right)^N \right]$$ For large $N$, using the approximation $(1 - x)^N \approx e^{-Nx}$: $$1 - \left(1 - M^{-l}\right)^N \approx 1 - e^{-N M^{-l}}$$ Notice that when $M^l \ll N$, $e^{-N M^{-l}} \approx 0 \implies \text{term } \approx 1$.
When $M^l \gg N$, $e^{-N M^{-l}} \approx 1 - N M^{-l} \implies \text{term } \approx N M^{-l}$.
The transition point occurs when $M^l \approx N \implies l \approx \log_M N$.
Evaluating the summation rigorously yields: $$\mathbb{E}[l_{\max}] = \log_M N + \frac{\gamma}{\ln M} + \frac{1}{2} + o(1) = \mathbf{\mathcal{O}(\log_M N)}$$ where $\gamma \approx 0.5772$ is the Euler-Mascheroni constant. Q.E.D.

Step 3: Proof of Logarithmic Overall Search Complexity:
The greedy search starts at the global entry point on layer $l_{\max}$.
On each layer $l \in \{l_{\max}, l_{\max}-1, \dots, 1\}$, greedy routing moves along geometric links until discovering the node closest to $\mathbf{q}$ within that layer.
Because each layer is a Delaunay graph approximation (Navigable Small World) with bounded degree $\le M$, Kleinberg's small-world navigation theorem guarantees that the expected number of hops on each layer is bounded by a constant $C(M)$ independent of $N$.
Total expected hops across all upper layers down to Layer 0 is: $$\mathbb{E}[T_{\text{routing}}] \le \sum_{l=1}^{\mathbb{E}[l_{\max}]} C(M) = C(M) \cdot \mathbb{E}[l_{\max}] = C(M) \cdot \mathcal{O}\left(\frac{\ln N}{\ln M}\right) = \mathbf{\mathcal{O}(\log N)}$$ At Layer 0, a bounded beam search of size efSearch evaluates at most $2M \cdot \text{efSearch} = \mathcal{O}(1)$ additional candidates.
Summing all stages: $$\mathbb{E}[T_{\text{search}}] = \mathcal{O}(\log N) + \mathcal{O}(1) = \mathbf{\mathcal{O}(\log N)}$$ Q.E.D. HNSW reduces search across billions of vectors from linear to logarithmic time complexity!

import numpy as np

class ProductQuantizer:
    def __init__(self, d: int, m: int, k_sub: int = 256):
        assert d % m == 0, "Embedding dimension d must be divisible by sub-vector count m"
        self.d = d
        self.m = m
        self.d_sub = d // m
        self.k_sub = k_sub
        # Codebooks shape: (m, k_sub, d_sub)
        self.codebooks = np.zeros((m, k_sub, self.d_sub), dtype=np.float32)

    def fit(self, training_data: np.ndarray, num_iterations: int = 20):
        """Train k-means centroids for each orthogonal sub-vector space"""
        N = training_data.shape[0]
        for j in range(self.m):
            sub_data = training_data[:, j * self.d_sub : (j + 1) * self.d_sub]
            # Initialize centroids randomly from data samples
            indices = np.random.choice(N, size=self.k_sub, replace=False)
            centroids = sub_data[indices].copy()

            for _ in range(num_iterations):
                # Compute squared distances between samples and centroids: (N, k_sub)
                diff = sub_data[:, np.newaxis, :] - centroids[np.newaxis, :, :]
                dists = np.sum(diff ** 2, axis=-1)
                labels = np.argmin(dists, axis=1)

                # Update centroids
                for c in range(self.k_sub):
                    members = sub_data[labels == c]
                    if len(members) > 0:
                        centroids[c] = members.mean(axis=0)

            self.codebooks[j] = centroids

    def encode(self, vectors: np.ndarray) -> np.ndarray:
        """Compress float32 vectors into m uint8 bytes"""
        N = vectors.shape[0]
        codes = np.zeros((N, self.m), dtype=np.uint8)
        for j in range(self.m):
            sub_data = vectors[:, j * self.d_sub : (j + 1) * self.d_sub]
            diff = sub_data[:, np.newaxis, :] - self.codebooks[j][np.newaxis, :, :]
            dists = np.sum(diff ** 2, axis=-1)
            codes[:, j] = np.argmin(dists, axis=1).astype(np.uint8)
        return codes

    def compute_distance_table(self, query: np.ndarray) -> np.ndarray:
        """Pre-compute squared Euclidean distances between query sub-vectors and all centroids"""
        # Shape: (m, k_sub)
        distance_table = np.zeros((self.m, self.k_sub), dtype=np.float32)
        for j in range(self.m):
            q_sub = query[j * self.d_sub : (j + 1) * self.d_sub]
            diff = self.codebooks[j] - q_sub[np.newaxis, :]
            distance_table[j] = np.sum(diff ** 2, axis=-1)
        return distance_table

    def search_adc(self, query: np.ndarray, compressed_codes: np.ndarray, top_k: int = 5) -> tuple[np.ndarray, np.ndarray]:
        """Asymmetric Distance Computation (ADC) via lookup table"""
        dist_table = self.compute_distance_table(query) # (m, k_sub)
        
        # Accumulate distances using fast table lookups
        # compressed_codes has shape (N, m)
        N = compressed_codes.shape[0]
        scores = np.zeros(N, dtype=np.float32)
        for j in range(self.m):
            scores += dist_table[j, compressed_codes[:, j]]

        top_k_indices = np.argpartition(scores, top_k)[:top_k]
        top_k_indices = top_k_indices[np.argsort(scores[top_k_indices])]
        return top_k_indices, scores[top_k_indices]

1. The Physical Constraints of Edge Hardware

Deploying AI models to edge devices (Apple iPhones, Android smartphones, DJI drones, Raspberry Pi microcontrollers, and VR headsets) requires engineering under severe physical constraints:

  • Thermal Envelopes: Edge devices have passive cooling with zero fans. Sustained compute exceeding $3$ to $5 \text{ Watts}$ causes thermal throttling, rapidly draining batteries and degrading user experience.
  • Memory Bandwidth & Capacity: While cloud servers feature 80GB HBM3 memory running at 3.35 TB/s, smartphones share 4GB to 8GB of low-power LPDDR5 RAM ($50-100\text{ GB/s}$) across the operating system and camera pipeline.
  • Dedicated Neural Accelerators: Modern edge SoCs deploy specialized NPUs (Apple Neural Engine ANE, Qualcomm Hexagon NPU, Google Tensor TPU) that deliver peak TOPS only when computations are mapped strictly to 8-bit or 16-bit integer SIMD tensors.

2. MobileNet: Depthwise Separable Convolutions (Howard et al., Google 2017)

Standard 2D convolutions perform spatial filtering and channel combination simultaneously in a single heavy operation. MobileNet factors this into two decoupled steps:

  1. Depthwise Convolution: Applies a single $D_K \times D_K$ convolutional filter per input channel independently (computes spatial features with zero inter-channel communication).
  2. Pointwise Convolution: Applies a $1 \times 1$ convolution across all channels, linearly combining spatial features into $N$ output channels.

🏆 The Mathematical FLOPs Reduction Derivation

Let input feature map be $D_F \times D_F \times M$ and output be $D_F \times D_F \times N$ with filter size $D_K \times D_K$:

  • Standard Convolution FLOPs: $$\text{FLOPs}_{\text{std}} = D_K \cdot D_K \cdot M \cdot N \cdot D_F \cdot D_F$$
  • Depthwise Separable Convolution FLOPs: $$\text{FLOPs}_{\text{sep}} = \underbrace{D_K \cdot D_K \cdot M \cdot D_F \cdot D_F}_{\text{Depthwise Step}} + \underbrace{M \cdot N \cdot D_F \cdot D_F}_{\text{Pointwise Step}}$$

Compute the ratio of computation:

$$\text{Ratio} = \frac{D_K^2 \cdot M \cdot D_F^2 + M \cdot N \cdot D_F^2}{D_K^2 \cdot M \cdot N \cdot D_F^2} = \frac{D_K^2 \cdot M + M \cdot N}{D_K^2 \cdot M \cdot N} = \mathbf{\frac{1}{N} + \frac{1}{D_K^2}}$$

For standard $3 \times 3$ filters ($D_K = 3$) with $N = 512$ channels:

$$\text{Ratio} = \frac{1}{512} + \frac{1}{9} \approx 0.00195 + 0.11111 \approx \mathbf{0.113} \implies \mathbf{88.7\% \text{ Reduction in FLOPs!}}$$

Depthwise Separable Convolutions deliver an $8.8\times$ reduction in computational operations and parameter count with virtually zero loss in visual accuracy!

3. Uniform Affine Quantization & Integer GEMM

Converting a 32-bit floating point tensor $r \in [r_{\min}, r_{\max}]$ to an 8-bit unsigned integer $q \in [0, 255]$ maps continuous values to discrete grid steps:

$$q = \text{clamp}\left( \left\lfloor \frac{r}{S} \right\rceil + Z, \; 0, \; 255 \right)$$ $$S = \frac{r_{\max} - r_{\min}}{255}, \quad Z = \text{round}\left( -\frac{r_{\min}}{S} \right)$$

where $S > 0$ is the real Scale Factor and $Z \in \mathbb{Z}$ is the integer Zero-Point that maps real zero to an exact integer representation.

Integer Arithmetic in Matrix Multiplication (GEMM)

When computing $Y = X W$, the dequantized approximation is:

$$\hat{Y}_{i, k} = \sum_{j=1}^D S_X(q_{X, i, j} - Z_X) \cdot S_W(q_{W, j, k} - Z_W) = S_X S_W \sum_{j=1}^D (q_{X, i, j} - Z_X)(q_{W, j, k} - Z_W)$$

Expanding the product:

$$\hat{Y}_{i, k} = S_X S_W \left( \sum_{j=1}^D q_{X, i, j} q_{W, j, k} - Z_W \sum_{j=1}^D q_{X, i, j} - Z_X \sum_{j=1}^D q_{W, j, k} + D \cdot Z_X Z_W \right)$$

The Hardware Miracle: The core summation $\sum q_X q_W$ is computed using fast 8-bit integer dot products (ARM NEON SDOT, Intel VNNI VPDPBUSD, NVIDIA DP4A) with 32-bit accumulation. The weight sum $\sum q_W$ and offset $D \cdot Z_X Z_W$ are pre-computed offline once!

4. Quantization-Aware Training (QAT) & Straight-Through Estimators

Post-Training Quantization (PTQ) often degrades compact edge networks. Quantization-Aware Training (QAT) models quantization noise during backprop using Fake-Quantization:

$$\hat{r} = S \cdot \left( \text{clamp}\left( \left\lfloor \frac{r}{S} \right\rceil + Z, \; q_{\min}, \; q_{\max} \right) - Z \right)$$

Because the rounding function $\lfloor x \rceil$ has derivative zero almost everywhere, standard backpropagation fails. The Straight-Through Estimator (STE - Bengio et al., 2013) models the gradient as an identity pass-through within dynamic range bounds:

$$\frac{\partial \hat{r}}{\partial r} = \begin{cases} 1 & \text{if } r_{\min} \le r \le r_{\max} \\ 0 & \text{otherwise} \end{cases}$$

Problem 7.3.5 Expert Google Univ. of Toronto

QUESTION: In Hinton's Knowledge Distillation (Hinton et al., 2015), a compact student model with logits $\mathbf{z}_S \in \mathbb{R}^C$ is trained to match the softened probability distribution of a large teacher model with logits $\mathbf{z}_T \in \mathbb{R}^C$.

The soft distillation cross-entropy loss with distillation temperature $T > 0$ is:

$$\mathcal{L}_{\text{KD}} = -\sum_{i=1}^C q_i(T) \ln p_i(T)$$

where $q_i(T) = \frac{\exp(z_{T, i} / T)}{\sum_k \exp(z_{T, k} / T)}$ and $p_i(T) = \frac{\exp(z_{S, i} / T)}{\sum_k \exp(z_{S, k} / T)}$.

Tasks:

  1. Derive the gradient of $\mathcal{L}_{\text{KD}}$ with respect to student logit $z_{S, i}$.
  2. Using the Taylor expansion of the exponential function $\exp(x) \approx 1 + x$ for large $T$ (where $z_i / T \to 0$), prove that in the high-temperature limit ($T \to \infty$): $$\frac{\partial \mathcal{L}_{\text{KD}}}{\partial z_{S, i}} \approx \frac{1}{C T^2} \left( (z_{S, i} - \bar{z}_S) - (z_{T, i} - \bar{z}_T) \right)$$ where $\bar{z}_S = \frac{1}{C}\sum_k z_{S, k}$ and $\bar{z}_T = \frac{1}{C}\sum_k z_{T, k}$.
  3. Prove that minimizing distillation loss at high temperature is mathematically equivalent to minimizing Mean Squared Error (MSE) between zero-meaned teacher and student logits, and explain why multiplying $\mathcal{L}_{\text{KD}}$ by $T^2$ is mathematically essential.
✓ Mathematical Proof of High-Temperature KD Equivalence to Logit MSE

Step 1: Gradient with Respect to Student Logits:
Recall that for softmax probabilities with temperature $T$, the derivative $\frac{\partial p_j(T)}{\partial z_{S, i}}$ is: $$\frac{\partial p_j(T)}{\partial z_{S, i}} = \frac{1}{T} p_i(T)(\delta_{i, j} - p_j(T))$$ Differentiating $\mathcal{L}_{\text{KD}}$: $$\frac{\partial \mathcal{L}_{\text{KD}}}{\partial z_{S, i}} = -\sum_{j=1}^C \frac{q_j(T)}{p_j(T)} \frac{\partial p_j(T)}{\partial z_{S, i}} = -\sum_{j=1}^C \frac{q_j(T)}{p_j(T)} \left[ \frac{1}{T} p_i(T)(\delta_{i, j} - p_j(T)) \right]$$ $$= -\frac{1}{T} \left( q_i(T) - p_i(T) \sum_{j=1}^C q_j(T) \right)$$ Since $\sum_{j=1}^C q_j(T) = 1$: $$\frac{\partial \mathcal{L}_{\text{KD}}}{\partial z_{S, i}} = \mathbf{\frac{1}{T} \big( p_i(T) - q_i(T) \big)}$$

Step 2: Taylor Expansion in High-Temperature Limit ($T \to \infty$):
When $T \gg |z_k|$, the exponent $z_k / T$ is close to zero. We apply the first-order Taylor expansion $e^x \approx 1 + x$: $$\exp\left(\frac{z_{S, i}}{T}\right) \approx 1 + \frac{z_{S, i}}{T}$$ Summing across all $C$ classes: $$\sum_{k=1}^C \exp\left(\frac{z_{S, k}}{T}\right) \approx \sum_{k=1}^C \left(1 + \frac{z_{S, k}}{T}\right) = C + \frac{1}{T}\sum_{k=1}^C z_{S, k} = C \left( 1 + \frac{\bar{z}_S}{T} \right)$$ where $\bar{z}_S = \frac{1}{C}\sum z_{S, k}$.
Now expand the student softmax probability: $$p_i(T) = \frac{1 + \frac{z_{S, i}}{T}}{C\left(1 + \frac{\bar{z}_S}{T}\right)} \approx \frac{1}{C} \left(1 + \frac{z_{S, i}}{T}\right)\left(1 - \frac{\bar{z}_S}{T}\right) \approx \frac{1}{C}\left(1 + \frac{z_{S, i} - \bar{z}_S}{T}\right)$$ Applying the exact same Taylor expansion to the teacher probabilities: $$q_i(T) \approx \frac{1}{C}\left(1 + \frac{z_{T, i} - \bar{z}_T}{T}\right)$$ Subtracting the two probabilities: $$p_i(T) - q_i(T) \approx \frac{1}{C} \left(1 + \frac{z_{S, i} - \bar{z}_S}{T} - 1 - \frac{z_{T, i} - \bar{z}_T}{T}\right) = \frac{1}{C T} \left( (z_{S, i} - \bar{z}_S) - (z_{T, i} - \bar{z}_T) \right)$$ Substituting back into the gradient from Step 1: $$\frac{\partial \mathcal{L}_{\text{KD}}}{\partial z_{S, i}} = \frac{1}{T} \big( p_i(T) - q_i(T) \big) \approx \mathbf{\frac{1}{C T^2} \Big( (z_{S, i} - \bar{z}_S) - (z_{T, i} - \bar{z}_T) \Big)} \quad \text{Q.E.D.}$$

Step 3: Equivalence to Logit MSE & Necessity of $T^2$:
Consider the Mean Squared Error loss between zero-meaned logits: $$\mathcal{L}_{\text{MSE}} = \frac{1}{2 C} \sum_{i=1}^C \left( (z_{S, i} - \bar{z}_S) - (z_{T, i} - \bar{z}_T) \right)^2$$ The gradient is: $$\frac{\partial \mathcal{L}_{\text{MSE}}}{\partial z_{S, i}} = \frac{1}{C} \left( (z_{S, i} - \bar{z}_S) - (z_{T, i} - \bar{z}_T) \right)$$ Comparing with our derivation in Step 2: $$\frac{\partial \mathcal{L}_{\text{KD}}}{\partial z_{S, i}} \approx \frac{1}{T^2} \frac{\partial \mathcal{L}_{\text{MSE}}}{\partial z_{S, i}}$$ Why the $T^2$ multiplier is essential:
Notice that the gradient of $\mathcal{L}_{\text{KD}}$ scales as $1/T^2$! If $T = 5$, the gradient magnitude is suppressed by $25\times$. If $T = 10$, gradients are suppressed by $100\times$!
To prevent the distillation loss from being drowned out by the hard ground-truth label cross-entropy loss $\mathcal{L}_{\text{CE}}$, Hinton multiplies $\mathcal{L}_{\text{KD}}$ by $T^2$: $$\mathcal{L}_{\text{total}} = (1 - \alpha)\mathcal{L}_{\text{CE}} + \alpha \mathbf{T^2} \mathcal{L}_{\text{KD}}$$ This cancels the $1/T^2$ suppression, ensuring stable, balanced gradient updates regardless of temperature!

✓ Mathematical Derivation of Optimal 2:4 Structured Sparsity

Step 1: Proof of Optimal Projection via Component Analysis:
Let $\hat{\mathbf{w}}$ have at most 2 non-zero elements. Let index set $\mathcal{I} \subset \{1, 2, 3, 4\}$ with $|\mathcal{I}| = 2$ denote the indices of the zeroed elements ($\hat{w}_j = 0$ for $j \in \mathcal{I}$).
For elements not zeroed ($k \notin \mathcal{I}$), setting $\hat{w}_k = w_k$ trivially minimizes $(w_k - \hat{w}_k)^2 = 0$.
Therefore, the squared error is: $$\|\mathbf{w} - \hat{\mathbf{w}}\|_2^2 = \sum_{j \in \mathcal{I}} (w_j - 0)^2 + \sum_{k \notin \mathcal{I}} (w_k - w_k)^2 = \sum_{j \in \mathcal{I}} w_j^2 = \sum_{j \in \mathcal{I}} |w_j|^2$$ To minimize the squared error, we must choose the 2-element index set $\mathcal{I}$ that minimizes $\sum_{j \in \mathcal{I}} |w_j|^2$.
Because the objective is a separable sum of non-negative terms $|w_j|^2$, the global minimum is uniquely achieved by selecting the indices corresponding to the two smallest magnitudes in $\mathbf{w}$: $$\mathcal{I}^* = \arg\min_{|\mathcal{I}|=2} \sum_{j \in \mathcal{I}} |w_j|^2 = \big\{ \text{indices of } |w_{(1)}| \text{ and } |w_{(2)}| \big\} \quad \text{Q.E.D.}$$

Step 2: Numerical Projection Computation:
Given $\mathbf{w} = [0.45, \; -0.82, \; 0.12, \; -0.95]$:
Compute absolute magnitudes: $$|w_1| = 0.45, \quad |w_2| = 0.82, \quad |w_3| = 0.12, \quad |w_4| = 0.95$$ Sorting magnitudes in ascending order: $$|w_{(1)}| = 0.12\ (w_3), \quad |w_{(2)}| = 0.45\ (w_1), \quad |w_{(3)}| = 0.82\ (w_2), \quad |w_{(4)}| = 0.95\ (w_4)$$ Zero out the two smallest elements ($w_1$ and $w_3$): $$\hat{\mathbf{w}}^* = [\mathbf{0.0}, \; \mathbf{-0.82}, \; \mathbf{0.0}, \; \mathbf{-0.95}]$$ Squared approximation error: $$\|\mathbf{w} - \hat{\mathbf{w}}^*\|_2^2 = |w_1|^2 + |w_3|^2 = (0.45)^2 + (0.12)^2 = 0.2025 + 0.0144 = \mathbf{0.2169}$$

Step 3: Hardware Acceleration Mechanism:
In general unstructured sparsity, skipping zero multiplications requires pointer-based sparse formats (CSR / CSC) with high memory indirection overhead that destroys GPU SIMD parallelism.
NVIDIA 2:4 Sparse Tensor Cores:

  1. The model weights are compressed by $50\%$ in VRAM: each 4-element block stores only the 2 non-zero FP16 values ($2 \times 2\text{ bytes} = 4\text{ bytes}$) plus a 4-bit metadata index (2 bits per non-zero value, specifying original indices $0, 1, 2,$ or $3$).
  2. At execution time, the Sparse Matrix Multiply unit uses the 4-bit index to multiplex and fetch the exact 2 matching activations from the dense input vector.
  3. A modified MAC tree evaluates the two multiplications in parallel on half-sized hardware, doubling math throughput ($2\times$ TFLOPS) while cutting memory bandwidth traffic in half!

import torch
import torch.nn as nn

class StraightThroughEstimator(torch.autograd.Function):
    @staticmethod
    def forward(ctx, r: torch.Tensor, scale: torch.Tensor, zero_point: torch.Tensor, qmin: int = 0, qmax: int = 255):
        ctx.save_for_backward(r, scale, zero_point)
        ctx.qmin = qmin
        ctx.qmax = qmax

        # 1. Quantize: q = clamp(round(r / S) + Z)
        q = torch.clamp(torch.round(r / scale) + zero_point, qmin, qmax)
        # 2. Dequantize: r_hat = S * (q - Z)
        r_hat = scale * (q - zero_point)
        return r_hat

    @staticmethod
    def backward(ctx, grad_output: torch.Tensor):
        r, scale, zero_point = ctx.saved_tensors
        qmin, qmax = ctx.qmin, ctx.qmax

        # Straight-Through Estimator: Pass gradient strictly inside [r_min, r_max]
        r_min = scale * (qmin - zero_point)
        r_max = scale * (qmax - zero_point)
        mask = (r >= r_min) & (r <= r_max)

        grad_r = grad_output * mask.float()
        return grad_r, None, None, None, None

class FakeQuantizeAffine(nn.Module):
    def __init__(self, num_bits: int = 8):
        super().__init__()
        self.qmin = 0
        self.qmax = 2**num_bits - 1

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        if self.training:
            # Dynamically compute scale and zero-point
            r_min = x.detach().min()
            r_max = x.detach().max()
            scale = (r_max - r_min) / (self.qmax - self.qmin)
            scale = torch.clamp(scale, min=1e-8)
            zero_point = torch.round(-r_min / scale)
            zero_point = torch.clamp(zero_point, self.qmin, self.qmax)
            return StraightThroughEstimator.apply(x, scale, zero_point, self.qmin, self.qmax)
        else:
            return x

if __name__ == "__main__":
    torch.manual_seed(42)
    fake_quant = FakeQuantizeAffine(num_bits=8)
    
    # Input tensor with gradient tracking
    x = torch.tensor([-2.5, -0.8, 0.0, 1.5, 4.2], requires_grad=True)
    out = fake_quant(x)
    loss = out.sum()
    loss.backward()

    print(f"Original Tensor      : {x.data}")
    print(f"Fake-Quantized Output: {out.data}")
    print(f"STE Gradients Passed : {x.grad}")
