1. The Recursive Axis-Aligned Partitioning Paradigm

Linear models divide the feature space with a single flat hyperplane ($\mathbf{w}^T \mathbf{x} + b = 0$). While computationally efficient, linear boundaries fail on non-linear geometries (such as the XOR problem or concentric circles) without manual polynomial feature expansion.

Decision Trees abandon the global parametric assumption entirely. Instead, they apply a greedy, top-down recursive partitioning strategy that divides the feature space $\mathbb{R}^d$ into a collection of mutually exclusive hyper-rectangles using axis-aligned orthogonal cuts ($x_j \le \theta$):

$$\hat{y}(\mathbf{x}) = \sum_{m=1}^{|T|} c_m \mathbb{I}(\mathbf{x} \in R_m)$$

where $R_m$ is region $m$ associated with leaf node $m$, and $c_m$ is the leaf output:

  • Classification: Plurality vote (majority class) $c_m = \arg\max_k \sum_{\mathbf{x}_i \in R_m} \mathbb{I}(y_i = k)$, or empirical class probability distribution $p_{mk} = \frac{1}{|R_m|} \sum_{\mathbf{x}_i \in R_m} \mathbb{I}(y_i = k)$.
  • Regression: Under squared loss ($L_2$), the optimal constant prediction is the sample mean $c_m = \frac{1}{|R_m|} \sum_{\mathbf{x}_i \in R_m} y_i$. Under absolute loss ($L_1$), the optimal prediction is the sample median $c_m = \text{median}(\{y_i \mid \mathbf{x}_i \in R_m\})$.

2. Splitting Criteria: Classification & Regression

At each internal node, the tree must choose the feature $j$ and split threshold $\theta$ that maximizes the purity of the resulting child nodes.

Splitting Criterion Task Mathematical Formula Computational Characteristics
Gini Impurity Classification $I_G(S) = 1 - \sum_{k=1}^K p_k^2$ Fastest ($1$ CPU cycle per evaluation). Default in CART / scikit-learn.
Shannon Entropy Classification $H(S) = -\sum_{k=1}^K p_k \log_2(p_k)$ Slower ($20\text{--}50$ CPU cycles for transcendentals). Strongly penalizes impure nodes. Used in ID3 / C4.5.
Misclassification Error Classification $E(S) = 1 - \max_k p_k$ Not strictly concave; poor for tree growth because it fails to reward purity improvements off the majority class.
Variance Reduction (MSE) Regression $I_{\text{Var}}(S) = \frac{1}{|S|} \sum_{i \in S} (y_i - \bar{y}_S)^2$ Standard $L_2$ regression split. Equivalent to maximizing child separation: $\frac{N_L N_R}{N} (\bar{y}_L - \bar{y}_R)^2$.

The Information Gain Formula

When a candidate split partitions dataset $S$ of size $N$ into Left subset $S_L$ of size $N_L$ and Right subset $S_R$ of size $N_R$, the Information Gain is the reduction in impurity:

$$\Delta I = I(S) - \left[ \frac{N_L}{N} I(S_L) + \frac{N_R}{N} I(S_R) \right]$$

Because the impurity functions (Gini and Entropy) are strictly concave functions of the probability vector $\mathbf{p}$, Jensen's inequality guarantees that $\Delta I \ge 0$ always: splitting a node can never increase impurity!

3. Overfitting & Minimal Cost-Complexity Pruning

An unconstrained decision tree will grow until every training point sits in its own isolated leaf node ($100\%$ training accuracy, zero bias). However, such trees suffer from massive variance, capturing random data noise rather than structural signal.

Minimal Cost-Complexity Pruning ($L_0$ Regularization)

Breiman et al. introduced Cost-Complexity Pruning, defining a regularized loss function that balances training misclassification rate $\mathcal{R}(T)$ with tree complexity (number of terminal leaves $|T|$):

$$\mathcal{R}_\alpha(T) = \mathcal{R}(T) + \alpha |T|$$

where $\alpha \ge 0$ is the complexity tuning parameter:

  • $\alpha = 0$: The original, unconstrained full tree $T_{\max}$.
  • $\alpha \to \infty$: The simplest possible tree (a single root node).

For every internal node $t$, collapsing its entire descendant subtree $T_t$ into a single leaf increases empirical error by $\mathcal{R}(t) - \mathcal{R}(T_t)$ while reducing leaf count by $|T_t| - 1$. The effective cost-complexity threshold is:

$$\alpha_{\text{eff}}(t) = \frac{\mathcal{R}(t) - \mathcal{R}(T_t)}{|T_t| - 1}$$

Pruning the node with the smallest $\alpha_{\text{eff}}$ produces a finite, nested hierarchy of optimal subtrees $T_0 \supset T_1 \supset T_2 \supset \dots \supset \{\text{root}\}$, from which the optimal subtree is selected via cross-validation.

Problem 2.4.5 Hard Google DeepMind Meta FAIR

QUESTION: Prove rigorously from first principles that for any discrete probability distribution vector $\mathbf{p} = [p_1, \dots, p_K]$ on the probability simplex $\Delta^K$, both the Gini Impurity $I_G(\mathbf{p}) = 1 - \sum_{k=1}^K p_k^2$ and Shannon Entropy $H(\mathbf{p}) = -\sum_{k=1}^K p_k \ln(p_k)$ are strictly concave functions of $\mathbf{p}$. From this, apply Jensen's Inequality to prove that Information Gain is strictly non-negative ($\Delta I \ge 0$) for any split.

✓ Complete Step-by-Step Mathematical Proof

Step 1: Prove Concavity of Gini Impurity:
Compute the Hessian matrix of $I_G(\mathbf{p})$ with respect to $\mathbf{p}$:
First derivative: $\frac{\partial I_G}{\partial p_i} = -2 p_i$.
Second derivative: $$\frac{\partial^2 I_G}{\partial p_i \partial p_j} = -2 \delta_{ij} \implies \nabla^2 I_G(\mathbf{p}) = -2 \mathbf{I}_K$$ For any non-zero vector $\mathbf{v} \neq \mathbf{0}$: $$\mathbf{v}^T \nabla^2 I_G(\mathbf{p}) \mathbf{v} = -2 \|\mathbf{v}\|_2^2 < 0$$ The Hessian is strictly negative definite everywhere, proving that $I_G(\mathbf{p})$ is strictly concave.

Step 2: Prove Concavity of Shannon Entropy:
First derivative: $\frac{\partial H}{\partial p_i} = -\ln(p_i) - 1$.
Second derivative: $$\frac{\partial^2 H}{\partial p_i \partial p_j} = -\frac{1}{p_i} \delta_{ij} \implies \nabla^2 H(\mathbf{p}) = -\text{diag}\left( \frac{1}{p_1}, \dots, \frac{1}{p_K} \right)$$ Since $p_k > 0$, all diagonal entries are strictly negative: $$\mathbf{v}^T \nabla^2 H(\mathbf{p}) \mathbf{v} = -\sum_{k=1}^K \frac{v_k^2}{p_k} < 0, \quad \forall \mathbf{v} \neq \mathbf{0}$$ The Hessian is strictly negative definite, proving that $H(\mathbf{p})$ is strictly concave.

Step 3: Prove Information Gain $\Delta I \ge 0$ via Jensen's Inequality:
Let a split divide parent node $S$ (size $N$) into Left $S_L$ ($N_L$) and Right $S_R$ ($N_R$).
Notice that the parent class probability vector is the exact weighted average of child probability vectors: $$\mathbf{p}_S = \frac{N_L}{N} \mathbf{p}_L + \frac{N_R}{N} \mathbf{p}_R$$ Let $f(\mathbf{p})$ be any concave impurity measure ($I_G$ or $H$). By Jensen's Inequality for concave functions: $$f\left( \alpha \mathbf{p}_L + (1-\alpha)\mathbf{p}_R \right) \ge \alpha f(\mathbf{p}_L) + (1-\alpha) f(\mathbf{p}_R), \quad \text{where } \alpha = \frac{N_L}{N} \in [0, 1]$$ Substitute $\mathbf{p}_S$: $$f(\mathbf{p}_S) \ge \frac{N_L}{N} f(\mathbf{p}_L) + \frac{N_R}{N} f(\mathbf{p}_R)$$ Rearranging terms: $$\Delta I = f(\mathbf{p}_S) - \left[ \frac{N_L}{N} f(\mathbf{p}_L) + \frac{N_R}{N} f(\mathbf{p}_R) \right] \ge 0$$ Q.E.D. Because Gini and Entropy are concave, splitting a node is mathematically guaranteed to never increase impurity!

Problem 2.4.6 Hard Microsoft Apple

QUESTION: A categorical feature $X$ has $K$ unordered levels $\{c_1, \dots, c_K\}$.

  1. How many non-trivial binary partitions of these $K$ categories exist? Show that brute-force evaluation scales as $\mathcal{O}(2^K)$.
  2. Prove Fisher's Exact Splitting Theorem (Breiman et al., 1984) for binary classification: prove that sorting the categories by their empirical proportion of positive instances $p(y=1 \mid X=c_k)$ reduces the search space from $2^{K-1}-1$ to only $K-1$ splits, while guaranteeing the mathematically optimal Gini / Entropy split.
✓ Complete Step-by-Step Mathematical Proof

Step 1: Combinatorial Explosion of Categorical Splits:
A binary split partitions the $K$ categories into two non-empty disjoint subsets $A$ and $B$.
The number of non-empty subsets is $2^K - 2$. Because swapping subsets $A$ and $B$ produces the identical split, we divide by 2: $$\text{Number of Unique Binary Splits} = \frac{2^K - 2}{2} = 2^{K-1} - 1$$ For a zip-code or city feature with $K = 50$ categories, $2^{49} - 1 \approx 5.6 \times 10^{14}$ candidate splits! A brute-force search is completely impossible.

Step 2: Fisher's Theorem Proof:
For binary classification ($y \in \{0, 1\}$), let $\bar{y}_k = P(y = 1 \mid X = c_k)$ denote the proportion of positive labels in category $c_k$.
Sort the categories in ascending order of positive response rates: $$\bar{y}_{(1)} \le \bar{y}_{(2)} \le \dots \le \bar{y}_{(K)}$$ Breiman et al. (1984) proved that for any strictly concave impurity function $f$, the optimal subset split $A^*$ that maximizes impurity reduction must be an interval partition of this sorted sequence: $$A^* = \{c_{(1)}, c_{(2)}, \dots, c_{(m)}\} \quad \text{for some } 1 \le m \le K-1$$ Mathematical Intuition: If a partition contained a category with higher positive rate in subset $A$ and a category with lower positive rate in subset $B$, swapping them strictly increases the separation between the child means $(\bar{y}_A - \bar{y}_B)^2$, which by variance decomposition strictly increases information gain.
Therefore, an algorithm only needs to evaluate the $K-1$ adjacent splits along the sorted order!
Complexity: Sorting costs $\mathcal{O}(K \log K)$, and evaluating $K-1$ splits costs $\mathcal{O}(K)$. Total time collapses from $\mathcal{O}(2^K)$ to $\mathcal{O}(K \log K)$!

Correct Option: D

Exhaustive Analysis of All Options:

  • Option D WILL alter the tree: A quadratic transformation is not monotonic (points with different original values map to the same squared distance). This scrambles the sort order of the data points, altering candidate split partitions.
  • Options A, B, and C will NOT alter the tree: Decision tree splitting rules depend strictly on the rank order of feature values, never their absolute numerical scale. Code Lab 2.4 — Recursive Binary CART Classifier

import numpy as np

class TreeNode:
    def __init__(self, feature=None, threshold=None, left=None, right=None, *, value=None):
        self.feature = feature
        self.threshold = threshold
        self.left = left
        self.right = right
        self.value = value

    @property
    def is_leaf(self):
        return self.value is not None

class DecisionTreeClassifierScratch:
    def __init__(self, max_depth=5, min_samples_split=2):
        self.max_depth = max_depth
        self.min_samples_split = min_samples_split
        self.root = None

    def _gini(self, y):
        counts = np.bincount(y)
        probs = counts / len(y)
        return 1.0 - np.sum(probs ** 2)

    def _best_split(self, X, y):
        best_gain = -1.0
        split_feat, split_thresh = None, None
        parent_gini = self._gini(y)

        n_samples, n_features = X.shape
        for feat in range(n_features):
            thresholds = np.unique(X[:, feat])
            for thresh in thresholds:
                left_mask = X[:, feat] <= thresh
                right_mask = ~left_mask

                if np.sum(left_mask) == 0 or np.sum(right_mask) == 0:
                    continue

                # Weighted Gini impurity
                n_l, n_r = np.sum(left_mask), np.sum(right_mask)
                gini_l = self._gini(y[left_mask])
                gini_r = self._gini(y[right_mask])
                weighted_gini = (n_l / n_samples) * gini_l + (n_r / n_samples) * gini_r
                gain = parent_gini - weighted_gini

                if gain > best_gain:
                    best_gain = gain
                    split_feat = feat
                    split_thresh = thresh

        return split_feat, split_thresh

    def _build_tree(self, X, y, depth=0):
        n_samples, n_features = X.shape
        n_labels = len(np.unique(y))

        # Stopping criteria: pure node, max depth, or min samples
        if depth >= self.max_depth or n_labels == 1 or n_samples < self.min_samples_split:
            leaf_value = np.bincount(y).argmax()
            return TreeNode(value=leaf_value)

        feat, thresh = self._best_split(X, y)
        if feat is None:
            return TreeNode(value=np.bincount(y).argmax())

        left_mask = X[:, feat] <= thresh
        right_mask = ~left_mask

        left_child = self._build_tree(X[left_mask], y[left_mask], depth + 1)
        right_child = self._build_tree(X[right_mask], y[right_mask], depth + 1)
        return TreeNode(feature=feat, threshold=thresh, left=left_child, right=right_child)

    def fit(self, X, y):
        self.root = self._build_tree(X, y)

    def _predict_sample(self, x, node):
        if node.is_leaf:
            return node.value
        if x[node.feature] <= node.threshold:
            return self._predict_sample(x, node.left)
        return self._predict_sample(x, node.right)

    def predict(self, X):
        return np.array([self._predict_sample(x, self.root) for x in X])

if __name__ == "__main__":
    from sklearn.datasets import load_iris
    data = load_iris()
    X, y = data.data, data.target
    clf = DecisionTreeClassifierScratch(max_depth=3)
    clf.fit(X, y)
    preds = clf.predict(X)
    print(f"CART Training Accuracy: {np.mean(preds == y) * 100:.2f}%")
