Rather than training independent trees in parallel, each consecutive tree $h_m(\mathbf{x})$ is trained to predict the negative gradient (pseudo-residuals) of the loss with respect to previous ensemble predictions $F_{m-1}(\mathbf{x})$, scaled by shrinkage factor $\eta$.

1. From Bagging to Boosting: Functional Gradient Descent

While Random Forests train trees independently in parallel to reduce variance, Boosting trains trees sequentially in series to reduce bias. Each new tree is explicitly constructed to correct the residual mistakes made by the collective ensemble of all previous trees:

$$F_m(\mathbf{x}) = F_{m-1}(\mathbf{x}) + \eta f_m(\mathbf{x})$$

where $\eta \in (0, 1]$ is the shrinkage learning rate (step size), and $f_m(\mathbf{x})$ is the $m$-th base learner (decision tree).

Gradient Boosting as Optimization in Function Space

Jerome Friedman (2001) realized that fitting residuals is mathematically equivalent to Gradient Descent in Function Space. In standard parameter optimization, we update weights along the negative gradient in parameter space: $\mathbf{w} \leftarrow \mathbf{w} - \eta \nabla_{\mathbf{w}} \mathcal{L}$. In Gradient Boosting, we treat the predictions $F(\mathbf{x}_1), \dots, F(\mathbf{x}_N)$ as the parameters themselves, updating along the negative gradient in prediction space:

$$r_{im} = -\left[ \frac{\partial \mathcal{L}(y_i, F(\mathbf{x}_i))}{\partial F(\mathbf{x}_i)} \right]_{F = F_{m-1}}$$

These pseudo-residuals $r_{im}$ define the gradient direction for any differentiable loss function:

Loss Function $\mathcal{L}(y, F)$ Task Type Negative Gradient (Pseudo-Residual $r_i$) Optimal Leaf Update $c_j$
Squared Error: $\frac{1}{2}(y - F)^2$ Continuous Regression $y_i - F(\mathbf{x}_i)$ (Standard Residual) Mean of residuals: $\frac{1}{|R_j|} \sum_{i \in R_j} r_i$
Absolute Error ($L_1$): $|y - F|$ Robust Regression $\text{sign}(y_i - F(\mathbf{x}_i))$ Median of residuals: $\text{median}_{i \in R_j}(y_i - F(\mathbf{x}_i))$
Binary Log-Loss: $-[y \ln p + (1-y)\ln(1-p)]$ Binary Classification $y_i - \sigma(F(\mathbf{x}_i)) = y_i - p_i$ Newton step: $\frac{\sum_{i \in R_j} (y_i - p_i)}{\sum_{i \in R_j} p_i(1 - p_i)}$

2. AdaBoost: Exponential Loss & Sample Re-Weighting

Before Friedman generalized boosting to arbitrary loss functions, Yoav Freund and Robert Schapire (1995) introduced AdaBoost (Adaptive Boosting). Rather than fitting residuals, AdaBoost reweights training samples so that misclassified samples receive exponentially higher weights in the next iteration:

$$w_i^{(m+1)} = w_i^{(m)} \exp\left( \alpha_m \mathbb{I}(y_i \neq G_m(\mathbf{x}_i)) \right)$$

The classifier weight $\alpha_m$ is determined by its weighted training error $\text{err}_m$:

$$\alpha_m = \frac{1}{2} \ln\left( \frac{1 - \text{err}_m}{\text{err}_m} \right)$$

Freund and Schapire proved that AdaBoost is an exact coordinate descent optimizer minimizing the Exponential Loss $\mathcal{L}(y, F) = \exp(-y F(\mathbf{x}))$. However, because exponential loss grows unbounded for large negative margins, AdaBoost is notoriously sensitive to mislabeled outliers, leading to the dominance of modern GBDTs with robust log-loss.

3. The XGBoost Formulation: Second-Order Taylor Expansion

Tianqi Chen and Carlos Guestrin (2016) revolutionized machine learning by introducing XGBoost (eXtreme Gradient Boosting). While classical GBDT approximates loss using only first-order gradients, XGBoost applies a Second-Order Taylor Expansion, incorporating both the gradient and the Hessian curvature to derive exact closed-form optimal leaf weights and regularized split gains.

Full Derivation of the XGBoost Objective

At iteration $t$, we add tree $f_t(\mathbf{x})$ to minimize the penalized objective:

$$\mathcal{L}^{(t)} = \sum_{i=1}^N \mathcal{L}\left(y_i, \hat{y}_i^{(t-1)} + f_t(\mathbf{x}_i)\right) + \Omega(f_t)$$

where $\Omega(f_t) = \gamma T + \frac{1}{2} \lambda \sum_{j=1}^T w_j^2$ is the tree complexity penalty ($T$ terminal leaves, leaf weights $w_j$).

Apply the second-order Taylor expansion $f(x + \Delta x) \approx f(x) + f'(x)\Delta x + \frac{1}{2} f''(x)\Delta x^2$:

$$\mathcal{L}^{(t)} \approx \sum_{i=1}^N \left[ \mathcal{L}(y_i, \hat{y}_i^{(t-1)}) + g_i f_t(\mathbf{x}_i) + \frac{1}{2} h_i f_t^2(\mathbf{x}_i) \right] + \gamma T + \frac{1}{2} \lambda \sum_{j=1}^T w_j^2$$

where the first and second derivatives are defined as:

$$g_i = \left[ \frac{\partial \mathcal{L}(y_i, \hat{y}_i)}{\partial \hat{y}_i} \right]_{\hat{y}_i = \hat{y}_i^{(t-1)}}, \qquad h_i = \left[ \frac{\partial^2 \mathcal{L}(y_i, \hat{y}_i)}{\partial \hat{y}_i^2} \right]_{\hat{y}_i = \hat{y}_i^{(t-1)}}$$

Remove the constant term $\mathcal{L}(y_i, \hat{y}_i^{(t-1)})$ and group samples by leaf node $I_j = \{i \mid q(\mathbf{x}_i) = j\}$:

$$\tilde{\mathcal{L}}^{(t)} = \sum_{j=1}^T \left[ \left( \sum_{i \in I_j} g_i \right) w_j + \frac{1}{2} \left( \sum_{i \in I_j} h_i + \lambda \right) w_j^2 \right] + \gamma T$$

Define cumulative leaf gradients $G_j = \sum_{i \in I_j} g_i$ and Hessians $H_j = \sum_{i \in I_j} h_i$:

$$\tilde{\mathcal{L}}^{(t)} = \sum_{j=1}^T \left[ G_j w_j + \frac{1}{2} (H_j + \lambda) w_j^2 \right] + \gamma T$$

Differentiating with respect to leaf weight $w_j$ and setting to zero:

$$\frac{\partial \tilde{\mathcal{L}}^{(t)}}{\partial w_j} = G_j + (H_j + \lambda) w_j = 0 \implies \mathbf{w_j^* = -\frac{G_j}{H_j + \lambda}}$$

Substituting $w_j^*$ back into the objective yields the Optimal Tree Structure Score:

$$\tilde{\mathcal{L}}^*(q) = -\frac{1}{2} \sum_{j=1}^T \frac{G_j^2}{H_j + \lambda} + \gamma T$$

When evaluating a candidate split partitioning leaf $j$ into Left ($L$) and Right ($R$) children, the exact XGBoost Split Gain is:

$$\text{Gain} = \frac{1}{2} \left[ \frac{G_L^2}{H_L + \lambda} + \frac{G_R^2}{H_R + \lambda} - \frac{(G_L + G_R)^2}{H_L + H_R + \lambda} \right] - \gamma$$

4. Modern Enterprise GBDT: LightGBM vs. CatBoost

On multi-million-row industrial datasets, XGBoost's exact pre-sorted greedy split search creates an I/O and memory bottleneck. Modern engineering frameworks revolutionized tabular AI:

LightGBM (Microsoft Research, 2017)

  • Histogram-Based Feature Binning: Discretizes continuous 32-bit float features into 256 discrete integer bins (1 byte each). Computing histogram bin boundaries takes $\mathcal{O}(N)$, and split searching takes $\mathcal{O}(\text{bins})$, slashing memory consumption by $80\%$ and speeding up training by $15\times$.
  • Gradient-based One-Side Sampling (GOSS): Keeps all instances with large gradients ($|g_i| > a$), and randomly samples a subset $b$ from instances with small gradients ($|g_i| \le a$), focusing training on hard, unlearned errors while preserving mathematical unbiasedness via sample reweighting $\frac{1-a}{b}$.
  • Exclusive Feature Bundling (EFB): Bundles mutually exclusive sparse features (e.g. one-hot encoded columns) into single dense features.
  • Leaf-Wise (Best-First) Tree Growth: Instead of growing trees level-by-level (depth-wise), LightGBM splits the single leaf that maximizes global loss reduction, achieving significantly lower loss at equivalent leaf counts.

CatBoost (Yandex, 2018)

  • Symmetric (Oblivious) Trees: Uses the exact same split condition across all nodes at the same tree depth. This eliminates branching memory jumps and allows trees to be compiled into SIMD bitwise CPU machine code, achieving sub-microsecond inference latency!
  • Ordered Target Encoding: Encodes categorical variables using historical cumulative averages computed over random permutations of the dataset, mathematically eliminating target leakage.

QUESTION: In AdaBoost, a weak classifier $G_1$ achieves a weighted classification error rate of $\text{err}_1 = 0.20$ ($20\%$).

  1. Compute the classifier importance weight $\alpha_1 = \frac{1}{2} \ln\left(\frac{1 - \text{err}_1}{\text{err}_1}\right)$.
  2. If a training sample with initial weight $w_i^{(1)} = 0.10$ was misclassified by $G_1$, compute its updated weight $w_i^{(2)}$ (before normalization).
  3. If another sample with initial weight $0.10$ was correctly classified, compute its updated weight.
✓ Complete Step-by-Step Numerical Solution

Step 1: Compute Classifier Weight $\alpha_1$: $$\frac{1 - \text{err}_1}{\text{err}_1} = \frac{1 - 0.20}{0.20} = \frac{0.80}{0.20} = 4.0$$ $$\alpha_1 = \frac{1}{2} \ln(4.0) = \frac{1}{2} (1.38629) = \mathbf{0.69315}$$

Step 2: Update Weight for Misclassified Sample:
Formula: $w_i^{(2)} = w_i^{(1)} e^{\alpha_1}$. $$w_{\text{misclassified}}^{(2)} = 0.10 \times e^{0.69315} = 0.10 \times 2.0 = \mathbf{0.2000}$$ The weight of the misclassified sample doubles!

Step 3: Update Weight for Correctly Classified Sample:
Formula: $w_i^{(2)} = w_i^{(1)} e^{-\alpha_1}$. $$w_{\text{correct}}^{(2)} = 0.10 \times e^{-0.69315} = 0.10 \times 0.5 = \mathbf{0.0500}$$ The weight of the correctly classified sample is halved!
Result: Misclassified samples are penalized with $4\times$ the relative importance of correctly classified samples in the subsequent iteration.

Problem 2.5B.3 Medium Apple

QUESTION: An XGBoost candidate split divides a parent leaf into Left ($L$) and Right ($R$) children with the following cumulative statistics:

  • Left Child: $G_L = -8.0, \ H_L = 4.0$
  • Right Child: $G_R = -4.0, \ H_R = 6.0$

The tree complexity penalty is $\gamma = 1.0$ and $L_2$ regularization is $\lambda = 2.0$. Compute:

  1. The parent leaf statistics $G_{\text{parent}}$ and $H_{\text{parent}}$, and the parent score.
  2. The Left and Right child scores.
  3. The exact XGBoost Split Gain. Should the tree execute this split?
✓ Complete Step-by-Step Algorithmic Trace

Step 1: Parent Statistics and Score: $$G_{\text{parent}} = G_L + G_R = -8.0 + (-4.0) = -12.0$$ $$H_{\text{parent}} = H_L + H_R = 4.0 + 6.0 = 10.0$$ Parent score term: $$\text{Score}_{\text{parent}} = \frac{G_{\text{parent}}^2}{H_{\text{parent}} + \lambda} = \frac{(-12.0)^2}{10.0 + 2.0} = \frac{144.0}{12.0} = \mathbf{12.00}$$

Step 2: Child Node Scores: $$\text{Score}_L = \frac{G_L^2}{H_L + \lambda} = \frac{(-8.0)^2}{4.0 + 2.0} = \frac{64.0}{6.0} \approx \mathbf{10.6667}$$ $$\text{Score}_R = \frac{G_R^2}{H_R + \lambda} = \frac{(-4.0)^2}{6.0 + 2.0} = \frac{16.0}{8.0} = \mathbf{2.0000}$$

Step 3: Evaluate Split Gain: $$\text{Gain} = \frac{1}{2} \left[ \text{Score}_L + \text{Score}_R - \text{Score}_{\text{parent}} \right] - \gamma$$ $$\text{Gain} = \frac{1}{2} \left[ 10.6667 + 2.0000 - 12.0000 \right] - 1.0$$ $$\text{Gain} = \frac{1}{2} \left[ 0.6667 \right] - 1.0 = 0.3333 - 1.0 = \mathbf{-0.6667}$$ Conclusion: The split gain is NEGATIVE ($\text{Gain} = -0.6667 < 0$). The improvement in objective ($0.3333$) is insufficient to cover the leaf creation penalty $\gamma = 1.0$. XGBoost strictly REJECTS the split and keeps the parent node intact (pre-pruning).

Problem 2.5B.4 Medium Amazon

QUESTION: In LightGBM's Gradient-based One-Side Sampling (GOSS), an engineer processes $N = 100$ instances. The top fraction is set to $a = 0.20$ ($20\%$) and the sample fraction is set to $b = 0.10$ ($10\%$).

  1. How many instances with large gradients are kept deterministically?
  2. How many instances with small gradients are randomly sampled?
  3. By what multiplicative factor must the gradients of the sampled small-gradient instances be scaled to guarantee that the expected gradient sum remains mathematically unbiased?
✓ Complete Step-by-Step Algorithmic Solution

Step 1: Top Large-Gradient Subset ($A$): $$N_A = a \times N = 0.20 \times 100 = \mathbf{20 \text{ instances}}$$ All 20 instances with the largest absolute gradients $|g_i|$ are kept deterministically.

Step 2: Sampled Small-Gradient Subset ($B$):
Remaining small-gradient pool: $N - N_A = 100 - 20 = 80$ instances.
Sample count: $$N_B = b \times (N - N_A) = 0.10 \times 80 = \mathbf{8 \text{ instances}}$$ Total training subset size: $N_A + N_B = 20 + 8 = 28$ instances ($72\%$ reduction in compute!).

Step 3: Importance Weighting Scale Factor:
Since 8 instances are chosen uniformly from a pool of 80, the sampling probability is $p = \frac{N_B}{N - N_A} = \frac{8}{80} = 0.10 = b$.
By the Horvitz-Thompson estimator, to keep the expectation unbiased ($\mathbb{E}[\tilde{G}] = G$), each sampled instance must be scaled by the inverse sampling ratio: $$\text{Scale Factor} = \frac{1 - a}{b} = \frac{1 - 0.20}{0.10} = \frac{0.80}{0.10} = \mathbf{8.00\times}$$ Result: Each sampled small-gradient instance is multiplied by $8.0\times$ during split score accumulation, preserving exact gradient expectations.

Problem 2.5B.5 Hard Google DeepMind Meta

QUESTION: Prove that AdaBoost's update rule for classifier weights: $$\alpha_m = \frac{1}{2} \ln\left( \frac{1 - \text{err}_m}{\text{err}_m} \right)$$ is the exact analytical solution that minimizes the Exponential Loss $\mathcal{L}(\alpha) = \sum_{i=1}^N w_i \exp(-y_i \alpha G_m(\mathbf{x}_i))$ with respect to $\alpha \in \mathbb{R}$, where $y_i, G_m(\mathbf{x}_i) \in \{-1, +1\}$.

✓ Complete Step-by-Step Mathematical Proof

Step 1: Partition the Loss Sum into Correct and Incorrect Sets:
For any sample $i$, the product $y_i G_m(\mathbf{x}_i)$ takes one of two values:

  • If $G_m(\mathbf{x}_i) = y_i$ (correct classification): $y_i G_m(\mathbf{x}_i) = +1 \implies e^{-y_i \alpha G_m} = e^{-\alpha}$.
  • If $G_m(\mathbf{x}_i) \neq y_i$ (incorrect classification): $y_i G_m(\mathbf{x}_i) = -1 \implies e^{-y_i \alpha G_m} = e^{+\alpha}$.
Split the exponential loss summation: $$\mathcal{L}(\alpha) = \sum_{y_i = G_m(\mathbf{x}_i)} w_i e^{-\alpha} + \sum_{y_i \neq G_m(\mathbf{x}_i)} w_i e^{+\alpha}$$ $$= e^{-\alpha} \sum_{y_i = G_m(\mathbf{x}_i)} w_i + e^{+\alpha} \sum_{y_i \neq G_m(\mathbf{x}_i)} w_i$$

Step 2: Express in Terms of Weighted Error $\text{err}_m$:
Assume normalized weights $\sum_{i=1}^N w_i = 1$. The weighted error is: $$\text{err}_m = \sum_{y_i \neq G_m(\mathbf{x}_i)} w_i \implies \sum_{y_i = G_m(\mathbf{x}_i)} w_i = 1 - \text{err}_m$$ Substitute these into the objective: $$\mathcal{L}(\alpha) = (1 - \text{err}_m) e^{-\alpha} + \text{err}_m e^{+\alpha}$$

Step 3: Differentiate and Solve for $\alpha^*$:
$$\frac{d\mathcal{L}}{d\alpha} = -(1 - \text{err}_m) e^{-\alpha} + \text{err}_m e^{+\alpha} = 0$$ $$\text{err}_m e^{+\alpha} = (1 - \text{err}_m) e^{-\alpha}$$ Multiply both sides by $e^{+\alpha}$: $$\text{err}_m e^{2\alpha} = 1 - \text{err}_m \implies e^{2\alpha} = \frac{1 - \text{err}_m}{\text{err}_m}$$ Take the natural logarithm: $$2\alpha = \ln\left( \frac{1 - \text{err}_m}{\text{err}_m} \right) \implies \mathbf{\alpha^* = \frac{1}{2} \ln\left( \frac{1 - \text{err}_m}{\text{err}_m} \right)}$$ Q.E.D. The AdaBoost coefficient $\alpha_m$ is the exact line-search minimizer of the exponential loss!

Problem 2.5B.6 Hard OpenAI Anthropic

QUESTION: In GBDT for binary classification under Binary Cross-Entropy loss: $$\mathcal{L}(y_i, F_i) = \ln(1 + e^{F_i}) - y_i F_i, \quad y_i \in \{0, 1\}$$

  1. Prove that the first derivative (gradient) is $g_i = p_i - y_i$, where $p_i = \sigma(F_i)$.
  2. Prove that the second derivative (Hessian) is $h_i = p_i (1 - p_i)$.

Code Lab 2.5B — Gradient Boosting Regressor from Scratch

🔗 View in GitHub: part2_classical_ml/ch25b_gradient_boosting/gbdt_scratch.py

import numpy as np
from sklearn.tree import DecisionTreeRegressor

class GradientBoostingRegressorScratch:
    def __init__(self, n_estimators=50, learning_rate=0.1, max_depth=3):
        self.n_estimators = n_estimators
        self.learning_rate = learning_rate
        self.max_depth = max_depth
        self.base_pred = None
        self.trees = []

    def fit(self, X, y):
        # 1. Initialize base model with constant mean prediction
        self.base_pred = np.mean(y)
        f_m = np.full(len(y), self.base_pred)

        for _ in range(self.n_estimators):
            # 2. Compute negative gradient (pseudo-residuals) for MSE loss:
            # L = 0.5 * (y - f)^2 ==> -dL/df = (y - f)
            residuals = y - f_m

            # 3. Fit weak regression tree to residuals
            tree = DecisionTreeRegressor(max_depth=self.max_depth)
            tree.fit(X, residuals)
            self.trees.append(tree)

            # 4. Update ensemble predictions with shrinkage
            f_m += self.learning_rate * tree.predict(X)

    def predict(self, X):
        preds = np.full(len(X), self.base_pred)
        for tree in self.trees:
            preds += self.learning_rate * tree.predict(X)
        return preds

if __name__ == "__main__":
    np.random.seed(42)
    X = np.linspace(-3, 3, 200).reshape(-1, 1)
    y = np.sin(X).ravel() + 0.1 * np.random.randn(200)

    gb = GradientBoostingRegressorScratch(n_estimators=40, learning_rate=0.1, max_depth=2)
    gb.fit(X, y)
    preds = gb.predict(X)
    mse = np.mean((preds - y) ** 2)
    print(f"Gradient Boosting Regressor MSE: {mse:.4f}")
