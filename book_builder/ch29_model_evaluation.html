Foundation • Core Pillar

1. The Tyranny of Accuracy & The Confusion Matrix Algebra

In toy academic benchmarks with balanced $50/50$ classes, classification accuracy ($\frac{\text{Correct}}{\text{Total}}$) is an intuitive metric. In production enterprise AI, accuracy is virtually useless and actively dangerous.

Consider credit card fraud detection: out of $1,000,000$ transactions, exactly $100$ are fraudulent ($0.01\%$ prevalence). A trivial dummy classifier that outputs return 0 for every transaction achieves a phenomenal $99.99\%$ accuracy while failing to catch a single dollar of fraudulent theft! Evaluating models requires dissecting the Confusion Matrix:

Metric Mathematical Formula Physical Meaning Critical Production Context
Precision (PPV) $\frac{\text{TP}}{\text{TP} + \text{FP}}$ When the model predicts Positive, how often is it correct? Spam filters, automated ban hammers (Minimize False Alarms).
Recall (Sensitivity / TPR) $\frac{\text{TP}}{\text{TP} + \text{FN}}$ Out of all actual Positive cases, how many did the model catch? Cancer screening, fraud detection (Minimize Missed Detections).
Specificity (TNR) $\frac{\text{TN}}{\text{TN} + \text{FP}}$ Out of all actual Negative cases, how many were correctly identified? Baseline population filtering.
False Positive Rate (FPR) $\frac{\text{FP}}{\text{TN} + \text{FP}} = 1 - \text{Specificity}$ Probability that an actual negative sample is falsely flagged. X-axis of the ROC curve.
$F_1$ Score $2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}$ Harmonic mean balancing precision and recall. Penalizes extreme disparities (if Precision=1.0 but Recall=0.01, $F_1 \approx 0.02$).
$F_\beta$ Score $(1 + \beta^2) \frac{\text{Precision} \cdot \text{Recall}}{\beta^2 \text{Precision} + \text{Recall}}$ General weighted harmonic mean. $\beta=2$ weights recall $2\times$ over precision. High-stakes medical triage where missing a disease is catastrophic.
Matthews Correlation (MCC) $\frac{\text{TP}\cdot\text{TN} - \text{FP}\cdot\text{FN}}{\sqrt{(\text{TP}+\text{FP})(\text{TP}+\text{FN})(\text{TN}+\text{FP})(\text{TN}+\text{FN})}}$ Pearson correlation between binary actuals and predictions ($[-1, +1]$). The single most robust scalar metric on severely imbalanced datasets.

2. Receiver Operating Characteristic (ROC) & The Mann-Whitney U Theorem

Binary classifiers output continuous confidence scores or probabilities $\hat{p} = f(\mathbf{x}) \in [0, 1]$. Applying a fixed decision threshold $\tau = 0.5$ creates a single confusion matrix. The ROC Curve visualizes classifier performance across all possible thresholds $\tau \in [0, 1]$ by plotting:

$$y\text{-axis: } \text{True Positive Rate (TPR)} = \frac{\text{TP}(\tau)}{\text{TP}(\tau) + \text{FN}(\tau)}, \quad x\text{-axis: } \text{False Positive Rate (FPR)} = \frac{\text{FP}(\tau)}{\text{TN}(\tau) + \text{FP}(\tau)}$$

A random guessing classifier produces the diagonal line $\text{TPR} = \text{FPR}$ with $\text{AUC} = 0.50$. A perfect classifier forms a right angle through $(0, 1)$ with $\text{AUC} = 1.00$.

🏆 The Wilcoxon-Mann-Whitney Equivalence Theorem

Why is ROC-AUC universally favored in scoring algorithms? Because of an extraordinary mathematical equivalence: The Area Under the ROC Curve is identically equal to the probability that a randomly selected positive sample receives a higher score than a randomly selected negative sample!

$$\text{AUC} = P(S_+ > S_-) + \frac{1}{2} P(S_+ = S_-)$$

Where $S_+ \sim f(\mathbf{x} \mid y=1)$ and $S_- \sim f(\mathbf{x} \mid y=0)$.

Furthermore, AUC can be computed in $O(N \log N)$ time without integrating trapezoids, directly using the Mann-Whitney $U$ rank-sum statistic:

$$\text{AUC} = \frac{R_+ - \frac{N_+(N_+ + 1)}{2}}{N_+ N_-}$$

Where $R_+$ is the sum of ranks assigned to positive instances when all $N = N_+ + N_-$ samples are pooled and sorted in ascending order.

3. Precision-Recall Dynamics Under Severe Imbalance

While ROC-AUC is scale-invariant and threshold-independent, it exhibits a dangerous blind spot when negative cases vastly outnumber positives ($N_- \gg N_+$, such as ad click-through rates or cyber intrusion detection):

$$\text{FPR} = \frac{\text{FP}}{\text{TN} + \text{FP}} \approx \frac{\text{FP}}{N_-}$$

If $N_- = 10,000,000$ and a model produces $\text{FP} = 10,000$ false alarms, the False Positive Rate is a negligible $\text{FPR} = \frac{10,000}{10,000,000} = 0.001$ ($0.1\%$). The ROC curve stays hugged against the top-left corner, reporting an impressive $\text{AUC} = 0.98$!

However, if the positive cohort only had $N_+ = 100$ true fraud cases, and the model caught all of them ($\text{TP} = 100$), the Precision is:

$$\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}} = \frac{100}{100 + 10,000} = \frac{100}{10,100} \approx 0.0099 \quad (0.99\%)$$

For every $1$ real fraudster caught, security analysts must investigate $100$ false alarms! The Precision-Recall (PR) Curve exposes this reality by plotting Precision vs. Recall across all thresholds. Unlike ROC curves whose baseline is always $0.50$, the baseline for a PR curve is the dataset prevalence $\pi = \frac{N_+}{N_+ + N_-}$. In severe imbalance, PR-AUC (Average Precision) is the mandatory evaluation metric.

4. Probability Calibration & Expected Calibration Error (ECE)

In high-stakes autonomous systems (self-driving cars, medical diagnosis, algorithmic trading), a model must not only predict the correct class—its predicted probability $\hat{p} \in [0, 1]$ must represent the true frequency of occurrence. If a weather model predicts an $80\%$ chance of rain on 100 separate days, it must rain on exactly 80 of those days.

Expected Calibration Error (ECE)

To quantify calibration, we partition predictions into $M$ equally spaced bins $B_1, \dots, B_M \subset [0, 1]$ (typically $M = 10$ or $15$). For each bin $B_m$:

$$\operatorname{acc}(B_m) = \frac{1}{|B_m|} \sum_{i \in B_m} \mathbb{I}(y_i = \hat{y}_i), \quad \operatorname{conf}(B_m) = \frac{1}{|B_m|} \sum_{i \in B_m} \hat{p}_i$$

Expected Calibration Error (ECE) is the weighted average absolute difference between confidence and accuracy:

$$\text{ECE} = \sum_{m=1}^M \frac{|B_m|}{N} |\operatorname{acc}(B_m) - \operatorname{conf}(B_m)|$$

The Brier Score

The Brier Score measures the mean squared error of predicted probabilities: $\text{BS} = \frac{1}{N} \sum_{i=1}^N (\hat{p}_i - y_i)^2$. Murphy (1973) proved that the Brier Score decomposes into three interpretable components:

$$\text{BS} = \text{Reliability (Calibration Error)} - \text{Resolution (Discrimination Power)} + \text{Uncertainty (Entropy)}$$

Post-Hoc Calibration Techniques

  • Platt Scaling (Sigmoid): Fits a univariate logistic regression on uncalibrated model logits $z_i$: $\hat{p}_{\text{cal}} = \sigma(A z_i + B)$. Parameters $A, B$ are fitted on validation data via log-loss. Ideal for SVMs and shallow networks.
  • Isotonic Regression: Fits a non-parametric, piece-wise constant monotonically non-decreasing step function. Free of parametric assumptions, but requires large validation sets ($N > 1,000$) to avoid overfitting.
  • Temperature Scaling: For multi-class deep networks, divides all pre-softmax logits by a learned scalar temperature $T > 0$: $\hat{p}_i = \frac{e^{z_i / T}}{\sum_j e^{z_j / T}}$. When $T > 1$, it softens overconfident probabilities without changing the $\arg\max$ top-1 predictions or accuracy!

Problem 2.9.1 Level 1 • Direct Numerical Warm-Up Drill Google

QUESTION: A hospital AI diagnostic system is evaluated on a test cohort of $N = 1,000$ patients. The confusion matrix yields:

  • True Positives ($\text{TP}$): $40$
  • False Positives ($\text{FP}$): $60$
  • False Negatives ($\text{FN}$): $10$
  • True Negatives ($\text{TN}$): $890$
  1. Calculate the overall Classification Accuracy.
  2. Calculate Precision and Recall (Sensitivity).
  3. Calculate Specificity and False Positive Rate (FPR).
  4. Calculate the balanced $F_1$ score.
  5. Calculate the $F_2$ score (which weights recall twice as heavily as precision).
  6. Calculate the Matthews Correlation Coefficient (MCC).
✓ Complete Step-by-Step Arithmetic Solution

Step 1: Classification Accuracy:
$$\text{Accuracy} = \frac{\text{TP} + \text{TN}}{N} = \frac{40 + 890}{1000} = \frac{930}{1000} = 0.9300 \quad (93.00\%)$$

Step 2: Precision and Recall:
$$\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}} = \frac{40}{40 + 60} = \frac{40}{100} = 0.4000 \quad (40.00\%)$$ $$\text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}} = \frac{40}{40 + 10} = \frac{40}{50} = 0.8000 \quad (80.00\%)$$

Step 3: Specificity and FPR:
$$\text{Specificity} = \frac{\text{TN}}{\text{TN} + \text{FP}} = \frac{890}{890 + 60} = \frac{890}{950} \approx 0.9368 \quad (93.68\%)$$ $$\text{FPR} = 1 - \text{Specificity} = \frac{60}{950} \approx 0.0632 \quad (6.32\%)$$

Step 4: $F_1$ Score:
$$F_1 = 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}} = 2 \cdot \frac{0.40 \times 0.80}{0.40 + 0.80} = 2 \cdot \frac{0.32}{1.20} = \frac{0.64}{1.20} \approx 0.5333$$

Step 5: $F_2$ Score:
With $\beta = 2$, $\beta^2 = 4$: $$F_2 = (1 + 4) \cdot \frac{\text{Precision} \cdot \text{Recall}}{4 \cdot \text{Precision} + \text{Recall}} = 5 \cdot \frac{0.40 \times 0.80}{4(0.40) + 0.80} = 5 \cdot \frac{0.32}{1.60 + 0.80} = \frac{1.60}{2.40} \approx 0.6667$$ Because recall ($0.80$) is higher than precision ($0.40$), the $F_2$ score rewards the model for prioritizing clinical sensitivity.

Step 6: Matthews Correlation Coefficient (MCC):
$$\text{Numerator} = (\text{TP} \cdot \text{TN}) - (\text{FP} \cdot \text{FN}) = (40 \times 890) - (60 \times 10) = 35600 - 600 = 35000$$ $$\text{Denominator} = \sqrt{(\text{TP}+\text{FP})(\text{TP}+\text{FN})(\text{TN}+\text{FP})(\text{TN}+\text{FN})}$$ $$\text{Denominator} = \sqrt{(100)(50)(950)(900)} = \sqrt{4,275,000,000} \approx 65383.48$$ $$\text{MCC} = \frac{35000}{65383.48} \approx 0.5353$$ An MCC of $0.5353$ indicates moderate positive correlation, exposing the fact that despite a superficial $93\%$ accuracy, the model has significant false positive noise.

Problem 2.9.2 Level 1 • Direct Formula Drill Meta

QUESTION: A machine learning weather forecasting model predicts the probability of rainfall $\hat{p}_i$ for 4 consecutive days, with observed binary outcomes $y_i \in \{0, 1\}$:

DayPredicted Probability $\hat{p}_i$Ground Truth Outcome $y_i$
Day 1$0.90$$1$ (Rain)
Day 2$0.80$$1$ (Rain)
Day 3$0.40$$0$ (No Rain)
Day 4$0.10$$0$ (No Rain)
  1. Calculate the exact Brier Score of the model: $\text{BS} = \frac{1}{N} \sum_{i=1}^N (\hat{p}_i - y_i)^2$.
  2. Calculate the Brier Score of a naive baseline model that always predicts the climatological sample mean $\bar{y}$ for all days.
  3. Compute the Brier Skill Score (BSS) of the model relative to the climatological baseline: $\text{BSS} = 1 - \frac{\text{BS}_{\text{model}}}{\text{BS}_{\text{ref}}}$.
✓ Complete Step-by-Step Mathematical Solution

Step 1: Compute Model Brier Score:
For each observation, calculate squared error $(\hat{p}_i - y_i)^2$:

  • Day 1: $(0.90 - 1)^2 = (-0.10)^2 = 0.0100$
  • Day 2: $(0.80 - 1)^2 = (-0.20)^2 = 0.0400$
  • Day 3: $(0.40 - 0)^2 = (0.40)^2 = 0.1600$
  • Day 4: $(0.10 - 0)^2 = (0.10)^2 = 0.0100$
$$\text{BS}_{\text{model}} = \frac{0.0100 + 0.0400 + 0.1600 + 0.0100}{4} = \frac{0.2200}{4} = 0.0550$$

Step 2: Compute Climatological Baseline Brier Score:
The base rate of rain in the dataset is: $$\bar{y} = \frac{1 + 1 + 0 + 0}{4} = \frac{2}{4} = 0.50$$ The baseline predicts $\hat{p}_{\text{ref}} = 0.50$ for every day:

  • Day 1: $(0.50 - 1)^2 = (-0.50)^2 = 0.25$
  • Day 2: $(0.50 - 1)^2 = (-0.50)^2 = 0.25$
  • Day 3: $(0.50 - 0)^2 = (0.50)^2 = 0.25$
  • Day 4: $(0.50 - 0)^2 = (0.50)^2 = 0.25$
$$\text{BS}_{\text{ref}} = \frac{0.25 + 0.25 + 0.25 + 0.25}{4} = 0.2500$$

Step 3: Compute Brier Skill Score (BSS):
$$\text{BSS} = 1 - \frac{\text{BS}_{\text{model}}}{\text{BS}_{\text{ref}}} = 1 - \frac{0.0550}{0.2500} = 1 - 0.2200 = 0.7800 \quad (78.00\%)$$ A Brier Skill Score of $+0.78$ demonstrates that the model reduces probabilistic forecast variance by $78\%$ compared to naive climatological guessing.

Problem 2.9.5 Level 3 • FAANG / Research Lab Proof Google Meta

QUESTION: Prove rigorously that for continuous prediction scores $S$, the Area Under the ROC Curve is mathematically equivalent to the probability that a randomly chosen positive sample receives a higher score than a randomly chosen negative sample: $$\text{AUC} = P(S_+ > S_-)$$

✓ Complete Mathematical Proof via Fubini's Theorem

Step 1: Probability Definitions in ROC Space:
Let $S_+$ and $S_-$ be random variables representing the scores assigned to positive ($Y=1$) and negative ($Y=0$) instances respectively, with probability density functions $f_+(s)$ and $f_-(s)$, and cumulative distribution functions $F_+(s)$ and $F_-(s)$.
For any threshold $\tau \in (-\infty, \infty)$: $$\text{TPR}(\tau) = P(S_+ \ge \tau) = 1 - F_+(\tau) = \int_{\tau}^{\infty} f_+(s) \, ds$$ $$\text{FPR}(\tau) = P(S_- \ge \tau) = 1 - F_-(\tau) = \int_{\tau}^{\infty} f_-(s) \, ds$$

Step 2: Formulate AUC as an Integral:
The area under the ROC curve is the integral of $\text{TPR}$ with respect to $\text{FPR}$ as the threshold sweeps from $\tau = \infty$ ($\text{FPR} = 0$) to $\tau = -\infty$ ($\text{FPR} = 1$): $$\text{AUC} = \int_{0}^{1} \text{TPR} \, d(\text{FPR})$$ Perform a change of variables from $\text{FPR}$ to the threshold parameter $\tau$.
Since $\text{FPR}(\tau) = 1 - F_-(\tau)$, the differential is: $$d(\text{FPR}(\tau)) = -f_-(\tau) \, d\tau$$ When $\text{FPR} = 0 \implies \tau = \infty$, and when $\text{FPR} = 1 \implies \tau = -\infty$.

Step 3: Integrate Over the Score Support:
Substituting into the AUC integral: $$\text{AUC} = \int_{\infty}^{-\infty} \text{TPR}(\tau) \cdot (-f_-(\tau) \, d\tau) = \int_{-\infty}^{\infty} \text{TPR}(\tau) f_-(\tau) \, d\tau$$ Now substitute the definition of $\text{TPR}(\tau) = P(S_+ > \tau)$: $$\text{AUC} = \int_{-\infty}^{\infty} P(S_+ > \tau) f_-(\tau) \, d\tau$$

Step 4: Recognize the Law of Total Probability:
Notice that $f_-(\tau) \, d\tau$ is the probability density that the negative score $S_-$ takes value $\tau$.
The integral $\int_{-\infty}^{\infty} P(S_+ > \tau) f_-(\tau) \, d\tau$ is precisely the expected value: $$\mathbb{E}_{S_-} [P(S_+ > S_- \mid S_-)] = P(S_+ > S_-)$$ Thus: $$\text{AUC} = P(S_+ > S_-)$$ This completes the proof. The Area Under the ROC Curve is the exact non-parametric probability that the classifier ranks an arbitrary positive instance higher than an arbitrary negative instance. $\blacksquare$

Problem 2.9.6 Level 3 • FAANG / Research Lab Proof Google Amazon

QUESTION: In clinical triage, failing to detect a life-threatening infection (False Negative) is substantially worse than ordering an unnecessary blood test (False Positive). Starting from a generalized weighted harmonic mean formulation between Precision and Recall, derive the mathematical formula for the $F_\beta$ score and prove why setting $\beta = 2$ weights Recall twice as heavily as Precision.

✓ Complete First-Principles Derivation

Step 1: Weighted Harmonic Mean Formulation:
The weighted harmonic mean $H$ of two positive quantities $P$ (Precision) and $R$ (Recall) with non-negative weights $w_P$ and $w_R$ (where $w_P + w_R = 1$) is defined as: $$\frac{1}{H} = \frac{w_P \frac{1}{P} + w_R \frac{1}{R}}{w_P + w_R} = w_P \frac{1}{P} + w_R \frac{1}{R}$$ Inverting both sides: $$H = \frac{1}{\frac{w_P}{P} + \frac{w_R}{R}} = \frac{P \cdot R}{w_R P + w_P R}$$

Step 2: Parameterize Relative Weight via $\beta$:
We define $\beta \in (0, \infty)$ such that Recall is considered $\beta$ times as important as Precision. In terms of weight allocation: $$\frac{w_R}{w_P} = \beta^2 \implies w_R = \beta^2 w_P$$ Since $w_P + w_R = 1$: $$w_P + \beta^2 w_P = 1 \implies w_P(1 + \beta^2) = 1 \implies w_P = \frac{1}{1 + \beta^2}$$ $$w_R = \frac{\beta^2}{1 + \beta^2}$$

Step 3: Substitute Weights into Harmonic Mean:
$$\frac{1}{F_\beta} = \left(\frac{1}{1 + \beta^2}\right) \frac{1}{P} + \left(\frac{\beta^2}{1 + \beta^2}\right) \frac{1}{R}$$ $$\frac{1}{F_\beta} = \frac{1}{1 + \beta^2} \left[ \frac{1}{P} + \frac{\beta^2}{R} \right] = \frac{1}{1 + \beta^2} \left[ \frac{R + \beta^2 P}{P \cdot R} \right]$$ Taking the reciprocal: $$F_\beta = (1 + \beta^2) \frac{P \cdot R}{\beta^2 P + R}$$ Multiplying and rearranging in standard textbook form: $$F_\beta = (1 + \beta^2) \frac{\text{Precision} \cdot \text{Recall}}{\beta^2 \text{Precision} + \text{Recall}}$$

Step 4: Mathematical Behavior for $\beta = 2$:
When $\beta = 2$: $$F_2 = (1 + 4) \frac{P \cdot R}{4 P + R} = 5 \frac{P \cdot R}{4 P + R}$$ Examine the partial derivatives to see sensitivity: $$\frac{\partial (1/F_\beta)}{\partial (1/R)} = \frac{\beta^2}{1 + \beta^2}, \quad \frac{\partial (1/F_\beta)}{\partial (1/P)} = \frac{1}{1 + \beta^2}$$ The ratio of partial derivatives is: $$\frac{\frac{\partial (1/F_\beta)}{\partial (1/R)}}{\frac{\partial (1/F_\beta)}{\partial (1/P)}} = \beta^2 = 2^2 = 4$$ In terms of relative error penalties, a drop in Recall penalizes the $F_2$ score $4\times$ more severely in inverse harmonic terms, which mathematically reflects valuing Recall twice as much ($\beta = 2$) as Precision. $\blacksquare$

Problem 2.9.7 Level 4 • Conceptual Trap MCQ Google Meta

QUESTION: An AI system for cyber security intrusion detection monitors $1,000,000$ daily network requests, of which exactly $100$ are malicious cyber attacks ($0.01\%$ prevalence). The validation pipeline reports an outstanding $\text{ROC-AUC} = 0.980$. However, when deployed, the network security operations center (SOC) complains that the tool is unusable because over $95\%$ of alerts generated are benign false alarms. Why did ROC-AUC fail to diagnose this issue?

  1. ROC-AUC was calculated using the trapezoidal rule instead of Simpson's rule, inflating the metric by $50\%$.
  2. In ROC curves, $\text{FPR} = \frac{\text{FP}}{\text{TN} + \text{FP}}$ has total negatives ($\approx 1,000,000$) in the denominator. A small FPR of $0.002$ produces $2,000$ false alarms; since there are only $100$ true attacks, Precision collapses to $< 5\%$ despite a near-perfect ROC curve.
  3. ROC-AUC is undefined for datasets where prevalence is less than $1\%$, causing NaN values that scikit-learn defaults to $0.980$.
  4. The test data suffered from label flipping where malicious attacks were accidentally labeled as $0$.
✓ Correct Answer: B • Comprehensive Distractor Analysis

Detailed Analysis:
This is the single most common real-world failure mode in evaluating models under extreme class imbalance ($N_+ \ll N_-$).
The False Positive Rate is defined as: $$\text{FPR} = \frac{\text{FP}}{N_-}$$ Here, $N_- = 999,900 \approx 10^6$.
Suppose the model operates at an exceptional operating point with $\text{TPR} = 90\%$ ($90$ out of $100$ attacks caught) and a seemingly negligible $\text{FPR} = 0.2\% = 0.002$.
In ROC space, $(0.002, 0.90)$ is extremely close to the ideal top-left corner $(0, 1)$, yielding an overall $\text{ROC-AUC} \approx 0.98$.
However, let us calculate the absolute number of False Positives: $$\text{FP} = \text{FPR} \times N_- = 0.002 \times 999,900 \approx 2,000 \text{ false alarms!}$$ The resulting Precision is: $$\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}} = \frac{90}{90 + 2000} = \frac{90}{2090} \approx 0.043 \quad (4.3\%)$$ Out of every 100 alerts sent to the security team, 96 are false alarms! The security engineers suffer from alert fatigue and turn off the system.
Lesson: Under severe class imbalance, ROC-AUC is misleadingly optimistic because large $N_-$ masks high absolute FP counts. Precision-Recall AUC (PR-AUC) must always be reported.

Why Other Options are False:

  • A is FALSE: Integration methods (trapezoidal vs. Simpson's) differ by at most $0.0001$, not $50\%$.
  • C is FALSE: ROC-AUC is mathematically well-defined for any dataset having at least 1 positive and 1 negative sample ($N_+ \ge 1, N_- \ge 1$).
  • D is FALSE: Label flipping would decrease both ROC-AUC and Precision; the issue here is the mathematical nature of the FPR denominator under massive negative sample size.

Problem 2.9.8 Level 4 • Assertion-Reasoning & Temperature Scaling Google OpenAI

QUESTION: Evaluate the following Assertion and Reason regarding calibration in deep neural networks:

Assertion (A): Applying Temperature Scaling $\hat{p}_i = \frac{e^{z_i / T}}{\sum_{j} e^{z_j / T}}$ with an optimal scalar $T > 1$ to the pre-softmax logits $z$ of an overconfident deep neural network dramatically reduces Expected Calibration Error (ECE) while leaving the model's top-1 classification accuracy and ROC-AUC completely unchanged.

Reason (R): Dividing all logits by a strictly positive scalar constant $T > 0$ is a strictly monotonic transformation that preserves the ordinal ranking of logits ($\arg\max_k z_k = \arg\max_k \frac{z_k}{T}$), ensuring that decision boundaries and pairwise orderings are invariant while the softmax probabilities are softened toward empirical accuracy.

  1. Both (A) and (R) are true, and (R) is the correct mathematical explanation of (A).
  2. Both (A) and (R) are true, but (R) is NOT the correct explanation of (A).
  3. (A) is true, but (R) is false.
  4. (A) is false, but (R) is true.
✓ Correct Answer: A • Comprehensive Invariance Proof

Detailed Analysis:
Analysis of Reason (R):
Consider pre-softmax logits $\mathbf{z} = [z_1, \dots, z_K]^T \in \mathbb{R}^K$.
For any scalar $T > 0$, the function $g(z) = \frac{z}{T}$ has derivative $g'(z) = \frac{1}{T} > 0$, making it a strictly monotonically increasing function.
Therefore: $$z_i > z_j \iff \frac{z_i}{T} > \frac{z_j}{T}$$ The $\arg\max$ operation is invariant: $$\arg\max_{k \in \{1,\dots,K\}} \frac{e^{z_k / T}}{\sum_j e^{z_j / T}} = \arg\max_{k \in \{1,\dots,K\}} \frac{z_k}{T} = \arg\max_{k \in \{1,\dots,K\}} z_k$$ The predicted top-1 class is identical for every input sample. Furthermore, for binary classification where score $S = \sigma(z / T)$, the pairwise ranking between any two samples $a$ and $b$ is preserved: $z_a > z_b \iff \sigma(z_a / T) > \sigma(z_b / T)$. Reason (R) is true.

Analysis of Assertion (A):
Because the top-1 predicted class is invariant for every sample, the overall classification accuracy is strictly identical before and after temperature scaling.
Because the pairwise orderings of scores are invariant ($P(S_a > S_b)$ is unchanged), by the Wilcoxon-Mann-Whitney theorem, the ROC-AUC is strictly identical.
However, modern deep neural networks (Guo et al., 2017) are severely overconfident due to negative log-likelihood training with batch normalization and weight decay: they output confidence $\hat{p} = 0.99$ for predictions that only have $85\%$ empirical accuracy.
Setting $T > 1$ pulls the softmax outputs away from the extreme boundaries $\{0, 1\}$ and toward the uniform distribution, aligning predicted probabilities $\hat{p}$ with observed accuracy and drastically slashing Expected Calibration Error (ECE) from $15\%$ down to $< 2\%$.
Thus, (A) is true, and (R) provides the exact mathematical justification. $\blacksquare$

import numpy as np

def fast_roc_auc(y_true, y_scores):
    """
    Computes exact ROC-AUC via the Wilcoxon-Mann-Whitney rank-sum theorem.
    Time Complexity: O(N log N) dominated by sorting.
    """
    y_true = np.asarray(y_true)
    y_scores = np.asarray(y_scores)
    
    pos_mask = (y_true == 1)
    n_pos = np.sum(pos_mask)
    n_neg = len(y_true) - n_pos
    
    if n_pos == 0 or n_neg == 0:
        raise ValueError("Both positive and negative samples required to compute ROC-AUC.")
        
    # Sort scores in ascending order and rank them (1-indexed)
    order = np.argsort(y_scores)
    ranks = np.empty_like(order, dtype=float)
    ranks[order] = np.arange(1, len(y_scores) + 1)
    
    # Handle tied scores by averaging their ranks
    unique_scores, inv_idx, counts = np.unique(y_scores, return_inverse=True, return_counts=True)
    tied_scores = unique_scores[counts > 1]
    for s in tied_scores:
        ties = (y_scores == s)
        ranks[ties] = np.mean(ranks[ties])
        
    # Wilcoxon U statistic
    r_pos = np.sum(ranks[pos_mask])
    u_stat = r_pos - (n_pos * (n_pos + 1)) / 2.0
    return u_stat / (n_pos * n_neg)

def expected_calibration_error(y_true, y_probs, n_bins=10):
    """
    Computes Expected Calibration Error (ECE) across equally spaced bins.
    """
    y_true = np.asarray(y_true)
    y_probs = np.asarray(y_probs)
    bin_limits = np.linspace(0.0, 1.0, n_bins + 1)
    
    ece = 0.0
    N = len(y_true)
    
    for i in range(n_bins):
        bin_lower = bin_limits[i]
        bin_upper = bin_limits[i + 1]
        
        # Binned indices
        in_bin = (y_probs >= bin_lower) & (y_probs < bin_upper if i < n_bins - 1 else y_probs <= bin_upper)
        n_in_bin = np.sum(in_bin)
        
        if n_in_bin > 0:
            bin_acc = np.mean(y_true[in_bin])
            bin_conf = np.mean(y_probs[in_bin])
            ece += (n_in_bin / N) * np.abs(bin_acc - bin_conf)
            
    return ece

if __name__ == "__main__":
    np.random.seed(42)
    y_actual = np.array([1, 1, 0, 1, 0, 0, 1, 0, 1, 0])
    y_pred_scores = np.array([0.95, 0.85, 0.70, 0.60, 0.40, 0.15, 0.88, 0.35, 0.72, 0.20])
    
    auc = fast_roc_auc(y_actual, y_pred_scores)
    ece = expected_calibration_error(y_actual, y_pred_scores, n_bins=5)
    
    print(f"Wilcoxon-Mann-Whitney ROC-AUC : {auc:.4f}")
    print(f"Expected Calibration Error   : {ece:.4f}")
