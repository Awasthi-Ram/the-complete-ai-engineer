Foundation • Core Pillar

1. The Ordinary Least Squares (OLS) Formulation

Linear regression models the relationship between a continuous scalar target $y \in \mathbb{R}$ and a $d$-dimensional feature vector $\mathbf{x} = [x_1, \dots, x_d]^T \in \mathbb{R}^d$ through a linear combination parameterized by weight vector $\mathbf{w} \in \mathbb{R}^d$ and scalar bias (intercept) $b \in \mathbb{R}$:

$$\hat{y} = w_1 x_1 + w_2 x_2 + \dots + w_d x_d + b = \mathbf{w}^T \mathbf{x} + b$$

To express this compactly across a dataset of $N$ observations, we augment the feature matrix $\mathbf{X} \in \mathbb{R}^{N \times (d+1)}$ with a leading column of ones ($x_{i0} = 1$) to absorb bias $b$ into the parameter vector $\mathbf{w} \in \mathbb{R}^{d+1}$:

$$\hat{\mathbf{y}} = \mathbf{X} \mathbf{w}, \quad \text{where } \mathbf{X} = \begin{bmatrix} 1 & x_{11} & \cdots & x_{1d} \\ 1 & x_{21} & \cdots & x_{2d} \\ \vdots & \vdots & \ddots & \vdots \\ 1 & x_{N1} & \cdots & x_{Nd} \end{bmatrix}, \quad \mathbf{w} = \begin{bmatrix} b \\ w_1 \\ \vdots \\ w_d \end{bmatrix}, \quad \mathbf{y} = \begin{bmatrix} y_1 \\ y_2 \\ \vdots \\ y_N \end{bmatrix}$$

The objective of Ordinary Least Squares (OLS) is to find the parameter vector $\mathbf{w}^*$ that minimizes the Residual Sum of Squares (RSS) / Mean Squared Error (MSE):

$$\mathcal{L}(\mathbf{w}) = \frac{1}{2N} \|\mathbf{y} - \mathbf{X} \mathbf{w}\|_2^2 = \frac{1}{2N} (\mathbf{y} - \mathbf{X} \mathbf{w})^T (\mathbf{y} - \mathbf{X} \mathbf{w})$$

2. Analytical Derivation: The Normal Equations

Expanding the matrix quadratic loss function:

$$\mathcal{L}(\mathbf{w}) = \frac{1}{2N} \left[ \mathbf{y}^T \mathbf{y} - \mathbf{y}^T \mathbf{X} \mathbf{w} - \mathbf{w}^T \mathbf{X}^T \mathbf{y} + \mathbf{w}^T \mathbf{X}^T \mathbf{X} \mathbf{w} \right]$$

Notice that $\mathbf{y}^T \mathbf{X} \mathbf{w}$ is a $1 \times 1$ scalar, which is identically equal to its transpose $(\mathbf{y}^T \mathbf{X} \mathbf{w})^T = \mathbf{w}^T \mathbf{X}^T \mathbf{y}$. Combining these like terms:

$$\mathcal{L}(\mathbf{w}) = \frac{1}{2N} \left[ \mathbf{y}^T \mathbf{y} - 2 \mathbf{w}^T (\mathbf{X}^T \mathbf{y}) + \mathbf{w}^T (\mathbf{X}^T \mathbf{X}) \mathbf{w} \right]$$

Applying standard matrix calculus gradient rules ($\nabla_{\mathbf{w}} (\mathbf{w}^T \mathbf{a}) = \mathbf{a}$ and $\nabla_{\mathbf{w}} (\mathbf{w}^T \mathbf{A} \mathbf{w}) = 2 \mathbf{A} \mathbf{w}$ for symmetric $\mathbf{A} = \mathbf{X}^T \mathbf{X}$):

$$\nabla_{\mathbf{w}} \mathcal{L}(\mathbf{w}) = \frac{1}{N} \left[ -\mathbf{X}^T \mathbf{y} + \mathbf{X}^T \mathbf{X} \mathbf{w} \right] = \frac{1}{N} \mathbf{X}^T (\mathbf{X}\mathbf{w} - \mathbf{y})$$

Setting the gradient to zero yields the foundational Normal Equations:

$$\mathbf{X}^T \mathbf{X} \mathbf{w}^* = \mathbf{X}^T \mathbf{y} \implies \mathbf{w}^*_{\text{OLS}} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$$

The Geometry of OLS: The Hat Matrix Projection

Substituting $\mathbf{w}^*_{\text{OLS}}$ into the prediction equation reveals the geometric engine of least squares:

$$\hat{\mathbf{y}} = \mathbf{X} \mathbf{w}^* = \mathbf{X} (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y} = \mathbf{H} \mathbf{y}$$

where $\mathbf{H} = \mathbf{X} (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \in \mathbb{R}^{N \times N}$ is the Hat Matrix (so named because it puts the "hat" on $\mathbf{y}$).

🏆 Properties of the Hat Matrix $\mathbf{H}$

  1. Symmetric: $\mathbf{H}^T = (\mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T)^T = \mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T = \mathbf{H}$.
  2. Idempotent: $\mathbf{H}^2 = \mathbf{H} \mathbf{H} = \mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T \mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T = \mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T = \mathbf{H}$. Projecting a vector that is already on the subspace leaves it unchanged!
  3. Orthogonal Residuals: The residual error vector $\mathbf{e} = \mathbf{y} - \hat{\mathbf{y}} = (\mathbf{I} - \mathbf{H})\mathbf{y}$ is strictly orthogonal to the column space of $\mathbf{X}$: $$\mathbf{X}^T \mathbf{e} = \mathbf{X}^T (\mathbf{I} - \mathbf{H})\mathbf{y} = (\mathbf{X}^T - \mathbf{X}^T \mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T)\mathbf{y} = (\mathbf{X}^T - \mathbf{X}^T)\mathbf{y} = \mathbf{0}$$ Geometric Meaning: $\hat{\mathbf{y}}$ is the perpendicular orthogonal projection of the high-dimensional target vector $\mathbf{y} \in \mathbb{R}^N$ onto the $d$-dimensional subspace spanned by the feature columns of $\mathbf{X}$!

3. Statistical Foundations: The Gauss-Markov Theorem

Under what conditions is OLS the optimal estimator? The Gauss-Markov Theorem provides the classical answer: if the following four conditions hold, OLS is the BLUE (Best Linear Unbiased Estimator)—meaning it achieves the lowest possible variance among all linear unbiased estimators:

  1. Linearity in Parameters: $y = \mathbf{X}\mathbf{w}^* + \boldsymbol{\epsilon}$.
  2. Strict Exogeneity: Conditional expectation of errors is zero: $\mathbb{E}[\boldsymbol{\epsilon} \mid \mathbf{X}] = \mathbf{0}$. (No omitted variable bias).
  3. Homoscedasticity & No Autocorrelation: $\text{Cov}(\boldsymbol{\epsilon} \mid \mathbf{X}) = \sigma^2 \mathbf{I}_N$. All noise variances are equal, and sample errors are completely uncorrelated.
  4. No Multicollinearity: $\mathbf{X}$ has full column rank ($\text{rank}(\mathbf{X}) = d+1$). Columns of $\mathbf{X}$ are linearly independent.

4. Regularized Linear Models: Ridge, Lasso & ElasticNet

In modern machine learning, features are frequently correlated ($X^T X$ is ill-conditioned) or high-dimensional ($d > N$). Regularization introduces a controlled amount of bias to dramatically slash variance:

1. Ridge Regression ($L_2$ Regularization / Weight Decay)

Ridge penalizes the squared $L_2$ Euclidean norm of the weight coefficients:

$$\mathcal{L}_{\text{Ridge}}(\mathbf{w}) = \frac{1}{2N} \|\mathbf{y} - \mathbf{X}\mathbf{w}\|_2^2 + \frac{\lambda}{2} \|\mathbf{w}_{1:d}\|_2^2$$

The analytical solution is:

$$\mathbf{w}^*_{\text{Ridge}} = (\mathbf{X}^T \mathbf{X} + N \lambda \mathbf{I}')^{-1} \mathbf{X}^T \mathbf{y}$$

where $\mathbf{I}' = \text{diag}(0, 1, 1, \dots, 1)$ ensures the bias intercept is never penalized.

Ridge Shrinkage in SVD Coordinates: Let the SVD of $\mathbf{X}$ be $\mathbf{U}\boldsymbol{\Sigma}\mathbf{V}^T$ with singular values $\sigma_i$. Expanding the Ridge solution reveals how it modulates each coordinate:

$$\mathbf{w}^*_{\text{Ridge}} = \sum_{i=1}^d \left( \frac{\sigma_i^2}{\sigma_i^2 + N\lambda} \right) \frac{\mathbf{u}_i^T \mathbf{y}}{\sigma_i} \mathbf{v}_i$$

Notice the shrinkage factor $\frac{\sigma_i^2}{\sigma_i^2 + N\lambda} \in (0, 1)$:

  • For high-variance principal directions ($\sigma_i \gg \lambda$), shrinkage is negligible ($\approx 1$).
  • For low-variance, noise-dominated directions ($\sigma_i \ll \lambda$), the shrinkage factor approaches $0$, ruthlessly suppressing noise-induced variance!

2. Lasso Regression ($L_1$ Regularization & Exact Sparsity)

Lasso penalizes the $L_1$ Manhattan norm of weights:

$$\mathcal{L}_{\text{Lasso}}(\mathbf{w}) = \frac{1}{2N} \|\mathbf{y} - \mathbf{X}\mathbf{w}\|_2^2 + \lambda \|\mathbf{w}_{1:d}\|_1 = \frac{1}{2N} \|\mathbf{y} - \mathbf{X}\mathbf{w}\|_2^2 + \lambda \sum_{j=1}^d |w_j|$$

Because $|w_j|$ has a sharp non-differentiable corner at zero, there is no closed-form matrix inversion. Instead, we solve Lasso using Coordinate Descent. Optimizing with respect to a single weight $w_j$ while fixing all other weights yields the Soft-Thresholding Operator:

$$w_j^* = S_\lambda(\rho_j) = \text{sign}(\rho_j) \max(|\rho_j| - \lambda, 0) = \begin{cases} \rho_j - \lambda & \text{if } \rho_j > \lambda \\ 0 & \text{if } -\lambda \le \rho_j \le \lambda \\ \rho_j + \lambda & \text{if } \rho_j < -\lambda \end{cases}$$

where $\rho_j = \mathbf{x}_j^T (\mathbf{y} - \sum_{k \neq j} \mathbf{x}_k w_k)$ is the partial residual correlation. Any feature whose correlation with the residual is within $[-\lambda, \lambda]$ is set to EXACT NUMERICAL ZERO. Lasso performs automatic, embedded feature selection!

3. ElasticNet (Combining $L_1$ and $L_2$)

When features are highly correlated, Lasso tends to arbitrarily pick one feature from the group and zero out the rest. When $d > N$, Lasso can select at most $N$ non-zero features. ElasticNet solves both limitations by combining both penalties:

$$\mathcal{L}_{\text{ElasticNet}}(\mathbf{w}) = \frac{1}{2N} \|\mathbf{y} - \mathbf{X}\mathbf{w}\|_2^2 + \lambda \left[ \alpha \|\mathbf{w}\|_1 + \frac{1 - \alpha}{2} \|\mathbf{w}\|_2^2 \right]$$

The $L_1$ term enforces sparsity, while the strictly convex $L_2$ term enforces the grouping effect (correlated features are shrunk together rather than arbitrarily dropped).

Problem 2.2.5 Hard Google DeepMind Meta

QUESTION: Prove the Gauss-Markov Theorem for linear regression from first principles. Specifically, let $\hat{\mathbf{w}} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y}$ be the OLS estimator. Let $\tilde{\mathbf{w}} = \mathbf{C} \mathbf{y}$ be any other arbitrary linear unbiased estimator of $\mathbf{w}^*$. Prove that the difference between their covariance matrices:

$$\text{Cov}(\tilde{\mathbf{w}}) - \text{Cov}(\hat{\mathbf{w}})$$

is a Positive Semi-Definite (PSD) matrix, proving that OLS achieves minimum variance in every linear projection direction $\mathbf{a}^T \text{Cov}(\hat{\mathbf{w}}) \mathbf{a} \le \mathbf{a}^T \text{Cov}(\tilde{\mathbf{w}}) \mathbf{a}$.

✓ Complete Step-by-Step Mathematical Proof

Step 1: Characterize the Linear Estimator:
Let $\tilde{\mathbf{w}} = \mathbf{C} \mathbf{y}$ where $\mathbf{C} \in \mathbb{R}^{d \times N}$.
Define the deviation from the OLS matrix: $\mathbf{D} = \mathbf{C} - (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T$.
Thus, $\mathbf{C} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T + \mathbf{D}$.

Step 2: Enforce the Unbiasedness Constraint:
For $\tilde{\mathbf{w}}$ to be an unbiased estimator of $\mathbf{w}^*$: $$\mathbb{E}[\tilde{\mathbf{w}}] = \mathbb{E}[\mathbf{C}\mathbf{y}] = \mathbb{E}[\mathbf{C}(\mathbf{X}\mathbf{w}^* + \boldsymbol{\epsilon})] = \mathbf{C}\mathbf{X}\mathbf{w}^* + \mathbf{C}\mathbb{E}[\boldsymbol{\epsilon}] = \mathbf{C}\mathbf{X}\mathbf{w}^*$$ For $\mathbb{E}[\tilde{\mathbf{w}}] = \mathbf{w}^*$ to hold for all possible vectors $\mathbf{w}^*$, we must have: $$\mathbf{C} \mathbf{X} = \mathbf{I}_d$$ Substitute $\mathbf{C} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T + \mathbf{D}$: $$((\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T + \mathbf{D}) \mathbf{X} = \mathbf{I}_d \implies (\mathbf{X}^T \mathbf{X})^{-1} (\mathbf{X}^T \mathbf{X}) + \mathbf{D} \mathbf{X} = \mathbf{I}_d \implies \mathbf{I}_d + \mathbf{D} \mathbf{X} = \mathbf{I}_d$$ Therefore, unbiasedness strictly requires: $$\mathbf{D} \mathbf{X} = \mathbf{0}$$

Step 3: Compute Covariance Matrix of $\tilde{\mathbf{w}}$:
Since $\tilde{\mathbf{w}} = \mathbf{C}\mathbf{y} = \mathbf{C}(\mathbf{X}\mathbf{w}^* + \boldsymbol{\epsilon}) = \mathbf{w}^* + \mathbf{C}\boldsymbol{\epsilon}$: $$\text{Cov}(\tilde{\mathbf{w}}) = \mathbb{E}[(\tilde{\mathbf{w}} - \mathbf{w}^*)(\tilde{\mathbf{w}} - \mathbf{w}^*)^T] = \mathbb{E}[\mathbf{C}\boldsymbol{\epsilon}\boldsymbol{\epsilon}^T \mathbf{C}^T] = \mathbf{C} \mathbb{E}[\boldsymbol{\epsilon}\boldsymbol{\epsilon}^T] \mathbf{C}^T$$ By the homoscedasticity assumption $\mathbb{E}[\boldsymbol{\epsilon}\boldsymbol{\epsilon}^T] = \sigma^2 \mathbf{I}_N$: $$\text{Cov}(\tilde{\mathbf{w}}) = \sigma^2 \mathbf{C} \mathbf{C}^T$$ Substitute $\mathbf{C} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T + \mathbf{D}$: $$\mathbf{C} \mathbf{C}^T = \left( (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T + \mathbf{D} \right) \left( \mathbf{X} (\mathbf{X}^T \mathbf{X})^{-1} + \mathbf{D}^T \right)$$ Expand the four terms: $$\mathbf{C} \mathbf{C}^T = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{X} (\mathbf{X}^T \mathbf{X})^{-1} + (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{D}^T + \mathbf{D} \mathbf{X} (\mathbf{X}^T \mathbf{X})^{-1} + \mathbf{D} \mathbf{D}^T$$ Using $\mathbf{D} \mathbf{X} = \mathbf{0}$ and its transpose $\mathbf{X}^T \mathbf{D}^T = \mathbf{0}^T = \mathbf{0}$: The middle two cross-terms vanish completely: $$\mathbf{C} \mathbf{C}^T = (\mathbf{X}^T \mathbf{X})^{-1} + \mathbf{D} \mathbf{D}^T$$

Step 4: Subtract the Covariances:
Recall that the OLS covariance is $\text{Cov}(\hat{\mathbf{w}}) = \sigma^2 (\mathbf{X}^T \mathbf{X})^{-1}$. Therefore: $$\text{Cov}(\tilde{\mathbf{w}}) - \text{Cov}(\hat{\mathbf{w}}) = \sigma^2 \left[ (\mathbf{X}^T \mathbf{X})^{-1} + \mathbf{D}\mathbf{D}^T \right] - \sigma^2 (\mathbf{X}^T \mathbf{X})^{-1} = \mathbf{\sigma^2 \mathbf{D} \mathbf{D}^T}$$ For any non-zero vector $\mathbf{a} \in \mathbb{R}^d$: $$\mathbf{a}^T (\sigma^2 \mathbf{D} \mathbf{D}^T) \mathbf{a} = \sigma^2 (\mathbf{D}^T \mathbf{a})^T (\mathbf{D}^T \mathbf{a}) = \sigma^2 \|\mathbf{D}^T \mathbf{a}\|_2^2 \ge 0$$ The difference is strictly Positive Semi-Definite, achieving equality if and only if $\mathbf{D} = \mathbf{0}$ ($\tilde{\mathbf{w}} = \hat{\mathbf{w}}$).
Q.E.D. OLS is uniquely the Best Linear Unbiased Estimator (BLUE)!

Problem 2.2.6 Hard OpenAI Anthropic

QUESTION: Prove mathematically why $L_1$ Lasso regularization induces exact sparsity ($w_j = 0$), whereas $L_2$ Ridge regularization only causes coefficient shrinkage ($w_j \to 0$ but $w_j \neq 0$). Use both the sub-gradient optimality conditions and the geometry of contour intersections.

✓ Complete Step-by-Step Mathematical Analysis

Step 1: Subdifferential Optimality of Lasso:
Consider a scalar objective with squared loss and regularizer: $$\mathcal{L}(w) = \frac{1}{2} (y - w)^2 + \lambda |w|$$ For $w \neq 0$, the derivative is $(w - y) + \lambda \text{sign}(w)$. Setting to zero: $$w = y - \lambda \text{ if } y > \lambda, \qquad w = y + \lambda \text{ if } y < -\lambda$$ At the point $w = 0$, the function $|w|$ is non-differentiable; its subdifferential is the set of all supporting slopes $\partial |w| = [-1, 1]$.
Fermat's optimality rule for non-smooth convex optimization states that $0$ is a global minimum if and only if $0 \in \partial \mathcal{L}(0)$: $$\partial \mathcal{L}(0) = (0 - y) + \lambda [-1, 1] = -y + [-\lambda, \lambda] = [-y - \lambda, \ -y + \lambda]$$ The condition $0 \in [-y - \lambda, -y + \lambda]$ holds whenever: $$-\lambda \le y \le \lambda \iff |y| \le \lambda$$ Key Insight: There is an entire continuous interval of empirical observations $[-\lambda, \lambda]$ of non-zero width $2\lambda$ where the exact optimal solution is locked onto $w^* = 0$!

Step 2: Contrast with Ridge $L_2$:
For Ridge: $$\mathcal{L}(w) = \frac{1}{2} (y - w)^2 + \frac{\lambda}{2} w^2 \implies \frac{\partial \mathcal{L}}{\partial w} = (w - y) + \lambda w = 0 \implies w^* = \frac{y}{1 + \lambda}$$ For any non-zero observation $y \neq 0$, $w^* = \frac{y}{1 + \lambda} \neq 0$. The Ridge estimate is zero if and only if the empirical observation $y$ is already identically zero (a set of measure zero).

Step 3: Geometric Intersection of Contours:
In constrained optimization, minimizing RSS subject to $\|\mathbf{w}\|_p \le C$ finds the point where the elliptical level curves of the RSS loss first touch the constraint ball:

  • The $L_1$ ball ($\sum |w_i| \le C$): A cross-polytope (rhombus in 2D) with sharp corners located precisely on the coordinate axes where other coordinates are zero ($w_1 = C, w_2 = 0$). Because the corners are non-smooth, the outward normal cone at the corners spans a wide angle ($90^\circ$). The expanding RSS ellipse has a massive probability of making its first contact at a corner point, forcing coordinates to exact zero.
  • The $L_2$ ball ($\sum w_i^2 \le C^2$): A smooth Euclidean sphere. The normal vector exists uniquely everywhere, so the ellipse touches the sphere at an arbitrary smooth point off the axes, keeping all weights non-zero.

Problem 2.2.7 Medium Google

QUESTION: In regularized linear regression (Ridge, Lasso, ElasticNet), why do machine learning practitioners never regularize the bias term $b$ (intercept)?

  1. Regularizing the bias term causes the Hessian matrix to become singular.
  2. Regularizing the bias would make the model's predictions sensitive to shifting the origin of the target variable $y \to y + c$, causing systematic under-prediction of non-zero-centered targets.
  3. The derivative of the bias penalty cannot be computed in closed form.
  4. The bias term does not contribute to the variance of the model.
✓ Complete Conceptual Analysis & Explanation

Correct Option: B

Exhaustive Analysis of All Options:

  • Option B is TRUE: The intercept $b$ captures the global baseline average of the target $\bar{y}$. If the target is house prices centered around $\$500,000$, penalizing $b^2$ would shrink the predicted baseline toward $\$0$, introducing massive arbitrary bias simply because the target was not zero-centered. Regularization should constrain the model's sensitivity to feature variations (the slopes $w_j$), never the baseline location of the target distribution.
  • Option A is FALSE: Adding regularization to any parameter increases the diagonal of the Hessian, making it strictly more positive definite, not singular.
  • Option C is FALSE: The derivative of $\frac{\lambda}{2} b^2$ is simply $\lambda b$, trivially easy to compute.
  • Option D is FALSE: Estimating the bias from finite samples introduces variance $\sigma^2 / N$, but this is minimal and necessary to maintain an unbiased baseline.

Problem 2.2.8 Hard Microsoft

Assertion (A): Severe multicollinearity between features in a dataset inflates the variance of individual OLS regression weights $\text{Var}(\hat{w}_j) \to \infty$, but has virtually zero impact on the model's overall prediction accuracy on new test points that follow the exact same collinear covariance structure.

  1. Both (A) and (R) are true, and (R) is the correct explanation of (A).
  2. Both (A) and (R) are true, but (R) is NOT the correct explanation of (A).
  3. (A) is true, but (R) is false.
  4. (A) is false, but (R) is true.

Correct Option: C

Exhaustive Analysis of Assertion & Reason:

Code Lab 2.2 — OLS Normal Equations vs. Mini-Batch SGD

import numpy as np

class LinearRegressionScratch:
    def __init__(self, lr=0.01, batch_size=32, epochs=50, l2_reg=1e-4):
        self.lr = lr
        self.batch_size = batch_size
        self.epochs = epochs
        self.l2_reg = l2_reg
        self.w = None

    def fit_normal_equation(self, X, y):
        """Analytical Ridge OLS solution: w = (X^T X + lambda I)^-1 X^T y"""
        X_b = np.c_[np.ones((X.shape[0], 1)), X] # Add bias column
        d = X_b.shape[1]
        I = np.eye(d)
        I[0, 0] = 0.0 # Do not regularize bias!
        self.w = np.linalg.solve(X_b.T @ X_b + self.l2_reg * I, X_b.T @ y)

    def fit_sgd(self, X, y):
        """Mini-Batch Stochastic Gradient Descent"""
        N, d = X.shape
        X_b = np.c_[np.ones((N, 1)), X]
        self.w = np.zeros(d + 1)

        for epoch in range(self.epochs):
            indices = np.random.permutation(N)
            for start_idx in range(0, N, self.batch_size):
                batch_idx = indices[start_idx:start_idx + self.batch_size]
                X_batch = X_b[batch_idx]
                y_batch = y[batch_idx]

                # Prediction & Error
                preds = X_batch @ self.w
                errors = preds - y_batch

                # Gradient: (1/B) * X^T (Xw - y) + lambda * w
                grad = (X_batch.T @ errors) / len(batch_idx)
                grad[1:] += self.l2_reg * self.w[1:] # Regularize weights only

                self.w -= self.lr * grad

    def predict(self, X):
        X_b = np.c_[np.ones((X.shape[0], 1)), X]
        return X_b @ self.w

if __name__ == "__main__":
    np.random.seed(42)
    X = 2 * np.random.rand(100, 3)
    y = 4 + 3 * X[:, 0] + 1.5 * X[:, 1] - 2 * X[:, 2] + np.random.randn(100) * 0.1

    model = LinearRegressionScratch(lr=0.05, epochs=100)
    model.fit_normal_equation(X, y)
    print("OLS Normal Equations Weights:", np.round(model.w, 4))

    model_sgd = LinearRegressionScratch(lr=0.05, epochs=200)
    model_sgd.fit_sgd(X, y)
    print("Mini-Batch SGD Weights      :", np.round(model_sgd.w, 4))
